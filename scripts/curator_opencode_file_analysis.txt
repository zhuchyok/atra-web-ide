Прочитай следующие файлы и ответь на вопросы по каждому:

1. Файл: knowledge_os/docker-compose.yml
   - Какой VICTORIA_URL задан в секции backend (atra-web-ide-backend или аналог)?
   - На каком порту маппится victoria-agent (снаружи)?
   - Какие сети (networks) есть у backend и victoria-agent — они в одной сети?

2. Файл: backend/app/config.py
   - Какое значение VICTORIA_URL по умолчанию?
   - Есть ли настройки таймаута HTTP к Victoria?

3. Файл: backend/app/routers/chat.py (или аналогичный файл роутера чата)
   - Какой endpoint вызывается у Victoria (/run, /chat, /api/chat)?
   - Используется ли streaming (SSE)?
   - Какой HTTP-таймаут задан при запросе к Victoria?

4. Файл: frontend/src (или src/frontend) — любой файл конфига, где задан базовый URL backend
   - Куда фронтенд отправляет запросы чата (какой хост:порт)?

По каждому пункту дай конкретный ответ: значение переменной или строки кода. В конце дай список из 3-5 наиболее вероятных причин, почему OpenCode UI не получает ответ от Victoria, на основе того, что нашёл в файлах.
