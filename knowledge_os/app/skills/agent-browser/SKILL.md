# Agent Browser Skill

## Когда использовать
- Автоматический сбор данных с веб-сайтов
- Заполнение форм автоматически
- Login и авторизация
- Навигация по сложным веб-приложениям
- Скриншотинг страниц
- Извлечение данных из таблиц

## Возможности

### Автоматизация
- Заполнение форм (input, select, checkbox, radio)
- Клики по элементам
- Скроллинг
- Upload файлов
- Навигация по URL

### Извлечение данных
- Парсинг HTML таблиц
- Извлечение JSON из страниц
- Сбор ссылок
- Извлечение мета-тегов

### Безопасность
- Не сохраняй пароли без явного запроса
- Используй sandboxed browser
- Очищай данные после использования

## Процесс

### 1. Планирование
```
1. Определи цель
2. Создай список URL
3. Составь последовательность действий
```

### 2. Выполнение
```
1. Открой страницу
2. Сделай скриншот (до и после)
3. Извлеки данные
4. Обработай ошибки
```

### 3. Финализация
```
1. Сохрани данные
2. Сделай отчёт
3. Очисти следы
```

## Output
Результаты сохраняй в структурированном виде:
- JSON для данных
- Markdown для отчётов
