# SOP Generation Skill (Singularity 20.0)

## Обзор

Этот скилл превращает разовый успех в воспроизводимый стандарт. Если задача выполнена на высокий балл, система автоматически синтезирует пошаговую инструкцию (SOP).

## Когда использовать

- Когда задача выполнена на 8/10 и выше.
- Когда решение является типовым для сложных процессов.
- Для наполнения базы знаний проверенными алгоритмами действий.

## Процесс

1. **Trigger**: Завершение задачи с высоким баллом аудита.
2. **Synthesis**: Виктория структурирует опыт выполнения в формат SOP.
3. **Documentation**: Создание Markdown-файла в `docs/SOP/`.
4. **Registration**: Регистрация SOP в базе знаний (RAG) для будущего использования.

## Структура SOP

- Название процесса.
- Триггеры применения.
- Пошаговая инструкция.
- Типичные ошибки (Pitfalls).
- Инструменты и команды.

## Результат

- Готовый документ в `docs/SOP/`.
- Узел знаний типа `sop_document`.
