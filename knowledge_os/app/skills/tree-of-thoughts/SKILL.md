# Tree of Thoughts Skill

Навык на основе **Tree of Thoughts (ToT)** от исследователей. Обеспечивает +40-50% улучшение на planning задачи.

## Когда использовать

Используй этот навык для:

- Сложных задач планирования
- Задач с множеством возможных решений
- Задач, где нужно найти оптимальный путь
- Архитектурных решений

## Методология

Tree of Thoughts работает через:

1. **Generate** - Генерация множества вариантов решения
2. **Evaluate** - Оценка каждого варианта
3. **Prune** - Отсечение слабых ветвей
4. **Expand** - Развитие перспективных ветвей
5. **Select** - Выбор оптимального решения

## Примеры использования

```
Пользователь: "Спроектируй архитектуру для системы обработки данных"

Tree of Thoughts:
├─ Вариант 1: Монолитная архитектура
│  ├─ Плюсы: Простота
│  └─ Минусы: Масштабируемость
├─ Вариант 2: Микросервисы
│  ├─ Плюсы: Масштабируемость
│  └─ Минусы: Сложность
└─ Вариант 3: Гибридный подход
   └─ Оптимальный баланс
```

Активируется через `tree_of_thoughts.py` для сложных planning задач.
