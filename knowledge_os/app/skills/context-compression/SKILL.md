# Context Compression Skill

Навык для **Context Compression** - сжатие контекста для экономии 20-30% токенов без потери качества.

## Когда использовать

Используй этот навык для:

- Длинных контекстов
- Экономии токенов
- Оптимизации стоимости
- Работы с большими файлами

## Методология

Context Compression работает через:

1. **Analysis** - Анализ контекста
2. **Extraction** - Извлечение ключевой информации
3. **Compression** - Сжатие избыточной информации
4. **Validation** - Проверка сохранения смысла
5. **Optimization** - Оптимизация размера

## Примеры использования

```
Длинный файл: 10,000 строк кода

Context Compression:
1. Анализ: Структура, ключевые функции
2. Извлечение: Важные части
3. Сжатие: 10,000 → 2,000 строк
4. Результат: Сохранение смысла, экономия 80% токенов
```
