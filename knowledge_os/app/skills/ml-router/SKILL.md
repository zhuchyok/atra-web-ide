# ML Router Skill

Навык на основе **ML Router** от Singularity 5.0. Машинное обучение для выбора оптимальной модели обеспечивает экономию 95% токенов.

## Когда использовать

Используй этот навык для:

- Оптимального выбора модели
- Экономии токенов
- Баланса качества и стоимости
- Адаптивного выбора

## Методология

ML Router работает через:

1. **Task Analysis** - Анализ задачи
2. **Model Selection** - Выбор модели на основе ML
3. **Cost-Quality Balance** - Баланс стоимости и качества
4. **Learning** - Обучение на опыте
5. **Optimization** - Оптимизация выбора

## Примеры использования

```
Задача: Простой вопрос

ML Router:
1. Анализ: Простая задача
2. Выбор: Быстрая модель (экономия токенов)
3. Результат: Качество сохранено, стоимость снижена на 95%

Задача: Сложный reasoning

ML Router:
1. Анализ: Сложная задача
2. Выбор: Мощная модель (качество важнее)
3. Результат: Оптимальный баланс
```

## Интеграция

Активируется через `ml_router_*.py` для оптимизации выбора модели.
