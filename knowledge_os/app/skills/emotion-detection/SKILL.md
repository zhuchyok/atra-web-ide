# Emotion Detection Skill

Навык на основе **Emotional Response Modulation** от Singularity 9.0. Адаптация под настроение пользователя обеспечивает User satisfaction +15%.

## Когда использовать

Используй этот навык для:

- Адаптации тона ответов
- Улучшения user experience
- Понимания эмоционального состояния
- Персонализации коммуникации

## Методология

Emotion Detection работает через:

1. **Text Analysis** - Анализ текста пользователя
2. **Emotion Recognition** - Распознавание эмоций
3. **Tone Adaptation** - Адаптация тона ответа
4. **Response Modulation** - Модуляция ответа
5. **Feedback Learning** - Обучение на обратной связи

## Примеры использования

```
Пользователь: "Почему это не работает?!!!" (фрустрация)

Emotion Detection:
1. Распознавание: Фрустрация, раздражение
2. Адаптация: Более терпеливый, поддерживающий тон
3. Ответ: "Понимаю вашу фрустрацию. Давайте разберемся вместе..."
4. Результат: User satisfaction улучшен
```

## Интеграция

Активируется через `emotion_detector.py` для улучшения UX.
