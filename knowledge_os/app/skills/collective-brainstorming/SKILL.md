# Collective Brainstorming Skill (Singularity 20.0)

## Обзор

Этот скилл позволяет экспертам корпорации ATRA проводить автономные сессии мозгового штурма без участия пользователя. Виктория координирует процесс, а эксперты (Игорь, Анна, Елена) вносят свой вклад в дизайн и планирование.

## Когда использовать

- Проектирование новых крупных компонентов.
- Сложные архитектурные изменения.
- Решение проблем, затрагивающих несколько доменов (Backend, Frontend, Security).
- Когда в запросе есть слова: "brainstorm", "обсуди с экспертами", "спроектируй", "коллективное обсуждение".

## Процесс (Автономный)

1. **Exploration**: Эксперты анализируют контекст и дают начальные оценки.
2. **Clarification**: Эксперты задают друг другу уточняющие вопросы.
3. **Approaches**: Каждый эксперт предлагает 2-3 варианта реализации.
4. **Design Synthesis**: Виктория синтезирует финальный технический дизайн.
5. **Implementation Planning**: Виктория создает пошаговый план реализации.

## Как запустить

Скилл интегрирован в `ai_core.py`. Для активации достаточно использовать ключевые слова в запросе к Виктории.

Пример:

> "Виктория, проведи brainstorm по интеграции новой системы кэширования для ML-моделей."

## Результат

- Финальный дизайн (Markdown).
- Пошаговый план реализации.
- Полный лог обсуждения в `docs/plans/BRAINSTORM_YYYY-MM-DD_HH-MM.md`.
