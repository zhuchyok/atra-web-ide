# Adversarial Red Teaming Skill (Singularity 20.0)

## Обзор

Этот скилл обеспечивает «иммунитет» корпорации. Каждое новое важное знание или SOP проходит через атаку «Адвоката Дьявола», который пытается найти в нем изъяны.

## Когда использовать

- После генерации нового SOP.
- При добавлении критических инсайтов в базу знаний.
- В рамках ночного цикла обучения для верификации накопленной мудрости.

## Процесс

1. **Attack**: Критик получает контент и задачу «уничтожить» его аргументами.
2. **Analysis**: Поиск security-рисков, логических дыр и неэффективных советов.
3. **Verdict**: Вынесение решения — выжило знание или уничтожено.
4. **Update**: Обновление уверенности (confidence_score) и создание алертов при провале теста.

## Результат

- Повышенная надежность базы знаний.
- Автоматическое выявление и удаление «мусорных» или опасных инструкций.
- Лог атаки в метаданных узла знаний.
