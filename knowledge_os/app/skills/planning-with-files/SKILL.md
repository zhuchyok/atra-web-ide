# Planning with Files Skill

## Когда использовать
- Многодневные проекты
- Задачи с многими подзадачами
- Планирование спринтов
- Roadmap проекты
- Долгосрочное отслеживание прогресса

## Файлы

### plan.md (Основной план)
```markdown
# Project Plan

## Цель
Краткое описание цели проекта

## Задачи
- [ ] Task 1 - описание
- [x] Task 2 - выполнено
- [ ] Task 3 - в процессе

## Milestones
- [ ] Milestone 1 - дата
```

### todo.md (Текущие задачи)
```markdown
# TODO

## Today
- [ ] Задача 1
- [ ] Задача 2

## Tomorrow  
- [ ] Задача 3

## Backlog
- [ ] Задача 4
```

## Процесс

### Инициализация
1. Создай plan.md с целями
2. Создай todo.md с задачами
3. Определи milestones

### Обновление
1. При изменении статуса → обнови markdown
2. Ежедневно обновляй TODO секцию
3. Добавляй новые задачи в backlog

### Отчёт
- Progress = done/total * 100%
- Burndown chart если нужна

## Commands
- `/plan show` - показать текущий план
- `/plan add <task>` - добавить задачу
- `/plan done <task>` - отметить выполненным
- `/plan progress` - показать прогресс
