# Swarm Intelligence Skill

Навык на основе **Swarm Intelligence** - коллективного интеллекта. Обеспечивает +50-70% улучшение на complex задачи.

## Когда использовать

Используй этот навык для:

- Очень сложных задач, требующих экспертизы из разных областей
- Задач без однозначного решения
- Задач, где нужен консенсус экспертов
- Критичных решений

## Методология

Swarm Intelligence работает через:

1. **Decomposition** - Разбиение задачи на подзадачи
2. **Expert Assignment** - Назначение экспертов на каждую подзадачу
3. **Parallel Execution** - Параллельное выполнение
4. **Consensus** - Согласование результатов
5. **Integration** - Интеграция решений

## Примеры использования

```
Пользователь: "Создай полноценную веб-приложение с авторизацией"

Swarm Intelligence:
- Архитектор: Проектирует структуру
- Backend Developer: Создает API
- Frontend Developer: Создает UI
- Security Expert: Проверяет безопасность
- QA Engineer: Тестирует систему
→ Консенсус и интеграция
```

## Интеграция

Активируется через `swarm_intelligence.py` для очень сложных задач.
