# Code Analysis Skill

Навык для глубокого анализа кода: поиск багов, оптимизация, рефакторинг, анализ архитектуры.

## Когда использовать

Используй этот навык для:

- Поиска багов и уязвимостей
- Оптимизации производительности
- Рефакторинга кода
- Анализа архитектуры
- Code review

## Методология

Code Analysis работает через:

1. **Static Analysis** - Статический анализ кода
2. **Pattern Detection** - Обнаружение паттернов и антипаттернов
3. **Performance Analysis** - Анализ производительности
4. **Security Check** - Проверка безопасности
5. **Best Practices** - Проверка соответствия best practices

## Примеры использования

```
Пользователь: "Проанализируй этот код на баги и оптимизацию"

Code Analysis:
1. Чтение кода
2. Поиск потенциальных багов
3. Анализ сложности алгоритмов
4. Проверка безопасности
5. Рекомендации по оптимизации
```
