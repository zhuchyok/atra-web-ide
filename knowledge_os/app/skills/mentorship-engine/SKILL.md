# Mentorship Engine Skill (Singularity 20.0)

## Обзор

Этот скилл позволяет Виктории выступать в роли Верховного Ментора. Она анализирует результаты работы других экспертов, выставляет оценки и формирует рекомендации на будущее.

## Когда использовать

- После завершения сложных задач для оценки качества.
- Для выявления пробелов в компетенциях экспертов.
- Для формирования базы «лучших практик» и «типичных ошибок».

## Процесс

1. **Selection**: Выбор недавно завершенных задач.
2. **Audit**: Анализ ТЗ и результата выполнения через призму Level 20 Wisdom.
3. **Scoring**: Выставление оценки от 0 до 10.
4. **Feedback**: Генерация Mentorship Note — конкретного совета для эксперта.
5. **Injection**: Автоматическое внедрение совета в контекст эксперта при его следующем вызове.

## Результат

- Оценка качества в метаданных задачи.
- Узел знаний типа `mentorship_note`.
- Повышение качества последующих выполнений за счет обратной связи.
