## 📊 ОЖИДАЕМАЯ СТАТИСТИКА

После запуска бота и генерации сигналов, в таблице `filter_checks` должны появиться записи:

### Типы фильтров:

- `btc_trend` - проверка соответствия тренду BTC
- `eth_trend` - проверка соответствия тренду ETH
- `sol_trend` - проверка соответствия тренду SOL

### Примеры записей:

**Блокировка:**

```sql
symbol: 'ADAUSDT'
filter_type: 'eth_trend'
passed: 0
reason: 'LONG против сильного ETH тренда (strength=1.234%)'
```

**Успешное прохождение:**

```sql
symbol: 'ADAUSDT'
filter_type: 'eth_trend'
passed: 1
reason: NULL
```
