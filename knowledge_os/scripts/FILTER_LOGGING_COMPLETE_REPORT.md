## 📊 СТРУКТУРА ЛОГИРОВАНИЯ

### Формат записи в БД (`filter_checks`):

```python
{
    "symbol": "BTCUSDT",           # Торговый символ
    "filter_type": "eth_trend",     # Тип фильтра
    "passed": 0,                    # 0 = не прошел, 1 = прошел
    "reason": "LONG против сильного ETH тренда (strength=1.234%)",  # Причина блокировки
    "created_at": "2025-01-27 02:48:40"  # Время создания
}
```

### Типы фильтров:

- `btc_trend` - Фильтр тренда BTC
- `eth_trend` - Фильтр тренда ETH
- `sol_trend` - Фильтр тренда SOL
