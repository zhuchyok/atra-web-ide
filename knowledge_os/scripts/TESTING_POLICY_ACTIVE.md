## 📝 ПРОЦЕСС

### При создании нового модуля:

1. **Создать модуль:**

   ```bash
   touch new_module.py
   ```

2. **СРАЗУ создать тесты:**

   ```bash
   touch tests/unit/test_new_module.py
   ```

3. **Написать код и тесты**

4. **Проверить:**

   ```bash
   pytest tests/unit/test_new_module.py -v
   pytest tests/unit/test_new_module.py --cov=new_module
   ```

5. **Закоммитить вместе:**
   ```bash
   git add new_module.py tests/unit/test_new_module.py
   git commit -m "feat: Add new_module with tests"
   ```
