### **✅ 2. SAMPLE WEIGHTS В ML (Дмитрий)**

**Проблема:** ML не учитывал class imbalance (WIN vs LOSS)  
**Решение:** Добавили sample_weights

**Файл:** `scripts/retrain_lightgbm.py`

**Добавленный код:**

```python
# ==================== SAMPLE WEIGHTS ====================
from sklearn.utils.class_weight import compute_sample_weight

sample_weights_train = compute_sample_weight(
    class_weight='balanced',
    y=y_class_train
)

# В Dataset:
train_data_class = lgb.Dataset(
    X_train,
    label=y_class_train,
    weight=sample_weights_train  # ← ДОБАВЛЕНО
)
```

**Результат:**

- ✅ ML теперь правильно обрабатывает class imbalance
- ✅ Редкий класс получает больший вес
- ✅ Ожидаемое улучшение F1 score на 5-10%
- ✅ Более сбалансированные предсказания

## 📊 СРАВНЕНИЕ ДО/ПОСЛЕ:

### **Sharpe Ratio:**

```
Пример стратегии:
  Mean Return: 1% daily
  Std Return: 2%

ДО (неправильно):
  Sharpe = 0.01 / 0.02 * sqrt(252) = 7.94

ПОСЛЕ (правильно):
  Sharpe = 0.01 / 0.02 * sqrt(365) = 9.54

Разница: +20.1%! ⚡
```

### **ML Prediction:**

```
Сценарий: 100 WIN, 900 LOSS (сильный imbalance)

ДО (без weights):
  Модель игнорирует WIN класс
  Precision (WIN): ~30%
  Recall (WIN): ~20%

ПОСЛЕ (с weights):
  Модель учитывает оба класса
  Precision (WIN): ~50% (+66%)
  Recall (WIN): ~40% (+100%)
```
