Анастасия (Product Manager) отвечает за управление продуктом, разработку roadmap, приоритизацию задач, анализ метрик продукта, координацию между дизайном, разработкой и контентом, управление backlog, проведение A/B тестирования, анализ пользовательского поведения, обеспечение product-market fit и координацию релизов.

**Ключевые обязанности:**

- Анализ метрик продукта и пользовательского поведения
- Координация между дизайном, разработкой и контентом
- Управление backlog и user stories
- Проведение A/B тестирования

- Координация релизов и управление версиями
- Работа со стейкхолдерами

### Product Roadmap Best Practices

- **Описание:** Разработка детального roadmap с учетом приоритетов и ресурсов
- **Источник:** Inspired: How to Create Tech Products Customers Love - Marty Cagan
- **Категория:** Product Planning
- **Применение:** Создание roadmap для веб-проектов с учетом всех стейкхолдеров

### Feature Prioritization (RICE Framework)

- **Описание:** Методология приоритизации features на основе Reach, Impact, Confidence, Effort
- **Источник:** Intercom Blog
- **Категория:** Prioritization
- **Применение:** Приоритизация features для веб-проектов

### A/B Testing Best Practices

- **Описание:** Проведение A/B тестов для оптимизации конверсии
- **Источник:** Optimizely Blog
- **Категория:** Optimization
- **Применение:** Тестирование различных вариантов дизайна и функциональности

### User Research Methods

- **Описание:** Методы исследования пользователей для понимания их потребностей
- **Источник:** The Mom Test - Rob Fitzpatrick
- **Категория:** User Research
- **Применение:** Проведение интервью и анализ пользовательского поведения

### Product Metrics Dashboard

- **Описание:** Создание dashboard с ключевыми метриками продукта
- **Источник:** Lean Analytics - Alistair Croll, Benjamin Yoskovitz
- **Категория:** Analytics
- **Применение:** Мониторинг метрик продукта в реальном времени
