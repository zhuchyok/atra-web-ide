**Задача:** Реализация leveraged backtest engine

**Файл:** `backtests/leveraged_strategy.py`

**Основные изменения:**

```python
class LeveragedBacktestEngine:
    def __init__(self, leverage=2.5):
        self.balance = 10000  # $10k
        self.leverage = leverage
        self.margin_used = 0
        self.free_margin = self.balance

    def calc_pos_size_leveraged(self, entry, sl):
        # Размер с учётом плеча
        risk = self.balance * RISK_PER_TRADE
        price_risk = abs(entry - sl)
        base_size = risk / price_risk

        # С плечом можем взять больше
        leveraged_size = base_size * self.leverage

        # Проверка маржи
        required_margin = leveraged_size * entry / self.leverage
        if required_margin > self.free_margin * 0.7:
            return 0  # Недостаточно маржи

        return leveraged_size

    def check_liquidation(self, pos, current_price):
        # Проверка ликвидации
        if pos['side'] == "LONG":
            liq_price = pos['entry'] * (1 - 0.9/self.leverage)
        else:
            liq_price = pos['entry'] * (1 + 0.9/self.leverage)

        return current_price <= liq_price if pos['side'] == "LONG" else current_price >= liq_price
```

**Действия:**

1. Создать новый backtest engine с поддержкой leverage
2. Добавить расчёт маржи и free margin
3. Проверка ликвидации для каждой позиции
4. Расчёт комиссий с учётом плеча
