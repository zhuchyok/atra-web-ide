## 📝 КАК ДОБАВИТЬ КЛЮЧИ

### Вариант 1: Добавить в файл `env`

Отредактируйте файл `env` и добавьте:

```bash
# ============================================================================
# API КЛЮЧИ ДЛЯ БИРЖИ BITGET
# ============================================================================

BITGET_API_KEY=your_api_key_here
BITGET_SECRET_KEY=your_secret_key_here
BITGET_PASSPHRASE=your_passphrase_here
```

### Вариант 2: Установить через переменные окружения

```bash
export BITGET_API_KEY="your_api_key_here"
export BITGET_SECRET_KEY="your_secret_key_here"
export BITGET_PASSPHRASE="your_passphrase_here"
```

### Вариант 3: Использовать зашифрованное хранилище

Если ключи хранятся в зашифрованном виде, используйте `exchange_adapter.py` для их расшифровки.
