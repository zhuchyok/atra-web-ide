# ⚡ БЫСТРАЯ СПРАВКА: ОЦЕНКА КОМАНДОЙ

**Для автоматического применения к любым техническим решениям**

---

## 🎯 КОГДА ПРИМЕНЯТЬ

✅ **Применять автоматически:**

- Предложения новых решений
- Код для внедрения
- Архитектурные решения
- Изменения в критических компонентах
- Новые фичи

❌ **НЕ применять:**

- Простые вопросы
- Информационные запросы
- Документация без кода
- Мелкие исправления (typos)

---

## 👥 7 РОЛЕЙ (КРАТКО)

1. **Архитектор:** Архитектура, структура, масштабируемость
2. **Backend:** Качество кода, производительность, безопасность
3. **Data Engineer:** Данные, API, источники
4. **QA:** Тестируемость, покрытие тестами
5. **Аналитик:** Алгоритмы, метрики, обоснованность
6. **DevOps:** Деплой, мониторинг, надежность
7. **Документация:** Полнота, понятность

---

## 📋 БЫСТРЫЙ ЧЕКЛИСТ

### Критические проблемы (блокируют):

- [ ] Неправильные API/несовместимость
- [ ] Нет тестов для критического функционала
- [ ] Нет валидации критических данных
- [ ] Нет обработки ошибок
- [ ] Проблемы безопасности

### Важные проблемы:

- [ ] Плохая архитектура
- [ ] Низкое качество кода
- [ ] Нет документации
- [ ] Нет мониторинга

---

## 📊 ШКАЛА ОЦЕНОК

- **10/10:** Идеально, готово к production
- **8-9/10:** Отлично, мелкие исправления
- **6-7/10:** Хорошо, требует исправлений
- **4-5/10:** Удовлетворительно, значительные исправления
- **0-3/10:** Неудовлетворительно, не готово
