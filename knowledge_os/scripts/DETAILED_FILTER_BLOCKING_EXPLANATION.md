def check_rsi_warning(df: pd.DataFrame, signal_type: str) -> bool:

def check_rsi_warning(df, signal_type):

### 💡 Почему RSI Warning блокирует:

**1. Защита от перекупленности (LONG):**

- RSI > 70 = актив перекуплен
- Высокий риск отката вниз
- Блокируем LONG, чтобы не входить на пике

**2. Защита от перепроданности (SHORT):**

- RSI < 30 = актив перепродан
- Высокий риск отскока вверх
- Блокируем SHORT, чтобы не входить на дне

**3. Комбинация с AI уверенностью:**

- Если RSI экстремальный + AI уверенность < 0.3
- Блокируем, потому что недостаточно подтверждений
- Защита от ложных сигналов

---

### 📈 Когда разблокируется:

**RSI Warning разблокирует сигналы, когда:**

- RSI выйдет из экстремальной зоны:
  - Для LONG: RSI < 70
  - Для SHORT: RSI > 30
- ИЛИ AI уверенность повысится (> 0.3)
- ИЛИ появятся дополнительные подтверждения (объем, тренд)

**Ожидаемое время:**

- Может быть через несколько часов
- Зависит от движения рынка
- TRXUSDT и DYMUSDT должны выйти из перепроданности

### 🔍 Как работает MTF Confirmation фильтр:

**Логика проверки (упрощенная):**

```python
async def check_mtf_confirmation(symbol, signal_type, timeframe='4h'):
    # Получаем данные H4
    df_h4 = await get_data(symbol, '4h')

    # Рассчитываем EMA на H4
    ema_fast = df_h4['close'].ewm(span=12).mean()
    ema_slow = df_h4['close'].ewm(span=26).mean()

    # Рассчитываем MACD
    macd_fast = df_h4['close'].ewm(span=12).mean()
    macd_slow = df_h4['close'].ewm(span=26).mean()
    macd = macd_fast - macd_slow
    macd_signal = macd.ewm(span=9).mean()
    macd_hist = macd - macd_signal

    current_price = df_h4['close'].iloc[-1]
    current_ema_fast = ema_fast.iloc[-1]
    current_ema_slow = ema_slow.iloc[-1]
    current_macd_hist = macd_hist.iloc[-1]

    # Рассчитываем скоринг
    score = calculate_base_mtf_score(signal_type, metrics, thresholds)

    if signal_type == "BUY":  # LONG
        # Требуем: цена > EMA_fast > EMA_slow
        if current_price > current_ema_fast and current_ema_fast > current_ema_slow:
            # И MACD подтверждает
            if current_macd_hist > 0:
                # И скоринг достаточен
                if score >= 0.0:  # Минимальный порог
                    return True  # Подтверждено
        return False  # Не подтверждено
    else:  # SELL (SHORT)
        # Требуем: цена < EMA_fast < EMA_slow
        if current_price < current_ema_fast and current_ema_fast < current_ema_slow:
            # И MACD подтверждает
            if current_macd_hist < 0:
                # И скоринг достаточен
                if score >= 0.0:  # Минимальный порог
                    return True  # Подтверждено
        return False  # Не подтверждено
```

**Полная логика (с учетом волатильности и режима):**

- Проверяет EMA выравнивание (цена, EMA_fast, EMA_slow)
- Проверяет MACD histogram (направление импульса)
- Проверяет волатильность (высокая волатильность требует больше подтверждений)
- Учитывает рыночный режим (BULL/BEAR/RANGE)
- Рассчитывает скоринг на основе всех факторов
- Минимальный порог: score >= 0.0

**Условия для LONG:**

- ✅ Цена > EMA_fast > EMA_slow (бычий тренд на H4)
- ✅ MACD histogram > 0 (положительный импульс)
- ✅ Скоринг >= 0.0 (достаточное подтверждение)
- ✅ Низкая волатильность ИЛИ достаточно подтверждений

**Условия для SHORT:**

- ✅ Цена < EMA_fast < EMA_slow (медвежий тренд на H4)
- ✅ MACD histogram < 0 (отрицательный импульс)
- ✅ Скоринг >= 0.0 (достаточное подтверждение)
- ✅ Низкая волатильность ИЛИ достаточно подтверждений

### 💡 Почему MTF блокирует:

**1. Защита от ложных сигналов:**

- H4 таймфрейм показывает общий тренд
- Если H4 не подтверждает, сигнал может быть ложным
- Блокируем, чтобы не входить против тренда

**2. Требование выравнивания EMA:**

- Для LONG: цена > EMA_fast > EMA_slow
- Для SHORT: цена < EMA_fast < EMA_slow
- Если EMA не выровнены, тренд не подтвержден

**3. Требование подтверждения MACD:**

- MACD должен подтверждать направление тренда
- Для LONG: MACD > MACD_signal
- Для SHORT: MACD < MACD_signal

**4. Защита от высокой волатильности:**

- Если волатильность высокая + нет подтверждения
- Блокируем, потому что риск ложного сигнала высок

---

### 📈 Когда разблокируется:

**MTF разблокирует сигналы, когда:**

**Для LONG:**

- H4 EMA выровняются: цена > EMA_fast > EMA_slow
- MACD подтвердит: MACD > MACD_signal
- H4 покажет бычий тренд

**Для SHORT:**

- H4 EMA выровняются: цена < EMA_fast < EMA_slow
- MACD подтвердит: MACD < MACD_signal
- H4 покажет медвежий тренд
- Волатильность снизится или появится подтверждение

**Ожидаемое время:**

- Может быть через несколько часов (когда H4 свеча закроется)
- Зависит от движения рынка
- SUIUSDT должен показать бычий тренд на H4
- LINKUSDT, NEARUSDT должны показать медвежий тренд на H4
