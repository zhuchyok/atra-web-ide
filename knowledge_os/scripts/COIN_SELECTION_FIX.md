## ✅ РЕШЕНИЕ

### 1. **Найдена правильная логика фильтрации**

Функция `get_filtered_top_usdt_pairs_fast()` в `pair_filtering.py`:

```python
async def get_filtered_top_usdt_pairs_fast(top_n=500, final_limit=200):
    """
    Fast version without OHLC analysis - only volume filtering
    """
    # 1. Получает топ-500 монет по объему с Binance
    top_pairs = await get_top_usdt_pairs_by_volume(limit=min(top_n, 500))

    # 2. Фильтрует невалидные пары
    filtered_pairs = [symbol for symbol in top_pairs if is_valid_pair(symbol)]

    # 3. Убирает стейблкоины
    from config import STABLECOIN_SYMBOLS
    filtered_pairs = [symbol for symbol in filtered_pairs
                     if symbol not in STABLECOIN_SYMBOLS]

    # 4. Возвращает final_limit монет
    return filtered_pairs[:final_limit]
```

**Эта функция:**

- ✅ Получает топ-500 по объему
- ✅ Фильтрует невалидные пары
- ✅ Убирает стейблкоины
- ✅ Применяет белый/черный списки
- ✅ Возвращает отфильтрованный список

---

### 2. **Создан новый скрипт загрузки**

`scripts/download_top_coins_yearly.py`:

```python
from pair_filtering import get_filtered_top_usdt_pairs_fast

TOP_N = 500  # Получаем топ-500
FINAL_LIMIT = 30  # Финальный лимит

async def main():
    # Получаем отфильтрованные монеты
    symbols = await get_filtered_top_usdt_pairs_fast(
        top_n=TOP_N,
        final_limit=FINAL_LIMIT
    )

    # Загружаем данные для каждой монеты
    for symbol in symbols:
        df = await loader.fetch_ohlcv(symbol, "1h", days=365)
        all_data[symbol] = df
```
