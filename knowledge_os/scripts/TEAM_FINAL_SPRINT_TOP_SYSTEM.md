### **ДЕНЬ 1: ОПТИМИЗАЦИЯ СТРАТЕГИИ** 🔧

#### **Алексей (Data Scientist) - 8 часов**

**Задача 1: Оптимизация ML порогов (4 часа)**

- [ ] Протестировать 10+ комбинаций ML порогов
- [ ] Найти оптимум для 10-15 сделок/год
- [ ] Целевые метрики: WR > 70%, PF > 2.0, Доход > +2%
- [ ] Создать отчет с рекомендациями

**Задача 2: Улучшение ML модели (4 часа)**

- [ ] Добавить features:
  - `correlation_btc`, `correlation_eth`, `correlation_sol`
  - `spread_estimate` (ATR-based)
  - `liquidity_score` (Volume-based)
  - `market_regime` (BULL/NEUTRAL/BEAR)
  - `dominant_leader` (BTC/ETH/SOL)
- [ ] Переобучить модель на новых features
- [ ] Валидация: ROC AUC > 0.95, Accuracy > 95%

#### **Мария (Quant Analyst) - 8 часов**

**Задача 1: Оптимизация TP/SL (3 часа)**

- [ ] Протестировать 20+ комбинаций TP/SL
- [ ] Найти оптимум для W/L > 0.9
- [ ] Учесть trailing stop (50% → 60-70%)
- [ ] Partial TP: 30% на TP1, 70% на TP2

**Задача 2: Оптимизация Trailing Stop (3 часа)**

- [ ] Протестировать разные точки активации (40%, 50%, 60%, 70%)
- [ ] Оптимизировать прогресс до break-even (0.8, 1.0, 1.2)
- [ ] Найти баланс: минимизировать ранние выходы, защитить прибыль

**Задача 3: Risk/Reward анализ (2 часа)**

- [ ] Рассчитать оптимальный R/R для каждой монеты
- [ ] Учесть волатильность (ATR-based)
- [ ] Создать динамические TP/SL таблицы

#### **Игорь (Strategy Developer) - 8 часов**

**Задача 1: Реализация улучшенных фильтров (4 часа)**

- [ ] Spread Filter: реальный bid-ask spread (если API доступен)
- [ ] Liquidity Filter: глубина стакана (depth API)
- [ ] Усиление Volume Filter: динамический порог (1.5-2.0)
- [ ] Correlation Filter: блокировать сигналы на коррелированных монетах одновременно

**Задача 2: Adaptive Strategy (4 часа)**

- [ ] Определение режима рынка (BULL/NEUTRAL/BEAR)
- [ ] Адаптивные пороги ML:
  - BULL: ослабить (48%/0.8%)
  - NEUTRAL: стандарт (50%/1.0%)
  - BEAR: усилить (55%/1.5%)
- [ ] Интеграция в `signal_live.py`

- [ ] Ускорение на 30-50%

#### **Сергей (DevOps) - 8 часов**

**Задача 1: Real-time мониторинг (4 часа)**

- [ ] Настроить Grafana дашборд:
  - Win Rate (текущий, скользящая средняя 7д/30д)
  - Profit Factor
  - Доходность (дневная, месячная, годовая)
  - Max DD
  - Количество сделок (день/неделя/месяц)
  - ML метрики (avg confidence, avg expected profit)
- [ ] Prometheus для сбора метрик
- [ ] InfluxDB для временных рядов

**Задача 2: Алерты в Telegram (2 часа)**

- [ ] Win Rate < 55% за последние 7 дней → алерт
- [ ] Max DD > 2% → критический алерт
- [ ] Profit Factor < 1.2 за 30 дней → предупреждение
- [ ] Нет сделок > 14 дней → уведомление
- [ ] ML модель деградирует (accuracy < 90%) → алерт

**Задача 3: Auto-retraining pipeline (2 часа)**

- [ ] Cron job: каждые 14 дней
- [ ] Скачать новые паттерны из БД
- [ ] Переобучить модель
- [ ] A/B тест новой модели (7 дней, 30% трафика)
- [ ] Если новая лучше → автоматический деплой

#### **Дмитрий (Risk Manager) - 8 часов**

**Задача 1: Risk Management система (4 часа)**

- [ ] Position Sizing:
  - Kelly Criterion (оптимальный размер позиции)
  - Max 2% капитала на сделку
  - Динамическая корректировка по Win Rate
- [ ] Portfolio Risk:
  - Max 3 одновременные позиции
  - Не более 2 позиций на коррелированных монетах
  - Daily loss limit: -1% от капитала
- [ ] Emergency Stop:
  - Max DD > 3% → остановить торговлю на 24 часа
  - Win Rate < 40% за 10 сделок → ручной режим

**Задача 2: Backtesting улучшенной системы (4 часа)**

- [ ] Запустить бектест со всеми улучшениями
- [ ] Проверить на разных периодах:
  - Год (365 дней)
  - Bull рынок (последние 90 дней)
  - Bear рынок (коррекция)
- [ ] Stress testing: Max DD, worst case scenario
- [ ] Monte Carlo симуляция (1000 симуляций)
