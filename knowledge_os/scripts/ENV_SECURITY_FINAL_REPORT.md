## 🔐 УСТАНОВЛЕННОЕ ПРАВИЛО

### Обязательное правило проекта:

> **НИКОГДА не коммитьте файл `env` с реальными ключами в git.**
> **ВСЕГДА используйте `.env` (который в `.gitignore`) для реальных ключей.**

### Структура файлов:

- **`.env`** - реальные ключи (в `.gitignore`) ✅
- **`env`** - шаблон без ключей (может быть закоммичен) ✅
- **`env.prod`** / **`env.dev`** - шаблоны для окружений ✅

### Приоритет загрузки:

1. **`.env`** (приоритет) - реальные ключи
2. `ATRA_ENV_FILE` (переменная окружения)
3. `env.prod` / `env.dev` (в зависимости от `ATRA_ENV`)
4. `env` (шаблон, fallback)
