
- **Было:** 3 свечи

- **Эффект:** Более надежное подтверждение тренда

### 3. **Фильтр по истории сигналов**

```python
# Фильтр по истории сигналов (избегаем частых сигналов)
if i >= 10:
    recent_signals = 0
    for j in range(i-10, i):
        if df["close"].iloc[j] <= df["bb_lower"].iloc[j] or df["close"].iloc[j] >= df["bb_upper"].iloc[j]:
            recent_signals += 1
    if recent_signals >= 3:  # Максимум 3 сигнала за последние 10 свечей
        return None, None
```

- **Цель:** Избегать частых сигналов на одном активе
- **Эффект:** Снижение количества сделок

### 4. **Фильтр по силе движения**

```python
# Фильтр по силе движения (избегаем слабых движений)
price_change_1h = abs(current_price - df["close"].iloc[i-1]) / df["close"].iloc[i-1] * 100
price_change_4h = abs(current_price - df["close"].iloc[i-4]) / df["close"].iloc[i-4] * 100

if price_change_1h < 0.3 or price_change_4h < 0.8:  # Минимальное движение
    return None, None
```

- **Цель:** Только активные движения
- **Эффект:** Повышение качества сигналов
