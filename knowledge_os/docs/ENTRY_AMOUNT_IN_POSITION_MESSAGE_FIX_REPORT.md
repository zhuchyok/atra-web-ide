# Отчет об исправлении сообщений об открытии позиций

## Проблема

Пользователь сообщил: **"нужно добавить сумму входа Позиция по LINKUSDT открыта!"**

В сообщениях об открытии позиций отображался **"Риск: 411.98 USDT"**, но не было **суммы входа**, которая показывает сколько средств фактически было использовано для открытия позиции.

## Анализ проблемы

### ❌ Было:

```
✅ Позиция по LINKUSDT открыта!
Режим: SPOT | LONG | Плечо: x1.0
Средняя цена: 21.752
🎯 TP1: 21.969
🚀 TP2: 22.187
Объём: 18.9404
Риск на сделку: 1.90%
Риск: 411.98 USDT
```

**Проблема**: Показывался "Риск" (общая стоимость позиции), но не было "Суммы входа" (сколько средств использовано).

### ✅ Стало:

```
✅ Позиция по LINKUSDT открыта!
Режим: SPOT | LONG | Плечо: x1.0
Средняя цена: 21.752
🎯 TP1: 21.969
🚀 TP2: 22.187
Объём: 18.9404
Риск на сделку: 1.90%
💵 Сумма входа: 411.98 USDT
```

**Исправление**: Добавлена "💵 Сумма входа" которая показывает фактически использованные средства.

## Исправления

balance_data = recalculate_balance_and_risks(user_data, user_id)

## Логика расчета суммы входа

### Формула:

```python
# Спот торговля
Сумма входа = free_deposit × risk_pct / 100

# Фьючерсы
Сумма входа = free_deposit × risk_pct / 100 × leverage
```

### Где:

- **free_deposit** = свободные средства (депозит - риски открытых позиций)
- **risk_pct** = процент риска на сделку
- **leverage** = плечо (для фьючерсов)

### Примеры:

**Спот торговля:**

- Свободные средства: 1000 USDT
- Риск: 2%
- Сумма входа: 1000 × 2% = **20 USDT**

**Фьючерсы:**

- Свободные средства: 1000 USDT
- Риск: 2%
- Плечо: 5x
- Сумма входа: 1000 × 2% × 5 = **100 USDT**
