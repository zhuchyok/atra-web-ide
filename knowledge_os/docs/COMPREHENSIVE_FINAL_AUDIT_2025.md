## 9. ОСТАВШИЕСЯ РЕКОМЕНДАЦИИ (Опциональные)

### 🔶 **Приоритет 3 (Низкий):**

#### **9.1 HTTPS для REST API и Dashboard**

- **Статус:** Требует внешней конфигурации (nginx, SSL сертификаты)
- **Описание:** Настройка HTTPS на уровне reverse proxy (nginx)
- **Влияние:** Повышает безопасность при использовании через интернет

#### **9.2 JWT Аутентификация для REST API**

- **Статус:** Опционально, если нужен доступ через интернет
- **Описание:** Добавление JWT токенов для защиты API
- **Влияние:** Повышает безопасность при публичном доступе

#### **9.3 Event Bus для слабой связанности**

- **Статус:** Опционально, для дальнейшего масштабирования
- **Описание:** Реализация event bus (например, Redis Pub/Sub)
- **Влияние:** Улучшает масштабируемость и гибкость

#### **9.4 Dependency Injection**

- **Статус:** Опционально, для улучшения тестируемости
