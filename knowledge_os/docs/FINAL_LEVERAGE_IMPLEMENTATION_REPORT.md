## 🔄 Логика расчета плеча

### **Для SPOT торговли:**

```
Плечо = 1x (всегда)
```

### **Для FUTURES торговли:**

```
Базовое плечо = f(депозит)
Риск-множитель = f(режим фильтров)
Итоговое плечо = базовое плечо × риск-множитель
Ограничения: от 1x до 20x
```

### **Таблица базового плеча:**

| Депозит (USDT) | Базовое плечо |
| -------------- | ------------- |
| < 100          | 1x            |
| 100-499        | 2x            |
| 500-999        | 3x            |
| 1000-4999      | 5x            |
| 5000-9999      | 8x            |
| ≥ 10000        | 10x           |

### **Риск-множители:**

| Режим фильтров   | Риск-толерантность | Множитель |
| ---------------- | ------------------ | --------- |
| Мягкий           | Агрессивная        | 1.5x      |
| Сбалансированный | Умеренная          | 1.0x      |
| Строгий          | Консервативная     | 0.5x      |
