## 📊 ПРИМЕРЫ УЛУЧШЕНИЙ

### **Пример 1: Анализ торговой стратегии**

#### ❌ **ДО (неправильно):**

```
"Что ты думаешь о новой стратегии DCA?"
```

#### ✅ **ПОСЛЕ (правильно):**

```
"Какие эксперты из команды должны обсудить стратегию DCA?
Что бы сказали Павел (Trading Strategy Developer), Мария (Risk Manager) и Максим (Data Analyst)?
Какие аргументы они приведут за и против?"
```

## 🎯 ШАБЛОНЫ ДЛЯ РАЗНЫХ СИТУАЦИЙ

### **1. Анализ проблемы:**

```
"Какие эксперты из команды должны обсудить [проблему]?
Что бы сказали [Эксперт1], [Эксперт2] и [Эксперт3]?
Как они подойдут к диагностике и решению?"
```

### **2. Оценка решения:**

```
"Какая группа специалистов подходит для оценки [решения]?
Какие аргументы приведут [Эксперт1] и [Эксперт2]?
Какие риски укажет [Эксперт3]?"
```

### **3. Планирование:**

```
"Какие эксперты должны составить план для [задачи]?
Как [Эксперт1] подойдет к архитектуре?
Какие метрики предложит [Эксперт2]?
Какие риски учтет [Эксперт3]?"
```

### **4. Оптимизация:**

```
"Какая команда специалистов подходит для оптимизации [компонента]?
Что бы сказали [Эксперт1], [Эксперт2] и [Эксперт3]?
Какие метрики они проанализируют и какие улучшения предложат?"
```
