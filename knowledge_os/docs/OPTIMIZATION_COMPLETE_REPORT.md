### 3. ✅ HTTPS для REST API

#### **Реализовано:**

**rest_api.py:**

- ✅ Параметр `use_https` в `run_rest_api()` и `run_rest_api_async()`
- ✅ Автоматическая проверка SSL сертификатов
- ✅ Fallback на HTTP если сертификаты не найдены
- ✅ Пути к сертификатам через env переменные

**main.py:**

- ✅ Интеграция через `USE_HTTPS` env переменную
- ✅ Автоматическое определение протокола

**scripts/generate_self_signed_ssl.sh:**

- ✅ Скрипт генерации self-signed сертификатов
- ✅ 4096-bit RSA ключ
- ✅ Действителен 365 дней

#### **Использование:**

**Для разработки:**

```bash
./scripts/generate_self_signed_ssl.sh
export USE_HTTPS=true
python3 main.py
```

**Для продакшена (Let's Encrypt):**

```bash
export SSL_KEYFILE=/etc/letsencrypt/live/domain.com/privkey.pem
export SSL_CERTFILE=/etc/letsencrypt/live/domain.com/fullchain.pem
export USE_HTTPS=true
python3 main.py
```
