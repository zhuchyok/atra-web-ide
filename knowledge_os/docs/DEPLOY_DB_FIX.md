# 🔧 РАЗВЕРТЫВАНИЕ ИСПРАВЛЕНИЯ БАЗЫ ДАННЫХ

## 📋 Проблема

На сервере появляется предупреждение:

```
⚠️ Проблемы производительности: ['❌ База данных сигналов пуста']
```

## 🔍 Причина

Ошибка в SQL запросе в функции `insert_signal_log` - несоответствие между количеством столбцов (25) и плейсхолдеров (24).

## ✅ Решение

Исправлен SQL запрос в файле `db.py`, добавлен недостающий плейсхолдер.

## 🚀 Развертывание на сервере

### Вариант 1: Автоматическое обновление (рекомендуется)

```bash
# На сервере выполните:
cd /path/to/atra
chmod +x update_and_restart.sh
./update_and_restart.sh
```

### Вариант 2: Ручное обновление

```bash
# 1. Остановите систему
./bot_manager.sh stop

# 2. Обновите код
git pull origin worker

# 3. Запустите систему
./bot_manager.sh start
```

### Вариант 3: Только перезапуск (если код уже обновлен)

```bash
# Перезапустите систему
./restart_system.sh
```
