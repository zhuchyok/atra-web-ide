# 🎯 РУКОВОДСТВО ПО ТРЕМ РЕЖИМАМ ФИЛЬТРАЦИИ БЛОКОВ

## 🚀 Что нового?

Система анализа блоков теперь работает с **тремя режимами фильтрации**, каждый из которых имеет свои настройки и подходит для разных стилей торговли.

## 📊 Три режима фильтрации

### 🔴 **STRICT (Строгий)**

- **Отклонение:** При противоречии блоков >50% (1.5x)
- **Ослабление:** При противоречии блоков >20% (1.2x)
- **Усиление:** При подтверждении блоков >20% (0.8x)
- **Плечо:** Умеренное (множитель 1.0x)
- **Результат:** Максимальная точность, меньше сигналов

### 🟡 **SOFT (Мягкий)**

- **Отклонение:** При противоречии блоков >100% (2.0x)
- **Ослабление:** При противоречии блоков >50% (1.5x)
- **Усиление:** При подтверждении блоков >30% (0.7x)
- **Плечо:** Агрессивное (множитель 1.5x)
- **Результат:** Баланс точности и частоты сигналов

### 🟢 **ULTRA_SOFT (Ультра мягкий)**

- **Отклонение:** При очень сильном противоречии >200% (3.0x)
- **Ослабление:** При сильном противоречии >100% (2.0x)
- **Усиление:** При сильном подтверждении >40% (0.6x)
- **Плечо:** Ультра агрессивное (множитель 2.0x)
- **Результат:** Максимум сигналов, минимальная фильтрация

## 🎯 Как это работает

### Пример 1: STRICT режим

```
Ситуация: Блоки продавцов в 1.76x сильнее блоков покупателей
LONG сигнал: ❌ ОТКЛОНЕН (1.76 > 1.5)
SHORT сигнал: 🔥 УСИЛЕН (1.76 > 1.0)
Плечо: 5x (для депозита 1000 USDT)
```

### Пример 2: SOFT режим

```
Ситуация: Блоки продавцов в 1.76x сильнее блоков покупателей
LONG сигнал: ⚠️ ОСЛАБЛЕН (1.76 > 1.5, но < 2.0)
SHORT сигнал: 🔥 УСИЛЕН (1.76 > 1.0)
Плечо: 7x (для депозита 1000 USDT)
```

### Пример 3: ULTRA_SOFT режим

```
Ситуация: Блоки продавцов в 1.76x сильнее блоков покупателей
LONG сигнал: Обычный (1.76 < 2.0)
SHORT сигнал: 🔥 УСИЛЕН (1.76 > 1.0)
Плечо: 10x (для депозита 1000 USDT)
```

## 📈 Статистика фильтрации

### STRICT режим:

- **Отклонено:** ~17% сигналов
- **Ослаблено:** ~33% сигналов
- **Усилено:** ~50% сигналов
- **Нейтрально:** ~0% сигналов
- **Плечо:** Умеренное (1.0x множитель)

### SOFT режим:

- **Отклонено:** ~0% сигналов
- **Ослаблено:** ~17% сигналов
- **Усилено:** ~17% сигналов
- **Нейтрально:** ~67% сигналов
- **Плечо:** Агрессивное (1.5x множитель)

### ULTRA_SOFT режим:

- **Отклонено:** ~0% сигналов
- **Ослаблено:** ~0% сигналов
- **Усилено:** ~17% сигналов
- **Нейтрально:** ~83% сигналов
- **Плечо:** Ультра агрессивное (2.0x множитель)

## 💡 Практические рекомендации

### Для консервативных трейдеров:

**Используйте STRICT режим**

- ✅ Максимальная точность сигналов
- ✅ Меньше ложных сигналов
- ✅ Умеренное плечо для безопасности
- ⚠️ Меньше сигналов в целом

### Для умеренных трейдеров:

**Используйте SOFT режим**

- ✅ Хороший баланс точности и частоты
- ✅ Фильтрация явно противоречивых сигналов
- ✅ Агрессивное плечо для роста
- ✅ Сохранение большинства сигналов

### Для агрессивных трейдеров:

**Используйте ULTRA_SOFT режим**

- ✅ Максимум сигналов
- ✅ Минимальная фильтрация
- ✅ Максимальное плечо для быстрого роста
- ⚠️ Больше ложных сигналов

## 🎛️ Выбор режима в боте

### В интерфейсе бота:

При настройке вы увидите **3 кнопки**:

- 🔴 **Строгий** - для консервативных трейдеров
- 🟡 **Мягкий** - для умеренных трейдеров
- 🟢 **Ультра мягкий** - для агрессивных трейдеров

### Автоматическая настройка:

Система автоматически применяет соответствующий режим:

- **strict_entry_signal** → STRICT фильтрация
- **soft_entry_signal** → SOFT фильтрация
- **ultra_soft_entry_signal** → ULTRA_SOFT фильтрация

## 📊 Интерпретация сигналов

### ❌ Отклоненные сигналы:

```
[BLOCKS] LONG сигнал отклонен: Отклонен: блоки продавцов в 1.76x сильнее
```

**Действие:** Сигнал не генерируется, торговля не рекомендуется

### ⚠️ Ослабленные сигналы:

```
LONG ⚠️ - Вход: 45000
```

**Действие:** Используйте меньший размер позиции, более консервативные TP/SL

### 🔥 Усиленные сигналы:

```
SHORT 🔥 - Вход: 45000
```

**Действие:** Можно увеличить размер позиции, более агрессивные TP/SL

### Обычные сигналы:

```
LONG - Вход: 45000
```

**Действие:** Стандартная торговля

## 📈 Мониторинг эффективности

### Ключевые метрики для отслеживания:

1. **Процент отклоненных сигналов** - показывает строгость фильтрации
2. **Процент усиленных сигналов** - показывает качество подтверждений
3. **Win rate по типам сигналов** - эффективность фильтрации
4. **Средний профит по типам** - качество фильтрации
5. **Эффективность плеча** - соотношение риска и доходности

### Рекомендации по мониторингу:

- Ведите дневник отклоненных сигналов
- Сравнивайте результаты разных режимов
- Анализируйте эффективность усиленных сигналов
- Корректируйте пороги на основе результатов
- Отслеживайте эффективность плеча
