## 🎯 **ОТВЕТ НА ВАШ ВОПРОС:**

### **✅ По умолчанию торговля КРУГЛОСУТОЧНАЯ!**

Если вы **не устанавливали торговые часы**, то система работает **круглосуточно** и **НЕ влияет** на принятие сигналов.

## 🔍 **КАК РАБОТАЮТ ТОРГОВЫЕ ЧАСЫ:**

### **📋 Функция `check_user_trading_hours`:**

```python
def check_user_trading_hours(user_data):
    """Проверка торговых часов пользователя"""
    th = user_data.get("trading_hours")
    if not th:
        return True  # ← КЛЮЧЕВОЕ: если не установлены - разрешаем торговлю

    now = get_msk_now()
    hour = now.hour
    start = th.get("start", 0)
    end = th.get("end", 24)

    # Проверяем, что текущий час входит в торговые часы
    if start <= end:
        # Обычный случай: 9-18
        return start <= hour < end
    else:
        # Переход через полночь: 23-7
        return hour >= start or hour < end
```

### **🎯 Логика работы:**

1. **Если `trading_hours` НЕ установлены** → `return True` (разрешаем торговлю)
2. **Если `trading_hours` установлены** → проверяем текущее время

## 🚀 **ЧТО ПРОИСХОДИТ В РАЗНЫХ СЛУЧАЯХ:**

### **✅ Случай 1: Торговые часы НЕ установлены**

```
📋 user_data.get("trading_hours") → None
🔍 check_user_trading_hours() → return True
✅ Сигналы генерируются и отправляются КРУГЛОСУТОЧНО
```

### **✅ Случай 2: Торговые часы установлены (например, 9-18)**

```
📋 user_data.get("trading_hours") → {"start": 9, "end": 18}
🔍 check_user_trading_hours() → проверяет текущий час
⏰ Если сейчас 14:00 → return True (внутри торговых часов)
⏰ Если сейчас 22:00 → return False (вне торговых часов)
```

## 📈 **СИСТЕМА DCA ПРИ ВНЕ ТОРГОВЫХ ЧАСОВ:**

### **🎯 Если пользователь вне торговых часов:**

1. **Новые сигналы НЕ генерируются**
2. **НО если есть открытая позиция** → DCA сигнал сохраняется в очередь
3. **При начале торговой сессии** → все накопленные DCA сигналы обрабатываются

### **💡 Пример:**

```
⏰ 22:00 (вне торговых часов)
📊 Есть открытая позиция BTCUSDT
🔄 Система генерирует DCA сигнал
💾 Сохраняет в pending_dca_signals
❌ НЕ отправляет пользователю

⏰ 09:00 (начало торговых часов)
🔄 Система проверяет pending_dca_signals
📤 Отправляет все накопленные DCA сигналы
✅ Пользователь получает сигналы для усреднения
```
