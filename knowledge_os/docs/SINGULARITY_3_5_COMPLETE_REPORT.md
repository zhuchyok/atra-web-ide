## 🚀 КАК ИСПОЛЬЗОВАТЬ

### **1. Настройка мониторинга и бэкапов:**

```bash
cd /root/knowledge_os
bash scripts/setup_all_monitoring.sh
```

### **2. Применение миграции БД:**

```bash
psql -U admin -d knowledge_os -f db/migrations/add_tasks_table.sql
```

### **3. Запуск улучшенных компонентов:**

```bash
# Orchestrator (каждые 30 минут)
*/30 * * * * cd /root/knowledge_os && python3 app/enhanced_orchestrator.py

# Иммунитет (каждые 6 часов)
0 */6 * * * cd /root/knowledge_os && python3 app/enhanced_immunity.py

# Мониторинг (каждые 5 минут)
*/5 * * * * cd /root/knowledge_os && python3 app/enhanced_monitor.py
```

### **4. Запуск улучшенного Dashboard:**

```bash
cd /root/knowledge_os/dashboard
streamlit run app_enhanced.py --server.port 8502
```

### **5. Использование улучшенного поиска:**

```python
# В MCP инструментах
search_knowledge("query", mode="auto")  # Автоматический режим
search_knowledge("query", mode="hybrid")  # Гибридный
search_knowledge_detailed("query")  # Детальные результаты
```
