### 1. Оптимизация API запросов ✅

#### **Изменения:**

- ✅ Уменьшена частота запросов: 20 → 15 req/min
- ✅ Увеличен интервал: 3.0с → 4.0с
- ✅ Увеличены TTL кеша: 30с → 60с (CRITICAL), 60с → 120с (HIGH), 120с → 300с (MEDIUM), 300с → 600с (LOW)

- ✅ Увеличена задержка между символами: 0.5с → 1.0с

#### **Файлы:**

- `smart_rate_limiter.py` - оптимизированы лимиты
- `adaptive_cache.py` - увеличены TTL
- `hybrid_data_manager.py` - оптимизированы max_age_rules
- `signal_live.py` - использование кеша везде

#### **Ожидаемый результат:**

- Снижение нагрузки на API на 25-30%
- Меньше срабатываний circuit breaker
- Больше cache hits

### 3. HTTPS для REST API ✅

#### **Реализовано:**

- ✅ Поддержка HTTPS в `rest_api.py`
- ✅ Автоматическая проверка сертификатов
- ✅ Fallback на HTTP если сертификаты не найдены
- ✅ Интеграция с `main.py` через `USE_HTTPS` env
- ✅ Скрипт генерации self-signed сертификатов

#### **Файлы:**

- `rest_api.py` - добавлена поддержка HTTPS
- `main.py` - интеграция с env переменной
- `scripts/generate_self_signed_ssl.sh` - генерация сертификатов

#### **Использование:**

```bash
# Для разработки
./scripts/generate_self_signed_ssl.sh
export USE_HTTPS=true
python3 main.py

# Для продакшена (Let's Encrypt)
export SSL_KEYFILE=/path/to/key.pem
export SSL_CERTFILE=/path/to/cert.pem
export USE_HTTPS=true
python3 main.py
```
