## 📖 ПОЛНЫЙ СПОСОБ (С СИНХРОНИЗАЦИЕЙ ДАННЫХ)

> **💡 Этот способ нужен ТОЛЬКО если вы хотите синхронизировать данные команды между несколькими проектами.**  
> Для одного проекта достаточно "БЫСТРОГО СПОСОБА" выше.

### **Шаг 1: Клонировать или открыть новый проект**

```bash
# Если проект еще не клонирован
git clone https://github.com/your-org/new-project.git
cd new-project

# Или просто перейдите в существующий проект
cd /path/to/new-project
```

---

### **Шаг 2: Скопировать скрипты синхронизации**

Скопируйте из проекта ATRA:

```bash
# Создать директорию scripts если нет
mkdir -p scripts

# Скопировать скрипт синхронизации
cp /path/to/atra/scripts/sync_team_data.py scripts/
cp /path/to/atra/scripts/setup_team_sync.sh scripts/
cp /path/to/atra/scripts/auto_sync_team_data.sh scripts/

# Сделать исполняемыми
chmod +x scripts/sync_team_data.py
chmod +x scripts/setup_team_sync.sh
chmod +x scripts/auto_sync_team_data.sh
```

---

### **Шаг 3: Настроить синхронизацию данных команды**

#### **Вариант A: Если есть центральный репозиторий**

```bash
# Установить переменные окружения
export TEAM_DATA_REPO="https://github.com/your-org/team-data.git"
export TEAM_DATA_DIR=".team_data"

# Получить данные команды
python scripts/sync_team_data.py pull
```

#### **Вариант B: Если нет центрального репозитория**

```bash
# Использовать интерактивную настройку
bash scripts/setup_team_sync.sh
```

Или скопировать данные напрямую из проекта ATRA:

```bash
# Создать директорию
mkdir -p .team_data

# Скопировать данные из проекта ATRA
cp -r /path/to/atra/.team_data/* .team_data/
```

---

### **Шаг 4: Скопировать правила Cursor**

```bash
# Скопировать .cursorrules из синхронизированных данных
cp .team_data/.cursorrules .cursorrules

# Или напрямую из проекта ATRA
cp /path/to/atra/.cursorrules .cursorrules
```

---

### **Шаг 5: Проверить настройку**

```bash
# Проверить статус синхронизации
python scripts/sync_team_data.py status
```

## 🚨 РЕШЕНИЕ ПРОБЛЕМ

### **Проблема: Команда не активируется**

**Решение:**

1. Проверьте наличие `.cursorrules` в корне проекта
2. Перезапустите Cursor IDE
3. Откройте новый чат (не продолжайте старый)

---

### **Проблема: Данные не синхронизируются**

**Решение:**

```bash
# Проверить переменные окружения
echo $TEAM_DATA_REPO
echo $TEAM_DATA_DIR

# Инициализировать заново
rm -rf .team_data
python scripts/sync_team_data.py sync
```

---

### **Проблема: Скрипт не найден**

**Решение:**

```bash
# Проверить путь
which python3

# Использовать полный путь
python3 /path/to/scripts/sync_team_data.py status
```
