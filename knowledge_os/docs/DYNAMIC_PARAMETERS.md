# 🎯 Динамические параметры торговой системы ATRA

## 📊 Обзор системы

Торговая система ATRA использует **динамические параметры**, которые автоматически адаптируются к рыночным условиям:

- 🎯 **Динамический риск** - 1-5% в зависимости от волатильности и тренда
- ⚡ **Динамическое плечо** - 1-20x на основе базового плеча, тренда и волатильности
- 📈 **Динамические TP/SL** - адаптируются под волатильность рынка
- 🔄 **Автоматическая оптимизация** - параметры обновляются в реальном времени

- Боковой рынок + средняя волатильность = 2% риск
- Сильная волатильность + слабый тренд = 1% риск

```python
    # При высокой волатильности: уменьшаем плечо
    # Диапазон: 1-20x
```

**Формула:**

```

volatility_factor = 1 / (1 + volatility * 3)  # уменьшаем при высокой волатильности

```

**Примеры:**

- Базовое плечо 5x + сильный тренд + низкая волатильность = 15x
- Базовое плечо 3x + боковой рынок + средняя волатильность = 3x
- Базовое плечо 10x + высокая волатильность = 2-3x
