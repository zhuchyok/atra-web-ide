# 🎯 АВТОМАТИЧЕСКАЯ ОПТИМИЗАЦИЯ ПАРАМЕТРОВ ATRA

## 📋 Обзор системы

Система автоматической оптимизации ATRA предназначена для постоянного улучшения параметров торговой стратегии на основе анализа исторических данных и текущей производительности.

### 🔧 Что делает система:

1. **Анализирует текущую производительность** стратегии
2. **Оптимизирует параметры** для топ-50 монет по объему
3. **Тестирует новые параметры** на исторических данных
4. **Применяет лучшие параметры** если они дают улучшение >5%
5. **Автоматически перезапускает бота** после применения новых параметров
6. **Ведет историю оптимизаций** в папке `optimization_history/`

## 🚀 Быстрый старт

## 📅 Расписание оптимизации

### Ежедневная оптимизация

- **Время:** 06:00 утра
- **Тип:** Быстрая оптимизация (25 испытаний)
- **Цель:** Поддержание производительности

### Еженедельная полная оптимизация

- **Время:** Воскресенье 08:00
- **Тип:** Полная оптимизация (100 испытаний)
- **Цель:** Глубокий анализ и улучшение

### Проверка производительности

- **Частота:** Каждые 4 часа
- **Действие:** Мониторинг без оптимизации
- **Автооптимизация:** При падении производительности ниже порога

## ⚙️ Настройка параметров

### Параметры оптимизации

В файле `auto_optimization_scheduler.py`:

```python
class AutoOptimizationScheduler:
    def __init__(self):
        self.performance_threshold = 0.6  # Минимальная оценка для применения
        self.config.optimization_trials = 25  # Количество испытаний
```

### Оптимизируемые параметры

- **EMA быстрая/медленная** - Периоды экспоненциальных скользящих средних
- **RSI период/максимум** - Параметры индикатора относительной силы
- **ATR период** - Период среднего истинного диапазона
- **TP/SL множители** - Множители для take profit и stop loss
- **Минимальный объем** - Фильтр по объему торгов

### Оценка производительности

Система использует комбинированную оценку:

```python
score = (
    win_rate * 0.3 +                    # Винрейт 30%
    min(profit_factor, 3) / 3 * 0.3 +   # Фактор прибыли 30%
    (1 - max_drawdown) * 0.2 +          # Максимальная просадка 20%
    max(0, sharpe_ratio) / 2 * 0.2      # Коэффициент Шарпа 20%

```

### Критерии применения параметров

Новые параметры применяются только если:

- Улучшение производительности > 5%
- Оценка выше порогового значения (0.6)
- Успешная оптимизация > 80% монет

def start_scheduler(self):

    # Еженедельная полная оптимизация в воскресенье в 8:00
