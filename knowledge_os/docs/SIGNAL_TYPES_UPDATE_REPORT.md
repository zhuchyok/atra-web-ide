## 📊 **Логика работы системы**

### **Схема отправки сигналов:**

```
1. Проверяем открытые позиции пользователя
   ├── Есть открытая позиция по монете
   │   ├── Отправляем DCA ТОРГОВЫЙ СИГНАЛ ✅
   │   └── НЕ отправляем НОВЫЙ ТОРГОВЫЙ СИГНАЛ ❌
   │
   └── НЕТ открытой позиции по монете
       ├── Отправляем НОВЫЙ ТОРГОВЫЙ СИГНАЛ ✅
       └── НЕ отправляем DCA ТОРГОВЫЙ СИГНАЛ ❌
```

### **Типы сигналов:**

#### **1. DCA ТОРГОВЫЙ СИГНАЛ:**

- **Когда отправляется**: Только если у пользователя есть открытая позиция по данной монете
- **Цель**: Усреднение существующей позиции
- **Содержание**:
  - Объем усреднения
  - Новая средняя цена
  - Обновленные TP1/TP2
  - Количество усреднений
  - Общий объем позиции

#### **2. НОВЫЙ ТОРГОВЫЙ СИГНАЛ:**

- **Когда отправляется**: Только если у пользователя НЕТ открытой позиции по данной монете
- **Цель**: Открытие новой позиции
- **Содержание**:
  - Цена входа
  - Take Profit уровни
  - Риск на сделку
  - Технический анализ
  - Новостная информация

## 🔧 **Технические детали**

### **Проверка открытых позиций:**

```python
user_positions = user_data.get('open_positions', [])
has_user_long = any(
    pos["symbol"] == symbol and pos.get("side", "long") == "long"
    for pos in user_positions
)
has_user_short = any(
    pos["symbol"] == symbol and pos.get("side", "long") == "short"
    for pos in user_positions
)
```

### **Логика блокировки:**

```python
# Если у пользователя есть открытая позиция по данной монете, пропускаем новые сигналы
if has_user_long or has_user_short:
    print(f"[DEBUG] {symbol}: Пользователь {user_id} имеет открытую позицию, пропускаем новые торговые сигналы")
    continue
```

## 📈 **Преимущества новой системы**

### **1. Четкое разделение сигналов:**

- **DCA ТОРГОВЫЙ СИГНАЛ** - для усреднения
- **НОВЫЙ ТОРГОВЫЙ СИГНАЛ** - для новых позиций

### **2. Правильная логика отправки:**

- Пользователи с открытыми позициями получают только DCA сигналы
- Пользователи без позиций получают только новые сигналы
- Нет дублирования или конфликтов

### **3. Улучшенная читаемость кода:**

- Добавлены комментарии для ясности
- Логика разделена на четкие блоки
- Легко понять, какой тип сигнала отправляется
