## 📊 ДОСТУПНЫЕ КОМАНДЫ

### **Основные команды:**

- `/start` - Начать работу с ботом
- `/help` - Справка по командам
- `/status` - Статус бота и системы
- `/balance` - Баланс пользователя
- `/positions` - Открытые позиции
- `/myreport` - Персональный отчет

### **Команды настроек:**

- `/set_balance` - Установить баланс
- `/set_risk` - Установить риск на сделку
- `/set_trade_mode` - Режим торговли (spot/futures)
- `/set_filter_mode` - Режим фильтров (strict/soft)
- `/set_trading_hours` - Часы торговли
- `/mode` - Режим (manual/auto)

### **Команды торговли:**

- `/accept` - Принять сигнал
- `/close` - Закрыть позицию
- `/close_all` - Закрыть все позиции
- `/trade_history` - История сделок

### **Команды отчетов:**

- `/report` - Общий отчет
- `/report_week` - Недельный отчет
- `/perf` - Производительность
- `/portfolio` - Портфель
- `/sentiment` - Рыночный сентимент
