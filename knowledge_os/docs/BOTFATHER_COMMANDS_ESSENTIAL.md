# 📋 Список команд для BotFather (только необходимые)

## 🎯 **ОСНОВНЫЕ КОМАНДЫ**

### 💰 **Управление депозитом**

```
set_balance - Установить депозит для торговли
balance - Показать текущий баланс и позиции
```

### 📊 **Торговля**

```
positions - Открытые позиции с P&L
myreport - Персональный торговый отчет
```

### ⚙️ **Настройки**

```
set_trade_mode - Выбор режима торговли (SPOT/FUTURES)
set_filter_mode - Выбор режима фильтров (Строгий/Мягкий)
```

### ✅ **Принятие сигналов**

```
accept - Принять торговый сигнал
```

### ❓ **Помощь**

```
help - Список всех команд
start - Начать работу с ботом
```

## 🔧 **АДМИНСКИЕ КОМАНДЫ**

### 📊 **Статистика и мониторинг**

```
status - Статус бота и последние сигналы
report - Отчет за день по всем пользователям
report_week - Отчет за неделю
```

### 👥 **Управление пользователями**

```
all_users - Список всех пользователей
user_stats - Статистика по конкретному пользователю
```

### 🚀 **Управление системой**

```
restart - Перезапуск системы сигналов
optimize - Запуск автоматической оптимизации
```
