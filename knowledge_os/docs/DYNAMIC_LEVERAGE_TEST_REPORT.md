# Отчет: Тестирование динамического плеча

## 🎯 Цель тестирования

Проверить, что система корректно использует динамическое плечо с минимальным значением 2x для фьючерсов вместо принудительного плеча 2x.

## ✅ Исправления, которые были внесены

### 1. Функция `calculate_user_leverage`

Добавлена проверка минимального плеча для фьючерсов:

```python
# Для фьючерсов минимальное плечо должно быть 2
if leverage < 2:
    leverage = 2
```

### 2. Логика в функциях обработки сигналов

Заменил принудительное плечо 2x на динамическое с пересчетом:

```python
# БЫЛО (НЕПРАВИЛЬНО):
leverage = user_data.get("leverage", 2)  # Принудительно 2x
if leverage <= 1:
    leverage = 2

# СТАЛО (ПРАВИЛЬНО):
leverage = user_data.get("leverage", 1)
if leverage <= 1:
    leverage = calculate_user_leverage(deposit, "futures", filter_mode)
```
