## 📊 ПРИМЕРЫ РАБОТЫ

### **Сценарий 1: Низкий volume_ratio (0.35), сильные индикаторы**

```
Базовый порог: 0.3
AI порог: 0.3 (базовый, нет метрик)
Компенсация: 0.21 (сильные индикаторы, 0.3 * 0.7)
Финальный: min(0.3, 0.21) = 0.21
Результат: ✅ Сигнал проходит (0.35 > 0.21)
```

### **Сценарий 2: Низкий volume_ratio (0.35), слабые индикаторы**

```
Базовый порог: 0.3
AI порог: 0.3 (базовый)
Компенсация: 0.3 (слабые индикаторы, без компенсации)
Финальный: min(0.3, 0.3) = 0.3
Результат: ✅ Сигнал проходит (0.35 > 0.3)
```

### **Сценарий 3: Очень низкий volume_ratio (0.15), сильные индикаторы**

```
Базовый порог: 0.3
AI порог: 0.3 (базовый)
Компенсация: 0.21 (сильные индикаторы)
Финальный: min(0.3, 0.21) = 0.21

```

### **Сценарий 4: Высокий Win Rate, AI ослабляет**

```

Результат: ✅ Сигнал проходит легче
```

### **Сценарий 5: Низкий Win Rate, AI ужесточает**

```

AI порог: 0.39 (низкий WR, ужесточает: 0.3 * 1.3)
Компенсация: 0.3 (средние индикаторы)
Финальный: min(0.39, 0.3) = 0.3
```
