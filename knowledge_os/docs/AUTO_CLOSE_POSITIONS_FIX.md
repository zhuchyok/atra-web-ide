# Исправление автоматического закрытия позиций при TP2

## 🎯 Проблема

Пользователь правильно заметил, что позиции **НЕ закрываются автоматически** при достижении тейк-профита. Функция `check_take_profits()` только отправляла уведомления, но не закрывала позиции.

## ❌ Что было неправильно:

- Позиции оставались в списке открытых позиций
- Баланс не пересчитывался
- Свободный депозит не обновлялся
- Позиции не перемещались в историю сделок

## ✅ Исправления

### 1. Добавлено автоматическое закрытие при TP2

**Было:**

```python
# Обновляем стадию позиции
pos['stage'] = 'tp2_reached'

# Отправляем уведомление
msg = f"✅ Позиция автоматически закрывается при достижении TP"
await notify_user(int(user_id), msg)
```

**Стало:**

```python
# АВТОМАТИЧЕСКОЕ ЗАКРЫТИЕ ПОЗИЦИИ ПРИ TP2
# Обновляем позицию как закрытую
pos['stage'] = 'closed'
pos['exit_price'] = tp2
pos['exit_time'] = get_msk_now().strftime("%Y-%m-%dT%H:%M:%S")
pos['profit'] = profit

# Перемещаем позицию в историю
trade_history = user_data.get('trade_history', [])
trade_history.append(pos.copy())
user_data['trade_history'] = trade_history

# Удаляем позицию из открытых
open_positions.remove(pos)

# Обновляем баланс пользователя
total_profit = user_data.get('total_profit', 0) + profit
user_data['total_profit'] = total_profit

# Пересчитываем свободный депозит
deposit = user_data.get('deposit', 0)
free_deposit = deposit + total_profit
user_data['free_deposit'] = free_deposit

# Отправляем уведомление
msg = f"✅ Позиция автоматически закрыта!"
await notify_user(int(user_id), msg)
```

### 2. Добавлен импорт get_msk_now

```python
# Импортируем get_msk_now для временных меток
from utils import get_msk_now
```

## 🔧 Что теперь происходит при достижении TP2:

### 1. **Закрытие позиции:**

- Стадия меняется на `'closed'`
- Добавляется цена выхода (`exit_price`)
- Добавляется время закрытия (`exit_time`)
- Добавляется прибыль (`profit`)

### 2. **Перемещение в историю:**

- Позиция копируется в `trade_history`
- Удаляется из `open_positions`

### 3. **Обновление баланса:**

- Обновляется `total_profit`
- Пересчитывается `free_deposit`

### 4. **Уведомление:**

- Отправляется сообщение "Позиция автоматически закрыта!"
