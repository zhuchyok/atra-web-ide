# 🟢 ИНДИКАТОР "АНОМАЛИЯ"

## 📋 Описание

Индикатор "Аномалия" показывает соотношение объема торгов за 24 часа к рыночной капитализации монеты. Этот индикатор помогает определить, когда торговля монетой становится аномально активной, что может указывать на потенциальные возможности или риски.

## 🎯 Система индикации кружков

Индикатор использует систему визуальных кружков для отображения уровня активности:

| Кружки      | Соотношение объема к капитализации | Описание                      |
| ----------- | ---------------------------------- | ----------------------------- |
| Без кружков | < 60%                              | **Нормальный объем торгов**   |
| 🟢          | 60% - 100%                         | **Повышенная активность**     |
| 🟢🟢        | 100% - 120%                        | **Высокая активность**        |
| 🟢🟢🟢      | 120% - 140%                        | **Аномальная активность** ⚠️  |
| 🟢🟢🟢🟢    | 140% - 160%                        | **Критическая активность** ⚠️ |
| 🟢🟢🟢🟢🟢  | > 160%                             | **Максимальная аномалия** ⚠️  |

## 🔧 Техническая реализация

### Функции

1. **`get_market_cap_data(symbol)`** - получает данные о капитализации и объеме с CoinGecko API
2. **`calculate_anomaly_indicator(volume_24h, market_cap)`** - рассчитывает индикатор аномалии
3. **`get_anomaly_emoji(circles_count)`** - возвращает эмодзи для визуализации
4. **`get_anomaly_indicator(symbol)`** - основная функция получения индикатора

### Интеграция в сигналы

Индикатор автоматически добавляется во все торговые сигналы:

- **Новые торговые сигналы**
- **DCA сигналы**
- **Накопленные DCA сигналы**

## 🎯 Практическое применение

### Торговые стратегии

1. **Консервативная стратегия**
   - Входить только при нормальной активности (0-1 кружок)
   - Избегать аномальных ситуаций

2. **Агрессивная стратегия**
   - Искать возможности при аномальной активности (3+ кружка)
   - Быстрые входы и выходы

3. **Смешанная стратегия**
   - Нормальная активность для долгосрочных позиций
   - Аномальная активность для скальпинга

### Риск-менеджмент

- **Высокая аномалия** может указывать на:
  - Манипуляции рынка
  - Новости или события
  - Временную нестабильность

- **Низкая активность** может означать:
  - Стабильный рынок
  - Отсутствие интереса
  - Низкую ликвидность

## ⚠️ Ограничения

1. **API лимиты** - CoinGecko имеет ограничения на запросы
2. **Задержка данных** - данные могут быть с задержкой до 24 часов
3. **Волатильность** - соотношение может быстро меняться
4. **Контекст** - нужно учитывать общую рыночную ситуацию

## 🔄 Обновления

Индикатор обновляется:

- При каждом новом торговом сигнале
- При формировании DCA сигналов
- При обработке накопленных сигналов

Данные кэшируются для оптимизации производительности и снижения нагрузки на API.
