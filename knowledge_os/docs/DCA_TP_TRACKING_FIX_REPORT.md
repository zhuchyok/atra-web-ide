# Отчет об исправлении отслеживания TP для DCA позиций

**Дата:** 5 октября 2025
**Статус:** 🔍 Диагностика завершена, исправление в процессе

## 🐛 Проблема

Пользователь сообщил:

> "был сигнал дца для TUTUSDT
> я усреднился по данному сигналу
> тп1 и тп2 были достигнуты и позиция закрылась
> но уведомления о тп1 и тп2 не приходили (видимо на дца не приходит или не учитывает/не отслеживает тп1 и тп2 новые с учетом усреднения что мы усреднились и теперь новые тп1 и тп2 а не старые)"

### Сигнал DCA:

```
📈 DCA позиция добавлена!

🔸 Символ: TUTUSDT
🔸 DCA #3
🔸 Цена входа: 0.10
🔸 Количество: 1308.768751
🔸 Плечо: 5.0x
🔸 Риск: 130.00
🔸 Сумма входа: 130
🔸 Средняя цена: 0.10
🔸 TP1: 0.10 (+0.81% / +4.05% с плечом)
🔸 TP2: 0.10 (+0.98% / +4.89% с плечом)
```

### Результат:

- ✅ Позиция закрылась по TP1 и TP2
- ❌ Уведомления о достижении TP1 и TP2 НЕ пришли

## 🔍 Диагностика

### Причина проблемы:

После принятия DCA сигнала система:

1. ✅ **Правильно** рассчитывает новую среднюю цену
2. ✅ **Правильно** рассчитывает новые TP1 и TP2 от новой средней цены
3. ✅ **Правильно** обновляет `qty`, `entry_price`, `n_dca` в позиции
4. ❌ **НЕ обновляет** `tp1` и `tp2` в существующей позиции

Это означает, что функция `check_take_profits()` продолжает отслеживать **старые TP1 и TP2** (от первого входа), а не новые, рассчитанные от новой средней цены после усреднения.

### Пример проблемы:

**Первый вход:**

- Цена входа: 0.12
- TP1: 0.1212 (+1%)
- TP2: 0.1224 (+2%)

**После DCA #3:**

- Новая средняя цена: 0.10
- Новые TP1: 0.10081 (+0.81%)
- Новые TP2: 0.10098 (+0.98%)
- **Но в позиции остались старые TP1: 0.1212 и TP2: 0.1224**

Когда цена достигает 0.10081 и 0.10098, система проверяет старые TP (0.1212 и 0.1224), которые не достигнуты, и не отправляет уведомления.

## ✅ Решение

### Необходимо обновить код обновления позиции после DCA:

**БЫЛО:**

```python
# Обновляются только базовые параметры
existing_position["qty"] = total_qty
existing_position["entry_price"] = avg_price_new
existing_position["n_dca"] = existing_position.get("n_dca", 0) + 1
existing_position["risk_amount"] = existing_position.get("risk_amount", 0) + dca_risk_amount
existing_position["risk_pct"] = dynamic_risk_pct
existing_position["leverage"] = dynamic_leverage
```

**ДОЛЖНО БЫТЬ:**

```python
# Обновляются ВСЕ параметры включая TP1 и TP2
existing_position["qty"] = total_qty
existing_position["entry_price"] = avg_price_new
existing_position["n_dca"] = existing_position.get("n_dca", 0) + 1
existing_position["risk_amount"] = existing_position.get("risk_amount", 0) + dca_risk_amount
existing_position["risk_pct"] = dynamic_risk_pct
existing_position["leverage"] = dynamic_leverage
# КРИТИЧЕСКИ ВАЖНО: обновляем TP1 и TP2 с новыми значениями
existing_position["tp1"] = tp1  # Новый TP1 от новой средней цены
existing_position["tp2"] = tp2  # Новый TP2 от новой средней цены
```

### Где находится код обновления позиции:

Согласно документации, код обновления позиции находится в:

1. **`telegram_handlers.py`** - функция `handle_accept_button()` (обработка кнопки принятия DCA сигнала)
2. **`telegram_bot_trading.py`** - функция `accept_signal_cmd()` (обработка команды `/accept` для DCA)

### Файлы для исправления:

1. **`telegram_handlers.py`** - добавить обновление `tp1` и `tp2` при обработке DCA кнопки
2. **`telegram_bot_trading.py`** - добавить обновление `tp1` и `tp2` при обработке DCA команды

## 🎯 Ожидаемый результат после исправления:

1. ✅ При принятии DCA сигнала система обновит `tp1` и `tp2` в позиции
2. ✅ Функция `check_take_profits()` будет отслеживать **новые TP1 и TP2**
3. ✅ Уведомления о достижении TP1 и TP2 будут приходить корректно
4. ✅ Позиция будет закрываться по новым TP с отправкой уведомлений
