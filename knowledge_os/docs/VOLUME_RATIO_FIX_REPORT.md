## 🔧 РЕШЕНИЕ

### **✅ РЕАЛИЗОВАННЫЕ ИСПРАВЛЕНИЯ:**

#### **1. Добавлена функция calculate_volume_ratio:**

```python
def calculate_volume_ratio(df, current_index, lookback=20):
    """
    Рассчитывает volume_ratio на основе доступных данных

    Приоритеты:
    1. Реальные данные volume (если есть)
    2. ATR как прокси для объема
    3. Волатильность как прокси для объема
    4. Константа 1.0 как fallback
    """
```

#### **2. Многоуровневая логика расчета:**

**Уровень 1: Реальные данные объема**

```python
if 'volume' in df.columns and len(df) > lookback:
    current_volume = df['volume'].iloc[current_index]
    avg_volume = df['volume'].iloc[start_idx:current_index + 1].mean()
    return current_volume / avg_volume
```

**Уровень 2: ATR как прокси**

```python
elif 'atr' in df.columns and len(df) > lookback:
    current_atr = df['atr'].iloc[current_index]
    avg_atr = df['atr'].iloc[start_idx:current_index + 1].mean()
    return current_atr / avg_atr
```

**Уровень 3: Волатильность как прокси**

```python
elif 'volatility' in df.columns and len(df) > lookback:
    current_volatility = df['volatility'].iloc[current_index]
    avg_volatility = df['volatility'].iloc[start_idx:current_index + 1].mean()
    return current_volatility / avg_volatility
```

#### **3. Заменены константы на вызовы функции:**

**До исправления:**

```python
df["volume_ratio"] = 1.0  # Константа
```

**После исправления:**

```python
df["volume_ratio"] = calculate_volume_ratio(df, len(df) - 1)  # Реальный расчет
```

#### **4. Добавлен пересчет для всех точек данных:**

```python
# Пересчитываем volume_ratio после расчета ATR и volatility
for i in range(len(df)):
    df.loc[df.index[i], "volume_ratio"] = calculate_volume_ratio(df, i)
```
