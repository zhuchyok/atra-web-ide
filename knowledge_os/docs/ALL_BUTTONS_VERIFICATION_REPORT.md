## 🚀 **ДЕТАЛЬНЫЙ АНАЛИЗ**

### **1. Парсинг кнопок:**

```python
# accept_BTCUSDT_50000_52000_long
parts = ['accept', 'BTCUSDT', '50000', '52000', 'long']
symbol = parts[1]  # BTCUSDT
entry_price = float(parts[2])  # 50000
tp_price = float(parts[3])  # 52000
side = parts[4]  # long

# close_BTCUSDT
parts = ['close', 'BTCUSDT']
symbol = parts[1]  # BTCUSDT

# dca_ETHUSDT_3000_3300_long_2
parts = ['dca', 'ETHUSDT', '3000', '3300', 'long', '2']
symbol = parts[1]  # ETHUSDT
entry_price = float(parts[2])  # 3000
tp_price = float(parts[3])  # 3300
side = parts[4]  # long
dca_count = int(parts[5])  # 2
```

### **2. Логика кнопки принятия:**

```python
# Расчет параметров
risk_amount = deposit * (risk_pct / 100)  # 1000 * 0.02 = 20 USDT
qty = risk_amount / entry_price  # 20 / 50000 = 0.0004

# Создание позиции
position = {
    'symbol': symbol,
    'side': side,
    'entry_price': entry_price,
    'tp_price': tp_price,
    'qty': qty,
    'status': 'open'
}

# Обновление баланса
user_data['balance'] = deposit - risk_amount  # 1000 - 20 = 980 USDT
```

### **3. Логика кнопки закрытия:**

```python
# Поиск позиции
for pos in positions:
    if pos.get('symbol') == symbol and pos.get('status') == 'open':
        position_to_close = pos

# Расчет PnL
if side == 'long':
    pnl = (current_price - entry_price) * qty
else:
    pnl = (entry_price - current_price) * qty

# Обновление баланса
user_data['balance'] += pnl

# Перемещение в историю
user_data['trade_history'].append(position_to_close)
```

### **4. Логика кнопки DCA:**

```python
# Создание DCA позиции
position = {
    'symbol': symbol,
    'side': side,
    'entry_price': entry_price,
    'tp_price': tp_price,
    'qty': qty,
    'dca_count': dca_count,  # Учет количества DCA
    'status': 'open'
}
```

### **5. Логика кнопки подтверждения:**

```python
# Массовое закрытие позиций
for pos in user_data['positions']:
    if pos.get('status') == 'open':
        pos['status'] = 'closed'
        pos['close_time'] = datetime.now().isoformat()
        closed_count += 1

# Перемещение в историю
user_data['trade_history'].extend([pos for pos in user_data['positions'] if pos.get('status') == 'closed'])
```
