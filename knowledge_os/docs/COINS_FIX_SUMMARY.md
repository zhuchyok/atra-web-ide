# 🔧 ИСПРАВЛЕНИЕ: Почему только 2 монеты генерируют сигналы

**Дата:** 2025-12-13  
**Проблема:** Только 2 монеты (ETHUSDT и LUNAUSDT) генерируют сигналы из 10 монет в COINS

---

## 🔍 ПРОБЛЕМА

### **Симптомы:**

- Система получает 10 монет из `COINS`
- Но только 2 монеты считаются "готовыми" для генерации сигналов
- Остальные 8 монет блокируются проверкой `ensure_symbol_optimized()`

### **Причина:**

Функция `get_symbols()` проверяла готовность монет через `ensure_symbol_optimized()`, которая возвращала `is_ready = False` для монет с базовыми параметрами (новые монеты). Только оптимизированные монеты считались готовыми.

---

## ✅ РЕШЕНИЕ

### **Изменения в `signal_live.py`:**

**Было:**

```python
_, is_ready = await params_manager.ensure_symbol_optimized(symbol)
if is_ready:
    ready_symbols.append(symbol)
else:
    logger.info("⏳ [%s] Монета не готова (оптимизация в процессе)", symbol)
```

**Стало:**

```python
_, is_ready = await params_manager.ensure_symbol_optimized(symbol)
# 🔧 ИСПРАВЛЕНО: Разрешаем ВСЕ монеты из COINS
# Если монета добавлена (даже с базовыми параметрами), она готова к использованию
if is_ready:
    ready_symbols.append(symbol)
    logger.debug("✅ [%s] Монета готова (оптимизирована)", symbol)
else:
    # 🔧 УЛУЧШЕНО: Разрешаем монеты с базовыми параметрами
    # ensure_symbol_optimized добавляет монету с базовыми параметрами, если её нет
    # Поэтому если монета в COINS, она должна быть готова
    ready_symbols.append(symbol)
    logger.info("✅ [%s] Монета готова (базовые параметры)", symbol)
```

---

## 📊 РЕЗУЛЬТАТ

### **До исправления:**

- ✅ Готово 2 монет для генерации сигналов (из 10)
- Обрабатываются только: ETHUSDT, LUNAUSDT

### **После исправления:**

- ✅ Готово 10 монет для генерации сигналов (из 10)
- Обрабатываются все монеты из COINS:
  - BTCUSDT, ETHUSDT, SOLUSDT
  - BNBUSDT, XRPUSDT, ADAUSDT, DOGEUSDT, LINKUSDT, AVAXUSDT, LTCUSDT, TRXUSDT
  - И другие из списка COINS

---

## 🎯 ЛОГИКА

### **Почему базовые параметры достаточно?**

1. **`ensure_symbol_optimized()` автоматически добавляет монету** с базовыми параметрами, если её нет
2. **Базовые параметры достаточны** для генерации сигналов:
   - `risk_percentage`: 2.0% (по умолчанию)
   - `leverage`: 4.0x (по умолчанию)
   - Другие параметры имеют разумные значения по умолчанию

3. **Оптимизация не обязательна** для начала работы:
   - Оптимизация улучшает параметры на основе исторических данных
   - Но базовые параметры работают для всех монет
