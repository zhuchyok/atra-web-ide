## 📱 Логика обработки ошибок

### Новая стратегия:

```python
for attempt in range(max_retries):  # max_retries = 1
    try:
        # Попытка получения новостей
        response = await session.get(url, params=params, timeout=10)

        if response.status == 200:
            # Успешное получение
            return process_news(response.json())
        elif response.status == 429:  # Rate limit
            print(f"API rate limit, попытка {attempt + 1}/{max_retries}")
            # Больше не повторяем - сразу выходим
            return []
        else:
            # Другие ошибки - сразу выходим
            return []

    except Exception as e:
        print(f"API ошибка: {e}, попытка {attempt + 1}/{max_retries}")
        # Больше не повторяем - сразу выходим
        return []
```

### Преимущества:

- **Быстрый выход** при ошибках
- **Меньше времени ожидания**
- **Сохранение кэша** для повторного использования
