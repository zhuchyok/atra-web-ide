# 📊 СТАТУС МАССОВОГО СКРИНИНГА

## ✅ ЗАПУЩЕНО

**Дата запуска**: 2025-01-XX  
**Процесс**: `mass_screening_by_correlation_groups.py`  
**PID**: Проверьте через `ps aux | grep mass_screening`

## 📋 ЧТО ДЕЛАЕТ СКРИПТ

1. **Загружает все монеты** из `data/backtest_data/` (~101 монета)
2. **Вычисляет корреляцию** каждой монеты к BTC, ETH, SOL
3. **Группирует монеты** по корреляционным группам:
   - BTC_HIGH (>0.75 к BTC)
   - ETH_HIGH (>0.75 к ETH)
   - SOL_HIGH (>0.75 к SOL)
4. **Запускает годовой бектест** (365 дней) для каждой монеты
5. **Выбирает топ-5 монет** из каждой группы по комбинированному скору

## ⏱️ ОЖИДАЕМОЕ ВРЕМЯ

- **~2-4 часа** (зависит от количества монет и производительности)
- Каждая монета: ~1-2 минуты на годовой бектест
