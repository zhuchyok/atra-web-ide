## 📋 СЛЕДУЮЩИЕ ШАГИ (НА СЕРВЕРЕ)

1. **Восстановить БД:**

   ```bash
   python scripts/restore_db_on_server.py
   ```

2. **Установить зависимости:**

   ```bash
   pip install numpy lightgbm scikit-learn
   ```

3. **Обучить ML модели:**

   ```bash
   python scripts/retrain_lightgbm.py
   ```

4. **Запустить бота:**

   ```bash
   systemctl start atra-bot
   ```

5. **Проверить работу:**
   - Проверить логи
   - Проверить генерацию сигналов
   - Проверить отправку в Telegram
