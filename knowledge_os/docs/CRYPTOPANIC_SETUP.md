# 🔥 Настройка Crypto Panic API

## 📋 Описание

Crypto Panic - это агрегатор новостей о криптовалютах, который предоставляет API для получения свежих новостей с анализом настроений.

## 🚀 Получение API ключа

### 1. Регистрация

1. Перейдите на https://cryptopanic.com/
2. Зарегистрируйтесь или войдите в аккаунт
3. Перейдите в раздел "Developers" → "API"

### 2. Получение ключа

1. Нажмите "Get API Key"
2. Выберите бесплатный план (Free)
3. Скопируйте полученный API ключ

### 3. Настройка в проекте

1. Откройте файл `.env`
2. Добавьте строку:

```bash
CRYPTOPANIC_API_KEY=ваш_api_ключ_здесь
```

## 🔧 Возможности API

### Фильтры новостей

- `hot` - горячие новости
- `rising` - растущие в популярности
- `important` - важные новости
- `saved` - сохраненные
- `lol` - забавные

### Анализ настроений

- `positive` - позитивные новости
- `negative` - негативные новости
- `neutral` - нейтральные новости

### Голосование

- Пользователи голосуют за новости
- Учитывается соотношение положительных/отрицательных голосов

## 📊 Интеграция в систему

### Автоматическая классификация

Система автоматически классифицирует новости на основе:

1. **Sentiment** - настроение от Crypto Panic
2. **Votes** - голоса пользователей
3. **Ключевые слова** - из конфигурации

### Приоритеты

1. **Crypto Panic sentiment** - если доступен
2. **Голоса пользователей** - если sentiment нейтральный
3. **Ключевые слова** - как fallback

## 🔄 Обновление настроек

### Изменение фильтра

В файле `signal_live.py` в функции `get_cryptopanic_news`:

```python
params = {
    'auth_token': CRYPTOPANIC_API_KEY,
    'currencies': base_symbol,
    'filter': 'hot',  # Измените на нужный фильтр
    'public': 'true'
}
```

### Добавление новых валют

Система автоматически обрабатывает все валюты, доступные в Crypto Panic.

## 📈 Мониторинг

### Логи системы

```
[NewsFilter] CryptoPanic: получено 5 новостей для BTCUSDT
[NewsFilter] Получено новостей: TradingView=1, CoinGecko=2, CryptoPanic=5, Итого уникальных=8
```

### Ошибки

- `400` - Неверный API ключ
- `429` - Превышен лимит запросов
- `500` - Ошибка сервера

## 🎯 Рекомендации

### Для продакшена

1. Используйте платный план для большего количества запросов
2. Настройте мониторинг ошибок API
3. Добавьте кэширование для оптимизации

### Для разработки

1. Используйте бесплатный план для тестирования
2. Добавьте fallback на другие источники новостей
3. Тестируйте с разными валютами
