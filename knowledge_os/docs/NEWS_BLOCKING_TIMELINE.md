# Время блокировки сигналов по новостям

## 📋 Обзор системы блокировки

Система блокировки сигналов работает на основе анализа новостей и применяет различные временные ограничения в зависимости от типа новости и режима торговли пользователя.

## ⏰ Временные параметры блокировки

### 1. **Блокировка по негативным новостям**

```python
# config.py
NEWS_SETTINGS = {
    "negative_block_hours": 2,   # Блокировка по негативным новостям (часы)
}
```

**Время блокировки: 2 часа**

### 2. **Кэширование позитивных новостей**

```python
# signal_live.py
CACHE_TTL = {
    'positive': 7200,     # 2 часа для позитивных новостей
}
```

**Время кэширования: 2 часа**

### 3. **Кэширование заблокированных монет**

```python
# signal_live.py
CACHE_TTL = {
    'blocked': 3600,      # 1 час для заблокированных
}
```

**Время кэширования: 1 час**

## 🎯 Логика блокировки по типам торговли

### **СПОТ торговля (LONG)**

#### **Негативная новость:**

- **Блокировка**: ✅ **ДА**
- **Время**: **2 часа** с момента публикации новости
- **Логика**: `block_until = published + timedelta(hours=NEWS_SETTINGS["negative_block_hours"])`
- **Результат**: Все LONG сигналы блокируются на 2 часа

#### **Позитивная новость:**

- **Блокировка**: ❌ **НЕТ**
- **Время**: **НЕ ПРИМЕНЯЕТСЯ**
- **Логика**: Позитивные новости усиливают LONG сигналы
- **Результат**: LONG сигналы отправляются с пометкой "усилен новостями"

### **ФЬЮЧЕРСЫ торговля (LONG)**

#### **Негативная новость:**

- **Блокировка**: ✅ **ДА**
- **Время**: **2 часа** с момента публикации новости
- **Логика**: Аналогично SPOT
- **Результат**: Все LONG сигналы блокируются на 2 часа

#### **Позитивная новость:**

- **Блокировка**: ❌ **НЕТ**
- **Время**: **НЕ ПРИМЕНЯЕТСЯ**
- **Логика**: Позитивные новости усиливают LONG сигналы
- **Результат**: LONG сигналы отправляются с пометкой "усилен новостями"

### **ФЬЮЧЕРСЫ торговля (SHORT)**

#### **Негативная новость:**

- **Блокировка**: ❌ **НЕТ**
- **Время**: **НЕ ПРИМЕНЯЕТСЯ**
- **Логика**: Негативные новости = сигнал SHORT для фьючерсов
- **Результат**: SHORT сигналы отправляются с пометкой "усилен новостями"

#### **Позитивная новость:**

- **Блокировка**: ✅ **ДА** (зависит от режима)
- **Время**: **2 часа** с момента публикации новости
- **Логика**: `if positive_news_flag and mode_settings['block_short_on_positive']`
- **Результат**: SHORT сигналы блокируются на 2 часа

## 🔧 Режимы новостного фильтра

### **1. Conservative (Консервативный)**

```python
"conservative": {
    "enable_negative_news": True,    # Блокировать по негативным новостям
    "enable_positive_news": True,    # Генерировать LONG по позитивным
    "block_short_on_positive": True, # Блокировать SHORT при позитивных
}
```

**Время блокировки SHORT при позитивных новостях: 2 часа**

### **2. Aggressive (Агрессивный)**

```python
"aggressive": {
    "enable_negative_news": False,   # НЕ блокировать по негативным новостям
    "enable_positive_news": True,    # Генерировать LONG по позитивным
    "block_short_on_positive": False, # НЕ блокировать SHORT при позитивных
}
```

**Время блокировки SHORT при позитивных новостях: НЕ ПРИМЕНЯЕТСЯ**

### **3. Technical Only (Только технический анализ)**

```python
"technical_only": {
    "enable_negative_news": False,   # НЕ блокировать по негативным новостям
    "enable_positive_news": False,   # НЕ генерировать по позитивным новостям
    "block_short_on_positive": False, # НЕ блокировать SHORT
}
```

**Время блокировки SHORT при позитивных новостях: НЕ ПРИМЕНЯЕТСЯ**

### **4. News Only (Только новостные сигналы)**

```python
"news_only": {
    "enable_negative_news": True,    # Блокировать по негативным новостям
    "enable_positive_news": True,    # Генерировать LONG по позитивным
    "block_short_on_positive": True, # Блокировать SHORT при позитивных
}
```

**Время блокировки SHORT при позитивных новостях: 2 часа**

## 🔄 Логика расчета времени блокировки

### **Для негативных новостей:**

```python
# signal_live.py строка 1419
block_until = published + timedelta(hours=NEWS_SETTINGS["negative_block_hours"])
set_cache('blocked', symbol, block_until)
```

**Пример:**

- Новость опубликована: 14:00
- Время блокировки: 14:00 + 2 часа = **16:00**
- Блокировка снимается: **16:00**

### **Для позитивных новостей (SHORT блокировка):**

```python
# Логика аналогична негативным новостям
block_until = published + timedelta(hours=NEWS_SETTINGS["negative_block_hours"])  # 2 часа
```

**Пример:**

- Позитивная новость: 15:30
- Время блокировки SHORT: 15:30 + 2 часа = **17:30**
- Блокировка SHORT снимается: **17:30**

## 🎯 Специальные случаи

### **1. Кэширование заблокированных монет**

```python
# Кэш заблокированных монет на 1 час
CACHE_TTL = {
    'blocked': 3600,      # 1 час для заблокированных
}
```

**Логика:**

- Монета заблокирована на 2 часа по новости
- Кэш заблокированных монет: 1 час
- **Результат**: Блокировка может быть снята через 1 час (кэш), но логика проверяет реальное время блокировки

### **2. Свежесть новостей**

```python
# config.py
NEWS_SETTINGS = {
    "freshness_hours": 2,        # Свежесть новостей (часы)
}
```

**Логика:**

- Только новости за последние 2 часа учитываются
- Старые новости не влияют на блокировку
- **Результат**: Блокировка автоматически снимается через 2 часа после публикации
