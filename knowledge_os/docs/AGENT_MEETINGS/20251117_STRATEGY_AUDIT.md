## 2. Анализ от агентов

### signal_live (генерация сигналов)

**Анализ текущей логики (на основе кода):**

1. **Точки входа (реальная реализация):**
   - **LONG Classic:** EMA кроссовер (`current_price > ema_fast and ema_fast > ema_slow`)
   - **LONG Alternative 3:** Отскок от минимума + объем + проверка `current_price > bb_lower`
   - **SHORT Classic:** Обратный EMA кроссовер (`current_price < ema_fast and ema_fast < ema_slow`)
   - **SHORT Alternative:** EMA близко к кроссоверу + медвежий бар + объем
   - Bollinger Bands используются **только как дополнительная проверка**, не как основной триггер
   - RSI, MACD, EMA для подтверждения тренда
   - Новые фильтры: Dominance, Interest Zones, Fibonacci, Volume Imbalance

2. **Выявленные проблемы (на основе кода):**
   - ❌ **Bollinger Bands используется минимально** - только в альтернативном паттерне 3 (строка 2523)
   - ❌ **Нет проверки структуры рынка** - не определяется тренд/флэт/разворот
   - ❌ **Нет проверки качества входа** - не проверяется расстояние от локального экстремума
   - ❌ **Отсутствуют свечные паттерны** - нет проверки поглощения, пин-баров, доджи
   - ❌ **EMA кроссовер может быть запоздалым** - вход происходит после начала движения
   - ❌ **Нет использования ADX** - не определяется сила тренда
   - ❌ **Volume используется только для фильтрации** - не для подтверждения входа

3. **Рекомендации:**
   - ✅ **Убрать зависимость от Bollinger Bands** - использовать только как опциональный фильтр
   - ✅ **Добавить определение структуры рынка** - тренд/флэт через EMA и структуру свечей
   - ✅ **Добавить проверку качества входа** - расстояние от локального экстремума (ATR-based)
   - ✅ **Интегрировать свечные паттерны** - поглощение, пин-бары для подтверждения
   - ✅ **Добавить ADX** - для определения силы тренда и фильтрации слабых сигналов
   - ✅ **Улучшить использование Volume** - Volume Profile для зон интереса

## 3. Консолидация выводов

### Ключевые недостатки (на основе анализа кода):

1. **Bollinger Bands используется минимально:**
   - ✅ **ХОРОШО:** BB не является основным триггером (используется только в альтернативном паттерне 3)
   - ❌ **ПРОБЛЕМА:** BB используется только как проверка `current_price > bb_lower` (строка 2523)
   - ❌ **ПРОБЛЕМА:** В AI score calculation BB используется для бонуса (строка 1493-1495), но это может давать ложные сигналы

2. **Отсутствие структуры рынка:**
   - ❌ Нет определения тренд/флэт/разворот перед входом
   - ❌ EMA кроссовер может работать в флэте (много ложных сигналов)
   - ❌ Нет привязки к ключевым уровням перед входом (только Interest Zones фильтр)

3. **Качество входа:**
   - ❌ Нет проверки расстояния от локального экстремума
   - ❌ Вход происходит по текущей цене без ожидания подтверждения
   - ❌ Нет использования свечных паттернов (поглощение, пин-бары, доджи)
   - ❌ EMA кроссовер может быть запоздалым (вход после начала движения)

4. **Недостаточное использование индикаторов:**
   - ❌ Нет ADX для определения силы тренда
   - ❌ Volume используется только для фильтрации, не для подтверждения входа
   - ❌ Нет Volume Profile для зон интереса
   - ❌ Нет Momentum индикатора для подтверждения движения

5. **Логика входа:**
   - ❌ LONG Classic: только EMA кроссовер (`current_price > ema_fast and ema_fast > ema_slow`)
   - ❌ Нет проверки, что цена откатилась к поддержке перед входом
   - ❌ Нет использования лимитных ордеров для лучшего входа

### Рекомендации по улучшению:

#### Фаза 1: Улучшение точек входа (приоритет: ВЫСОКИЙ)

1. **Улучшить логику входа (заменить EMA кроссовер):**
   - ❌ **УБРАТЬ:** Текущий EMA кроссовер как основной триггер (запоздалый вход)
   - ✅ **ДОБАВИТЬ:** Вход на откате к поддержке/сопротивлению (EMA, Фибоначчи, Interest Zones)
   - ✅ **ДОБАВИТЬ:** Проверка структуры рынка (тренд/флэт) перед входом
   - ✅ **ДОБАВИТЬ:** ADX для определения силы тренда (фильтровать слабые тренды)

2. **Добавить проверку структуры рынка:**
   - Определение тренда через EMA и структуру свечей
   - Определение флэта через диапазон цен (ATR-based)
   - Разные стратегии для тренда и флэта:
     - **Тренд:** Вход на откате к поддержке/сопротивлению
     - **Флэт:** Вход на границах диапазона

3. **Улучшить качество входа:**
   - Проверка расстояния от локального экстремума (ATR-based)
   - Подтверждение свечным паттерном (поглощение, пин-бары)
   - Использование лимитных ордеров на уровнях (поддержка/сопротивление/Фибоначчи)

4. **Оптимизировать использование Bollinger Bands:**
   - ✅ **ОСТАВИТЬ:** BB как опциональный фильтр перекупленности/перепроданности
   - ❌ **УБРАТЬ:** BB из основного триггера входа
   - ✅ **ИСПОЛЬЗОВАТЬ:** BB только для подтверждения (не для входа)

#### Фаза 2: Дополнительные фильтры (приоритет: СРЕДНИЙ)

1. **Свечные паттерны:**
   - Поглощение (engulfing)
   - Пин-бары (pin bars)
   - Доджи (doji)
   - Хаммеры (hammers)

2. **Volume Profile:**
   - Определение зон интереса через Volume Profile
   - Входы в зонах высокой ликвидности

3. **Momentum индикатор:**
   - Подтверждение движения

  - Автоматический выбор стратегии на основе режима рынка

  - Адаптивный расчет риска на основе качества входа

  - Использование адаптивной конфигурации при генерации сигналов
  - Автоматическое переключение между стратегиями

**Стратегии по режимам рынка:**

1. **TREND_UP / TREND_DOWN** → `TrendFollowingStrategy`
   - min_quality_score: 0.7 (строгие требования)
   - require_trend: True
   - Адаптивный риск: до 3% для высококачественных сигналов

2. **RANGE** → `RangeTradingStrategy`
   - min_quality_score: 0.65 (менее строгие требования)
   - require_trend: False (разрешаем входы в флэте)
   - Адаптивный риск: до 2% (уменьшенный)

3. **VOLATILE** → `BreakoutStrategy`
   - min_quality_score: 0.68 (средние требования)
   - require_trend: False
   - Адаптивный риск: до 2.4%

4. **REVERSAL** → `ReversalStrategy`
   - min_quality_score: 0.75 (очень строгие требования)
   - require_trend: False
   - Адаптивный риск: до 1.5% (минимальный)

**Конфигурация:**

# config.py
USE_ADAPTIVE_STRATEGY = True  # Включено по умолчанию

    "enable_adaptive_risk": True,  # Включить адаптивный риск
    "max_risk_multiplier": 1.5,  # Максимальный множитель (для высококачественных сигналов)
