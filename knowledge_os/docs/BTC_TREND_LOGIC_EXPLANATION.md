## 🎯 **ПРАВИЛА ГЕНЕРАЦИИ СИГНАЛОВ**

### ✅ **LONG сигналы формируются:**

- **При БЫЧЬЕМ тренде BTC** (btc_trend_status = True)
- **ИЛИ при отключенном фильтре BTC** (USE_BTC_TREND_FILTER = False)

### ✅ **SHORT сигналы формируются:**

- **При МЕДВЕЖЬЕМ тренде BTC** (btc_trend_status = False)
- **ИЛИ при отключенном фильтре BTC** (USE_BTC_TREND_FILTER = False)

## 🔧 **ТЕХНИЧЕСКАЯ РЕАЛИЗАЦИЯ**

### 1. **Определение тренда BTC:**

```python
def btc_trend_filter_soft(df_btc):
    """Мягкий фильтр тренда биткоина: только цена > EMA200"""
    df_btc["ema200"] = ta.trend.EMAIndicator(df_btc["close"], window=200).ema_indicator()
    df_btc["trend"] = df_btc["close"] > df_btc["ema200"]
    return df_btc["trend"]

def btc_trend_filter(df_btc):
    """Строгий фильтр тренда биткоина: цена > EMA200 И EMA25 растёт"""
    df_btc["ema200"] = ta.trend.EMAIndicator(df_btc["close"], window=200).ema_indicator()
    df_btc["ema25"] = ta.trend.EMAIndicator(df_btc["close"], window=25).ema_indicator()
    df_btc["trend"] = (df_btc["close"] > df_btc["ema200"]) & (df_btc["ema25"].diff() > 0)
    return df_btc["trend"]
```

### 2. **Логика фильтрации сигналов:**

```python
# Проверяем соответствие тренду BTC
if signal_type == "LONG" and btc_trend_status:  # Бычий тренд BTC
    print(f"[DEBUG] {symbol}: Условия для LONG выполнены + бычий тренд BTC, формируем сигнал!")
    # Сигнал будет добавлен
elif signal_type == "SHORT" and not btc_trend_status:  # Медвежий тренд BTC
    print(f"[DEBUG] {symbol}: Условия для SHORT выполнены + медвежий тренд BTC, формируем сигнал!")
    # Сигнал будет добавлен
else:
    print(f"[DEBUG] {symbol}: Сигнал {signal_type} не соответствует тренду BTC")
    continue  # Пропускаем сигнал
```

## 🔧 **НАСТРОЙКИ ФИЛЬТРА**


### **Мягкий режим (BTC_TREND_FILTER_SOFT = True):**

- **Бычий тренд:** Цена BTC > EMA200
- **Медвежий тренд:** Цена BTC < EMA200

### **Строгий режим (BTC_TREND_FILTER_SOFT = False):**

- **Бычий тренд:** Цена BTC > EMA200 И EMA25 растёт
- **Медвежий тренд:** Цена BTC < EMA200 ИЛИ EMA25 падает

## 📈 **РЕКОМЕНДАЦИИ**

### **Для разных рыночных условий:**

1. **Бычий рынок:** Оставить фильтр включенным для LONG сигналов
2. **Медвежий рынок:** Оставить фильтр включенным для SHORT сигналов
3. **Боковой рынок:** Можно отключить фильтр для большего количества сигналов
4. **Высокая волатильность:** Использовать строгий режим фильтра

### **Настройка под стратегию:**

- **Консервативная:** Включить фильтр BTC
- **Агрессивная:** Отключить фильтр BTC
- **Адаптивная:** Автоматическое переключение по условиям рынка
