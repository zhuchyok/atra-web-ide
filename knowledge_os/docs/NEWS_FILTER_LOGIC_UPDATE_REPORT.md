# 📰 ОБНОВЛЕНИЕ ЛОГИКИ НОВОСТНЫХ ФИЛЬТРОВ

## 🎯 ИЗМЕНЕНИЯ В ЛОГИКЕ

Обновлена логика новостных фильтров согласно новым требованиям. **Убрана генерация отдельных новостных сигналов** - теперь новостная логика интегрирована только в существующие технические сигналы:

### 🔧 **Conservative (Консервативный):**

- ✅ **Блокирует LONG сигналы** при негативных новостях
- ✅ **Усиливает LONG сигналы** при позитивных новостях
- ✅ **Блокирует SHORT сигналы** при позитивных новостях
- ✅ **Усиливает SHORT сигналы** при негативных новостях

### ⚡ **Aggressive (Агрессивный):**

- ❌ **НЕ блокирует LONG сигналы** при негативных новостях
- ✅ **Усиливает LONG сигналы** при позитивных новостях
- ❌ **НЕ блокирует SHORT сигналы** при позитивных новостях
- ✅ **Усиливает SHORT сигналы** при негативных новостях

        "enhance_long_on_positive": True,   # Усиливать LONG при позитивных новостях

### 2. **Обновлена логика обработки в `signal_live.py`**

```python
# ОБНОВЛЕННАЯ ЛОГИКА НОВОСТНЫХ ФИЛЬТРОВ
# Проверяем блокировку сигналов по новостям
if signal_type == "LONG" and negative_news_flag and mode_settings['block_long_on_negative']:
    print(f"[DEBUG] {symbol}: LONG сигнал заблокирован негативными новостями для пользователя {user_id} (режим: {news_mode})")
    signal_type = None  # Отменяем сигнал
elif signal_type == "SHORT" and positive_news_flag and mode_settings['block_short_on_positive']:
    print(f"[DEBUG] {symbol}: SHORT сигнал заблокирован позитивными новостями для пользователя {user_id} (режим: {news_mode})")
    signal_type = None  # Отменяем сигнал

# Проверяем усиление сигналов по новостям
has_news_enhancement = False
news_post = None

# Усиление LONG сигналов по позитивным новостям
if signal_type == "LONG" and positive_news_flag and mode_settings['enhance_long_on_positive']:
    has_news_enhancement = True
    news_post = positive_news_post
    print(f"[DEBUG] {symbol}: LONG сигнал усилен позитивными новостями для пользователя {user_id} (режим: {news_mode})")
# Усиление SHORT сигналов по негативным новостям
elif signal_type == "SHORT" and negative_news_flag and mode_settings['enhance_short_on_negative']:
    has_news_enhancement = True
    news_post = negative_news_post
    print(f"[DEBUG] {symbol}: SHORT сигнал усилен негативными новостями для пользователя {user_id} (режим: {news_mode})")
```

Убрана вся логика генерации отдельных сигналов по новостям:

- ❌ Удалена генерация SHORT сигналов по негативным новостям
- ✅ Оставлена только интеграция новостной логики в технические сигналы

## 🎯 **КЛЮЧЕВЫЕ ИЗМЕНЕНИЯ**

### **Упрощенные параметры:**

- `block_long_on_negative` - блокировка LONG при негативных новостях
- `block_short_on_positive` - блокировка SHORT при позитивных новостях
- `enhance_long_on_positive` - усиление LONG при позитивных новостях
- `enhance_short_on_negative` - усиление SHORT при негативных новостях

### **Логика работы:**

- **Блокировка**: Сигнал отменяется (`signal_type = None`)
- **Усиление**: Сигнал помечается флагом `has_news_enhancement = True` и содержит информацию о новости

## 📊 **РЕЗУЛЬТАТ**

Теперь система работает следующим образом:

### **Conservative режим:**

- 🚫 Блокирует LONG при негативных новостях
- ✅ Усиливает LONG при позитивных новостях
- 🚫 Блокирует SHORT при позитивных новостях
- ✅ Усиливает SHORT при негативных новостях

### **Aggressive режим:**

- ✅ Усиливает LONG при позитивных новостях
- ✅ Усиливает SHORT при негативных новостях
- ❌ НЕ блокирует никакие сигналы
