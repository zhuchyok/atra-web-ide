# 🌐 ССЫЛКИ НА ДАШБОРД И REST API

**Дата:** 2025-11-06

---

## 📊 WEB DASHBOARD

### **Локальный доступ:**

- **Порт 5001:** http://localhost:5001
- **Порт 5002:** http://localhost:5002 (если 5001 занят)

### **Удаленный доступ:**

- **Порт 5001:** http://[IP_СЕРВЕРА]:5001
- **Порт 5002:** http://[IP_СЕРВЕРА]:5002 (если 5001 занят)

---

## 🔗 REST API

### **Локальный доступ:**

- **HTTP:** http://localhost:8080
- **HTTPS:** https://localhost:8080 (если включен)

### **Удаленный доступ:**

- **HTTP:** http://[IP_СЕРВЕРА]:8080
- **HTTPS:** https://[IP_СЕРВЕРА]:8080 (если включен)

### **Swagger UI (документация API):**

- http://localhost:8080/docs
- http://[IP_СЕРВЕРА]:8080/docs

---

## 🚀 БЫСТРЫЙ ДОСТУП

### **Если бот запущен локально:**

```bash
# Дашборд
http://localhost:5001

# REST API
http://localhost:8080
http://localhost:8080/docs
```

### **Если бот запущен на сервере:**

```bash
# Дашборд
http://185.177.216.15:5001

# REST API
http://185.177.216.15:8080
http://185.177.216.15:8080/docs
```

---

## ✅ ПРОВЕРКА СТАТУСА

### **Проверить, запущен ли дашборд:**

```bash
# Проверить порты
lsof -i :5001 -i :5002

# Проверить в логах
tail -100 bot.log | grep Dashboard
```

### **Проверить, запущен ли REST API:**

```bash
# Проверить порт
lsof -i :8080

# Проверить в логах
tail -100 bot.log | grep "REST API"
```

---

## 📋 ПРИМЕЧАНИЯ

1. **Дашборд** запускается автоматически при запуске `main.py`
2. **REST API** запускается автоматически при запуске `main.py`
3. Если порт 5001 занят, дашборд автоматически переключается на 5002
4. Для удаленного доступа нужно открыть порты в firewall
