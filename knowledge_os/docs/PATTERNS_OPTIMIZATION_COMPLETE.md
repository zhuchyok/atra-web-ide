- Автоматическая очистка каждые 1000 паттернов
- Очистка при старте системы (если включено)
- Ручная очистка через скрипт `cleanup_patterns.py`

## 📝 Использование

### Автоматическая очистка:

Система автоматически очищает паттерны при достижении лимита (50,000).

### Ручная очистка:

```bash
python3 scripts/cleanup_patterns.py \
  --patterns-file ai_learning_data/trading_patterns.json \
  --max-patterns 50000
```

### Восстановление из бэкапа:

```bash
cp ai_learning_data/trading_patterns.json.backup \
   ai_learning_data/trading_patterns.json
```
