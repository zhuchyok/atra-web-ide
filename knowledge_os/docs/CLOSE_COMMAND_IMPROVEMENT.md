# 🚀 УЛУЧШЕНИЕ КОМАНДЫ `/close`

## 📅 Дата: 27 июля 2025

## 🎯 Обзор

Команда `/close` была значительно улучшена для повышения удобства использования. Теперь при вызове команды без параметров система автоматически показывает список всех открытых позиций с кнопками для быстрого закрытия.

## ✅ **ЧТО ИЗМЕНИЛОСЬ**

### 🔄 **Старое поведение:**

```
/close
❌ Укажите символ или 'all' для закрытия всех позиций:

Примеры:
• /close BTCUSDT - закрыть по текущей цене
• /close BTCUSDT 45000 - закрыть по цене 45000
• /close BTCUSDT 45000 0.5 - закрыть 0.5 BTC
• /close all - закрыть все позиции
```

### 🚀 **Новое поведение:**

```
/close
🔴 ЗАКРЫТИЕ ПОЗИЦИЙ

Количество: 3
Общий P&L: 125.50 USDT
Режим торговли: FUTURES

💡 Выберите позицию для закрытия:

🟢 BTCUSDT (LONG)
Цена входа: 44000.00
Текущая цена: 45000.00
Объём: 1.0000
P&L: 1000.00 USDT (+2.27%)
Режим: FUTURES
Плечо: x2

[🔴 Закрыть всю] [💰 Закрыть 50%]
[📊 Детали] [📈 Обновить P&L]
```

## 🎯 **НОВЫЕ ВОЗМОЖНОСТИ**

### 📊 **Автоматический расчет P&L:**

- Получение текущих цен с биржи
- Расчет прибыли/убытков для каждой позиции
- Сортировка по прибыльности (прибыльные сверху)

### 🎯 **Удобные кнопки:**

- **🔴 Закрыть всю** - закрыть всю позицию по текущей цене
- **💰 Закрыть 50%** - закрыть половину позиции по текущей цене
- **📊 Детали** - показать подробную информацию
- **📈 Обновить P&L** - обновить расчет прибыли/убытков

### 📈 **Сортировка позиций:**

- Прибыльные позиции показываются сверху
- Убыточные позиции показываются снизу
- Легко найти позиции для закрытия
