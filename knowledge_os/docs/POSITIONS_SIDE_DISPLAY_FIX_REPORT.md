# Отчет: Исправление отображения стороны сделки в команде /positions

## 🎯 **Проблема**

Пользователь сообщил: **"по команде /positions пришла сделка но позиция была шорт а не лонг а показывает лонг"**

## 🔍 **Анализ проблемы**

### **Что было найдено:**

1. **Проблема в сохранении стороны сделки** ❌
   - В функции `button` при создании новой позиции **НЕ сохранялась сторона сделки**
   - В строке 1030 отсутствовало поле `"side": side`

2. **Логика отображения работала правильно** ✅
   - В `positions_cmd` сторона извлекается как `side = pos.get("side", "long")`
   - Отображается как `{side.upper()}` в сообщении

3. **Функция `accept_signal_cmd` работала правильно** ✅
   - Сторона сохранялась корректно: `"side": side`

### **Корень проблемы:**

```python
# В функции button (строка 1030) - БЫЛО:
user_data["open_positions"].append({
    "symbol": symbol,
    "entry_price": None,
    "tp1": None,
    "tp2": None,
    "stage": "open",
    "risk_amount": risk_amount,
    "risk_pct": risk_pct,
    "leverage": leverage if trade_mode == "futures" else None,
    # ОТСУТСТВОВАЛО: "side": side
})

# В positions_cmd (строка 730):
side = pos.get("side", "long")  # По умолчанию "long"
```

## ✅ **Исправления**

### **1. Добавлено сохранение стороны сделки в функции `button`:**

```python
# Стало:
user_data["open_positions"].append({
    "symbol": symbol,
    "entry_price": None,
    "tp1": None,
    "tp2": None,
    "stage": "open",
    "risk_amount": risk_amount,
    "risk_pct": risk_pct,
    "leverage": leverage if trade_mode == "futures" else None,
    "side": side,  # ✅ Добавлено сохранение стороны сделки
})
```

**Результат:** Теперь сторона сделки сохраняется при принятии сигнала через кнопку
