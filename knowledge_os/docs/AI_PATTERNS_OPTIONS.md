## ⚡ ВАРИАНТ 3: АВТОМАТИЧЕСКОЕ УПРАВЛЕНИЕ (РЕКОМЕНДУЕТСЯ)

### Суть:

Система **сама** ограничивает количество паттернов, сохраняя только самые **ценные** и **свежие**.

### Стратегия управления:

#### 3.1 **Скользящее окно (Rolling Window)**

Храним только последние N паттернов (например, 15000):

- Старые паттерны автоматически удаляются
- Свежие данные → актуальное обучение
- Фиксированный размер → стабильная производительность

#### 3.2 **Умная очистка (Smart Cleanup)**

Паттерны фильтруются по важности:

- ✅ **Оставляем**: прибыльные паттерны (WIN)
- ✅ **Оставляем**: редкие символы
- ✅ **Оставляем**: паттерны с высокой точностью
- ❌ **Удаляем**: старые нейтральные паттерны
- ❌ **Удаляем**: дубликаты (похожие условия)
- ❌ **Удаляем**: паттерны старше 90 дней

#### 3.3 **Гибридный подход** (BEST)

Комбинация стратегий:

1. Храним **максимум 20000** паттернов
2. При превышении → умная очистка:
   - Удаляем паттерны старше **60 дней** (кроме WIN)
   - Из оставшихся удаляем **нейтральные**
   - Сохраняем **все WIN** и **все LOSS** (для обучения)
   - Среди нейтральных оставляем только **последние 5000**

### Как работает:

```python
def auto_manage_patterns(self, max_patterns=20000):
    """Автоматически управляет количеством паттернов"""
    if len(self.patterns) <= max_patterns:
        return  # Все хорошо

    from datetime import timedelta
    cutoff_date = datetime.now() - timedelta(days=60)

    # Разделяем паттерны
    important = []  # WIN, LOSS, недавние
    neutral = []     # Старые нейтральные

    for p in self.patterns:
        # Сохраняем все важные
        if p.result in ("WIN", "LOSS"):
            important.append(p)
        # Сохраняем свежие
        elif p.timestamp > cutoff_date:
            important.append(p)
        # Остальные - кандидаты на удаление
        else:
            neutral.append(p)

    # Если все еще много - берем последние N нейтральных
    if len(important) + len(neutral) > max_patterns:
        neutral_keep = max_patterns - len(important)
        neutral = sorted(neutral, key=lambda x: x.timestamp, reverse=True)[:neutral_keep]

    # Обновляем список
    self.patterns = important + neutral

    logger.info(f"🧹 Очистка паттернов: {len(important)} важных + {len(neutral)} нейтральных = {len(self.patterns)} всего")
```

### ✅ ПЛЮСЫ:

- ⚡ **Стабильная производительность** - фиксированный размер
- 🎯 **Умная очистка** - сохраняем важные данные
- 🔄 **Автоматически** - не требует вмешательства
- 💾 **Меньше памяти** и диска
- 🚀 **Быстрый старт** бота
- 📈 **Хорошая точность** - сохраняем WIN/LOSS для обучения

### ❌ МИНУСЫ:

- 🗑️ **Потеря истории** старых нейтральных паттернов
- ⚙️ **Сложнее** в реализации (нужен код управления)
- 🔧 **Настройка** параметров (сколько хранить, как фильтровать)

### 📊 Параметры для настройки:

# Возраст паттернов для удаления (дни)

### 🎯 Алгоритм работы:

1. **При запуске**:
   - Загружаем все паттерны (33156)
   - Автоочистка → оставляем 20000 лучших
   - Сохраняем в файл

2. **При добавлении паттерна**:
   - Добавляем новый паттерн
   - Каждые 1000 добавлений → автоочистка
   - Или проверяем лимит сразу

3. **При сохранении**:
   - Сохраняем только актуальные паттерны
   - Файл меньше → быстрее запись/чтение
