# 🎯 ОБЪЯСНЕНИЕ ДИНАМИЧЕСКОГО ПЛЕЧА

## 🎯 **ПОЧЕМУ ПОКАЗЫВАЕТСЯ ПЛЕЧО x1:**

### **❌ Проблема в команде `/myreport`:**

В команде `/myreport` плечо берется из статических данных пользователя:

```python
leverage = user_data.get("leverage") if trade_mode == "futures" else None
```

**Это неправильно!** Плечо должно рассчитываться динамически для каждого сигнала.

---

## 🔍 **КАК РАБОТАЕТ ДИНАМИЧЕСКОЕ ПЛЕЧО:**

### **📈 Функция `get_dynamic_leverage()`:**

```python
def get_dynamic_leverage(df, i, base_leverage=1):
    """
    Динамический расчет плеча на основе волатильности и тренда
    """
    # Рассчитывает плечо на основе:
    # 1. Волатильности рынка
    # 2. Силы тренда
    # 3. Базового плеча пользователя

    # Ограничивает плечо от 1x до 20x
    dynamic_leverage = max(1, min(dynamic_leverage, 20))

    return round(dynamic_leverage, 1)
```

### **🎯 Логика расчета:**

1. **Базовое плечо:** 1x (минимальное)
2. **Фактор тренда:** Увеличивает плечо при сильном тренде
3. **Фактор волатильности:** Уменьшает плечо при высокой волатильности
4. **Результат:** Плечо от 1x до 20x

- **Это неправильно!**

- Плечо рассчитывается динамически для каждого сигнала

- **При плече 1x:** 4 USDT × 1 = 4 USDT
