## 📈 Алгоритм анализа блоков

### 1. Идентификация блоков

- **Период анализа:** 100 свечей (настраивается)
- **Порог объема:** 1.5x от среднего (настраивается)
- **Критерии определения:**
  - Тело свечи > 60% от общего диапазона
  - Объем > 2x от среднего
  - Направление цены (close vs open)

### 2. Классификация блоков

- **Блоки покупателей:** Бычьи свечи с высоким объемом
- **Блоки продавцов:** Медвежьи свечи с высоким объемом
- **Группировка:** Близкие по цене блоки объединяются

### 3. Расчет силы блоков

- **Вес по расстоянию:** Ближе к текущей цене = больше вес
- **Нормализация:** Сила блоков нормализуется к 0-1
- **Факторы влияния:**
  - Расстояние от текущей цены (5%, 10%, 20%)
  - Объем блока относительно среднего
  - Количество блоков в группе

## 🎯 Система усиления сигналов

### Логика усиления:

```python
if signal_type == 'LONG':
    if buyer_strength > seller_strength:
        enhancement_factor = 1.0 + (buyer_strength - seller_strength) * 0.3
        enhancement_type = 'strengthened'
        emoji = '🔥'
    elif seller_strength > buyer_strength:
        enhancement_factor = 1.0 - (seller_strength - buyer_strength) * 0.2
        enhancement_type = 'weakened'
        emoji = '⚠️'
```

### Типы сигналов:

- **🔥 Усиленный:** Блоки подтверждают направление
- **⚠️ Ослабленный:** Блоки противоречат направлению
- **Обычный:** Блоки нейтральны или отсутствуют
