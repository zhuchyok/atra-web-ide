# Отчет о созданных .env файлах

## ✅ Созданные файлы

### 📄 Основные файлы конфигурации:

1. **`env.example`** - Шаблон со всеми переменными окружения
   - Содержит все 88 переменных из config.py
   - Подробные комментарии на русском языке
   - Значения по умолчанию для всех параметров

2. **`env.dev`** - Конфигурация для разработки
   - Быстрые интервалы обновления
   - Короткие кулдауны для тестирования
   - Включены алерты и отладочная информация
   - Отдельная база данных (`trading_dev.db`)

3. **`env.prod`** - Конфигурация для продакшена
   - Стабильные интервалы
   - Оптимизированные настройки для продакшена
   - Отключены алерты
   - Основная база данных (`trading.db`)

### 📚 Документация:

4. **`ENV_SETUP_GUIDE.md`** - Подробное руководство по настройке
   - Пошаговые инструкции
   - Объяснение всех переменных
   - Инструкции по получению API ключей
   - Troubleshooting

5. **`setup_env.sh`** - Интерактивный скрипт настройки
   - Автоматическое создание .env файла
   - Выбор окружения (dev/prod)
   - Проверка обязательных переменных
   - Цветной вывод и подсказки

## 🔧 Переменные окружения

### Обязательные для работы:

- `ATRA_ENV` - окружение (dev/prod)
- `TELEGRAM_TOKEN` / `TELEGRAM_TOKEN_DEV` - токены бота
- `TELEGRAM_CHAT_IDS` - ID чатов для уведомлений

### API ключи (опциональные):

- `CRYPTOPANIC_API_KEY` - для новостей CryptoPanic
- `TRADINGVIEW_API_KEY` - для TradingView
- `NEWSDATA_API_KEY` - для NewsData
- `ETHERSCAN_API_KEY` - для Ethereum Explorer
- `BSCSCAN_API_KEY` - для BSC Explorer
- `POLYGONSCAN_API_KEY` - для Polygon Explorer
- `ARBISCAN_API_KEY` - для Arbitrum Explorer

### Системные настройки:

- `DATABASE` - путь к базе данных
- `AUTO_FETCH_COINS` - автоматический подбор монет
- `MIN_DIFF_PERCENT` - минимальная разница в процентах

### Настройки производительности:

- `DYNAMIC_CALC_INTERVAL` - интервал пересчета
- `CYCLE_ALERT_SEC` - интервал цикла алертов
- `API_ALERT_MS` - время ответа API
- `ALERT_COOLDOWN_MIN` - кулдаун алертов

### Настройки хранения данных:

- `RETENTION_QUOTES_DAYS` - хранение котировок
- `RETENTION_SIGNALS_DAYS` - хранение сигналов
- `RETENTION_SIGNALS_LOG_DAYS` - хранение логов
- `RETENTION_APP_CACHE_DAYS` - хранение кеша

### Настройки AI/ML:

- `ML_SCORING_ENABLED` - включить ML скоринг
- `ML_MODEL_RETRAIN_HOURS` - интервал переобучения
- `ML_PREDICTION_THRESHOLD` - порог предсказания
- `ML_QUALITY_BOOST` - усиление качества

### Настройки Multi-Timeframe:

- `MTF_ENABLED` - включить MTF анализ
- `MTF_WEIGHT_1H_BULL/BEAR/NEUTRAL` - веса для разных рынков
- `MTF_WEIGHT_4H_BULL/BEAR/NEUTRAL` - веса для 4h
- `MTF_WEIGHT_1D_BULL/BEAR/NEUTRAL` - веса для дневного

## 🚀 Использование

### Быстрый старт:

```bash
# Автоматическая настройка
./setup_env.sh

# Или вручную
cp env.dev .env    # для разработки
cp env.prod .env   # для продакшена
```

### Редактирование:

```bash
nano .env
```

### Запуск:

```bash
python main.py
```
