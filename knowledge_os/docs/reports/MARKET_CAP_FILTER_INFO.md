## 📋 **ДВА УРОВНЯ ФИЛЬТРАЦИИ:**

### **Уровень 1: Whitelist (мягкий, 50M)**

```
Используется для генерации сигналов

Капитализация >= 50M USD:
  ✅ Попадает в whitelist
  ✅ Генерируются сигналы

Капитализация < 50M USD:
  ⚠️ Попадает в pending_check
  ⚠️ Требуется дополнительная проверка
```

### **Уровень 2: Blacklist (строгий, 150M)**

```
Используется для жесткой блокировки

Капитализация < 150M USD:
  ❌ Попадает в blacklist
  ❌ Полная блокировка

Капитализация >= 150M USD:
  ✅ НЕ блокируется
```

## 🛡️ **ЗАЩИТА:**

### **Комбинированные фильтры:**

```python
Монета должна пройти ВСЕ проверки:

1. Market Cap >= 50M USD         (whitelist)
2. Volume 24h >= 20M USDT         (ликвидность)
3. Volatility: 0.5% - 15%         (стабильность)
4. НЕ в blacklist                 (< 150M блокируется)
5. НЕ стейблкоин                  (USD1USDT и т.д.)
6. Нет дублей USDT                (CAKEUSDTUSDT)

→ Только качественные, ликвидные монеты!
```
