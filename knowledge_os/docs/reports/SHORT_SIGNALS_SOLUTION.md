# ✅ РЕШЕНИЕ ПРОБЛЕМЫ SHORT СИГНАЛОВ

## 🔍 **АНАЛИЗ:**

### **Почему нет SHORT сигналов:**

SHORT сигналы генерируются **ТОЛЬКО** для `trade_mode = 'futures'`

**В коде (signal_live.py, строка 1662):**

```python
if trade_mode != 'futures':
    logger.debug("🚫 SHORT сигнал пропущен (режим: %s)", trade_mode)
    return None, None
```

### **Как пользователь устанавливает режим:**

1. **При первом запуске /start:**
   - Вводит депозит
   - **Выбирает SPOT или FUTURES** (кнопками)
   - Выбирает режим фильтров

2. **Вручную через команду:**
   ```
   /set_trade_mode futures
   ```

---

## ✅ **ЧТО СДЕЛАНО:**

### **Улучшено описание при выборе режима:**

**Было:**

```
💵 SPOT — торговля без плеча
⚡ FUTURES — торговля с плечом
```

**Стало:**

```
💵 SPOT — торговля без плеча (только LONG сигналы)
⚡ FUTURES — торговля с плечом (LONG + SHORT сигналы)

⚠️ Рекомендуется FUTURES для полного использования стратегий
```

**Эффект:**

- ✅ Пользователь понимает разницу
- ✅ Видит что SPOT = только LONG
- ✅ Видит рекомендацию FUTURES
- ✅ Сознательно выбирает режим

## 📈 **СРАВНЕНИЕ РЕЖИМОВ:**

### **SPOT режим:**

```
✅ LONG сигналы: Да
❌ SHORT сигналы: Нет
💰 Плечо: 1x
📊 Возможности: 50% (только рост)
🛡️ Риск: Низкий
```

### **FUTURES режим:**

```
✅ LONG сигналы: Да
✅ SHORT сигналы: Да
💰 Плечо: до 10x
📊 Возможности: 100% (рост и падение)
⚡ Потенциал: В 2 раза выше
⚠️ Риск: Средний (контролируется)
```
