## 🔧 **КАК РАБОТАЕТ:**

### **Алгоритм:**

1. **Поиск локальных экстремумов**
   - Ищет локальные максимумы (resistance)
   - Ищет локальные минимумы (support)
   - Окно: 5 свечей в каждую сторону

2. **Кластеризация уровней**
   - Группирует близкие экстремумы (0.5% толерантность)
   - Считает количество касаний каждого уровня
   - Оставляет только значимые уровни (min 2 касания)

3. **Проверка близости**
   - Для LONG: проверяет близость к support (1% толерантность)
   - Для SHORT: проверяет близость к resistance (1% толерантность)

4. **Бонус к качеству**
   - Если цена близко к уровню → бонус +2% за каждый touch
   - Максимальный бонус: +15%
   - Прибавляется к `quality_score`

## 🛡️ **БЕЗОПАСНОСТЬ:**

### **Не ломает существующую логику:**

- ✅ Только БОНУС к качеству (дополнительно)
- ✅ Не заменяет существующие паттерны
- ✅ Ошибки обрабатываются (fallback)
- ✅ Если детектор недоступен → просто не даёт бонуса

### **Как это работает:**

```python
# До интеграции:
quality_score = 0.72 → проходит проверку (0.72 >= 0.70) ✅

# После интеграции (если близко к support):
quality_score = 0.72 + 0.06 (бонус) = 0.78 → проходит проверку ✅

# Сигнал стал ЛУЧШЕ качеством, не хуже!
```
