# ✅ ДИАПАЗОН ВОЛАТИЛЬНОСТИ ВОССТАНОВЛЕН

## 🔧 **ЧТО ИЗМЕНЕНО:**

### **Было (слишком широко):**

```python
min_volatility_pct: 0.001  # 0.1%
max_volatility_pct: 0.25   # 25%

После умножения на 100:
Диапазон: [0.1%, 25%]

Результат:
✅ Пропускает почти ВСЕ монеты
⚠️ Включая малоизвестные с высокой волатильностью (20-25%)
```

### **Стало (как было ранее):**

```python
min_volatility_pct: 0.005  # 0.5%
max_volatility_pct: 0.15   # 15%

После умножения на 100:
Диапазон: [0.5%, 15%]

Результат:
✅ Фильтрует слишком стабильные (<0.5%)
✅ Фильтрует слишком волатильные (>15%)
✅ Качественные монеты в диапазоне 0.5%-15%
```

## 🎯 **ЭФФЕКТ:**

### **До восстановления (0.1%-25%):**

```
Принимаются:
  - Известные монеты: ✅
  - Малоизвестные с волат. 20%+: ✅ (РИСК!)
  - Манипулируемые монеты: ✅ (РИСК!)

Отклоняются:
  - Только совсем стабильные (<0.1%)
```

### **После восстановления (0.5%-15%):**

```
Принимаются:
  - Известные монеты (2-8%): ✅
  - Качественные альткоины (5-12%): ✅

Отклоняются:
  - Слишком стабильные (<0.5%): ❌
  - Высокорискованные (>15%): ❌
  - Малоизвестные шиткоины: ❌
```

---

## 🛡️ **ЗАЩИТА:**

**Волатильность > 15% часто означает:**

- Манипуляции
- Pump & Dump схемы
- Малоизвестные токены
- Низкая ликвидность
- Высокий риск

**Фильтр 0.5%-15% защищает от этого!**
