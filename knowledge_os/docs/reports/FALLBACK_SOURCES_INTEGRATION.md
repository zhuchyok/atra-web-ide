## ✅ **ЧТО СДЕЛАНО:**

### **1. Добавлен fallback на Bybit в `pair_filtering.py`**

**Проблема:** При таймауте Binance API система падала, а не переключалась на резервные источники.

**Решение:** Добавлена каскадная система получения списка монет:

```python
1. Binance (основной источник)
   ↓ timeout/error
2. Bybit (резервный источник)
   ↓ timeout/error
3. Устаревший кэш (<1 час) с ПРЕДУПРЕЖДЕНИЕМ
   ↓ нет кэша
4. Возврат None → Повторная попытка через 30 сек (макс. 3 попытки)
   ↓ все попытки неудачны
5. Использование дефолтного списка COINS из config.py
```

## 🎯 **РЕЗУЛЬТАТ:**

### **До изменений:**

```
Binance timeout → ❌ Система падает
```

### **После изменений:**

```
Binance timeout →
  → Bybit успешно → ✅ Работаем с Bybit
  → Bybit timeout →
    → Есть кэш (<1 час)? → ⚠️ Работаем с ПРЕДУПРЕЖДЕНИЕМ
    → Нет кэша →
      → Попытка 1/3 → ждем 30 сек
      → Попытка 2/3 → ждем 30 сек
      → Попытка 3/3 → все неудачно
        → ℹ️ Используем дефолтный список (config.COINS)
```
