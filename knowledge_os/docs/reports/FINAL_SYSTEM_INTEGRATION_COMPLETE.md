## 🚀 КАК ИСПОЛЬЗОВАТЬ

### **Manual режим (по умолчанию):**

```
1. Получаете сигнал → статус PENDING
2. Нажимаете кнопку "Принять" или /accept
3. Позиция открывается → статус OPEN
4. Корреляция учитывает OPEN позиции
```

### **Auto режим:**

```
1. Подключаете ключи:
   /connect_bitget <api_key> <secret> <passphrase>

2. Активируете auto:
   /mode_set auto

3. Получаете сигнал:
   - Система автоматически создаёт ордер на Bitget
   - Ждёт исполнения (90 сек лимитный)
   - Фолбэк на маркет если не исполнен
   - После fill → статус OPEN

4. Синхронизация:
   - Каждые 3 мин проверка позиций на бирже
   - Автоматическое закрытие если позиция закрыта на бирже
   - Алерт о всех изменениях
```

### **Проверка режима:**

```
/mode — показать текущий режим и статус ключей
```

## 🔐 БЕЗОПАСНОСТЬ

### **Установка:**

```bash
# 1. Установить зависимости
pip install cryptography ccxt

# 2. Сгенерировать ключ шифрования
python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"

# 3. Создать .env файл
echo "ATRA_ENCRYPTION_KEY=<ваш_ключ>" > .env

# 4. Добавить .env в .gitignore
echo ".env" >> .gitignore
```

### **Создание API ключей на Bitget:**

```
1. Зайти в Bitget → API Management
2. Create API Key
3. Выбрать права:
   ☑️ Read
   ☑️ Trade
   ☐ Transfer (ОТКЛЮЧИТЬ!)
   ☐ Withdraw (ОТКЛЮЧИТЬ!)
4. Сохранить API Key, Secret, Passphrase
```

### **Подключение в боте:**

```
/connect_bitget <api_key> <secret> <passphrase>
```

## 📊 ЛОГИКА ПО РЕЖИМАМ

### **Manual:**

```
Сигнал → PENDING
  ↓ (не блокирует корреляцией)
TTL 60 мин
  ↓
/accept → OPEN + active_positions
  ↓ (блокирует корреляцией)
Корреляция: signals_log.result='OPEN'
```

### **Auto:**

```
Сигнал → PENDING
  ↓ (не блокирует)
Auto-exec → Ордер на бирже
  ↓
Fill → OPEN + active_positions
  ↓ (блокирует)
Синк каждые 3 мин ↔ Биржа
  ↓
Корреляция: active_positions (источник правды — биржа)
```
