# 📊 АНАЛИЗ БЛОКИРОВОК СИГНАЛОВ - ОТЧЕТ

## 🔍 ЦЕЛЬ АНАЛИЗА

Выяснить причины отсутствия сигналов и определить узкие места в фильтрах.

## 📈 ТЕКУЩИЕ ПАРАМЕТРЫ ФИЛЬТРОВ

### 1. **Direction Check** (Direction Confidence)

- **Требование:** 3/4 подтверждения из 4 проверок
- **Проверки:**
  1. **EMA Alignment:** EMA fast > EMA slow (для BUY) или EMA fast < EMA slow (для SELL)
  2. **Price vs EMA:** Цена > EMA fast (для BUY) или Цена < EMA fast (для SELL)
  3. **RSI:** RSI < 55 (для BUY) или RSI > 45 (для SELL) - **СМЯГЧЕНО**
  4. **MACD:** Бычий MACD (для BUY) или Медвежий MACD (для SELL)
- **Параметры EMA:** 12/26 (быстро/медленно) - **ОПТИМИЗИРОВАНО ДЛЯ ИНТРАДЕЙ**
- **Параметр RSI:** Период 12 - **ОПТИМИЗИРОВАНО ДЛЯ ИНТРАДЕЙ**

### 2. **Quality Score**

- **Требование:**
  - LONG: ≥ 0.68 - **СМЯГЧЕНО** (было 0.70)
  - SHORT: ≥ 0.72 - **СМЯГЧЕНО** (было 0.75)
- **Факторы:**
  - Volume quality (0.0-1.0)
  - Volatility quality (0.0-1.0)
  - RSI quality (0.0-1.0)
  - Pattern quality (0.0-1.0)

### 3. **Pattern Confidence**

- **Требование:** ≥ 0.60
- **Расчет:** На основе типа паттерна и дополнительных факторов

### 4. **RSI Warning**

- **Блокировка:**
  - RSI > 65 для BUY
  - RSI < 35 для SELL
- **Цель:** Предотвратить вход в экстремальных зонах

### 5. **MTF Confirmation**

- **Требование:** Подтверждение на H4 таймфрейме
- **Проверка:** Направление тренда на H4 должно совпадать с сигналом
- **Статус:** Включено (может блокировать сигналы)

### 6. **BTC Alignment**

- **Требование:** Направление BTC должно совпадать с сигналом
- **Цель:** Снизить риск против тренда BTC
- **Статус:** Включено (может блокировать сигналы)

### 7. **False Breakout Detector**

- **Проверка:** Обнаружение ложных пробоев
- **Цель:** Избежать входа на ложных пробоях
- **Статус:** Включено (может блокировать сигналы)

### 8. **Volume Quality**

- **Требование:** ≥ 0.80
- **Цель:** Предотвратить манипуляции объемом
- **Статус:** Включено (может блокировать сигналы)

### 9. **Anomaly Filter**

- **Проверка:** Аномалии в данных
- **Цель:** Избежать ложных сигналов из-за аномалий
- **Статус:** Включено (может блокировать сигналы)

## 🔴 ВОЗМОЖНЫЕ ПРИЧИНЫ ОТСУТСТВИЯ СИГНАЛОВ

### 1. **Рынок не соответствует критериям**

- Нет четкого тренда на 1H таймфрейме
- Низкая волатильность
- Нестабильные условия рынка
- Консолидация после сильных движений

### 2. **Строгие фильтры**

- **MTF Confirmation** может блокировать сигналы, если H4 тренд не совпадает
- **BTC Alignment** может блокировать сигналы, если BTC в противоположном тренде
- **Direction Check** требует 3/4 подтверждения
- **Quality Score** требует минимум 0.68/0.72

### 3. **Отсутствие паттернов**

- EMA не пересекаются
- Цена не формирует четких паттернов
- Объем недостаточен
- RSI в нейтральной зоне

### 4. **Проблемы с данными**

- Недостаточно исторических данных
- Проблемы с API биржи
- Задержки в получении данных
