```
🛡️ SL: 0.9909 (-1.00% / -4.45$)
```

## 🔧 **ТЕХНИЧЕСКИЕ ДЕТАЛИ:**

### **1. Форматирование изменено в `messaging_service.py`:**

- ✅ Короткая запись: "SL" вместо "Стоп-лосс"
- ✅ Добавлен расчет суммы убытка в USDT
- ✅ Формат: `-{процент}% / -{сумма в USDT}$`

### **2. Расчет суммы убытка:**

```python
# Рассчитываем сумму убытка в USDT
sl_amount_usdt = entry_amount_usdt * (abs(sl_pct) / 100)

# Если есть сумма входа - показываем полный формат
if sl_amount_usdt is not None:
    f"🛡️ SL: {price} (-{sl_pct}% / -{sl_amount_usdt}$)"
# Иначе - только проценты (fallback)
else:
    f"🛡️ SL: {price} (-{sl_pct}%)"
```
