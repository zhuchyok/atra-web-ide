**Местоположение:** `signal_live.py`, строки 1017-1073

**Функциональность:**

- ✅ Проверка volume_to_cap_ratio
- ✅ Расчет кружков аномалий (0-5)
- ✅ Блокировка максимального риска (5 кружков) - манипуляции
- ✅ Блокировка минимального риска (0 кружков) - низкая ликвидность
- ✅ Предупреждение при высоком риске (4 кружка)

**Механизм:**

```python

    return None, None  # Сигнал заблокирован

# Блокируем минимальный риск (0 кружков)

    return None, None  # Низкая ликвидность
```
