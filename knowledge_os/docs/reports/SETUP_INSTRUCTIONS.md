## 📋 БЫСТРЫЙ СТАРТ

### **1. Установка зависимостей**

```bash
pip install cryptography ccxt
```

### **2. Генерация ключа шифрования**

```bash
python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```

Сохраните полученный ключ!

### **3. Создание .env файла**

```bash
echo "ATRA_ENCRYPTION_KEY=<ваш_сгенерированный_ключ>" > .env
```

### **4. Добавление .env в .gitignore**

```bash
echo ".env" >> .gitignore
```

### **5. Запуск системы**

```bash
python main.py
```

## 🔧 НАСТРОЙКА РЕЖИМОВ

### **Manual режим (по умолчанию):**

```
/mode — проверить текущий режим
```

Готово! Сигналы будут приходить с кнопкой "Принять".

### **Auto режим (автоторговля):**

**Шаг 1: Создайте API ключи на Bitget**

```
1. Зайдите на Bitget.com
2. API Management → Create API
3. Выберите права:
   ✅ Read
   ✅ Trade
   ❌ Transfer (ОТКЛЮЧИТЬ!)
   ❌ Withdraw (ОТКЛЮЧИТЬ!)
4. Сохраните: API Key, Secret Key, Passphrase
```

**Шаг 2: Подключите ключи в боте**

```
/connect_bitget <api_key> <secret_key> <passphrase>
```

**Шаг 3: Активируйте auto режим**

```
/mode_set auto
```

**Готово!** Сигналы будут исполняться автоматически.

## 🔐 БЕЗОПАСНОСТЬ

### **ВАЖНО:**

1. **НЕ коммитьте .env в git!**
   - Файл содержит ключ шифрования
   - Потеря = потеря доступа к API ключам

2. **API ключи БЕЗ прав вывода!**
   - Только Read + Trade
   - БЕЗ Transfer и Withdraw

3. **Начните с малых сумм**
   - Протестируйте на 50-100 USDT
   - Убедитесь что всё работает
   - Постепенно увеличивайте

4. **Мониторьте алерты**
   - Система пришлёт уведомления о проблемах
   - Проверяйте позиции на бирже

## 🔄 РЕЖИМЫ РАБОТЫ

### **Manual (ручной):**

```
Сигнал → PENDING
  ↓
Кнопка "Принять" / /accept
  ↓
OPEN → позиция учитывается
  ↓
Не принят за 60 мин → EXPIRED
```

### **Auto (автоматический):**

```
Сигнал → PENDING
  ↓
Автоматический ордер на Bitget
  ↓
Fill → OPEN → позиция учитывается
  ↓
Синхронизация с биржей каждые 3 мин
```

## ❓ ЧАСТЫЕ ВОПРОСЫ

### **Q: Как переключиться между режимами?**

A: `/mode_set manual` или `/mode_set auto`

### **Q: Нужно ли отключать ключи при переходе на manual?**

A: Нет, они автоматически не используются в manual режиме.

### **Q: Что делать если ордер не исполнился?**

A: Система автоматически попробует маркет ордер и пришлёт алерт.

### **Q: Как проверить что позиции синхронизированы?**

A: В auto режиме синхронизация автоматическая каждые 3 минуты.

### **Q: Можно ли использовать разные биржи?**

A: Да, система поддерживает Bitget и Binance через ccxt.
