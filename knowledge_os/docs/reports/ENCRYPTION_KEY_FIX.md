# 🔐 ИСПРАВЛЕНИЕ: ОШИБКА РАСШИФРОВАНИЯ КЛЮЧЕЙ

**Проблема:** При перезапуске генерируется новый ключ шифрования, старые ключи Bitget не расшифровываются.

---

## ✅ РЕШЕНИЕ

### **ШАГ 1: Сохраните ключ шифрования**

Из ваших логов:

```
ATRA_ENCRYPTION_KEY=ogGkH4RhoZCtAPTRrrwBZI_5o0K1VmxJSoV1IGUQzUA=
```

Создайте файл `.env`:

```bash
echo "ATRA_ENCRYPTION_KEY=ogGkH4RhoZCtAPTRrrwBZI_5o0K1VmxJSoV1IGUQzUA=" > .env
```

### **ШАГ 2: Переподключите ключи Bitget**

В Telegram боте:

```
/disconnect_bitget
/connect_bitget <api_key> <secret> <passphrase>
```

### **ШАГ 3: Перезапустите систему**

```bash
python main.py
```

Теперь в логах НЕ должно быть ошибок расшифрования!

---

## 🔍 ПРОВЕРКА

**После перезапуска логи должны показывать:**

```
✅ Ключи bitget для user <id> сохранены (зашифрованы)
```

**БЕЗ ошибок:**

```
❌ Ошибка расшифрования  ← НЕ ДОЛЖНО БЫТЬ!
```

---

## ⚠️ ВАЖНО

**ВСЕГДА используйте один и тот же ключ шифрования!**

- Сохраните в `.env`
- Добавьте `.env` в `.gitignore`
- Не меняйте ключ после сохранения API ключей
- При смене ключа — переподключайте все API ключи заново

---

**СДЕЛАЙТЕ СЕЙЧАС:**

1. Создайте `.env` с ключом из логов
2. `/disconnect_bitget`
3. `/connect_bitget <новые_данные>`
4. Перезапустите бот

**Ошибки расшифрования исчезнут!** ✅
