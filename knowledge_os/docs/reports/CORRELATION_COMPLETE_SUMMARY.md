## 🔄 **КAK РАБОТАЕТ**

### **Шаг 1: Генерация сигнала**

```
LINKUSDT → generate_signal() → сигнал BUY
```

### **Шаг 2: Проверка корреляции**

```
LINKUSDT → check_correlation_risk_async()
├─ Получаем OHLC данные для LINK и ETH
├─ Вычисляем returns: [0.02, -0.01, 0.03, ...]
├─ Корреляция: np.corrcoef(LINK, ETH) = 0.85
└─ Группа: ETH_HIGH (correlation > 0.75)
```

### **Шаг 3: Проверка лимитов**

```
ETH_HIGH группа → проверяем активные сигналы
├─ ETHUSDT (ETH_HIGH) - уже отправлен 10 мин назад
├─ Всего активных: 1/2
└─ Лимит НЕ превышен → разрешить
```

### **Шаг 4: Отправка и сохранение**

```
Разрешение получено → отправляем в Telegram
├─ Сохраняем в стандартную историю
└─ Сохраняем в историю корреляции (для мониторинга)
```

### **Шаг 5: Следующий сигнал (блокировка)**

```
UNIUSDT → ETH_HIGH группа
├─ ETHUSDT (ETH_HIGH) - активен
├─ LINKUSDT (ETH_HIGH) - активен
└─ Всего: 2/2 → БЛОКИРОВКА

Лог: 🚫 [RISK] UNIUSDT BUY заблокирован: GROUP_LIMIT_EXCEEDED
```
