### **3. Улучшено описание режимов торговли:**

**Было:**

```

⚡ FUTURES — торговля с плечом
```

**Стало:**

```
💵 SPOT — торговля без плеча (только LONG сигналы)

```

**Эффект:**

- ✅ Пользователь видит что SPOT = только LONG
- ✅ Видит что FUTURES = LONG + SHORT
- ✅ Понимает рекомендацию
- ✅ Делает осознанный выбор
