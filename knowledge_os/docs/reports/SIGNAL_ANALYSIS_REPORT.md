# 📊 АНАЛИЗ БЛОКИРОВОК СИГНАЛОВ

## 🔍 ЦЕЛЬ АНАЛИЗА

Выяснить причины отсутствия сигналов и определить узкие места в фильтрах.

## 📈 МЕТОДИКА АНАЛИЗА

### 1. Проверка логов на блокировки

- Поиск сообщений о блокировках сигналов
- Анализ причин отклонения
- Подсчет частоты блокировок по каждому фильтру

### 2. Анализ Pipeline Statistics

- Проверка статистики прохождения этапов
- Определение узких мест в pipeline
- Расчет проходимости на каждом этапе

### 3. Анализ по символам

- Определение символов с наибольшим количеством блокировок
- Поиск общих причин блокировок
- Выявление паттернов блокировок

## 🔴 ОСНОВНЫЕ ФИЛЬТРЫ, КОТОРЫЕ МОГУТ БЛОКИРОВАТЬ СИГНАЛЫ

### 1. **Direction Check** (Direction Confidence)

- **Требование:** 3/4 подтверждения
- **Проверки:**
  - EMA alignment (EMA fast > EMA slow для BUY, наоборот для SELL)
  - Price vs EMA (цена > EMA fast для BUY)
  - RSI (< 55 для BUY, > 45 для SELL)
  - MACD (бычий для BUY, медвежий для SELL)
- **Параметры:** EMA 12/26, RSI период 12

### 2. **Quality Score**

- **Требование:** ≥ 0.68 для LONG, ≥ 0.72 для SHORT
- **Факторы:**
  - Volume quality
  - Volatility quality
  - RSI quality
  - Pattern quality

### 3. **Pattern Confidence**

- **Требование:** ≥ 0.60
- **Расчет:** На основе типа паттерна и дополнительных факторов

### 4. **RSI Warning**

- **Блокировка:** RSI > 65 для BUY, RSI < 35 для SELL
- **Цель:** Предотвратить вход в экстремальных зонах

### 5. **MTF Confirmation**

- **Требование:** Подтверждение на H4 таймфрейме
- **Проверка:** Направление тренда на H4 должно совпадать с сигналом

### 6. **BTC Alignment**

- **Требование:** Направление BTC должно совпадать с сигналом
- **Цель:** Снизить риск против тренда BTC

### 7. **False Breakout Detector**

- **Проверка:** Обнаружение ложных пробоев
- **Цель:** Избежать входа на ложных пробоях

### 8. **Volume Quality**

- **Требование:** ≥ 0.80
- **Цель:** Предотвратить манипуляции объемом

### 9. **Anomaly Filter**

- **Проверка:** Аномалии в данных
- **Цель:** Избежать ложных сигналов из-за аномалий

## 📊 ОЖИДАЕМЫЕ РЕЗУЛЬТАТЫ АНАЛИЗА

После запуска скрипта анализа мы получим:

1. **Статистику блокировок:**
   - Количество блокировок по каждому фильтру
   - Процент блокировок от общего числа попыток
   - Топ причин блокировок

2. **Статистику по символам:**
   - Символы с наибольшим количеством блокировок
   - Частые причины блокировок для каждого символа
   - Процент блокировок для каждого символа

3. **Pipeline Statistics:**
   - Общее количество попыток
   - Проходимость на каждом этапе
   - Узкие места в pipeline

4. **Последние блокировки:**
   - Детальная информация о последних блокировках
   - Время, символ, причина блокировки

## 💡 РЕКОМЕНДАЦИИ ПО УЛУЧШЕНИЮ

После анализа будут даны рекомендации:

1. **Если основная причина блокировок - Direction Check:**
   - Проверить параметры EMA и RSI
   - Возможно, смягчить требования (уже сделано: EMA 12/26, RSI < 55/45)

2. **Если основная причина - Quality Score:**
   - Проверить пороги Quality Score (уже смягчено: 0.68 для LONG, 0.72 для SHORT)
   - Возможно, дополнительно снизить пороги

3. **Если основная причина - MTF Confirmation:**
   - Проверить логику MTF Confirmation
   - Возможно, смягчить требования или отключить для интрадей

4. **Если основная причина - BTC Alignment:**
   - Проверить логику проверки BTC тренда
   - Возможно, сделать опциональным

5. **Если основная причина - Volume Quality:**
   - Проверить порог 0.80
   - Возможно, снизить до 0.70
