# 🔴 ПРОБЛЕМА: XPLUSDT закрылась сразу после открытия

## 📊 Факты из скриншота:

1. **Сигнал:** XPLUSDT SHORT в 00:06
2. **Открытие:** 00:07:08 - SHORT 129 XPL по 0.2617 USDT
3. **Закрытие:** 00:08:15 - Закрытие SHORT 129 XPL по 0.2685 USDT (Reduce only: Да)
4. **Время между открытием и закрытием:** 1 минута 7 секунд

## ❌ Проблема:

Позиция закрылась **через 1 минуту 7 секунд** после открытия, хотя защита на **3 минуты** должна была предотвратить это.

## 🔍 Возможные причины:

### 1. Позиция не найдена в БД при проверке защиты

**Место:** `main.py`, строки 1408-1431

**Проблема:**

- Запрос ищет позицию по `symbol` и `accepted_by`
- Если символ не совпадает (например, `XPLUSDT` vs `XPL/USDT:USDT`), позиция не найдется
- Защита не сработает, и позиция будет закрыта

**Проверка:**

- Нужно убедиться, что символ нормализуется одинаково при создании и при проверке

### 2. Проблема с нормализацией символа в `get_signal_data`

**Место:** `acceptance_database.py`, строка 850

**Код:**

```python
clean_symbol = symbol.replace('/', '').replace(':USDT', '')
```

**Проблема:**

- Если в `signals_log` символ сохранен как `XPLUSDT`
- А в синхронизации используется `XPL/USDT:USDT` или другой формат
- `get_signal_data` может не найти сигнал
- Позиция будет считаться "без сигнала" и не будет создана в БД
- Затем синхронизация закроет её, так как её нет на бирже (но она есть!)

### 3. Проблема с сохранением `entry_time`

**Место:** `acceptance_database.py`, `create_active_position()`

**Проблема:**

- Если `entry_time` не сохраняется правильно
- Или сохраняется в неправильном формате
- Защита не сможет правильно рассчитать время
- Позиция будет закрыта преждевременно

### 4. Проблема с определением направления (SHORT vs SELL)

**Место:** `main.py`, строки 561-568

**Проблема:**

- Сигнал: `SHORT`
- В БД может сохраняться как `SELL`
- При синхронизации может быть несоответствие

## 🔧 Решения:

### 1. Улучшить нормализацию символов

Убедиться, что символ нормализуется одинаково везде:

- При создании позиции
- При проверке сигнала
- При синхронизации

### 2. Улучшить логирование

Добавить больше логирования для отладки:

- Какой символ ищется в БД
- Какой символ найден на бирже
- Результат проверки защиты
- Время создания позиции

### 3. Улучшить проверку защиты

Добавить дополнительные проверки:

- Проверять не только по символу, но и по времени создания
- Проверять наличие позиции в БД перед закрытием
- Логировать все шаги проверки

### 4. Проверить формат символа в signals_log

Убедиться, что символ сохраняется в правильном формате:

- `XPLUSDT` (без разделителей)
- Не `XPL/USDT:USDT` или другие варианты
