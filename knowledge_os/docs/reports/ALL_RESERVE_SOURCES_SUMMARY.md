## 🔄 **СИСТЕМА FALLBACK:**

### **Автоматическое переключение:**

```python
Источник 1 → timeout/error
  ↓
Источник 2 → timeout/error
  ↓
Источник 3 → timeout/error
  ↓
...
  ↓
Источник N → success ✅
```

### **Умная система выбора:**

- ✅ **Приоритизация** - сначала самые надежные
- ✅ **Circuit Breaker** - блокировка сбойных источников
- ✅ **Rate Limiting** - защита от превышения лимитов
- ✅ **Параллельные запросы** - одновременно к нескольким источникам
- ✅ **Агрегация данных** - медиана/среднее из нескольких источников
- ✅ **Кэширование** - в БД на 5-60 минут

---

## 🛡️ **ЗАЩИТНЫЕ МЕХАНИЗМЫ:**

### **1. Circuit Breaker (Автомат защиты):**

- Блокирует источник после 5 ошибок подряд
- Разблокировка через 5 минут (300 сек)
- Защищает от перегрузки сбойных API

### **2. Rate Limiter (Ограничитель частоты):**

- Максимум 25 запросов в минуту на источник
- Автоматическая задержка при превышении
- Защита от бана по API лимитам

### **3. Timeout (Таймауты):**

- 15 секунд на запрос (по умолчанию)
- Быстрый переход к следующему источнику
- Предотвращение зависаний

### **4. Retry Logic (Повторные попытки):**

- 3 попытки с задержкой 30 секунд
- Только для критичных операций
- Логирование каждой попытки

1. Свежий кэш (< 5 мин) - мгновенно
