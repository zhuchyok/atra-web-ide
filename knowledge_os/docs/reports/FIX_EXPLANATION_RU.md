# ✅ ИСПРАВЛЕНИЕ: Автоматическое создание позиций из биржи

## 🔍 Проблема

Система автоматически создавала позиции в локальной БД из биржи **без проверки**, была ли позиция открыта через систему (из сигнала) или вручную.

### Что происходило:

1. **Синхронизация** находила позицию на бирже (например, LONG FFUSDT)
2. **Создавала** её в локальной БД через `upsert_active_position()`
3. **Выставляла** TP/SL ордера автоматически
4. **Начинала** отслеживать позицию, которую пользователь не открывал через систему

### Результат:

- Позиция LONG FFUSDT была найдена на бирже (неизвестного происхождения)
- Система создала её в БД и выставила 2 TP/SL ордера
- Пользователь получил уведомления о позиции, которую не открывал

---

## ✅ Исправление

### Добавлена проверка наличия сигнала:

```python
# Перед созданием позиции из биржи проверяем наличие сигнала
signal_data = await adb_local.get_signal_data(uid, symbol)
if not signal_data:
    # Позиция найдена на бирже, но НЕТ сигнала в БД
    # Это ручная позиция - НЕ создаем её в локальной БД
    logger.warning("⚠️ Позиция найдена на бирже, но нет сигнала. Пропускаем создание.")
    continue  # Не создаем позицию без сигнала
```

### Что изменилось:

1. ✅ **Проверка сигнала** - перед созданием позиции проверяется наличие сигнала в `signals_log`
2. ✅ **Пропуск ручных позиций** - если сигнала нет, позиция не создается в БД
3. ✅ **Нет TP/SL для ручных** - TP/SL ордера не выставляются для позиций без сигнала
4. ✅ **Логирование** - добавлено предупреждение в лог о ручных позициях

### Теперь система:

- ✅ **Создает позиции ТОЛЬКО из сигналов** - только позиции, открытые через систему

- ✅ Система будет управлять только позициями, открытыми через сигналы

## ❓ Вопрос о LONG позиции FFUSDT

**Откуда взялась LONG позиция на бирже?**

Возможные причины:

1. Позиция была открыта вручную (но вы утверждаете, что нет)
2. Позиция была открыта системой по ошибке (нужно проверить логи)
3. При закрытии SHORT открылась LONG (если `reduceOnly` не сработал)

**Сейчас:**

- Система больше не будет создавать такие позиции в БД
- Система больше не будет выставлять для них TP/SL
- Если позиция на бирже, но нет сигнала - система проигнорирует её

---

## 🔄 Что делать с существующей LONG позицией?

Если LONG позиция FFUSDT все еще открыта на бирже:

1. Закройте её вручную на бирже
2. Система не будет её отслеживать (так как нет сигнала)
3. TP/SL ордера нужно будет закрыть вручную (если они были выставлены системой)
