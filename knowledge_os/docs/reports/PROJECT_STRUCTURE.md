# Структура проекта ATRA

## 📁 Корневая директория

### Основные файлы

- `main.py` - Главный файл запуска системы
- `config.py` - Конфигурация проекта
- `db.py` - Работа с базой данных
- `signal_live.py` - Система генерации сигналов
- `exchange_api.py` - API для работы с биржами
- `adaptive_signal_system.py` - Адаптивная система сигналов
- `dependencies.py` - Проверка зависимостей

### Конфигурационные файлы

- `requirements.txt` - Python зависимости
- `pytest.ini` - Настройки тестирования
- `Dockerfile` - Docker конфигурация
- `docker-compose.yml` - Docker Compose конфигурация
- `Makefile` - Makefile для автоматизации

---

## 📂 Директории

### `/src` - Основной код проекта

Модульная структура приложения:

- `core/` - Ядро системы (конфигурация, локализация, кеш)
- `data/` - Работа с данными (провайдеры, валидация, технический анализ)
- `filters/` - Фильтры сигналов (аномалии, киты, новости, BTC тренд)
- `signals/` - Генерация сигналов (индикаторы, риск-менеджмент, DCA)
- `telegram/` - Telegram бот (обработчики, форматирование)
- `utils/` - Утилиты (db_init, shared_utils, helpers)
- `types.py` - Типы данных

### `/tests` - Тесты

Все тестовые файлы (247 файлов):

- `test_*.py` - Юнит-тесты
- `check_*.py` - Проверочные скрипты
- `debug_*.py` - Отладочные скрипты
- `analyze_*.py` - Аналитические скрипты
- `diagnose_*.py` - Диагностические скрипты

### `/backtests` - Бэктесты

Все файлы для бэктестинга (42 файла):

- `backtest*.py` - Скрипты бэктестов
- `*backtest*.py` - Различные варианты бэктестов

### `/ai` - AI/ML системы

Файлы искусственного интеллекта (23 файла):

- `ai_*.py` - AI модули (обучение, мониторинг, оптимизация)
- `demo_*.py` - Демонстрационные скрипты

### `/scripts` - Скрипты развертывания и управления

Bash и Python скрипты для управления системой:

- `*.sh` - Bash скрипты (развертывание, мониторинг, управление)
- `*.service` - Systemd сервисы
- `deploy_*.py` - Скрипты развертывания
- `setup_*.py` - Скрипты настройки

### `/archive` - Архив неиспользуемых файлов

Старые и неиспользуемые файлы (238 файлов):

- `unused_files/` - Полностью неиспользуемые файлы
- `old_versions/` - Старые версии файлов
- `experimental/` - Экспериментальные функции
- `backup_scripts/` - Резервные скрипты

### `/docs` - Документация

Документация проекта (850+ markdown файлов):

- Отчеты о багфиксах
- Руководства по использованию
- Описание систем и компонентов

### `/web` - Web интерфейс

Веб-дашборд:

- `dashboard.py` - Основной файл дашборда
- `static/` - Статические файлы (CSS, JS)
- `templates/` - HTML шаблоны

### `/exchanges` - Модули бирж

Интеграция с различными биржами

### `/examples` - Примеры использования

Примеры кода и конфигураций

```bash
# Основной запуск
python main.py

# Бэктест
python main.py backtest

# DCA бэктест
python main.py dca
```
