```

Retracement: лучшая цена (-0.3% от текущей)
Confirmation: защита от ложных пробоев
```

**Ожидаемый эффект:** +3% прибыльности за счет лучшего timing

### **1. Entry Timing:**

```

Если ошибка → fallback к immediate entry
Если слабый сигнал → ждет подтверждения
```

### **2. Adaptive Weights:**

```
Минимум 10 сделок → иначе используются текущие веса
Плавное изменение → макс 20% за раз
Проверка каждый час → не перегружает систему
```
