## ⚠️ ИЗВЕСТНЫЕ ПРОБЛЕМЫ И РЕШЕНИЯ

### **1. Баланс всё ещё 5000 вместо 1000**

**Причина:** `load_user_data()` кешируется где-то или БД не обновилась.

**РЕШЕНИЕ:**

1. Проверьте в Telegram: `/balance`
2. Если показывает 1000 — всё ОК, просто бот не перезагрузил
3. Перезапустите бот: `python3 main.py`
4. При следующем сигнале будет баланс=1000

**ИЛИ:**

```bash
# Вручную обновите БД
sqlite3 trading.db "UPDATE users SET deposit=1000, balance=1000;"
# Перезапустите бот
python3 main.py
```

---

### **2. SL/TP не выставляются (ошибка "The order type is illegal")**

**Причина:** Bitget не принимал типы `stop_market` и `take_profit_market`.

**ИСПРАВЛЕНО:** Использую тип `trigger` с `triggerPrice`.

**ПОСЛЕ ПЕРЕЗАПУСКА:** SL/TP будут выставляться успешно!

---

### **3. Плечо 10x вместо 2x**

**Причина:** Bitget использовал дефолтное плечо символа.

**ИСПРАВЛЕНО:**

- Вызов `set_leverage()` перед созданием ордера
- Передача плеча из сигнала (округлённого)

**ПОСЛЕ ПЕРЕЗАПУСКА:** Плечо будет правильным (2x)!
