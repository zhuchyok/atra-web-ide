## 🎯 **ПРАКТИЧЕСКОЕ ПРИМЕНЕНИЕ**

### **На сервере с talib:**

```python
# Система автоматически использует talib
from talib_wrapper import get_talib
talib = get_talib()  # Возвращает нативный talib

# Все функции работают как обычно
sma = talib.SMA(data, timeperiod=20)
rsi = talib.RSI(data, timeperiod=14)
```

### **На сервере без talib:**

```python
# Система автоматически переключается на fallback
from talib_wrapper import get_talib
talib = get_talib()  # Возвращает fallback класс

# API остается тем же, но используется pandas/ta
sma = talib.SMA(data, timeperiod=20)  # Работает через pandas
rsi = talib.RSI(data, timeperiod=14)  # Работает через pandas
```
