## 🎯 Как блоки влияют на сигналы

### 🔴 **STRICT режим:**

```python
# Отклонение при противоречии >50%
if seller_strength / buyer_strength >= 1.5:
    return None, None  # Сигнал отклонен

# Ослабление при противоречии >20%
elif seller_strength / buyer_strength >= 1.2:
    return "LONG ⚠️", price  # Сигнал ослаблен

# Усиление при подтверждении >20%
elif buyer_strength / seller_strength >= 1.25:
    return "LONG 🔥", price  # Сигнал усилен
```

### 🟢 **SOFT режим:**

```python
# Отклонение при противоречии >100%
if seller_strength / buyer_strength >= 2.0:
    return None, None  # Сигнал отклонен

# Ослабление при противоречии >50%

    return "LONG ⚠️", price  # Сигнал ослаблен

# Усиление при подтверждении >30%
```
