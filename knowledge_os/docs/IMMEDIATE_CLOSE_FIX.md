# 🛡️ ИСПРАВЛЕНИЕ: Немедленное закрытие позиций после открытия

**Дата:** 2025-11-06  
**Проблема:** Позиция ETHFIUSDT открылась в 19:59:16 и закрылась в 19:59:17 (через 1 секунду)

## 🔴 ПРОБЛЕМА

По скриншоту истории ордеров видно:

1. **19:59:16** - Открытие SHORT позиции ETHFIUSDT (26.4 ETHFI, 2x плечо)
2. **19:59:17** - Закрытие позиции (Reduce Only: Yes, PnL: +0.00792 USDT)

**Причина:** Синхронизация позиций запустилась сразу после открытия и не нашла позицию на бирже (задержка появления в API), поэтому закрыла её локально.

## ✅ РЕШЕНИЕ

### 1. Увеличено время защиты с 5 до 10 минут

**Было:**

```python
if time_since_entry < timedelta(minutes=5):
    # Пропускаем закрытие
```

**Стало:**

```python
if time_since_entry < timedelta(minutes=10):
    # Пропускаем закрытие (защита от преждевременного закрытия)
```

### 2. Улучшена защита при ошибках парсинга

**Было:**

```python
except (ValueError, TypeError) as e:
    logger.debug("Не удалось распарсить время")
    # Продолжаем выполнение (может закрыть позицию)
```

**Стало:**

```python
except (ValueError, TypeError) as e:
    logger.warning("Не удалось распарсить время. Защита: НЕ закрываем позицию (безопасный режим)")
    continue  # НЕ закрываем позицию при ошибке
```

### 3. Улучшено логирование

- Изменен уровень логирования с `DEBUG` на `WARNING` для ошибок парсинга
- Добавлены подробные сообщения о причине пропуска закрытия

## 📝 ИЗМЕНЕНИЯ В КОДЕ

### `main.py` - Функция `_sync_positions_periodically`

```python
# 🛡️ ЗАЩИТА: Не закрываем позиции, которые были открыты менее 10 минут назад
# Это защита от преждевременного закрытия из-за задержки появления позиции на бирже
try:
    from datetime import timedelta
    import sqlite3

    # Получаем время создания позиции из БД
    with sqlite3.connect(adb_local.db_path) as conn:
        cursor = conn.cursor()
        cursor.execute(
            """
            SELECT entry_time, created_at FROM active_positions
            WHERE symbol = ? AND accepted_by = ?
              AND UPPER(IFNULL(status,'open')) LIKE 'OPEN%'
            ORDER BY created_at DESC LIMIT 1
            """,
            (sym, str(uid))
        )
        result = cursor.fetchone()

        if result:
            entry_time_str = result[0] or result[1]
            if entry_time_str:
                try:
                    # Парсим время создания
                    if isinstance(entry_time_str, str):
                        entry_time = datetime.fromisoformat(entry_time_str.replace('Z', '+00:00'))
                    else:
                        entry_time = datetime.fromtimestamp(entry_time_str)

                    # Проверяем, прошло ли 10 минут (увеличено для надежности)
                    time_since_entry = datetime.now() - entry_time.replace(tzinfo=None) if entry_time.tzinfo else datetime.now() - entry_time

                    if time_since_entry < timedelta(minutes=10):
                        logger.warning(
                            "⏸️ [SYNC] Позиция %s для пользователя %d слишком новая "
                            "(открыта %s назад, требуется минимум 10 минут). "
                            "Пропускаем закрытие (защита от преждевременного закрытия).",
                            sym, uid, time_since_entry
                        )
                        continue
                except (ValueError, TypeError) as e:
                    logger.warning(
                        "⚠️ [SYNC] Не удалось распарсить время для позиции %s: %s. "
                        "Защита: НЕ закрываем позицию (безопасный режим)",
                        sym, e
                    )
                    # В случае ошибки парсинга НЕ закрываем позицию (безопасный режим)
                    continue
except Exception as e:
    logger.warning(
        "⚠️ [SYNC] Ошибка проверки времени создания позиции %s: %s. "
        "Защита: НЕ закрываем позицию (безопасный режим)",
        sym, e
    )
    # В случае ошибки проверки НЕ закрываем позицию (безопасный режим)
    continue
```

## 🎯 ОЖИДАЕМЫЕ РЕЗУЛЬТАТЫ

### До исправления:

- Позиции закрывались через 1-2 секунды после открытия
- Защита 5 минут не всегда срабатывала
- При ошибках парсинга позиции могли закрываться

### После исправления:

- Позиции не закрываются в течение 10 минут после открытия
- При ошибках парсинга позиции НЕ закрываются (безопасный режим)
- Подробное логирование помогает понять, что происходит
