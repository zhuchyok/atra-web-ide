# Отчет: Получение актуальной цены при принятии сигналов

## 🎯 **Проблема**

Пользователь сообщил: **"пользователь принимает сигнал с небольшой задержкой и нужно чтобы принятие учитывалось для расчета статистики цена монеты на момент принятия сделки"**

## 🔍 **Анализ проблемы**

### **Что было найдено:**

1. **Использование устаревшей цены** ❌
   - При принятии сигнала использовалась цена из исходного сигнала
   - Не учитывалось изменение цены за время между отправкой и принятием сигнала
   - Статистика рассчитывалась на основе устаревших данных

2. **Отсутствие получения актуальной цены** ❌
   - Функции `button` и `accept_signal_cmd` не получали текущую цену
   - Использовали только `entry_price` из callback_data
   - Нет fallback при ошибках получения цены

3. **Влияние на статистику** ❌
   - P&L рассчитывался на основе устаревшей цены входа
   - Статистика не отражала реальную ситуацию на рынке
   - Пользователь мог получать неточную информацию о прибыльности

### **Корень проблемы:**

```python
# В функции button - БЫЛО:
entry_price = float(data[3]) if len(data) > 3 else None
# ❌ Использовалась только цена из сигнала, без получения актуальной
```

## ✅ **Исправления**

### **1. Добавлено получение актуальной цены в функцию `button`:**

```python
# Стало:
original_entry_price = float(data[3]) if len(data) > 3 else None
# ... другие параметры ...

# Получаем актуальную цену на момент принятия сигнала
from exchange_api import get_ohlc_binance_sync
current_price = original_entry_price  # По умолчанию используем исходную цену

try:
    ohlc = get_ohlc_binance_sync(symbol, interval="1m", limit=1)
    if ohlc and len(ohlc) > 0:
        current_price = ohlc[-1]["close"]
        print(f"[DEBUG] Актуальная цена для {symbol}: {current_price} (исходная: {original_entry_price})")
    else:
        print(f"[WARNING] Не удалось получить актуальную цену для {symbol}, используем исходную: {original_entry_price}")
except Exception as e:
    print(f"[ERROR] Ошибка получения актуальной цены для {symbol}: {e}, используем исходную: {original_entry_price}")

# Используем актуальную цену для расчетов
entry_price = current_price
```

## 🔧 **Технические детали**

### **Файлы изменены:**

- `telegram_bot.py` (строка 870) - добавлено получение актуальной цены в функцию `button`
- `telegram_bot.py` (строка 4125) - добавлено получение актуальной цены в функцию `accept_signal_cmd`

### **Функции затронуты:**

- `button()` - добавлено получение актуальной цены при принятии сигнала
- `accept_signal_cmd()` - добавлено получение актуальной цены при ручном принятии

### **Логика работы:**

1. **Парсинг исходной цены:** Извлекаем `original_entry_price` из callback_data
2. **Получение актуальной цены:** Вызываем `get_ohlc_binance_sync` для получения текущей цены
3. **Fallback механизм:** При ошибке используем исходную цену
4. **Использование актуальной цены:** Все расчеты выполняются с актуальной ценой

### **Обработка ошибок:**

- ✅ Нет данных от API → используем исходную цену
- ✅ Ошибка сети → используем исходную цену
- ✅ Неправильный символ → используем исходную цену
- ✅ Успешное получение → используем актуальную цену
