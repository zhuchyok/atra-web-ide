## 🔧 Принципы единого стиля

### 1. **Структура сообщений:**

- **Заголовок** с эмодзи и типом действия
- **Основная информация** о депозите, позициях, свободных средствах
- **Детали операции** с маркированным списком (•)
- **Дополнительная информация** (баланс, TP, P&L)

### 2. **Форматирование:**

- **Жирный текст** для заголовков секций
- **Маркированные списки** (•) для деталей
- **Эмодзи** для визуального разделения
- **Единообразные отступы** и структура

### 3. **Информация:**

- **Всегда показывается:** депозит, количество позиций, свободные средства
- **Контекстная информация:** зависит от типа операции
- **Обновленный баланс:** для операций, влияющих на баланс

### 4. **Эмодзи и цвета:**

- **✅** - успешные операции (принятие сигналов)
- **🟢** - прибыльные операции (закрытие в плюс)
- **🔴** - убыточные операции (закрытие в минус)
- **📊** - детальная информация
- **💰** - финансовая информация
- **🎯** - целевые уровни (TP)
