## 📋 ОПИСАНИЕ ЗАДАЧИ

Внедрить автоматическую установку зависимостей при запуске торговой системы ATRA для обеспечения стабильной работы без необходимости ручной установки пакетов.

## 🎯 ЦЕЛИ

1. **Автоматическая проверка зависимостей** при запуске системы
2. **Автоматическая установка** отсутствующих пакетов
3. **Создание файла requirements.txt** со всеми необходимыми зависимостями
4. **Отдельный скрипт** для ручной установки зависимостей
5. **Проверка готовности системы** к запуску

### 2. Обновлен `main.py`

Добавлены функции:

#### `install_dependencies()`

- Проверяет наличие `requirements.txt`
- Проверяет наличие `pip`
- Устанавливает зависимости из `requirements.txt`
- Возвращает статус установки

#### `check_critical_dependencies()`

- Проверяет наличие критических модулей
- Автоматически устанавливает отсутствующие зависимости
- Проверяет готовность системы к запуску

#### Обновлена функция `main()`

- Добавлена проверка зависимостей перед запуском
- Система не запускается при отсутствии критических зависимостей

### 3. Создан `install_dependencies.py`

Интерактивный скрипт для установки зависимостей с поддержкой виртуального окружения:

#### Функции:

- `check_python_version()` - проверка версии Python
- `check_venv()` - проверка работы в виртуальном окружении
- `create_venv()` - создание виртуального окружения
- `upgrade_pip_in_venv()` - обновление pip в venv
- `install_requirements_in_venv()` - установка зависимостей в venv
- `verify_installation_in_venv()` - проверка установки в venv
- `create_activation_script()` - создание скриптов активации

#### Возможности:

- Интерактивный выбор способа установки
- Автоматическое создание виртуального окружения
- Установка в venv или глобальное окружение
- Создание скриптов активации для удобства
- Fallback механизмы для надежности

### 4. Создан `setup_venv.sh`

Быстрый bash скрипт для автоматической настройки виртуального окружения:

#### Возможности:

- Автоматическое создание и активация venv
- Обновление pip
- Установка зависимостей из requirements.txt
- Fallback установка критических пакетов
- Проверка готовности системы

## 🚀 СПОСОБЫ ИСПОЛЬЗОВАНИЯ

### 1. Быстрая установка виртуального окружения (macOS/Linux)

```bash
chmod +x setup_venv.sh
./setup_venv.sh
```

### 2. Интерактивная установка

```bash
python3 install_dependencies.py
```

Выберите способ установки (venv, глобальная, проверка).

### 3. Автоматическая установка при запуске

```bash
python3 main.py
```

Система автоматически проверит и установит зависимости перед запуском.

### 4. Классическая установка

```bash
pip install -r requirements.txt
```

Стандартная установка из requirements.txt.
