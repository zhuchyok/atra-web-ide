# 🎯 Система классификации волатильности ATRA

## 📊 Обзор системы

Система классификации волатильности автоматически распределяет криптовалюты по группам волатильности и применяет к каждой группе свои динамические параметры торговли:

- 🟢 **Низкая волатильность** (0-2%) - стабильные монеты
- 🟡 **Средняя волатильность** (2-5%) - сбалансированные монеты
- 🟠 **Высокая волатильность** (5-15%) - волатильные монеты
- 🔴 **Экстремальная волатильность** (15%+) - очень волатильные монеты

## 🧮 Алгоритм классификации

### Расчет волатильности

```python
def calculate_volatility(self, df):
    """Рассчитывает волатильность на основе ATR"""
    # ATR (Average True Range) за 14 периодов
    df["atr"] = ta.volatility.AverageTrueRange(
        df["high"], df["low"], df["close"], window=14
    ).average_true_range()

    # Волатильность как процент от цены
    current_price = df["close"].iloc[-1]
    current_atr = df["atr"].iloc[-1]
    volatility_pct = (current_atr / current_price) * 100

    return volatility_pct
```

### Группы волатильности

#### 🟢 Низкая волатильность (0-2%)

**Характеристики:**

- Стабильные монеты с предсказуемым поведением
- Низкий риск, но и низкий потенциал прибыли
- Подходят для консервативных трейдеров

**Динамические параметры:**

- **Риск:** 0.8x (снижен на 20%)
- **Плечо:** 1.2x (увеличено на 20%)
- **TP:** 0.8x (уменьшены на 20%)
- **SL:** 0.8x (уменьшен на 20%)
- **RSI порог:** 85 (более строгий)
- **Объем:** 0.5x (сниженные требования)

**Примеры:** BTCUSDT, ETHUSDT, BNBUSDT

#### 🟡 Средняя волатильность (2-5%)

**Характеристики:**

- Сбалансированные монеты с умеренным риском
- Оптимальное соотношение риск/прибыль
- Подходят для большинства трейдеров

**Динамические параметры:**

- **Риск:** 1.0x (стандартный)
- **Плечо:** 1.0x (стандартное)
- **TP:** 1.0x (стандартные)
- **SL:** 1.0x (стандартный)
- **RSI порог:** 80 (стандартный)
- **Объем:** 1.0x (стандартные требования)

**Примеры:** SOLUSDT, XRPUSDT, ADAUSDT, AVAXUSDT

#### 🟠 Высокая волатильность (5-15%)

**Характеристики:**

- Волатильные монеты с высоким потенциалом
- Повышенный риск, но и высокая прибыльность
- Подходят для опытных трейдеров

**Динамические параметры:**

- **Риск:** 0.6x (снижен на 40%)
- **Плечо:** 0.7x (снижено на 30%)
- **TP:** 1.5x (увеличены на 50%)
- **SL:** 1.3x (увеличен на 30%)
- **RSI порог:** 75 (более мягкий)
- **Объем:** 1.5x (повышенные требования)

**Примеры:** DOGEUSDT, SHIBUSDT, PEPEUSDT, BONKUSDT

#### 🔴 Экстремальная волатильность (15%+)

**Характеристики:**

- Очень волатильные монеты (только для опытных)
- Максимальный риск и максимальный потенциал
- Требуют особой осторожности

**Динамические параметры:**

- **Риск:** 0.4x (снижен на 60%)
- **Плечо:** 0.5x (снижено на 50%)
- **TP:** 2.0x (увеличены в 2 раза)
- **SL:** 1.5x (увеличен на 50%)
- **RSI порог:** 70 (очень мягкий)
- **Объем:** 2.0x (высокие требования)

**Примеры:** WIFUSDT, FLOKIUSDT, BOMEUSDT
