# 📋 РУКОВОДСТВО ПО ИСПОЛЬЗОВАНИЮ bot_menu.sh

**Интерактивное меню управления ботом ATRA**

---

## 🚀 Запуск меню

```bash
./bot_menu.sh
```

---

## 📊 Основные функции

### 1. ▶️ Запустить бота

- Проверяет, не запущен ли бот уже
- Запускает бот в фоновом режиме
- Сохраняет логи в `bot.log`

### 2. ⏹️ Остановить бота

- Останавливает все процессы бота
- Очищает lock файлы
- Проверяет успешность остановки

### 3. 🔄 Перезапустить бота

- Останавливает бот
- Запускает заново
- Проверяет статус

### 4. 📋 Просмотр логов (реальное время)

- **Все логи** - полный вывод `tail -f`
- **Только ошибки** - фильтр ERROR/CRITICAL/EXCEPTION
- **AUTO-исполнение** - логи авто-режима
- **Сигналы** - логи генерации сигналов
- **Последние 50 строк** - быстрый просмотр
- **Поиск по тексту** - фильтрация по ключевому слову

### 5. 🔄 Обновить код (git pull)

- **Обновить через git pull** - загружает изменения
- **Обновить и перезапустить** - загружает и перезапускает бота
- **Показать git log** - последние коммиты
- **Отменить** - выход без изменений

### 6. 📊 Статус системы

- Статус бота (запущен/остановлен)
- Информация о процессах (PID, CPU, MEM)
- Использование ресурсов
- Статистика логов
- Размер базы данных

### 7. 🗄️ Проверка базы данных

- Пользователи в авто-режиме
- Активные позиции
- Всего сигналов
- Pending сигналы

### 8. 📦 Установить зависимости

- Обновляет зависимости из `requirements.txt`
- Использует `pip3 install -r requirements.txt --upgrade`

### 9. 🗑️ Очистить логи

- Очищает файл `bot.log`
- Требует подтверждения

### 0. ❌ Выход

- Завершает работу меню

---

## 🎨 Особенности

### Цветной интерфейс

- 🟢 Зеленый - успешные операции
- 🔴 Красный - ошибки
- 🟡 Желтый - предупреждения
- 🔵 Синий - информация

### Автоматическая проверка статуса

- При каждом открытии меню показывается текущий статус бота
- Показываются последние записи из логов

### Безопасность

- Проверка перед остановкой
- Подтверждение перед очисткой логов
- Проверка существования процессов перед запуском

## 🔧 Технические детали

### Поддерживаемые процессы

- `python3 main.py`
- `uvicorn` (REST API)
- `flask` (Dashboard)

### Файлы

- `bot.log` - основной лог файл
- `bot.pid` - PID файл (создается при запуске)
- `telegram_polling.lock` - lock файл Telegram бота

### Команды

- `pkill -9 -f` - принудительная остановка процессов
- `nohup python3 main.py > bot.log 2>&1 &` - запуск в фоне
- `tail -f bot.log` - просмотр логов в реальном времени

---

## ⚠️ Важные замечания

1. **Просмотр логов в реальном времени** - используйте `Ctrl+C` для выхода
2. **Очистка логов** - необратимая операция, требуется подтверждение
3. **Обновление кода** - рекомендуется делать бэкап перед обновлением
4. **Перезапуск** - может занять несколько секунд для инициализации

### Меню не запускается

```bash
chmod +x bot_menu.sh
```

### Процессы не останавливаются

```bash
./kill_all.sh
```

### Логи не отображаются

```bash
ls -lh bot.log
# Проверьте размер файла
```
