## 📦 КОМПОНЕНТЫ

### **1. `knowledge_os/app/cursorrules_generator.py`**

Модуль для генерации `.cursorrules` из БД:

**Функционал:**

- ✅ Чтение экспертов из БД (таблица `experts`)
- ✅ Получение метрик каждого эксперта:
  - Количество знаний
  - Средняя уверенность
  - Количество взаимодействий
  - Средний feedback
- ✅ Получение доменов знаний эксперта
- ✅ Получение топ знаний эксперта
- ✅ Определение уровня эксперта (Guru/Expert/Advanced/Intermediate/Beginner)
- ✅ Генерация секций для каждого эксперта
- ✅ Обновление `.cursorrules` файла

**Уровни экспертов:**

- ⭐⭐⭐⭐⭐ **Guru**: 100+ знаний, confidence ≥ 0.9, 50+ взаимодействий
- ⭐⭐⭐⭐ **Expert**: 50+ знаний, confidence ≥ 0.8, 25+ взаимодействий
- ⭐⭐⭐ **Advanced**: 20+ знаний, confidence ≥ 0.7
- ⭐⭐ **Intermediate**: 10+ знаний
- ⭐ **Beginner**: менее 10 знаний

### **2. Интеграция в Nightly Learner**

**ФАЗА 9: UPDATE CURSORRULES** добавлена в `nightly_learner.py`:

```python
# --- ФАЗА 9: UPDATE CURSORRULES (ОБНОВЛЕНИЕ .CURSORRULES) ---
print("📝 Updating .cursorrules from database...")
try:
    from cursorrules_generator import update_cursorrules_file
    await update_cursorrules_file()
except Exception as e:
    print(f"⚠️ .cursorrules update error: {e}")
```

**Расписание:** Обновление происходит каждую ночь после всех других фаз обучения.
