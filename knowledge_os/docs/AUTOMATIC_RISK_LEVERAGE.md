# 🤖 АВТОМАТИЧЕСКАЯ СИСТЕМА РИСКОВ И ПЛЕЧЕЙ

## 📋 Обзор системы

Система полностью автоматизирована - **риски и плечи рассчитываются автоматически** на основе текущих рыночных условий. Пользователи **не могут** изменять эти параметры вручную для обеспечения безопасности и оптимальной работы стратегии.

## 🔄 Как работает автоматический расчет

### Риск (Risk Percentage)

- **Диапазон:** 0.5% - 5%
- **Факторы влияния:**
  - Волатильность рынка
  - Тренд BTC (бычий/медвежий)
  - Текущие рыночные условия
  - Сила сигнала

### Плечо (Leverage)

- **Диапазон:** 0.5x - 5x
- **Факторы влияния:**
  - Волатильность рынка
  - Тренд BTC
  - Режим торговли (spot/futures)
  - Текущие рыночные условия

## 🛡️ Преимущества автоматической системы

### 1. **Безопасность**

- Исключает человеческие ошибки
- Предотвращает чрезмерные риски
- Адаптируется к рыночным условиям

### 2. **Оптимизация**

- Максимальная прибыль в благоприятных условиях
- Минимизация потерь в неблагоприятных условиях
- Динамическая адаптация к рынку

### 3. **Простота использования**

- Не требует ручной настройки
- Работает "из коробки"
- Минимум действий от пользователя

## 📊 Алгоритмы расчета

### Динамический риск

```python
def get_dynamic_risk_pct(df, i, base_risk=2.0):
    # Анализ волатильности
    volatility = calculate_volatility(df, i)

    # Анализ тренда BTC
    btc_trend = get_btc_trend_status()

    # Корректировка риска
    if btc_trend == "BULLISH" and volatility < 0.02:
        risk_multiplier = 1.5  # Увеличиваем риск
    elif btc_trend == "BEARISH" or volatility > 0.05:
        risk_multiplier = 0.5  # Уменьшаем риск
    else:
        risk_multiplier = 1.0

    dynamic_risk = base_risk * risk_multiplier
    return min(max(dynamic_risk, 0.5), 5.0)  # Ограничения 0.5-5%
```

### Динамическое плечо

```python
def get_dynamic_leverage(df, i, base_leverage=1):
    # Анализ волатильности
    volatility = calculate_volatility(df, i)

    # Анализ тренда
    trend_strength = calculate_trend_strength(df, i)

    # Корректировка плеча
    if trend_strength > 0.7 and volatility < 0.03:
        leverage_multiplier = 2.0  # Увеличиваем плечо
    elif volatility > 0.06 or trend_strength < 0.3:
        leverage_multiplier = 0.5  # Уменьшаем плечо
    else:
        leverage_multiplier = 1.0

    dynamic_leverage = base_leverage * leverage_multiplier
    return min(max(dynamic_leverage, 0.5), 5.0)  # Ограничения 0.5-5x
```
