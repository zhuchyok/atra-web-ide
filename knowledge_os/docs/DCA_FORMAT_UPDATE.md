# Обновление формата DCA сигналов

## 🎯 Цель

Привести все DCA сигналы к единому стилю, соответствующему новым торговым сигналам.

## ✅ Выполненные изменения

## 🔧 Технические изменения

### 1. HTML форматирование

- Заменены Markdown теги (`*`, `` ` ``) на HTML теги (`<b>`, `<code>`)
- Добавлено единообразное форматирование для всех элементов

### 2. Структура сообщений

- Единый заголовок с эмодзи
- Структурированная информация в логическом порядке
- Отдельные блоки для DCA информации
- Быстрые команды в едином стиле

### 3. Кнопки принятия

- Все DCA сигналы теперь имеют кнопки принятия
- Обновлен формат callback_data для соответствия новым требованиям
- Единообразный текст кнопок

### 4. Информация о TP

- Добавлен расчет процентов для TP
- Единый формат отображения TP1 и TP2
- Информация о прибыли в процентах
