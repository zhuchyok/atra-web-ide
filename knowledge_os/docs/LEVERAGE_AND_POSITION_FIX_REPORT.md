# Отчет: Исправление проблемы с плечом и открытием позиций

## 🚨 Проблемы

1. **Плечо 1x для фьючерсов** - должно быть минимум 2x
2. **Позиция не открывается** - система показывает "Открытых позиций: 0"
3. **Неправильный расчет риска** - для фьючерсов с плечом расчет должен быть другим

## 🔍 Диагностика

### Проблема с плечом

В коде было неправильное определение плеча:

```python
# НЕПРАВИЛЬНО:
leverage = dynamic_leverage if dynamic_leverage is not None else (user_data.get("leverage", 1) if trade_mode == "futures" else 1)
```

**Проблема**: Для фьючерсов система брала `user_data.get("leverage", 1)`, но если плечо не установлено или равно 0, то использовалось значение по умолчанию 1.

### Проблема с открытием позиций

Позиция не открывалась из-за неправильного определения плеча, что влияло на расчет риска и проверки лимитов.

## ✅ Исправления

### 1. Правильное определение плеча

Заменили неправильную логику на правильную:

```python
# ПРАВИЛЬНО:
# Правильное определение плеча для фьючерсов
if dynamic_leverage is not None:
    leverage = dynamic_leverage
elif trade_mode == "futures":
    leverage = user_data.get("leverage", 2)  # Минимум 2x для фьючерсов
    if leverage <= 1:
        leverage = 2  # Принудительно устанавливаем минимум 2x
else:
    leverage = 1  # Для SPOT всегда 1x
```

### 2. Места исправления

Исправили определение плеча в трех местах:

1. **Функция `button`** (строка ~1228) - обработка нажатия кнопок в сигналах
2. **Функция `accept_signal_cmd`** (строка ~5025) - команда `/accept`
3. **Функция `button`** (строка ~1400) - логика открытия новой позиции

### 3. Логика исправления

- **Для фьючерсов**: Минимум 2x плечо, если установлено меньше - принудительно 2x
- **Для SPOT**: Всегда 1x плечо
- **Динамическое плечо**: Если передано в сигнале, используем его
