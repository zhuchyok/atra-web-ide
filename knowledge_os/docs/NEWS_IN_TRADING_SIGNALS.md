# 📰 НОВОСТИ В ТОРГОВЫХ СИГНАЛАХ

## ✅ РЕАЛИЗОВАНО

**Система уже включает краткую информацию о новостях в торговые сигналы!**

### 🎯 Как это работает:

#### 1. **Новостное усиление сигналов**

- Когда есть технический сигнал + соответствующая новость
- `news_enhanced: True` - флаг новостного усиления
- `news_post` - объект с информацией о новости

#### 2. **Формат включения новостей в сигнал**

```python
# Проверяем, усилен ли сигнал новостями
is_news_enhanced = signal.get('news_enhanced', False)
news_info = ""
if is_news_enhanced and signal.get('news_post'):
    news_post = signal['news_post']
    # Краткая информация о новости прямо в сигнале
    news_title = news_post.get('title', '')
    news_source = news_post.get('source', 'Unknown')

    # Сокращаем заголовок до 60 символов для компактности
    short_title = news_title[:60] + "..." if len(news_title) > 60 else news_title

    # Определяем тип новости (позитивная/негативная)
    news_type = "🟢" if signal.get('side') == 'long' else "🔴"

    news_info = f"\n{news_type} *Новость:* {short_title}\n📰 Источник: {news_source}\n"
```

#### 3. **Индикатор в заголовке сигнала**

```python
# Добавляем индикатор новостного усиления в заголовок
news_indicator = " 📰" if is_news_enhanced else ""

msg = f"{side_emoji} *НОВЫЙ ТОРГОВЫЙ СИГНАЛ*{news_indicator}\n\n"
```

### 🔧 Логика новостного усиления:

#### **LONG сигналы:**

- Технический LONG сигнал + позитивная новость
- `news_enhanced: True`
- `news_post: positive_news_post`

#### **SHORT сигналы:**

- Технический SHORT сигнал + негативная новость
- `news_enhanced: True`
- `news_post: negative_news_post`
- Только для фьючерсов (`trade_mode: 'futures'`)

### 📋 Источники новостей:

- **CoinGecko** - позитивные новости
- **TradingView** - технические новости
- **CryptoPanic** - негативные новости
