## 🚀 БЫСТРОЕ РЕШЕНИЕ

### Вариант 1: Принудительное обновление (рекомендуется)

```bash
# На сервере выполните:
cd /path/to/atra
chmod +x force_update_server.sh
./force_update_server.sh
```

### Вариант 2: Ручные команды

```bash
# 1. Остановите все процессы
pkill -f "python.*main.py"
sleep 5

# 2. Удалите lock файл
rm -f atra.lock

# 3. Обновите код принудительно
git reset --hard origin/worker
git pull origin worker

# 4. Запустите систему
nohup python3 main.py > system.log 2>&1 &
```

### Вариант 3: Через bot_manager

```bash
# Если bot_manager доступен:
./bot_manager.sh stop
git reset --hard origin/worker
git pull origin worker
./bot_manager.sh start
```
