# 🔍 ЧТО ТАКОЕ АВТОПОДБОР МОНЕТ (AUTO_FETCH_COINS)?

**Дата:** 2025-12-13  
**Вопрос:** Что означает "автоподбор" монет?

---

## 📖 ОПРЕДЕЛЕНИЕ

**Автоподбор (AUTO_FETCH_COINS)** — это режим, при котором система **автоматически получает список монет** из биржи через API, вместо использования заранее заданного списка `COINS` из `config.py`.

---

## 🔄 КАК ЭТО РАБОТАЕТ

### **1. Когда AUTO_FETCH_COINS = true:**

```python
# В config.py
AUTO_FETCH_COINS = os.getenv("AUTO_FETCH_COINS", "true")  # Включен
```

**Логика в `get_symbols()`:**

```python
if AUTO_FETCH_COINS:
    # Игнорируем COINS из config.py
    # Получаем монеты через API
    symbols = await get_filtered_top_usdt_pairs_fast(
        top_n=500,      # Запрашиваем топ-500 монет
        final_limit=200 # Оставляем топ-200 после фильтрации
    )
    return ready_symbols
```

### **2. Функция `get_filtered_top_usdt_pairs_fast()`:**

**Что делает:**

1. **Запрашивает данные с биржи** (Binance API)
2. **Получает список всех торговых пар** USDT
3. **Фильтрует по критериям:**
   - Объем торгов (volume)
   - Ликвидность
   - Исключает стейблкоины
   - Исключает дубликаты
4. **Возвращает топ-N монет** (например, топ-200)

**Пример:**

```python
async def get_filtered_top_usdt_pairs_fast(top_n=500, final_limit=200):
    """
    Получает топовые монеты с биржи через API

    Args:
        top_n: Сколько монет запросить (500)
        final_limit: Сколько оставить после фильтрации (200)

    Returns:
        List[str]: Список символов, например:
        ['BTCUSDT', 'ETHUSDT', 'BNBUSDT', 'SOLUSDT', ...]
    """
    # 1. Запрос к Binance API
    tickers = await binance_api.get_24h_ticker()

    # 2. Фильтрация по объему
    filtered = filter_by_volume(tickers, min_volume=1000000)

    # 3. Сортировка по объему (от большего к меньшему)
    sorted_coins = sort_by_volume(filtered)

    # 4. Возвращаем топ-N
    return sorted_coins[:final_limit]
```

## 📊 СРАВНЕНИЕ РЕЖИМОВ

### **AUTO_FETCH_COINS = false (Ручной список):**

```python
# Используется список COINS из config.py
COINS = [
    "BTCUSDT",
    "ETHUSDT",
    "SOLUSDT",
    # ... еще 19 монет
]
# Итого: 22 монеты (фиксированный список)
```

**Преимущества:**

- ✅ Контролируемый список
- ✅ Только проверенные монеты
- ✅ Быстрая работа (не нужно запрашивать API)

**Недостатки:**

- ❌ Нужно вручную добавлять новые монеты
- ❌ Может пропустить перспективные монеты
- ❌ Ограниченный набор (22 монеты)

---

### **AUTO_FETCH_COINS = true (Автоподбор):**

```python
# Система автоматически получает монеты через API
symbols = await get_filtered_top_usdt_pairs_fast(top_n=500, final_limit=200)
# Итого: ~200 монет (динамический список)
```

**Преимущества:**

- ✅ Автоматическое обновление списка
- ✅ Больше монет (до 200)
- ✅ Включает новые перспективные монеты
- ✅ Адаптируется к изменениям рынка

**Недостатки:**

- ❌ Зависит от доступности API
- ❌ Может включать нестабильные монеты
- ❌ Медленнее (нужно запрашивать API)
- ❌ Может вернуть только 2-6 монет, если они не оптимизированы

---

## 🎯 КАК ЭТО РАБОТАЕТ В НАШЕЙ СИСТЕМЕ

### **До исправления:**

```python
# AUTO_FETCH_COINS = true
if AUTO_FETCH_COINS:
    symbols = await get_filtered_top_usdt_pairs_fast(top_n=500, final_limit=200)
    # Но только оптимизированные монеты считались готовыми
    # Результат: только 2-6 монет
```

**Проблема:**

- Запрашивалось 200 монет
- Но только 2-6 были оптимизированы
- Остальные блокировались

---

### **После исправления:**

```python
# ПРИОРИТЕТ 0: intelligent_filter_system (143 монеты)
# ПРИОРИТЕТ 1: COINS (22 монеты)
# ПРИОРИТЕТ 2: AUTO_FETCH_COINS (если включен)
```

**Теперь:**

- ✅ Используются все 143 монеты из `intelligent_filter_system`
- ✅ Автоподбор используется как fallback
- ✅ Монеты с базовыми параметрами разрешены

## 🔧 ТЕКУЩАЯ КОНФИГУРАЦИЯ

### **В config.py:**

```python
AUTO_FETCH_COINS = os.getenv("AUTO_FETCH_COINS", "false")  # 🔧 ИСПРАВЛЕНО: false
```

**Значение:**

- `false` — используем `COINS` или `intelligent_filter_system` (143 монеты)
- `true` — используем автоподбор через API (до 200 монет)

---

## ✅ ИТОГ

**Автоподбор (AUTO_FETCH_COINS):**

- Это автоматическое получение списка монет через API биржи
- Вместо фиксированного списка `COINS`
- Может вернуть до 200 монет
- Но требует доступности API и оптимизации монет

**Текущая настройка:**

- `AUTO_FETCH_COINS = false` — используем 143 монеты из `intelligent_filter_system`
- Автоподбор используется как fallback, если `intelligent_filter_system` недоступен
