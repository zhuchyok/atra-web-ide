# Очистка кнопок из уведомлений о тейк-профитах

## 🎯 Проблема

Пользователь правильно заметил, что кнопки в уведомлениях о тейк-профитах не нужны, поскольку:

- **Позиции закрываются автоматически** при достижении TP
- **Система пересчитывает** все данные
- **В открытых позициях** позиция автоматически закрывается

## ✅ Выполненные изменения

### 1. Удалены кнопки из уведомлений о TP1

**Было:**

```python
# Кнопка "Закрыть 50%"
keyboard = InlineKeyboardMarkup([
    [
        InlineKeyboardButton(
            "🔴 Закрыть 50%",
            callback_data=f'close_tp|{symbol}|{close_price}|{close_50_qty:.4f}|{user_id}|tp1'
        ),
        InlineKeyboardButton(
            "🟢 Ждать TP2",
            callback_data=f'wait_tp2|{symbol}|{user_id}'
        )
    ]
])

await notify_user(int(user_id), msg, reply_markup=keyboard)
```

**Стало:**

```python
# Отправляем уведомление
msg = (
    f"🎯 <b>ТЕЙК ПРОФИТ 1 ДОСТИГНУТ!</b>\n\n"
    f"Символ: {symbol}\n"
    f"Сторона: {side.upper()}\n"
    f"Цена входа: {entry_price:.4f}\n"
    f"TP1: {tp1:.4f}\n"
    f"Текущая цена: {current_price:.4f}\n"
    f"Прибыль: {profit:.2f} USDT\n"
    f"Объём: {qty:.4f}\n\n"
    f"💡 Позиция автоматически закрывается при достижении TP"
)

await notify_user(int(user_id), msg)
```

## 🎉 Итог

Теперь уведомления о тейк-профитах:

- **Отправляются без кнопок** - только информационные
- **Содержат пояснение** о автоматическом закрытии
- **Не требуют действий** от пользователя
