## 🔄 РАБОТА С НЕСКОЛЬКИМИ ПРОЕКТАМИ

### **Вариант 1: Использовать экспертов напрямую в Cursor**

Просто используйте экспертов в промптах - они автоматически адаптируются к контексту проекта.

### **Вариант 2: Использовать систему multi-project (Python)**

Если нужно изолировать данные между проектами:

```bash
# 1. Создать проект
python scripts/manage_projects.py create \
    --name "Новый проект" \
    --description "Описание проекта" \
    --capabilities web development

# 2. Переключиться на проект
python scripts/manage_projects.py switch \
    --project-id project_новый_проект_1234567890

# 3. Использовать экспертов в Cursor (они автоматически работают в контексте проекта)
```
