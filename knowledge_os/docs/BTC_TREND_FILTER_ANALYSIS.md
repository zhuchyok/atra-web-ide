### 1. **ФУНКЦИИ ОПРЕДЕЛЕНИЯ ТРЕНДА** (`shared_utils.py`)

#### **Строгий фильтр:**

```python
def btc_trend_filter(df_btc):
    """Строгий фильтр тренда биткоина: цена > EMA200 И EMA25 растёт"""
    df_btc = df_btc.copy()
    df_btc["ema200"] = ta.trend.EMAIndicator(df_btc["close"], window=200).ema_indicator()
    df_btc["ema25"] = ta.trend.EMAIndicator(df_btc["close"], window=25).ema_indicator()
    df_btc["trend"] = (df_btc["close"] > df_btc["ema200"]) & (df_btc["ema25"].diff() > 0)
    return df_btc["trend"]
```

#### **Мягкий фильтр:**

```python
def btc_trend_filter_soft(df_btc):
    """Мягкий фильтр тренда биткоина: только цена > EMA200"""
    df_btc = df_btc.copy()
    df_btc["ema200"] = ta.trend.EMAIndicator(df_btc["close"], window=200).ema_indicator()
    df_btc["trend"] = df_btc["close"] > df_btc["ema200"]
    return df_btc["trend"]
```

#### **Главная функция:**

```python
def get_btc_trend_status(df_btc, use_soft_filter=True):
    """Получить текущий статус тренда биткоина"""
    if use_soft_filter:
        btc_trend = btc_trend_filter_soft(df_btc)
    else:
        btc_trend = btc_trend_filter(df_btc)
    current_trend = btc_trend.iloc[-1] if len(btc_trend) > 0 else False
    return current_trend
```

## 📊 АНАЛИЗ РЕЗУЛЬТАТОВ

### **🔍 ЧТО ПРОИСХОДИТ СЕЙЧАС:**

**При медвежьем тренде BTC:**

- Система показывает: `"Пропуск - медвежий тренд Bitcoin (не подходит для LONG)"`
- **Действие:** `continue` - пропускает все монеты

**При бычьем тренде BTC:**

- **Действие:** Продолжает анализ для LONG сигналов
- **Результат:** LONG сигналы генерируются

- Система должна показывать: `"Медвежий тренд Bitcoin - подходит для SHORT сигналов"`
- **Действие:** Продолжать анализ для SHORT сигналов
- **Результат:** SHORT сигналы должны генерироваться

**При бычьем тренде BTC:**

- Система должна показывать: `"Бычий тренд Bitcoin - подходит для LONG сигналов"`
- **Действие:** Продолжать анализ для LONG сигналов
