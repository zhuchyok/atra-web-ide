## 🚀 **ДЕТАЛЬНЫЙ АНАЛИЗ**

### **1. Бычий фильтр (обновленный):**

```python
def btc_trend_filter_soft(df_btc):
    """Мягкий фильтр тренда биткоина (интрадей 1h):
    бычий, если ЛЮБОЕ из условий:
    - close > EMA20
    - EMA7 > EMA25
    - (close > EMA100) И EMA25 растёт
    - погранично: close >= EMA25 * 0.99 (±1% от EMA25) - СНИЖЕНО
    - ДОПОЛНИТЕЛЬНО: close >= EMA50 * 0.98 (±2% от EMA50) - НОВОЕ
    """
    cond1 = df_btc["close"] > df_btc["ema20"]
    cond2 = df_btc["ema7"] > df_btc["ema25"]
    cond3 = (df_btc["close"] > df_btc["ema100"]) & (df_btc["ema25"].diff() > 0)
    cond4 = df_btc["close"] >= (df_btc["ema25"] * 0.99)  # СНИЖЕНО С 0.995
    cond5 = df_btc["close"] >= (df_btc["ema50"] * 0.98)  # НОВОЕ УСЛОВИЕ

    df_btc["trend"] = cond1 | cond2 | cond3 | cond4 | cond5
    return df_btc["trend"]
```

def btc_trend_filter_soft_bearish(df_btc):
    """Мягкий фильтр медвежьего тренда биткоина (интрадей 1h):
    медвежий, если ЛЮБОЕ из условий:
    - close < EMA20
    - EMA7 < EMA25
    - (close < EMA100) И EMA25 падает
    - погранично: close <= EMA25 * 1.01 (±1% выше EMA25) - СНИЖЕНО
    - ДОПОЛНИТЕЛЬНО: close <= EMA50 * 1.02 (±2% выше EMA50) - НОВОЕ
    """
    cond1 = df_btc["close"] < df_btc["ema20"]
    cond2 = df_btc["ema7"] < df_btc["ema25"]
    cond3 = (df_btc["close"] < df_btc["ema100"]) & (df_btc["ema25"].diff() < 0)
    cond4 = df_btc["close"] <= (df_btc["ema25"] * 1.01)  # СНИЖЕНО С 1.005

    df_btc["bear_trend"] = cond1 | cond2 | cond3 | cond4 | cond5
    return df_btc["bear_trend"]
