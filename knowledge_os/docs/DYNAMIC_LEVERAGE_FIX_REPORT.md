# Отчет: Исправление динамического плеча

## 🚨 Проблема

Пользователь указал, что я неправильно устанавливал принудительное плечо 2x вместо использования динамического плеча с минимальным значением 2x для фьючерсов.

## 🔍 Диагностика

### Проблема с принудительным плечом

Я исправил код так, что принудительно устанавливал плечо 2x для всех фьючерсов, но это неправильно. Плечо должно быть динамическим, но с минимальным значением 2x.

### Логика динамического плеча

Система имеет сложную логику расчета плеча:

1. **`calculate_base_leverage(deposit)`** - базовое плечо по размеру депозита
2. **`calculate_risk_based_leverage(deposit, risk_tolerance)`** - плечо с учетом риск-толерантности
3. **`calculate_user_leverage(deposit, trade_mode, filter_mode)`** - финальное плечо для пользователя

## ✅ Исправления

### 1. Исправление функции `calculate_user_leverage`

Добавил проверку минимального плеча для фьючерсов:

```python
def calculate_user_leverage(deposit, trade_mode, filter_mode):
    if trade_mode == "spot":
        return 1

    # Определяем риск-толерантность на основе режима фильтров
    if filter_mode == "soft":
        risk_tolerance = "aggressive"
    elif filter_mode == "balanced":
        risk_tolerance = "moderate"
    else:
        risk_tolerance = "conservative"

    # Рассчитываем динамическое плечо
    leverage = calculate_risk_based_leverage(deposit, risk_tolerance)

    # Для фьючерсов минимальное плечо должно быть 2
    if leverage < 2:
        leverage = 2

    return leverage
```

## 🎯 Логика динамического плеча

### Расчет базового плеча по депозиту:

- Депозит < 100 USDT → 1x
- Депозит 100-500 USDT → 2x
- Депозит 500-1000 USDT → 3x
- Депозит 1000-5000 USDT → 5x
- Депозит 5000-10000 USDT → 8x
- Депозит > 10000 USDT → 10x

### Множители риск-толерантности:

- **Консервативный** (строгие фильтры) → ×0.5
- **Умеренный** (сбалансированные фильтры) → ×1.0
- **Агрессивный** (мягкие фильтры) → ×1.5

### Пример расчета для депозита 888 USDT:

1. **Базовое плечо**: 3x (депозит 500-1000 USDT)
2. **Риск-толерантность**: агрессивный (мягкие фильтры) → ×1.5
3. **Промежуточное плечо**: 3 × 1.5 = 4.5x
4. **Финальное плечо**: 4.5x (больше минимального 2x)
