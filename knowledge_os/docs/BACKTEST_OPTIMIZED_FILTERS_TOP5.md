## 🚨 ВОЗМОЖНЫЕ ПРОБЛЕМЫ

### **1. Недостаточно данных:**

- **Симптом:** Ошибка загрузки данных
- **Решение:** Проверить подключение к Binance API

### **2. Медленная загрузка:**

- **Симптом:** Долгая загрузка данных
- **Решение:** Нормально для 3 месяцев данных, подождать

### **3. Ошибки в фильтрах:**

- **Симптом:** Ошибки в логах при применении фильтров
- **Решение:** Проверить конфигурацию фильтров в `src/core/config.py`

### **4. Низкое качество результатов:**

- **Симптом:** Win Rate < 40%, Profit Factor < 1.0
- **Решение:** Проанализировать причины, возможно требуется дополнительная оптимизация
