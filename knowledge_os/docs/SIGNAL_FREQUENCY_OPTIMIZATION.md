# Оптимизация частоты сигналов - Анализ и предложения

## 📊 Текущая ситуация

После удаления основного режима у нас остались только **два режима** в расширенной стратегии:

1. **SOFT режим** - больше сигналов, умеренное качество
2. **STRICT режим** - меньше сигналов, высокое качество

## 🔍 Анализ текущих настроек

### **Текущие ограничения в SOFT режиме:**

#### 1. **RSI фильтры:**

```python
rsi < 65,  # Перепроданость (было 70)
rsi > 35,  # Перекупленность (было 30)
```

#### 2. **Bollinger Bands:**

```python
current_price <= bb_middle * 0.995,  # Цена ниже средней полосы
current_price >= bb_middle * 1.005,  # Цена выше средней полосы
```

#### 3. **EMA фильтры:**

```python
ema7 > ema25 * 0.998,  # Восходящий тренд
ema7 < ema25 * 1.002,  # Нисходящий тренд
```

#### 4. **Объем и волатильность:**

```python
volume_ratio > 0.5,  # Объем
volatility > 0.3,    # Волатильность
```
