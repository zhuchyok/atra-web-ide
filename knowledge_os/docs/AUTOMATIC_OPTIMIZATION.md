# 🤖 АВТОМАТИЧЕСКАЯ ОПТИМИЗАЦИЯ ПАРАМЕТРОВ

## 📋 Обзор системы

Система **автоматической ежедневной оптимизации параметров фильтров** анализирует рыночные условия и автоматически корректирует параметры фильтров сигналов для максимальной эффективности.

## 🔄 Как работает оптимизация

### Время запуска

- **Ежедневная оптимизация:** 06:00 (МСК)
- **Интеграция:** Автоматически запускается вместе с основной системой

### Процесс оптимизации

1. **Анализ рыночных условий**
   - Получение OHLC данных за последние 7 дней
   - Расчет технических индикаторов (EMA, RSI, Bollinger Bands, Volatility, Momentum, Trend Strength)
   - Анализ текущих рыночных условий

2. **Адаптация параметров**
   - **Высокая волатильность:** Увеличиваем требования к тренду, уменьшаем к волатильности
   - **Низкая волатильность:** Уменьшаем требования к тренду, увеличиваем к волатильности
   - **Сильный тренд:** Уменьшаем требования к тренду
   - **Слабый тренд:** Увеличиваем требования к тренду
   - **Мало сигналов:** Ослабляем фильтры
   - **Много сигналов:** Усиливаем фильтры

3. **Применение параметров**
   - Автоматическое обновление `signal_live.py`
   - Сохранение истории оптимизации в `optimization_history.json`

## 📊 Параметры оптимизации

### Строгие фильтры (`strict`)

- **bb_touch:** Касание Bollinger Bands (1.01-1.05)
- **ema_trend:** Тренд EMA (0.998-1.002)
- **rsi_long/short:** Уровни RSI для LONG/SHORT (35-65)
- **volume_ratio:** Соотношение объема (0.5-1.5)
- **volatility:** Требования к волатильности (0.3-3.0)
- **momentum:** Требования к моменту (-0.2-0.2)
- **trend_strength:** Сила тренда (0.02-1.0)

### Мягкие фильтры (`soft`)

- Более мягкие условия для увеличения количества сигналов
- Адаптация к текущим рыночным условиям

## 🎯 Алгоритмы адаптации

### Адаптация к волатильности

```python
if volatility > 3.0:  # Высокая волатильность
    volatility *= 0.8  # Уменьшаем требования
    trend_strength *= 1.2  # Увеличиваем требования к тренду
elif volatility < 1.0:  # Низкая волатильность
    volatility *= 1.2  # Увеличиваем требования
    trend_strength *= 0.8  # Уменьшаем требования к тренду
```

### Адаптация к количеству сигналов

```python
if signal_count < 5:  # Мало сигналов
    rsi_long += 2  # Ослабляем RSI фильтры
    rsi_short -= 2
elif signal_count > 50:  # Много сигналов
    rsi_long -= 2  # Усиливаем RSI фильтры
    rsi_short += 2
```
