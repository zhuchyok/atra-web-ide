## 🔄 Новые режимы

### 🔴 СТРОГИЙ режим (strict)

- Высокое качество сигналов
- Меньше количество сигналов
- Сильные условия входа
- Рекомендуется для консервативной торговли

### 🟡 МЯГКИЙ режим (soft)

- Больше сигналов
- Умеренное качество
- Слабые условия входа
- Рекомендуется для агрессивной торговли

## 📋 Команды управления

```
/set_filter_mode strict  - установить строгий режим
/set_filter_mode soft    - установить мягкий режим
```

## 🛡️ Автоматические настройки

- **Строгий режим** → автоматически устанавливает **Консервативный** режим новостей
- **Мягкий режим** → автоматически устанавливает **Агрессивный** режим новостей
