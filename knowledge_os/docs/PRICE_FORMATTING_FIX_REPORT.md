### **Использование правильного форматирования цен:**

#### **1. Функция `get_full_price_format()`**

```python
def get_full_price_format(symbol):
    """
    Возвращает формат для полного отображения цены как на бирже
    """
    # Используем точно такой же формат как на бирже
    precision = get_symbol_precision(symbol)
    return f"{{:.{precision}f}}"
```
