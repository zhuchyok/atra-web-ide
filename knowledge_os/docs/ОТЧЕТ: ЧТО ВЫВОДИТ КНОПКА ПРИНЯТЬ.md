## 📱 ВЫВОД ОБЫЧНЫХ СИГНАЛОВ

### Пример сообщения обычного сигнала:

```
✅ Сигнал принят!
📅 Принят: 20.08.2025 21:39
Ваш текущий депозит: 1000.00 USDT.
Открытых позиций: 2 на 50.00 USDT.
Свободно для новых сделок: 950.00 USDT.
Риск на сделку: 3.20% (30.40 USDT).
Используемое плечо: x4
Сумма входа с учётом плеча: 30.40 USDT.

📊 ПОЗИЦИЯ BTCUSDT:
• Цена входа: 45000.00
• Объём: 0.0027
• TP1: 46125.00 (+2.5%)
• TP2: 47160.00 (+4.8%)
```

### ✅ Что выводится в обычных сигналах:

1. **📅 Время принятия сигнала**
2. **💰 Информация о депозите:**
   - Текущий депозит
   - Количество открытых позиций
   - Свободный депозит для новых сделок

3. **🎯 Динамические параметры:**
   - **Динамический риск:** `3.20% (30.40 USDT)`
   - **Динамическое плечо:** `x4`
   - **Сумма входа:** `30.40 USDT` (с учетом плеча)

4. **📊 Детали позиции:**
   - Символ
   - Цена входа
   - Объем позиции
   - **TP1 с динамическим процентом:** `46125.00 (+2.5%)`
   - **TP2 с динамическим процентом:** `47160.00 (+4.8%)`

## 🔄 ВЫВОД DCA СИГНАЛОВ (УСРЕДНЕНИЕ)

### Пример сообщения DCA сигнала:

```
✅ УСРЕДНЕНИЕ ПРИНЯТО

СИМВОЛ: BTCUSDT
Цена входа: 44000.00
Объём усреднения: 0.0015
Новая средняя цена: 44500.00
TP1: 45612.50 (+2.5%)
TP2: 46636.00 (+4.8%)
Усреднений: 2 (лимит: 4)
Общий объём: 0.0035
Режим: FUTURES
Плечо: x4
```

### ✅ Что выводится в DCA сигналах:

1. **✅ Заголовок усреднения**
2. **📊 Информация об усреднении:**
   - Символ
   - Цена входа для усреднения
   - Объем усреднения
   - **Новая средняя цена** (пересчитанная)

3. **🎯 Динамические тейк-профиты:**
   - **TP1 с динамическим процентом:** `45612.50 (+2.5%)`
   - **TP2 с динамическим процентом:** `46636.00 (+4.8%)`

4. **📈 Статистика усреднения:**
   - Количество усреднений (с лимитом)
   - Общий объем позиции
   - Режим торговли
   - **Динамическое плечо:** `x4`

## 🔧 ТЕХНИЧЕСКАЯ РЕАЛИЗАЦИЯ

### Код формирования сообщения обычного сигнала:

```python
msg = (
    f"✅ Сигнал принят!\\n"
    f"📅 Принят: {datetime.now().strftime('%d.%m.%Y %H:%M')}\\n"
    f"Ваш текущий депозит: {deposit:.2f} USDT.\\n"
    f"Открытых позиций: {total_positions} на {total_risk:.2f} USDT.\\n"
    f"Свободно для новых сделок: {free_deposit:.2f} USDT.\\n"
    f"Риск на сделку: {dynamic_risk_pct:.2f}% ({risk_amount:.2f} USDT).\\n"
)
if trade_mode == "futures" and dynamic_leverage:
    msg += f"Используемое плечо: x{dynamic_leverage}\\nСумма входа с учётом плеча: <b>{risk_amount:.2f} USDT</b>.\\n\\n"
else:
    msg += f"Сумма входа в сделку: <b>{risk_amount:.2f} USDT</b>.\\n\\n"

msg += (
    f"📊 <b>ПОЗИЦИЯ {symbol}:</b>\\n"
    f"• Цена входа: {entry_price:.2f}\\n"
    f"• Объём: {qty:.4f}\\n"
    f"• TP1: {tp1:.2f} ({'+' if side == 'long' else '-'}{tp1_pct:.1f}%)\\n"
    f"• TP2: {tp2:.2f} ({'+' if side == 'long' else '-'}{tp2_pct:.1f}%)\\n"
)
```

### Код формирования сообщения DCA сигнала:

```python
msg = (
    f"✅ *УСРЕДНЕНИЕ ПРИНЯТО*\n\n"
    f"СИМВОЛ: {symbol}\n"
    f"Цена входа: {fmt.format(entry_price)}\n"
    f"Объём усреднения: {new_qty:.4f}\n"
    f"Новая средняя цена: {fmt.format(avg_price_new)}\n"
    f"TP1: {fmt.format(tp1)} ({'+' if side == 'long' else '-'}{dynamic_tp1_pct:.1f}%)\n"
    f"TP2: {fmt.format(tp2)} ({'+' if side == 'long' else '-'}{dynamic_tp2_pct:.1f}%)\n"
    f"Усреднений: {dca_count} (лимит: 4)\n"
    f"Общий объём: {total_qty:.4f}\n"
    f"Режим: {trade_mode.upper()}\n"
    f"Плечо: x{dynamic_leverage}" if trade_mode == "futures" else ""
)
```
