## 🔍 ВОЗМОЖНЫЕ ПРИЧИНЫ

### 1. **Слишком строгие фильтры**

Все сигналы блокируются на этапе проверки фильтров:

#### AI Score Filter

- Порог: 5.0 (soft) / 10.0 (strict)
- **Проблема:** Возможно, слишком высокий порог для исторических данных

#### Direction Confidence

- Требуется: 3/4 (soft) или 4/4 (strict) подтверждений
- **Проблема:** Может быть слишком строгим для волатильного рынка

#### Quality Score

- Минимум: 0.68
- **Проблема:** Может блокировать валидные сигналы

#### Pattern Confidence

- Минимум: 0.60
- **Проблема:** Может быть слишком строгим

#### RSI Filter

- Параметры: 25-75 (восстановлены)
- **Проблема:** Может блокировать сигналы в нейтральной зоне

#### BTC Trend Filter

- Блокирует сигналы против тренда BTC
- **Проблема:** Может блокировать все сигналы если BTC в боковике

### 2. **Отсутствие логирования блокировок**

В логах нет информации о том, какие фильтры блокируют сигналы:

- Нет записей `🚫 [FILTER]`
- Нет статистики `filter_rejections`

### 3. **Проблемы с данными**

- Возможно, данные не загружены корректно
- Возможно, индикаторы не рассчитаны
- Возможно, недостаточно данных для расчета фильтров

## 🔧 РЕКОМЕНДАЦИИ

```python
# В generate_signal добавить:
logger.info("🔍 [FILTER_CHECK] %s: Проверка фильтров...", symbol)

```

### 2. Ослабить фильтры для диагностики

- Временно снизить пороги AI Score (5.0 → 3.0)
- Временно снизить Direction Confidence (3/4 → 2/4)
- Временно снизить Quality Score (0.68 → 0.50)

### 3. Проверить данные

- Убедиться, что данные загружены корректно
- Проверить расчет индикаторов
- Проверить наличие достаточного количества свечей

### 4. Добавить статистику фильтров

```python
# В конце бектеста вывести:
print("📊 СТАТИСТИКА ФИЛЬТРОВ:")
```
