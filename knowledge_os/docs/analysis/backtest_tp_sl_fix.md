# 🔧 Исправление: Бектест не учитывает дополнительную оптимизацию TP/SL

**Дата:** 2025-11-13  
**Проблема:** Бектест не применяет ту же логику оптимизации TP/SL, что и реальная система

## ❌ Проблема

### **Реальная система (`signal_live.py`):**

```python
# Строки 3047-3051
# 🏆 ОПТИМИЗАЦИЯ TP/SL: Улучшение соотношения (на основе бектеста)
# Увеличиваем TP на 20%, уменьшаем SL на 20% для лучшего Profit Factor
tp1_pct_optimized = tp1_pct * 1.2
tp2_pct_optimized = tp2_pct * 1.2
sl_pct_optimized = sl_pct_positive * 0.8
```

### **Бектест (`run_advanced_backtest.py`):**

```python
# Строки 160-170
# Рассчитываем цены БЕЗ дополнительной оптимизации
if direction == "LONG":
    tp1_price = entry_price * (1 + tp1_pct / 100)  # ❌ Нет * 1.2
    tp2_price = entry_price * (1 + tp2_pct / 100)  # ❌ Нет * 1.2
    sl_price = entry_price * (1 - base_sl_pct / 100)  # ❌ Нет * 0.8
```

## 🔍 Различия

| Компонент | Реальная система | Бектест   | Разница |
| --------- | ---------------- | --------- | ------- |
| **TP1**   | `tp1_pct * 1.2`  | `tp1_pct` | +20%    |
| **TP2**   | `tp2_pct * 1.2`  | `tp2_pct` | +20%    |
| **SL**    | `sl_pct * 0.8`   | `sl_pct`  | -20%    |

## 📊 Влияние на результаты

### **Текущие результаты бектеста:**

- Profit Factor: 0.80
- Win Rate: 45.10%
- Средний убыток: -132.83 USDT > Средняя прибыль: 127.45 USDT

### **Ожидаемые результаты после исправления:**

- **TP увеличен на 20%** → больше прибыльных сделок достигнут TP
- **SL уменьшен на 20%** → меньше убыточных сделок достигнут SL
- **Profit Factor:** 0.80 → **~1.0-1.2** (улучшение)
- **Win Rate:** 45% → **~48-50%** (улучшение)

## ✅ Решение

Нужно добавить в бектест ту же логику оптимизации, что и в реальной системе:

```python
# После получения tp1_pct, tp2_pct, base_sl_pct
# Применяем дополнительную оптимизацию
tp1_pct_optimized = tp1_pct * 1.2
tp2_pct_optimized = tp2_pct * 1.2
sl_pct_optimized = base_sl_pct * 0.8

# Затем рассчитываем цены
if direction == "LONG":
    tp1_price = entry_price * (1 + tp1_pct_optimized / 100)
    tp2_price = entry_price * (1 + tp2_pct_optimized / 100)
    sl_price = entry_price * (1 - sl_pct_optimized / 100)
```
