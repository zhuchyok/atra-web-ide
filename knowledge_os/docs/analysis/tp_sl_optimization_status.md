## 📊 Как работает ИИ-оптимизация TP

### **Метод `calculate_ai_optimized_tp()`:**

1. **Историческая эффективность символа:**
   - Анализирует успешные сделки по символу
   - Определяет оптимальные TP1/TP2 для символа

2. **Факторы:**
   - Волатильность (ATR) - вес 30%
   - Сила тренда - вес 25%
   - Профиль объема - вес 20%
   - Уровни поддержки/сопротивления - вес 15%
   - Рыночный сентимент - вес 10%

3. **ML-оптимизация на основе паттернов:**
   - Ищет топ-1000 похожих паттернов
   - Анализирует успешные паттерны (WIN)
   - Рассчитывает оптимальные TP из паттернов
   - Оценка уверенности на основе схожести

4. **Финальный расчет:**
   - Если уверенность ML > 0.5: использует 60% паттернов, 30% истории, 10% индикаторов
   - Если уверенность ML < 0.5: использует 70% истории, 30% индикаторов, 10% паттернов
