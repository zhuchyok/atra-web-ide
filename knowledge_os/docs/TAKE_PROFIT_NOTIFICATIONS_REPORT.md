### ✅ **Для LONG позиций:**

```python
# Проверяем достижение TP1

    tp1_reached = True

    tp2_reached = True
```

### ✅ **Для SHORT позиций:**

```python
# Проверяем достижение TP1

    tp1_reached = True

if side == 'short' and current_low <= tp2:
    tp2_reached = True
```

## 🔄 **УПРАВЛЕНИЕ СТАДИЯМИ ПОЗИЦИЙ:**

### 📊 **Стадии позиций:**

1. **`'open'`** - позиция открыта
2. **`'tp1_reached'`** - достигнут TP1
3. **`'tp2_reached'`** - достигнут TP2

### ✅ **Логика обновления стадий:**

```python
# При достижении TP1
if tp1_reached and pos.get('stage') == 'open':
    pos['stage'] = 'tp1_reached'
    # Отправляем уведомление

# При достижении TP2
elif tp2_reached and pos.get('stage') in ['open', 'tp1_reached']:
    pos['stage'] = 'tp2_reached'
    # Отправляем уведомление
```
