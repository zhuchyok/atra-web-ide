# 🔒 БЕЗОПАСНАЯ РАБОТА С GIT

**Как избежать потери исправлений в будущем**

---

## ⚠️ ЧТО ПОШЛО НЕ ТАК

### Проблема:

Команда `git reset --hard` **безвозвратно удалила** все локальные изменения:

```bash
git reset --hard origin/worker_v2  # ❌ ОПАСНО!
```

### Результат:

- ❌ Удалено исправление `main.py` (параметры dashboard)
- ❌ Удален файл `ai_config.py`
- ❌ Откачено исправление `web/dashboard.py`

## ✅ ПРАВИЛЬНЫЙ WORKFLOW

### 1. ВСЕГДА КОММИТЬТЕ ПЕРЕД PULL

```bash
# ШАГ 1: Проверяем что изменилось
git status

# ШАГ 2: Добавляем изменения
git add .

# ШАГ 3: Коммитим с понятным сообщением
git commit -m "🔧 Исправления ошибок системы"

# ШАГ 4: Теперь безопасно тянем изменения
git pull origin worker_v2
```

---

### 2. ЕСЛИ ЕСТЬ КОНФЛИКТЫ - НЕ ПАНИКУЕМ!

#### Вариант A: Оставить НАШИ изменения (рекомендуется для исправлений)

```bash
# При конфликте слияния:
git checkout --ours <файл>        # Берем НАШУ версию
git add <файл>
git commit -m "Resolved: kept local fixes"
```

#### Вариант B: Оставить удаленные изменения

```bash
git checkout --theirs <файл>      # Берем версию с GitHub
git add <файл>
git commit -m "Resolved: accepted remote changes"
```

#### Вариант C: Объединить вручную

```bash
# Открываем файл, редактируем конфликты вручную
# Удаляем маркеры: <<<<<<< ======= >>>>>>>
git add <файл>
git commit -m "Resolved: merged manually"
```

---

### 3. БЕЗОПАСНЫЕ КОМАНДЫ GIT

#### ✅ БЕЗОПАСНО:

```bash
git pull                    # Стандартный pull
git pull --rebase          # Pull с перебазированием
git stash                  # Временно спрятать изменения
git stash pop              # Вернуть спрятанные изменения
git merge                  # Слияние веток
git commit                 # Коммит изменений
git push                   # Отправка на сервер
```

#### ⚠️ ОСТОРОЖНО:

```bash
git reset --soft HEAD~1    # Откатить последний коммит (сохранить изменения)
git checkout -- <файл>     # Откатить изменения в файле
git clean -fd              # Удалить неотслеживаемые файлы
```

#### ❌ ОПАСНО (используйте ТОЛЬКО если уверены):

```bash
git reset --hard           # ❌ УДАЛЯЕТ ВСЕ локальные изменения!
git push --force           # ❌ Перезаписывает историю на сервере!
git clean -fdx             # ❌ Удаляет все неотслеживаемые файлы!
```

## 🔄 РЕКОМЕНДУЕМЫЙ WORKFLOW ДЛЯ СЕРВЕРА

### Обновление кода на сервере:

```bash
# 1. Подключаемся к серверу
ssh root@185.177.216.15

# 2. Переходим в папку проекта
cd /root/atra

# 3. СОХРАНЯЕМ локальные изменения
git stash

# 4. Тянем обновления
git pull origin worker_v2

# 5. Возвращаем локальные изменения (если нужно)
git stash pop

# 6. При конфликтах - решаем (см. выше)

# 7. Перезапускаем бота
pkill -9 -f main.py
nohup python3 main.py > main.log 2>&1 &
```

## 💾 АВТОМАТИЧЕСКИЙ BACKUP ПЕРЕД ИЗМЕНЕНИЯМИ

### Скрипт для безопасного обновления:

```bash
#!/bin/bash
# save_and_update.sh

echo "🔒 Создаем резервную копию..."
git branch backup-$(date +%Y%m%d-%H%M%S)

echo "💾 Сохраняем текущие изменения..."
git add .
git commit -m "Auto backup: $(date)" || echo "Нечего коммитить"

echo "⬇️ Тянем обновления..."
git pull origin worker_v2

echo "✅ Готово! Если что-то пошло не так:"
echo "   git reset --hard backup-YYYYMMDD-HHMMSS"
```

**Использование:**

```bash
chmod +x save_and_update.sh
./save_and_update.sh
```

## 🆘 ЕСЛИ ВСЕ ПОШЛО НЕ ТАК

### Восстановление после `git reset --hard`:

#### 1. Проверяем reflog (журнал всех действий):

```bash
git reflog
# Найдите коммит ДО reset (например: abc1234)
```

#### 2. Восстанавливаем:

```bash
git reset --hard abc1234
# Или создаем новую ветку:
git branch recovery abc1234
git checkout recovery
```

## 📋 ЧЕКЛИСТ ПЕРЕД КАЖДЫМ ОБНОВЛЕНИЕМ

- [ ] `git status` - проверить изменения

## 🎯 ИТОГО: ЗОЛОТОЕ ПРАВИЛО

### **НИКОГДА НЕ ИСПОЛЬЗУЙТЕ `git reset --hard` БЕЗ КОММИТА!**

Вместо этого:

```bash
# ПРАВИЛЬНО:
git add .
git commit -m "Текущие изменения"
git pull
# Решить конфликты если есть
git push
```

## 📞 БЫСТРАЯ ПОМОЩЬ

### Забыл закоммитить и сделал pull - есть конфликты:

```bash
git stash                    # Спрятать изменения
git pull                     # Тянуть обновления
git stash pop                # Вернуть изменения
# Решить конфликты вручную
git add .
git commit -m "Merged with fixes"
```

### Случайно сделал `git reset --hard`:

```bash
git reflog                   # Найти потерянный коммит
git reset --hard <commit>    # Восстановить
```

### Хочу откатить ОДИН файл:

```bash
git checkout HEAD -- <файл>  # Откатить к последнему коммиту
git checkout <commit> -- <файл>  # Откатить к конкретному коммиту
```
