```
FreeWhaleSignalIntegrator
├── enhance_signal_with_whale_data()
├── generate_whale_enhanced_message()
└── get_whale_confidence_boost()
```

### **2. Интеграция с signal_live.py**

```python
# Импорт системы
if WHALE_FREE_MODE:
    from free_whale_integration import FreeWhaleSignalIntegrator as WhaleSignalIntegrator
    print("[Whale] Бесплатная система отслеживания топ-100 китов подключена")

# Интеграция в сигналы
whale_integrator = WhaleSignalIntegrator()
enhanced_signal = await whale_integrator.enhance_signal_with_whale_data(symbol, original_signal)
whale_info = await whale_integrator.generate_whale_enhanced_message(symbol, enhanced_signal)
```

### **3. Конфигурация**

```python
# config.py
WHALE_TRACKING_ENABLED = True
WHALE_FREE_MODE = True

WHALE_ENHANCEMENT_SETTINGS = {
    "confidence_boost_confirm": 0.20,    # +20% при подтверждении китами
    "confidence_boost_contradict": -0.10, # -10% при противоречии китами
    "volume_ratio_threshold": 2.0,       # Порог соотношения объемов
    "cache_ttl_minutes": 30,             # Время жизни кэша
}
```
