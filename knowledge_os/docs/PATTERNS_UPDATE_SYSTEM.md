## 🆕 НОВОЕ: Обновление паттернов при закрытии сделок

### ✅ Реализовано:

1. **Функция `update_pattern_from_closed_trade()`:**
   - ✅ Создана в `ai_integration.py`
   - ✅ Обновляет паттерн результатом закрытой сделки (WIN/LOSS)
   - ✅ Добавляет profit_pct для обучения
   - ✅ Если паттерн не найден, создаёт новый из закрытой сделки

2. **Скрипт синхронизации:**
   - ✅ `scripts/sync_trades_to_patterns.py` - автоматический импорт из trading.db
   - ✅ Импортирует закрытые сделки за последние N часов
   - ✅ Обновляет паттерны результатами

### 📋 Как это работает:

```python
# При закрытии позиции:
await ai_integration.update_pattern_from_closed_trade(
    symbol="BTCUSDT",
    side="LONG",
    entry_price=50000.0,
    exit_price=51000.0,
    exit_reason="tp2",
    user_id=123,
    profit_pct=2.0,  # +2%
)

# Система:
# 1. Ищет паттерн с PENDING/ACCEPTED статусом
# 2. Обновляет result = "WIN" или "LOSS"
# 3. Обновляет profit_pct
# 4. Добавляет обновлённый паттерн в ai_learning
```

## 📊 Полный цикл обновления паттернов

### 1. Открытие сигнала:

```
Сигнал отправлен → record_signal_pattern_on_send() → Паттерн со статусом PENDING
Сигнал принят → record_signal_pattern() → Паттерн со статусом ACCEPTED
```

### 2. Закрытие позиции:

```
Позиция закрыта → update_pattern_from_closed_trade() → Паттерн обновлён результатом (WIN/LOSS)
```

### 3. Автоматический импорт:

```
Каждый час → sync_trades_to_patterns.py → Импорт закрытых сделок из trading.db
```

### 4. Непрерывное обучение:

```
Каждый час → continuous_learning() → Оптимизация параметров на основе новых паттернов
```

### 5. Обновление параметров:

```
Каждые 6 часов → SymbolSpecificOptimizer → Обновление индивидуальных параметров для символов
```
