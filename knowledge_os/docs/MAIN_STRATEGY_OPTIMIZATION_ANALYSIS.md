## ⚠️ Проблемы дублирования

### 1. Конфликт параметров

- **Основная стратегия**: `BB_WINDOW = 20`, `BB_STD = 2.0` (захардкожено)
- **Расширенная стратегия**: `"bb_window": 20`, `"bb_std": 2.0` (оптимизируется)

Если оптимизация изменит параметры расширенной стратегии, но основная стратегия останется с захардкоженными значениями, это приведет к:

- Разным результатам для одинаковых условий
- Путанице в логике
- Непредсказуемому поведению

### 2. Дублирование логики

## 🎯 Рекомендации

### 1. Убрать основную стратегию

Основная стратегия устарела и дублирует функциональность расширенной стратегии.

### 2. Использовать только расширенную стратегию

- **SOFT режим**: использует enhanced функции с мягкими фильтрами
- **STRICT режим**: использует простую логику с строгими фильтрами
- **Общая конфигурация**: `ENHANCED_STRATEGY_CONFIG` оптимизируется автоматически

### 3. Унифицировать параметры

Заменить все захардкоженные константы на параметры из `ENHANCED_STRATEGY_CONFIG`:

```python
# Вместо:
BB_WINDOW = 20
BB_STD = 2.0

# Использовать:
config = ENHANCED_STRATEGY_CONFIG
bb_window = config["bb_window"]
bb_std = config["bb_std"]
```
