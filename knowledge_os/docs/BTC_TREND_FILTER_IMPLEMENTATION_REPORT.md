## 🔧 **ТЕХНИЧЕСКИЕ ИЗМЕНЕНИЯ**

### **1. Конфигурация (config.py)**

```python
# Включение/отключение фильтра тренда биткоина
USE_BTC_TREND_FILTER = True  # Включено - фильтрует сигналы по тренду BTC

# Тип фильтра тренда биткоина
BTC_TREND_FILTER_SOFT = True  # True = мягкий фильтр, False = строгий фильтр
```

### **2. Глобальные переменные (shared_utils.py)**

```python
# Глобальная переменная для хранения статуса тренда BTC
btc_trend_status = True  # По умолчанию бычий тренд (True = бычий, False = медвежий)
```

### **3. Обновление статуса BTC (signal_live.py)**

```python
# Обновляем глобальную переменную в shared_utils
import shared_utils
shared_utils.btc_trend_status = btc_trend_status
```

### **4. Фильтрация в STRICT режиме**

```python
# НОВЫЙ: BTC ТРЕНД ФИЛЬТР для STRICT режима
if USE_BTC_TREND_FILTER:
    import shared_utils
    if hasattr(shared_utils, 'btc_trend_status'):
        btc_trend = shared_utils.btc_trend_status

        # Для LONG сигналов: BTC должен быть в бычьем тренде
        if all(long_conditions) and not btc_trend:
            print(f"[STRICT] LONG сигнал заблокирован медвежьим трендом BTC")
            return None, None

        # Для SHORT сигналов: BTC должен быть в медвежьем тренде
        if all(short_conditions) and btc_trend:
            print(f"[STRICT] SHORT сигнал заблокирован бычьим трендом BTC")
            return None, None
```

### **5. Фильтрация в SOFT режиме**

```python
# НОВЫЙ: BTC ТРЕНД ФИЛЬТР для SOFT режима
if USE_BTC_TREND_FILTER:
    import shared_utils
    if hasattr(shared_utils, 'btc_trend_status'):
        btc_trend = shared_utils.btc_trend_status

        # Для LONG сигналов: BTC должен быть в бычьем тренде
        if all(long_conditions) and not btc_trend:
            print(f"[SOFT] LONG сигнал заблокирован медвежьим трендом BTC")
            return None, None

        # Для SHORT сигналов: BTC должен быть в медвежьем тренде
        if all(short_conditions) and btc_trend:
            print(f"[SOFT] SHORT сигнал заблокирован бычьим трендом BTC")
            return None, None
```

## 🎯 **ЛОГИКА ФИЛЬТРАЦИИ**

### **Правила фильтрации:**

1. **LONG сигналы** - разрешены только при **бычьем тренде BTC** (`btc_trend_status = True`)
2. **SHORT сигналы** - разрешены только при **медвежьем тренде BTC** (`btc_trend_status = False`)

### **Определение тренда BTC:**

- **Мягкий фильтр** (`BTC_TREND_FILTER_SOFT = True`): `close > EMA200`
- **Строгий фильтр** (`BTC_TREND_FILTER_SOFT = False`): `close > EMA200 AND EMA25_diff > 0`
