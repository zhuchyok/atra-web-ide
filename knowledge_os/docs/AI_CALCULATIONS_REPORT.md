## 🔄 Полный цикл расчета параметров

```
1. Генерация сигнала
   ↓
2. 🤖 ИИ-расчет TP1/TP2
   → AITakeProfitOptimizer.calculate_ai_optimized_tp()
   → Анализ 50,000+ паттернов
   → Учёт волатильности, тренда, объёма
   ↓
3. 🤖 ИИ-расчет SL
   → get_dynamic_sl_level(use_ai_optimization=True)
   → Анализ паттернов и ATR
   → Учёт исторических убытков
   ↓
4. 🤖 ИИ-расчет Риска, Плеча, Суммы
   → AIPositionSizing.calculate_ai_optimized_position_size()
   → Анализ исторической эффективности
   → Учёт тренда, сентимента, здоровья аккаунта
   ↓
5. 🏆 Применение оптимизации TP/SL
   → TP1/TP2 × 1.2 (увеличение на 20%)
   → SL × 0.8 (уменьшение на 20%)
   ↓
6. Готовый сигнал с ИИ-оптимизированными параметрами
```
