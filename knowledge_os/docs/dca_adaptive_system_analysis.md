#### **1. АДАПТИВНЫЙ РАЗМЕР DCA** (`calculate_adaptive_dca_size`)

```python
def calculate_adaptive_dca_size(
    deposit: float, trade_mode: str, dca_count: int, base_risk_pct: float,
    current_price: float, avg_entry_price: float, volatility: float,
    trend_strength: float, market_regime: str = "neutral"
) -> Tuple[float, float]:
    """
    Рассчитывает адаптивный размер DCA с учетом:
    - Номера DCA (прогрессивное уменьшение)
    - Волатильности и тренда
    - Режима рынка
    - Соотношения цен
    """
    # Базовый размер DCA
    dca_risk_multiplier = get_dca_risk_multiplier(deposit, trade_mode)
    base_dca_risk = base_risk_pct * dca_risk_multiplier

    # Прогрессивное уменьшение размера DCA
    decay_factor = math.exp(-dca_count * 0.3)  # Экспоненциальное уменьшение
    adaptive_risk = base_dca_risk * decay_factor

    # Корректировка по волатильности
    volatility_factor = max(0.5, 1.0 - (volatility * 0.5))  # Снижаем при высокой волатильности

    # Корректировка по тренду
    trend_factor = max(0.7, 1.0 - (trend_strength * 0.3))  # Снижаем при сильном тренде

    # Корректировка по режиму рынка
    regime_factor = MARKET_REGIME_MULTIPLIERS.get(market_regime, {}).get("entry_size_mult", 1.0)

    # Дополнительная корректировка по соотношению цен
    price_ratio = current_price / avg_entry_price if avg_entry_price > 0 else 1.0
    price_factor = 1.0 + (price_ratio - 1.0) * 0.1  # Учитываем отклонение цены

    # Итоговый риск
    final_risk = adaptive_risk * volatility_factor * trend_factor * regime_factor * price_factor

    return position_size_usd, final_risk
```

### 🧠 **СИСТЕМА ОБУЧЕНИЯ DCA:**

#### **1. АДАПТАЦИЯ ПО ВОЛАТИЛЬНОСТИ:**

- **Высокая волатильность** → Снижение размера DCA (volatility_factor = 0.5-1.0)
- **Низкая волатильность** → Увеличение размера DCA (volatility_factor = 1.0)

#### **2. АДАПТАЦИЯ ПО ТРЕНДУ:**

- **Сильный тренд** → Снижение размера DCA (trend_factor = 0.7-1.0)
- **Слабый тренд** → Увеличение размера DCA (trend_factor = 1.0)

#### **3. АДАПТАЦИЯ ПО РЕЖИМУ РЫНКА:**

- **Bull market** → Увеличение размера DCA (+5%)
- **Bear market** → Снижение размера DCA (-30%)
- **Neutral** → Стандартный размер DCA

#### **4. АДАПТАЦИЯ ПО КОНФЛЮЭНСУ УРОВНЕЙ:**

- **Высокий конфлюэнс** → Снижение порога DCA, сближение TP
- **Низкий конфлюэнс** → Повышение порога DCA, стандартные TP

## ✅ **ВЫВОД: DCA СИСТЕМА ПОЛНОСТЬЮ АДАПТИВНА!**

**DCA система автоматически:**

1. **Адаптирует размер** под волатильность, тренд и режим рынка
2. **Прогрессивно уменьшает** размер с каждым усреднением
3. **Учитывает конфлюэнс** уровней для интеллектуального усреднения
4. **Сближает TP** при благоприятных условиях
5. **Защищает капитал** от переторговли
6. **Обучается** на основе рыночных условий
