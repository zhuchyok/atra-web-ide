# 📊 ATRA Dashboard - Руководство по доступу

## 🌐 Как открыть Dashboard

### **Основная ссылка:**

```
http://localhost:5000
```

### **Для доступа с других устройств:**

```
http://[IP_АДРЕС_СЕРВЕРА]:5000
```

---

## 🚀 Способы запуска Dashboard

### **Способ 1: Автоматический запуск (рекомендуется)**

Dashboard запускается **автоматически** при запуске основной системы ATRA:

```bash
python3 main.py
```

**В логах должно появиться:**

```
📊 Web Dashboard запущен на порту 5000
🚀 Запуск ATRA Dashboard на http://0.0.0.0:5000
```

### **Способ 2: Ручной запуск Dashboard**

Если нужно запустить только Dashboard:

```bash
cd web
python3 dashboard.py
```

**Или с параметрами:**

```bash
python3 dashboard.py --host 0.0.0.0 --port 5000 --debug
```

## 📱 Доступ к Dashboard

### **Локальный доступ (с того же сервера):**

- **URL:** `http://localhost:5000`
- **URL:** `http://127.0.0.1:5000`

### **Удаленный доступ (с других устройств):**

- **URL:** `http://[IP_СЕРВЕРА]:5000`

**Примеры:**

- `http://192.168.1.100:5000` (локальная сеть)
- `http://your-server.com:5000` (внешний сервер)

---

## 🔧 Настройка доступа

### **Переменные окружения:**

Создайте файл `.env` с настройками:

```bash
DASHBOARD_HOST=0.0.0.0
DASHBOARD_PORT=5000
```

### **Изменение порта:**

```bash
# Запуск на другом порту
python3 dashboard.py --port 8080
```

**Тогда доступ будет:** `http://localhost:8080`

## 🚨 Решение проблем

### **Dashboard не открывается:**

1. **Проверьте, запущен ли Dashboard:**

   ```bash
   netstat -tlnp | grep 5000
   ```

2. **Проверьте логи:**

   ```bash
   # В логах должно быть:
   📊 Web Dashboard запущен на порту 5000
   ```

3. **Проверьте доступность порта:**
   ```bash
   curl http://localhost:5000
   ```

### **Ошибка "Connection refused":**

1. **Убедитесь, что система запущена:**

   ```bash
   python3 main.py
   ```

2. **Проверьте, не заблокирован ли порт:**

   ```bash
   sudo ufw status
   ```

3. **Если используете Docker, проверьте проброс портов**

### **Dashboard в демо-режиме:**

Если видите сообщение "Демо режим: Включен":

1. Следуйте инструкции в `SERVER_DEMO_MODE_FIX_INSTRUCTIONS.md`
2. Перезапустите систему

## 🔐 Безопасность

### **Рекомендации:**

1. **Не открывайте Dashboard в интернет** без аутентификации
2. **Используйте VPN** для удаленного доступа
3. **Настройте файрвол** для ограничения доступа
4. **Регулярно обновляйте** систему

### **Настройка файрвола:**

```bash
# Разрешить доступ только с локальной сети
sudo ufw allow from 192.168.1.0/24 to any port 5000

# Или только с определенного IP
sudo ufw allow from 192.168.1.100 to any port 5000
```

## 🔄 API Endpoints

Dashboard также предоставляет API для программного доступа:

### **Основные endpoints:**

- `GET /api/stats` - статистика системы
- `GET /api/signals` - последние сигналы
- `GET /api/filters` - статус фильтров
- `GET /api/cache` - информация о кэше
- `GET /api/history` - история данных
- `GET /api/monitoring` - мониторинг (если доступен)
- `GET /api/alerts` - алерты (если доступны)
- `GET /api/risk` - риск-менеджмент
- `GET /api/quality` - качество данных
- `GET /api/optimization` - оптимизация
- `GET /api/performance` - производительность

### **Пример использования API:**

```bash
# Получить статистику
curl http://localhost:5000/api/stats

# Получить последние сигналы
curl http://localhost:5000/api/signals
```
