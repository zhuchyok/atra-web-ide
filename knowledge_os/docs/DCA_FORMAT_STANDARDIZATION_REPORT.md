# Отчет о стандартизации формата DCA сигналов

## Обзор изменений

Формат DCA (Dollar-Cost Averaging) сигналов был приведен к единому стандарту, соответствующему формату обычных торговых сигналов.

## Технические изменения

### 1. Добавление технических данных

```python
# Получаем технические данные для DCA сигналов
technical_data = get_technical_indicators(df, current_index)
```

### 2. Формирование технического анализа

```python
# Формируем технический анализ для DCA
technical_analysis = ""
if technical_data:
    rsi_emoji = "🔴" if technical_data.get('rsi', 0) > 70 else "🟢" if technical_data.get('rsi', 0) < 30 else "🟡"
    # ... остальные индикаторы
```

### 3. Добавление filter_mode

```python
filter_mode = user_data.get('filter_mode', 'strict')
```

### 4. Обновление callback_data

```python
# Создаем клавиатуру для DCA
short_time = now.strftime("%m%d%H%M")
short_price = f"{last['close']:.4f}"
short_risk = f"{risk_pct:.1f}"
short_leverage = f"{leverage:.1f}"

callback_data = f'accept|{symbol}|{short_time}|{short_price}|long|{short_risk}|{short_leverage}'
```

## Преимущества нового формата

1. **Единообразие** - DCA сигналы теперь имеют тот же стиль, что и обычные сигналы
2. **Информативность** - добавлен технический анализ и данные о китах
3. **Читаемость** - улучшена структура и форматирование
4. **Функциональность** - обновлены команды и callback_data
5. **Сумма входа** - явно указана сумма для входа в позицию
