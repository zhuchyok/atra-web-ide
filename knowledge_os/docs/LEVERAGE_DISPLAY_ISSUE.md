## ✅ **РЕШЕНИЕ ПРИМЕНЕНО:**

### 📋 **Исправлено в функции balance_cmd:**

```python

    leverage = user_data.get('leverage', 1)

if user_data.get('trade_mode') == 'futures':
    msg += f"\nПлечо: Динамическое (0.5x-5x)"
```

## 🔧 **Как работает динамическое плечо:**

### 📊 **Факторы влияния:**

- **Тренд рынка** - при сильном тренде плечо увеличивается до 3x
- **Волатильность** - при высокой волатильности плечо уменьшается
- **Рыночные условия** - адаптация к текущей ситуации

### 📈 **Диапазон плеча:**

- **Минимум:** 0.5x
- **Максимум:** 5x (с ограничением до 20x)
- **Базовое:** 1x

### ⚡ **Где используется:**

- **В сигналах** - автоматический расчет для каждой сделки
- **В DCA** - пересчет при усреднении
- **В позициях** - отображение актуального плеча
