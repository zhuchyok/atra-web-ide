# 🚀 ДИНАМИЧЕСКИЕ ПАРАМЕТРЫ СИСТЕМЫ

## 📅 Дата: 27 июля 2025

## 🎯 Обзор

Ваша торговая система использует **полностью автоматический динамический расчет** всех торговых параметров на основе рыночных условий в реальном времени.

## ⚡ Динамические параметры

### 🔄 **Автоматически рассчитываются:**

#### 1. **Риск (Risk Percentage)**

- **Основа:** Волатильность рынка (ATR)
- **Факторы:** Тренд BTC, рыночные условия
- **Диапазон:** 1-5% от депозита
- **Обновление:** Каждый сигнал

#### 2. **Плечо (Leverage)**

- **Основа:** Рыночная волатильность
- **Факторы:** ATR, тренд, ликвидность
- **Диапазон:** 1-10x
- **Обновление:** Каждый сигнал

#### 3. **Take Profit (TP1, TP2)**

- **Основа:** Динамический ATR
- **Факторы:** Волатильность, тренд
- **Расчет:** TP1 = ATR × 1.5, TP2 = ATR × 3.0
- **Обновление:** Каждый сигнал

#### 4. **Stop Loss (SL)**

- **Основа:** Динамический ATR
- **Факторы:** Волатильность, тип позиции
- **Расчет:** SL = ATR × 2.0
- **Обновление:** Каждый сигнал

#### 5. **Объем позиции (Position Size)**

- **Основа:** Риск и плечо
- **Формула:** (Депозит × Риск%) / (Цена × Плечо)
- **Обновление:** Каждый сигнал

## 🎛️ Ручные настройки (только базовые)

### ✅ **Что можно настроить вручную:**

1. **`set_balance`** - Размер депозита
2. **`set_trade_mode`** - Режим торговли (spot/futures)
3. **`set_filter_mode`** - Режим фильтров (strict/soft/enhanced)

### ❌ **Что НЕ нужно настраивать вручную:**

- ❌ `set_risk` - Риск рассчитывается автоматически на основе ATR и тренда
- ❌ `set_volume` - Объем рассчитывается автоматически
- ❌ `set_spread` - Спред учитывается в алгоритме
- ❌ `set_volatility` - Волатильность измеряется в реальном времени
- ❌ `set_min_profit` - Минимальная прибыль = TP1
- ❌ `set_max_profit` - Максимальная прибыль = TP2

## 🔧 Алгоритм динамического расчета

### 📊 **Формулы:**

```python
# Динамический риск
risk_pct = base_risk * volatility_multiplier * trend_multiplier

# Динамическое плечо
leverage = base_leverage * (1 + volatility_factor) * trend_factor

# Динамический TP
tp1 = entry_price + (atr * 1.5)  # для LONG
tp2 = entry_price + (atr * 3.0)  # для LONG

# Динамический SL
sl = entry_price - (atr * 2.0)   # для LONG
```

### 📈 **Факторы влияния:**

1. **Волатильность (ATR):**
   - Высокая → Больше риск, больше плечо
   - Низкая → Меньше риск, меньше плечо

2. **Тренд BTC:**
   - Бычий → Увеличение риска для LONG
   - Медвежий → Увеличение риска для SHORT

3. **Рыночные условия:**
   - Высокая ликвидность → Больше плечо
   - Низкая ликвидность → Меньше плечо

### ✅ **Эффективность:**

- Максимальная прибыль в благоприятных условиях

- Постоянная оптимизация параметров
