## **🔧 ТЕХНИЧЕСКОЕ РЕШЕНИЕ**

### **Использование функции `get_full_price_format()`:**

```python
def get_full_price_format(symbol):
    """
    Возвращает формат для полного отображения цены как на бирже
    """
    # Используем точно такой же формат как на бирже
    precision = get_symbol_precision(symbol)
    return f"{{:.{precision}f}}"
```

### **Функция `get_symbol_precision()` с правильной точностью:**

```python
def get_symbol_precision(symbol):
    """
    Возвращает правильную точность для символа как на бирже
    """
    PRECISION_MAP = {
        "BTCUSDT": 1,      # 45000.5
        "ETHUSDT": 2,      # 3200.50
        "ADAUSDT": 4,      # 0.4500
        "DOTUSDT": 3,      # 5.250
        "LINKUSDT": 3,     # 15.750
        "XRPUSDT": 4,      # 0.5200
        "TRXUSDT": 5,      # 0.08500
        "PLUMEUSDT": 5,    # 0.09000
        # ... и другие символы
    }

    return PRECISION_MAP.get(symbol, 2)  # По умолчанию 2 знака
```
