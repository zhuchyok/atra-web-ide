# Отчет о исправлении ошибки Invalid format specifier

## 🎯 Проблема

**Ошибка**: `Invalid format specifier`

**Место возникновения**: Функция `button` в `telegram_bot.py` при нажатии кнопки "принять торговый сигнал"

**Симптомы**:

- Ошибка в логах: `[TelegramBot] Exception while handling an update: Invalid format specifier`
- Бот продолжает работать, но кнопка принятия сигнала не работает корректно
- Возникла после исправления предыдущей ошибки `qty variable`

## 🔍 Анализ проблемы

### 📊 **Причина ошибки:**

#### **Неправильное использование f-строки с условным выражением**

```python
# ПРОБЛЕМНЫЙ КОД (было):
msg += f"📊 Объём позиции: {qty:.6f if qty is not None else 0.0} {symbol.replace('USDT', '')}\n"
```

**Проблема**: В f-строке нельзя использовать условные выражения с форматированием `.6f`. Python не может правильно интерпретировать такой синтаксис.

#### **Почему это не работает:**

- F-строки ожидают простые выражения или переменные
- Условные выражения с форматированием создают неоднозначность
- Python не может определить, к какой части выражения применять форматирование

## ✅ Решение

### 1. **Вынесение логики за пределы f-строки**

```python
# ИСПРАВЛЕННЫЙ КОД:
# Безопасное форматирование объема позиции
qty_display = f"{qty:.6f}" if qty is not None else "0.000000"

# Затем использование в f-строке
msg += f"📊 Объём позиции: {qty_display} {symbol.replace('USDT', '')}\n"
```

### 2. **Исправлены все места использования**

#### **Первое место (строки 1513, 1517):**

```python
# Безопасное форматирование объема позиции
qty_display = f"{qty:.6f}" if qty is not None else "0.000000"

if trade_mode == "futures" and leverage:
    msg += f"📊 Объём позиции: {qty_display} {symbol.replace('USDT', '')}\n"
else:
    msg += f"📊 Объём позиции: {qty_display} {symbol.replace('USDT', '')}\n"
```

#### **Второе место (строки 1572, 1576):**

```python
# Безопасное форматирование объема позиции для второго сообщения
qty_display_second = f"{qty:.6f}" if qty is not None else "0.000000"

if trade_mode == "futures" and leverage:
    msg += f"📊 Объём позиции: {qty_display_second} {symbol.replace('USDT', '')}\n"
else:
    msg += f"📊 Объём позиции: {qty_display_second} {symbol.replace('USDT', '')}\n"
```

### 3. **Преимущества нового подхода**

#### **Читаемость кода:**

- Логика форматирования вынесена отдельно
- Код стал более понятным и структурированным

#### **Безопасность:**

- Защита от ошибок форматирования
- Fallback значение для случаев, когда `qty` равно `None`

#### **Производительность:**

- Форматирование происходит один раз
- Переменная `qty_display` переиспользуется
