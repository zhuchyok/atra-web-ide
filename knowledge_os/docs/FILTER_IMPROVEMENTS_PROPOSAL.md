### **6. НОВЫЙ ПАРАМЕТР: КОНФЛЮЭНС ИНДИКАТОРОВ** ⭐⭐⭐⭐

```python
# ДОБАВИТЬ В config.py:

# Минимальное количество индикаторов, которые должны подтверждать сигнал
# Из 5 индикаторов: RSI, MACD, EMA, BB, Volume

MIN_CONFLUENCE_INDICATORS_STRICT = 4    # 4 из 5 для strict

# Список индикаторов для проверки конфлюэнса

    "rsi",      # RSI в правильном диапазоне
    "macd",     # MACD подтверждает направление
    "ema",      # EMA fast > slow (для long)
    "bb",       # Правильная позиция в BB
    "volume"    # Объем выше среднего
]
```

**Эффект:**

- ✅ ↓ 50-60% ложных сигналов
- ✅ Требует согласованность между индикаторами
- ✅ Высокая точность входов
