# 🐋 Настройка системы отслеживания китов (Whale Tracking)

## 📋 **Обзор системы**

Система отслеживания китов интегрирована в основную торговую систему и предоставляет:

- **Анализ крупных транзакций** на блокчейнах
- **Подтверждение/опровержение** технических сигналов
- **Усиление уверенности** сигналов на основе активности китов
- **Детальную информацию** о настроении китов

---

## 🔑 **Получение API ключей**

### **1. Etherscan (Ethereum)**

1. Перейдите на [etherscan.io](https://etherscan.io)
2. Зарегистрируйтесь или войдите в аккаунт
3. Перейдите в [API-Keys](https://etherscan.io/myapikey)
4. Создайте новый API ключ
5. Скопируйте ключ в `.env` файл:
   ```
   ETHERSCAN_API_KEY=your_etherscan_api_key_here
   ```

### **2. BSCScan (Binance Smart Chain)**

## ⚙️ **Настройка конфигурации**

### **1. Включение/отключение системы**

В файле `config.py`:

```python
# Включение/отключение системы отслеживания китов
WHALE_TRACKING_ENABLED = True  # или False для отключения
```

### **2. Настройка минимальных значений транзакций**

```python
WHALE_MIN_TRANSACTION_VALUES = {
    "BTC": 100,      # Минимум 100 BTC
    "ETH": 1000,     # Минимум 1000 ETH
    "USDT": 1000000, # Минимум 1M USDT
    "USDC": 1000000, # Минимум 1M USDC
    "BNB": 10000,    # Минимум 10K BNB
    "SOL": 50000,    # Минимум 50K SOL
    # Добавьте другие токены по необходимости
}
```

### **3. Настройка усиления сигналов**

```python
WHALE_ENHANCEMENT_SETTINGS = {
    "confidence_boost_confirm": 0.20,    # +20% при подтверждении китами
    "confidence_boost_contradict": -0.10, # -10% при противоречии китами
    "volume_ratio_threshold": 2.0,       # Порог соотношения объемов
    "cache_ttl_minutes": 30,             # Время жизни кэша (минуты)
}
```

## ⚠️ **Ограничения и рекомендации**

### **🔴 Ограничения бесплатных API:**

- **Etherscan**: 5 запросов/сек, 100,000/день
- **BSCScan**: 5 запросов/сек, 100,000/день
- **PolygonScan**: 5 запросов/сек, 100,000/день
- **Arbiscan**: 5 запросов/сек, 100,000/день

### **💡 Рекомендации:**

1. **Используйте платные API** для коммерческого использования
2. **Настройте кэширование** для снижения нагрузки
3. **Мониторьте лимиты** запросов
4. **Тестируйте на тестовых сетях** перед продакшеном

### **🚨 Важные замечания:**

- API ключи **НЕ должны** попадать в публичные репозитории
- Используйте **переменные окружения** для хранения ключей
- Регулярно **обновляйте** список известных кошельков китов
- **Мониторьте** качество данных от API
