# 🔧 ИСПРАВЛЕНИЕ ПРОБЛЕМЫ ДВОЙНОГО НАЖАТИЯ КНОПОК (ФИНАЛЬНАЯ ВЕРСИЯ)

## ❌ **ПРОБЛЕМЫ:**

1. Кнопки не срабатывали с первого раза - пользователь нажимает второй раз, а оказывается действие уже было выполнено
2. DCA кнопки не работали на старые сигналы (заблокированы проверкой на дубликаты)

---

## ✅ **ИСПРАВЛЕНИЯ:**

### 1. **Защита от двойного принятия обычных сигналов**

Добавлена проверка для **обычных (не DCA) сигналов** после определения типа сигнала:

```python
if pl['is_dca']:
    # DCA логика - проверка НЕ применяется
    is_dca_signal = True
else:
    # Обычный сигнал
    is_dca_signal = False

    # Проверка на дубликаты ТОЛЬКО для обычных сигналов
    entry_time = pl.get('ts', "")
    signal_key = f"{symbol}_{entry_time}"
    if "accepted_signals" in user_data:
        if any(s.get("signal_key") == signal_key for s in user_data["accepted_signals"]):
            await query.edit_message_text(
                "✅ <b>Сигнал уже принят</b>\n\n"
                f"Символ: {symbol}\n"
                f"Цена: {entry_price}\n\n"
                f"💡 Используйте кнопку DCA для усреднения позиции",
                parse_mode='HTML'
            )
            return
```

### 2. **Фильтрация последнего сигнала по пользователю**

- В `db.py`: добавлен параметр `user_id` в `get_last_signal_log(user_id=None)`
- В `telegram_commands.py`: команда `/last_signal` передает `user_id` текущего пользователя
- Каждый пользователь видит только свои сигналы
