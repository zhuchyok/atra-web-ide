# Анализ актуальности точки входа при повторной отправке сигналов

## 🎯 Проблема

**Вопрос**: Бывает, что система присылает сигнал, пользователь его не принимает, проходит какое-то время, система присылает сигнал еще раз с другой точкой входа. **Остается ли вход актуальным по нашей системе? Возможно, точка входа уже слишком далеко от сигнала?**

## 📊 Анализ текущей системы

### 🔍 Как работает система сейчас

#### 1. **Кэширование сигналов**

```python
# Константы
```

### ⚠️ **Выявленные проблемы**

#### 1. **Слишком короткий таймаут кэша**

- `SIGNAL_CACHE_TIMEOUT = 60` секунд (1 минута)
- После 1 минуты система может отправить повторный сигнал
- **Проблема**: За 1 минуту цена может сильно измениться

#### 2. **Слишком строгий tolerance**

- `tolerance = 0.001` (0.1% разницы)
- **Проблема**: Даже небольшое изменение цены (0.2-0.5%) может сделать сигнал неактуальным

#### 3. **Отсутствие проверки актуальности сигнала**

- Система не проверяет, остается ли сигнал актуальным по техническим условиям
- **Проблема**: Цена может уйти далеко от условий входа

### 4. **Динамический tolerance на основе волатильности**

```python
def calculate_dynamic_tolerance(df, i):
    """
    Рассчитывает динамический tolerance на основе волатильности
    """
    # Рассчитываем волатильность за последние 20 свечей
    closes = df['close'].iloc[i-20:i]
    volatility = closes.std() / closes.mean()

    # Базовый tolerance
    base_tolerance = 0.003  # 0.3%

    # Адаптируем под волатильность
    dynamic_tolerance = base_tolerance * (1 + volatility * 10)

    # Ограничиваем от 0.1% до 2%
    dynamic_tolerance = max(0.001, min(dynamic_tolerance, 0.02))

    return dynamic_tolerance
```

### 5. **Проверка расстояния от оптимальной точки входа**

```python
def check_entry_distance(df, i, side, current_price):
    """
    Проверяет, не слишком ли далеко цена от оптимальной точки входа
    """
    bb_middle = df['bb_middle'].iloc[i]
    bb_upper = df['bb_upper'].iloc[i]
    bb_lower = df['bb_lower'].iloc[i]

    if side == "LONG":
        # Для LONG оптимальная точка входа - около нижней полосы
        optimal_entry = bb_lower * 1.02
        distance = abs(current_price - optimal_entry) / optimal_entry * 100

        # Если цена ушла больше чем на 2% от оптимальной точки
        if distance > 2.0:
            return False, f"Цена ушла на {distance:.1f}% от оптимальной точки входа"

    elif side == "SHORT":
        # Для SHORT оптимальная точка входа - около верхней полосы
        optimal_entry = bb_upper * 0.98
        distance = abs(current_price - optimal_entry) / optimal_entry * 100

        # Если цена ушла больше чем на 2% от оптимальной точки
        if distance > 2.0:
            return False, f"Цена ушла на {distance:.1f}% от оптимальной точки входа"

    return True, "Точка входа актуальна"
```
