# 🌐 Единая база правил Cursor

## 📋 Как это работает

### ✅ Единая база для всех проектов

- **Источник:** `~/.cursor/universal-rules.md` - **ОДИН** файл для всех проектов
- **Копии:** Каждый проект имеет свой `.cursorrules` с копией универсальных правил
- **Синхронизация:** Изменения в единой базе применяются ко всем проектам

### 🔄 Автоматическое обновление

1. **Изменили универсальные правила** в `~/.cursor/universal-rules.md`
2. **Запустили синхронизацию:** `./scripts/sync-cursor-rules.sh ~`
3. **Все проекты обновлены** автоматически!

## 🚀 Быстрое использование

### Добавить новое правило во все проекты

```bash
# 1. Отредактируйте единую базу
code ~/.cursor/universal-rules.md

# 2. Добавьте новое правило

# 3. Синхронизируйте во все проекты
./scripts/sync-cursor-rules.sh ~
```

### Изменить существующее правило

```bash
# 1. Отредактируйте единую базу
code ~/.cursor/universal-rules.md

# 2. Внесите изменения

# 3. Синхронизируйте
./scripts/sync-cursor-rules.sh ~
```

### Новый проект автоматически получит актуальные правила

При создании нового проекта через `init-cursor-rules.sh`:

- Автоматически копируются **актуальные** универсальные правила из `~/.cursor/universal-rules.md`
- Не нужно ничего синхронизировать вручную

## ✅ Преимущества

1. **Единый источник истины** - все правила в одном месте
2. **Автоматическое обновление** - одна команда обновляет все проекты
3. **Сохранение специфичных правил** - правила проекта не теряются
4. **Версионирование** - можно отслеживать изменения в Git

## 🔍 Проверка синхронизации

```bash
# Проверить, какие проекты имеют старые правила
./scripts/sync-cursor-rules.sh ~

# Скрипт покажет:
# - Какие проекты обновлены
# - Какие пропущены (уже актуальны)
# - Хеш текущих правил
```

## 💡 Рекомендации

1. **Версионируйте универсальные правила** в Git:

   ```bash
   git add ~/.cursor/universal-rules.md
   git commit -m "Update universal Cursor rules"
   ```

2. **Создайте alias** для быстрой синхронизации:

   ```bash
   # В ~/.zshrc или ~/.bashrc
   alias sync-rules='~/Documents/GITHUB/atra/atra/scripts/sync-cursor-rules.sh ~'
   ```

3. **Синхронизируйте после изменений** - не забывайте запускать синхронизацию
