## 📋 Проблема

Пользователь сообщил, что проблема с отображением депозита **"💰 Депозит: 0 USDT"** не исправлена.

## 🔍 Диагностика

### Найденная причина

После анализа резервных копий файлов данных было обнаружено, что:

1. **В активном файле `user_data.json`** данные корректные:

   ```json
   {
     "556251171": {
       "deposit": 10000.0,
       "trade_mode": "spot",
       "filter_mode": "soft"
       // setup_step отсутствует - настройка завершена
     }
   }
   ```

2. **В резервной копии `user_data_20250802_004515.json`** данные некорректные:
   ```json
   {
     "556251171": {
       "setup_step": "trade_mode", // ❌ Настройка не завершена
       "deposit": 666.0,
       "trade_mode": "futures",
       "filter_mode": "soft"
     }
   }
   ```

### Вывод

Проблема заключалась в том, что пользователь работал с **устаревшей версией данных**, где у пользователя 556251171 был `setup_step: "trade_mode"`, что означало, что настройка не завершена.

- ✅ **Улучшен расчет плеча** для корректного отображения
- ✅ **Исправлено отображение фильтров** ("Строгий" вместо "Сбалансированный")
