### ❌ **1. Валидация цен на аномалии** (-0.15 балла / -1%)

**Проблема:**

```python
# Сейчас (нет валидации):
current_price = await get_current_price_robust(symbol)
# Может вернуть аномальную цену (слишком большая/малая)
```

**Что нужно:**

```python
def validate_price(price: float, symbol: str, entry_price: float) -> bool:
    """Валидация цены на аномалии"""
    # Проверка на разумные пределы (±50% от цены входа)
    if abs(price - entry_price) / entry_price > 0.5:
        logger.warning(f"⚠️ Аномальная цена {symbol}: {price} (вход: {entry_price})")
        return False
    # Проверка на положительное значение
    if price <= 0:
        return False
    # Проверка на спред (если доступен bid/ask)
    return True
```

**Влияние:** Среднее (fallback работает, но точность PnL может страдать)

**Время реализации:** 2-4 часа

async def get_prices_bulk(symbols: List[str]) -> Dict[str, float]:
    """Получает цены для всех символов параллельно"""
    # Используем bulk API если доступен
    # Или параллельные запросы
    # + кэш с TTL 10-30 секунд

    ])

**Что нужно:**

```python
# Добавить расчет:
def calculate_var(returns: pd.Series, confidence: float = 0.95) -> float:
    """Value at Risk"""
    return returns.quantile(1 - confidence)

def calculate_cvar(returns: pd.Series, confidence: float = 0.95) -> float:
    """Conditional VaR (Expected Shortfall)"""
    var = calculate_var(returns, confidence)
    return returns[returns <= var].mean()

def calculate_calmar_ratio(annual_return: float, max_dd: float) -> float:
    """Calmar Ratio = Annual Return / Max Drawdown"""
    return annual_return / abs(max_dd) if max_dd != 0 else 0
```

**Влияние:** Низкое (улучшение аналитики, но не критично для торговли)
