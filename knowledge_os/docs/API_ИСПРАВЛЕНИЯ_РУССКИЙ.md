
- API был удален или изменен
- Система делала множественные неудачные попытки подключения

**Влияние:**

- Множество ошибок в логах

- Лишняя нагрузка на HTTP клиент

### 2. **CoinGecko API** - Превышение лимита запросов ⚠️

```
Предупреждение: CoinGecko API rate limited (статус: 429)
Текущий лимит: 5 запросов/минуту
```

**Причина:**

- Бесплатный план CoinGecko имеет строгие лимиты
- Система делала слишком много запросов

**Влияние:**

- Частые HTTP 429 ошибки
- Переключение на резервные API
- Снижение качества данных
