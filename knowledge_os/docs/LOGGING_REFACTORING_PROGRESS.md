## 💡 ПРЕИМУЩЕСТВА

1. **Структурированное логирование:** Все логи идут через единую систему
2. **Уровни логирования:** Можно контролировать детализацию (DEBUG, INFO, WARNING, ERROR)
3. **Traceback:** `exc_info=True` добавляет полный traceback для ошибок
4. **Фильтрация:** Можно фильтровать логи по модулям и уровням
5. **Мониторинг:** Логи можно отправлять в системы мониторинга

## 📝 ПРИМЕРЫ УЛУЧШЕНИЙ

### До рефакторинга:

```python
except Exception as e:
    print(f"Ошибка расчета динамического плеча: {e}")
    return base_leverage
```

### После рефакторинга:

```python
except Exception as e:
    logger.error("Ошибка расчета динамического плеча: %s", e, exc_info=True)
    return base_leverage
```

**Преимущества:**

- Лог попадает в систему логирования
- Можно фильтровать по уровню ERROR
- `exc_info=True` добавляет полный traceback
- Форматирование через `%s` более эффективно
