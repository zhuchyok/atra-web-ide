## 📋 **ПРОБЛЕМА**

Пользователь сообщил, что пропал процесс настройки пользователя (start steps), где:

2. Выбирает режим торговли (SPOT/FUTURES)
3. Выбирает режим фильтров (Строгий/Мягкий)
4. Система считает настройку пройденной и готовой к работе

[🔴 Строгий] [🟢 Мягкий]

- `/help` - доступен после завершения настройки
