# 🤖 Автоматическая система обучения на основе результатов сделок

## 🎯 Обзор

Система **полностью автоматически** анализирует результаты сделок и обучается на них, **без участия пользователя**. Все кнопки HITL feedback убраны — система сама определяет паттерны успешных/неуспешных сигналов и применяет улучшения.

---

## 🔄 Как это работает

### 1. Автоматический анализ сделок

**Модуль:** `observability/auto_analyzer.py`

Система автоматически:

- Анализирует закрытые сделки из таблицы `trades` в БД
- Определяет проблемы на основе:
  - **RSI** (перекупленность/перепроданность)
  - **MACD** (несоответствие направления)
  - **BTC тренд** (несоответствие тренда)
  - **Объём** (низкий объём)
  - **Confidence** (низкая уверенность)
  - **AI Score** (низкий скор)
  - **PnL** (крупные убытки, стоп-ауты)

### 2. Генерация уроков

**Модуль:** `observability/feedback.py`

Система автоматически:

- Группирует сделки по проблемам
- Рассчитывает успешность (win rate) для каждой проблемы
- Генерирует рекомендации на основе статистики
- Сохраняет уроки в `observability/lessons.json`

### 3. Применение улучшений

**Модуль:** `observability/guidance.py`

Система автоматически:

- Применяет уроки к агентам через `GuidanceStore`
- Обновляет `configs/guidance/<agent>.json`
- Экспортирует в `configs/prompts/<agent>.yaml` и `docs/guidance/<agent>.md`
- Агенты загружают уроки при генерации сигналов

## 📊 Примеры автоматического анализа

### Пример 1: RSI перекупленность для LONG

**Проблема:** `rsi_overbought_long`

**Условие:** LONG сигналы при RSI > 75

**Статистика:**

- Количество случаев: 15
- Успешность: 20% (3 из 15)
- Средний PnL: -5.2 USD

**Автоматическая рекомендация:**

> "Блокировать LONG сигналы при RSI > 75 или увеличить фильтр RSI для LONG. Критично: успешность 20%, средний PnL -5.2 USD."

**Применение:**
Система автоматически блокирует LONG сигналы при RSI > 75 в будущем.

---

### Пример 2: BTC тренд не учтён для SHORT

**Проблема:** `btc_bullish_short`

**Условие:** SHORT сигналы при бычьем BTC тренде

**Статистика:**

- Количество случаев: 8
- Успешность: 25% (2 из 8)
- Средний PnL: -3.1 USD

**Автоматическая рекомендация:**

> "Блокировать SHORT сигналы при бычьем BTC тренде или усилить проверку BTC alignment. Внимание: успешность 25%, средний PnL -3.1 USD."

**Применение:**
Система автоматически усиливает проверку BTC alignment для SHORT сигналов.

### Пример 3: Низкий объём

## 🚀 Запуск автоматического анализа

### Ручной запуск:

```bash
# Полный анализ с применением улучшений
python scripts/run_auto_analysis.py --db trading.db --lookback-days 30 --apply-guidance

# Только анализ без применения
python scripts/run_auto_analysis.py --db trading.db --lookback-days 30
```

### Автоматический запуск:

**Cron job:** `infrastructure/cron/auto_analysis.cron`

```cron
# Запускается ежедневно в 03:00 MSK
0 3 * * * cd /root/atra && /root/atra/.venv/bin/python scripts/run_auto_analysis.py --db trading.db --lookback-days 30 --apply-guidance >> logs/auto_analysis.log 2>&1
```

## 🔍 Определяемые проблемы

### Технические индикаторы:

- `rsi_overbought_long` — LONG при RSI > 75
- `rsi_oversold_short` — SHORT при RSI < 25
- `macd_bearish_long` — LONG при медвежьем MACD
- `macd_bullish_short` — SHORT при бычьем MACD
- `btc_bearish_long` — LONG при медвежьем BTC тренде
- `btc_bullish_short` — SHORT при бычьем BTC тренде

### Качество сигнала:

- `low_volume` — Низкий объём
- `low_confidence` — Низкая уверенность (< 60%)
- `low_ai_score` — Низкий AI score (< 50)

### Результаты:

- `large_loss` — Крупные убытки (< -10 USD)
- `stopped_out` — Закрытие по стоп-лоссу

---

## 📈 Метрики анализа

Для каждой проблемы система рассчитывает:

1. **Количество случаев** — сколько раз проблема встречалась
2. **Успешность (win rate)** — процент прибыльных сделок
3. **Средний PnL** — средняя прибыль/убыток в USD
4. **Примеры** — до 5 примеров сделок с этой проблемой

## 🔧 Устранение неполадок

### Проблема: Недостаточно данных для анализа

**Решение:**

- Увеличьте `lookback_days` (например, до 60)
- Уменьшите `min_trades_for_analysis` (например, до 5)

### Проблема: Уроки не применяются

**Решение:**

- Проверьте логи: `logs/auto_analysis.log`
- Убедитесь, что флаг `--apply-guidance` установлен
- Проверьте права доступа к `configs/guidance/`
