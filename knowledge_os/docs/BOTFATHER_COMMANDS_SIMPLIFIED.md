## 🎯 **ПОДРОБНЫЕ ОПИСАНИЯ:**

### **🚀 Основные команды:**

1. **`/start`** - Запуск бота, приветствие и краткая инструкция
2. **`/help`** - Полная справка по всем командам
3. **`/balance`** - Текущий баланс, прибыль, открытые позиции, свободные средства
4. **`/positions`** - Список всех открытых позиций с P&L в реальном времени
5. **`/close`** - Интерактивное закрытие позиций с кнопками
6. **`/trade_history`** - История всех закрытых сделок с прибылью
7. **`/signal_stats`** - Статистика принятых сигналов и результатов

### **⚙️ Настройки:**

8. **`/set_balance`** - Установить начальный депозит для расчетов
9. **`/set_trade_mode`** - Переключить между SPOT и FUTURES режимами
10. **`/set_filter_mode`** - Выбрать режим: **Строгий** (качество) или **Мягкий** (количество)

### **📊 Отчеты:**

11. **`/myreport`** - Персональный отчёт с детальной статистикой
12. **`/status`** - Статус системы, производительность, уведомления
13. **`/last_signal`** - Информация о последнем сгенерированном сигнале

### **👑 Административные (только для админов):**

14. **`/add_user`** - Добавить нового пользователя в систему
15. **`/remove_user`** - Удалить пользователя из системы
16. **`/list_users`** - Показать список всех пользователей

## 🎯 **УБРАННЫЕ КОМАНДЫ:**

### **❌ Динамические параметры (рассчитываются автоматически):**

- `set_volume` - Объем позиции
- `set_spread` - Спред
- `set_volatility` - Волатильность
- `set_min_profit` - Минимальная прибыль
- `set_max_profit` - Максимальная прибыль
- `set_risk` - Риск на сделку

### **❌ Опасные команды (убраны для безопасности):**

- `close_all` - Закрыть все позиции
- `confirm_close_all` - Подтверждение закрытия всех

### **❌ Устаревшие команды:**

- `set_balance` - Оставлен для установки начального депозита

## 🎯 **ПРЕИМУЩЕСТВА УПРОЩЕНИЯ:**

1. **📱 Простота** - меньше команд, проще навигация
