
### ✅ Новостные фильтры работают всегда

В функции `check_and_send_signals` (строки 2355-2388) новостные фильтры **ВСЕГДА** вызываются:

```python
# --- Фильтр по новостям ---
news_blocked, block_until, news_post = await is_negative_news(symbol)

# --- Проверка позитивных новостей ---
positive_news_found, positive_news_post = await is_positive_news(symbol)
```

## 📋 КОГДА ПРИМЕНЯЮТСЯ ФИЛЬТРЫ

### 1. **При каждой проверке сигналов**

- Новостные фильтры вызываются для **каждой монеты** в цикле
- Происходит **асинхронный запрос** к 9 источникам новостей
- Результаты кэшируются на 1 час

### 2. **Применение фильтров по пользователям**

Фильтры применяются индивидуально для каждого пользователя:

```python
# Обрабатываем негативные новости согласно режиму пользователя
if news_blocked is True:
    for user_id, user_data in user_data_dict.items():
        news_mode = user_data.get('news_filter_mode', 'conservative')
        mode_settings = NEWS_FILTER_MODES.get(news_mode, NEWS_FILTER_MODES['conservative'])
        trade_mode = user_data.get('trade_mode', 'spot')
```

### 3. **Фильтрация сигналов**

```python
# Проверяем, не блокируется ли SHORT сигнал позитивными новостями
if signal_type == "SHORT" and positive_news_flag and mode_settings['block_short_on_positive']:
    print(f"[DEBUG] SHORT сигнал заблокирован позитивными новостями")
    signal_type = None  # Отменяем сигнал

# Проверяем новостное усиление для сигнала
if signal_type == "LONG" and positive_news_flag and mode_settings['enable_positive_news']:
    has_news_enhancement = True
    print(f"[DEBUG] LONG сигнал усилен позитивными новостями")
```

## 🎯 РЕЖИМЫ ФИЛЬТРАЦИИ

### Conservative режим (консервативный)

```python
"conservative": {
    "enable_negative_news": True,    # Блокировать по негативным новостям
    "enable_positive_news": True,    # Генерировать LONG по позитивным
    "block_short_on_positive": True, # Блокировать SHORT при позитивных
}
```

### Aggressive режим (агрессивный)

```python
"aggressive": {
    "enable_negative_news": False,   # НЕ блокировать по негативным новостям
    "enable_positive_news": True,    # Генерировать LONG по позитивным
    "block_short_on_positive": False, # НЕ блокировать SHORT при позитивных
}
```

## 📊 ЛОГИКА РАБОТЫ

### Для SPOT пользователей:

- **Conservative**: Блокирует сигналы при негативных новостях
- **Aggressive**: Игнорирует негативные новости

### Для FUTURES пользователей:

- **Негативные новости**: ВСЕГДА усиливают SHORT сигналы
- **Позитивные новости**: Усиливают LONG сигналы (если включено)

### Примеры логики:

```python
if trade_mode == 'futures':
    # Для пользователей с фьючерсами негативные новости ВСЕГДА усиливают SHORT сигналы
    negative_news_flag = True
elif mode_settings['enable_negative_news']:
    # Для пользователей со spot - блокируем только если включен режим
    continue  # Пропускаем сигнал
```
