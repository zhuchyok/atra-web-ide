### 1. **Функции генерации сигналов:**

### 2. **Технические индикаторы:**

- ✅ **Bollinger Bands** - полосы Боллинджера
- ✅ **EMA (7, 25)** - экспоненциальные скользящие средние
- ✅ **RSI (14)** - индекс относительной силы
- ✅ **Volume Ratio** - соотношение объемов
- ✅ **Volatility** - волатильность
- ✅ **Momentum** - импульс
- ✅ **Trend Strength** - сила тренда

### 3. **Условия для сигналов:**

#### 🟢 **LONG сигнал (строгий режим):**

```python
long_conditions = [
    current_price <= bb_lower * 1.01,  # Касание нижней полосы Боллинджера
    ema7 > ema25 * 1.001,              # Восходящий тренд
    rsi < 40,                          # Перепроданость
    volume_ratio > 1.2,                # Высокий объем
    volatility > 2,                    # Высокая волатильность
    momentum > 0,                      # Положительный импульс
    trend_strength > 0.5               # Сильный тренд
]
```

#### 🔴 **SHORT сигнал (строгий режим):**

```python
short_conditions = [
    current_price >= bb_upper * 0.99,  # Касание верхней полосы Боллинджера
    ema7 < ema25 * 0.999,              # Нисходящий тренд
    rsi > 60,                          # Перекупленность
    volume_ratio > 1.2,                # Высокий объем
    volatility > 2,                    # Высокая волатильность
    momentum < 0,                      # Отрицательный импульс
    trend_strength > 0.5               # Сильный тренд
]
```
