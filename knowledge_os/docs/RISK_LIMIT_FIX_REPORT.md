## 🔍 **АНАЛИЗ ПРОБЛЕМЫ**

### ❌ **Что происходило:**

1. **Переменная `deposit` не была определена** перед расчетом `global_limit`
2. **Дублирование проверки депозита** - система проверяла депозит дважды
3. **Некорректный расчет** - `global_limit = deposit * GLOBAL_RISK_LIMIT_PCT / 100` с неопределенной переменной

### 🔧 **Найденные проблемы:**

1. **Строка 1245**: `global_limit = deposit * GLOBAL_RISK_LIMIT_PCT / 100` - переменная `deposit` не определена
2. **Строки 1267-1271**: Дублирование проверки `if "deposit" not in user_data:`
3. **Отсутствие проверки** на корректность значения депозита

## ✅ **ИСПРАВЛЕНИЯ**

### 1. **Добавлена проверка депозита перед расчетом:**

```python
# Проверяем, что deposit определен и больше 0
if "deposit" not in user_data or user_data["deposit"] <= 0:
    await query.edit_message_reply_markup(reply_markup=None)
    await query.message.reply_text(
        "❗ Необходимо установить депозит для расчета рисков. Используйте команду /balance"
    )
    return

deposit = user_data["deposit"]
global_limit = deposit * GLOBAL_RISK_LIMIT_PCT / 100
```

### 2. **Убрано дублирование проверки:**

- Удалена повторная проверка `if "deposit" not in user_data:`
- Добавлен комментарий: `# Депозит уже проверен выше, поэтому продолжаем`

### 3. **Улучшена обработка ошибок:**

- Система теперь корректно обрабатывает случаи с неопределенным депозитом
- Пользователь получает понятное сообщение о необходимости установить депозит
