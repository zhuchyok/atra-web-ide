## 🚀 Как использовать

### Для нового проекта

1. Откройте проект в Cursor
2. Правила применятся автоматически (если настроена автоинициализация)
3. Или запустите вручную: `./scripts/init-cursor-rules.sh`

### Для существующих проектов

```bash
# Массовая инициализация всех проектов
./scripts/init-cursor-rules-all.sh ~

# Или для конкретной директории
./scripts/init-cursor-rules-all.sh ~/projects
```

### После изменения универсальных правил

```bash
# Синхронизировать все проекты
./scripts/sync-cursor-rules.sh ~
```

## 📋 Следующие шаги (опционально)

### 1. Настроить автоматическую инициализацию

```bash
./scripts/setup-cursor-auto-init.sh
source ~/.zshrc  # или ~/.bashrc
```

Теперь при открытии проекта правила будут применяться автоматически.

### 2. Создать alias для быстрой синхронизации

Добавьте в `~/.zshrc` или `~/.bashrc`:

```bash
alias sync-rules='~/Documents/GITHUB/atra/atra/scripts/sync-cursor-rules.sh ~'
```

Теперь можно синхронизировать правила командой:

```bash
sync-rules
```

### 3. Версионировать универсальные правила

```bash
# Добавьте в Git для отслеживания изменений
git add ~/.cursor/universal-rules.md
git commit -m "Add universal Cursor rules"
```
