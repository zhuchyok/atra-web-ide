## 🎯 Детальная логика Mean Reversion (основная стратегия)

### **LONG сигнал - строгие условия:**

```python
long_reversion_conditions = [
    # 1. Точное касание нижней полосы (очень строгое)
    current_price >= bb_lower * 0.995 and current_price <= bb_lower * 1.005,

    # 2. Цена значительно ниже средней полосы
    current_price < bb_middle * 0.99,  # Увеличено с 0.995 до 0.99

    # 3. Экстремальная перепроданость (очень строгая)
    rsi < 20,  # Снижено с 25 до 20

    # 4. Подтверждение трендом
    current_price > ema50 * 0.97,  # Более строгое условие

    # 5. Подтверждение свечами (5 свечей подряд)
    i >= 5 and all(df["close"].iloc[j] > df["close"].iloc[j-1] for j in range(i-4, i+1)),

    # 6. Дополнительное подтверждение объемом
    volume_ratio > volume_threshold,  # Оптимизированный порог

    # 7. Фильтр по силе возврата
    (bb_middle - current_price) / current_price * 100 > 1.5,  # Увеличено с 0.3 до 1.5

    # 8. Фильтр по настроениям
    sentiment_score > -sentiment_threshold  # Не слишком негативные настроения
]
```

### **SHORT сигнал - строгие условия:**

```python
short_reversion_conditions = [
    # 1. Точное касание верхней полосы (очень строгое)

    # 2. Цена значительно выше средней полосы

    # 4. Подтверждение трендом

    i >= 5 and all(df["close"].iloc[j] < df["close"].iloc[j-1] for j in range(i-4, i+1)),

    # 6. Дополнительное подтверждение объемом
    volume_ratio > volume_threshold,  # Оптимизированный порог

    # 7. Фильтр по силе возврата
    (current_price - bb_middle) / current_price * 100 > 1.5,  # Увеличено с 0.3 до 1.5

    # 8. Фильтр по настроениям
    sentiment_score < sentiment_threshold  # Не слишком позитивные настроения
]
```
