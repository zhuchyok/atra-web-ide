## **🔧 ТЕХНИЧЕСКИЕ ДЕТАЛИ**

### **Файлы обновлены:**

- `telegram_bot.py` - функции обработки принятия сигналов
- `signal_live.py` - форматы отправки сигналов

### **Ключевые особенности:**

#### **1. Единый стиль форматирования:**

- **Markdown** - `*заголовки*` и `**жирный текст**`
- **Код-блоки** - важные значения в `` `код-блоках` ``
- **Эмодзи-навигация** - каждый тип информации имеет свой эмодзи

#### **2. Структурированная информация:**

- 💰 **Депозит** - текущий баланс пользователя
- 📊 **Открытые позиции** - количество и общий риск
- 💵 **Свободные средства** - доступно для новых сделок
- 🎯 **Риск на сделку** - процент и сумма в USDT
- ⚡ **Плечо** - используемое плечо для фьючерсов
- 💎 **Сумма входа** - фактическая сумма для входа

#### **3. Различия между типами сигналов:**

**Новый сигнал:**

- ✅ Создает **новую позицию**
- 🎯 Показывает **тейк-профиты**
- 📊 Отображает **сумму входа**

**DCA сигнал:**

- ✅ **Обновляет существующую позицию**
- 📊 Показывает **новую среднюю цену**
- 🔢 Отображает **количество усреднений**
- 🎯 **Пересчитывает тейк-профиты**
