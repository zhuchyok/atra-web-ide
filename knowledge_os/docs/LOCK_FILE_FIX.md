# 🔒 ИСПРАВЛЕНИЕ ОШИБКИ С LOCK_FILE

## ❌ **ПРОБЛЕМА:**

В файле `main.py` использовалась переменная `lock_file`, которая не была определена, что приводило к ошибке:

```python
# Ошибка - переменная lock_file не определена
try:
    os.remove(lock_file)
except:
    pass
```

## ✅ **РЕШЕНИЕ:**

Добавлен полный механизм блокировки файлов для предотвращения запуска нескольких экземпляров системы.

### **🔧 Изменения в main.py:**

```python
import fcntl  # Добавлен импорт

if __name__ == "__main__":
    # Файл блокировки для предотвращения запуска нескольких экземпляров
    lock_file = "atra.lock"

    # Проверяем, не запущен ли уже процесс
    try:
        with open(lock_file, 'w') as f:
            fcntl.flock(f.fileno(), fcntl.LOCK_EX | fcntl.LOCK_NB)
            print("🔒 Блокировка установлена - запуск системы")
    except (IOError, OSError):
        print("❌ Система уже запущена! Закройте другой экземпляр.")
        exit(1)

    # ... основной код ...

    finally:
        # Освобождаем lock файл
        try:
            os.remove(lock_file)
            print("🔓 Блокировка снята")
        except:
            pass
```
