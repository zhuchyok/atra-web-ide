## 🔧 ЛОГИКА РАБОТЫ

### **Приоритет сигналов:**

```
1. Улучшенный возврат к средней (mean reversion) - ВЫСШИЙ ПРИОРИТЕТ
2. Улучшенный пробой полос (breakout) - СРЕДНИЙ ПРИОРИТЕТ
3. Улучшенный пробой после squeeze - НИЗКИЙ ПРИОРИТЕТ
4. Классические условия (fallback) - ПОСЛЕДНИЙ ПРИОРИТЕТ
```

### **Фильтрация по настроениям:**

```
LONG сигнал:
  - Блокируется если sentiment_score < -threshold
  - Разрешается если sentiment_score >= -threshold

SHORT сигнал:
  - Блокируется если sentiment_score > threshold
  - Разрешается если sentiment_score <= threshold
```

### **Пороги настроений:**

- **STRICT режим:** `±0.4` (строгий)
- **SOFT режим:** `±0.6` (мягкий)

## 🎯 КОМПОНЕНТЫ ENHANCED BOLLINGER

### **1. Improved Mean Reversion Signal**

- **Описание:** Улучшенный возврат к средней полосе Боллинджера

  - Точное касание полос Боллинджера

  - Всплеск объема
  - Подтверждение свечами
  - Сила возврата к средней

### **2. Improved Breakout Signal**

- **Описание:** Улучшенный пробой полос Боллинджера
- **Условия:**
  - Пробой верхней/нижней полосы
  - Подтверждение трендом (EMA)
  - Всплеск объема
  - Сила пробоя

### **3. Improved Squeeze Breakout Signal**

- **Описание:** Улучшенный пробой после сжатия полос
- **Условия:**
  - Сжатие полос Боллинджера
  - Пробой после сжатия
  - Подтверждение объемом
  - Направление пробоя
