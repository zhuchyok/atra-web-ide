# 🔧 ИСПРАВЛЕНИЕ: Лимит корреляционных групп

## 📊 ПРОБЛЕМА

**Симптомы:**

- В dev сигналы идут нормально
- В prod сигналы не генерируются
- В логах: `🚫 [SEND_SIGNAL BLOCK] XRPUSDT SELL: Корреляционный риск заблокирован - GROUP_LIMIT_EXCEEDED`

**Диагностика:**

```bash
# Проверка активных сигналов
❌ SOL_HIGH: 5/5 сигналов
   ⚠️ ЛИМИТ ДОСТИГНУТ! Блокируются новые сигналы
   - XRPUSDT SELL (9 мин назад)
   - XRPUSDT SELL (14 мин назад)
   - XRPUSDT SELL (21 мин назад)
   - XRPUSDT SELL (27 мин назад)
   - XRPUSDT SELL (39 мин назад)
```

**Причина:**

- Группа `SOL_HIGH` имеет лимит 5 сигналов
- В портфеле 14 монет из группы `SOL_HIGH`
- Лимит слишком низкий для портфеля

## ✅ РЕШЕНИЕ

**Изменение:**

```python
# correlation_risk_manager.py
'SOL_HIGH': {'max_signals': 10, 'cooldown': CORRELATION_COOLDOWN_SEC},  # 🔧 УВЕЛИЧЕНО: 5 → 10
```

**Обоснование:**

- Портфель состоит из 14 монет `SOL_HIGH`
- Лимит 5 сигналов блокирует большую часть портфеля
- Увеличение до 10 позволяет работать с основными монетами портфеля

## 📊 СТАТУС
