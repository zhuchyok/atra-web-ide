---

## 🎯 ПРОБЛЕМА

**Ранее:** Обучалось только 5 случайных экспертов каждый день (`LIMIT 5`)  
**Теперь:** Обучаются **ВСЕ активные эксперты** каждый день

---

## ✅ РЕШЕНИЕ

### **Изменения в `nightly_learner.py`:**

1. **Убран LIMIT 5** — теперь получаем всех активных экспертов
2. **Добавлена умная фильтрация** — пропускаем экспертов, которые обучались менее 24 часов назад
3. **Приоритет обучения** — сначала обучаются те, кто не обучался давно или никогда
4. **Индивидуальное отслеживание** — каждый эксперт обновляет свой `last_learned_at`

### **Логика обучения:**

```sql
SELECT id, name, role, department, system_prompt, last_learned_at
FROM experts
WHERE is_active = TRUE OR is_active IS NULL
ORDER BY
    CASE
        WHEN last_learned_at IS NULL THEN 0        -- Приоритет 0: никогда не обучались
        WHEN last_learned_at < NOW() - INTERVAL '24 hours' THEN 1  -- Приоритет 1: обучались > 24ч назад
        ELSE 2                                     -- Приоритет 2: обучались < 24ч назад (пропускаются)
    END,
    RANDOM()  -- Случайный порядок внутри приоритетов
```

## 📊 КАК РАБОТАЕТ

### **1. Ежедневный запуск (3:00 UTC):**

- `nightly_learner.py` запускается автоматически через cron
- Получает всех активных экспертов из БД
- Фильтрует тех, кто обучался менее 24 часов назад

### **2. Процесс обучения для каждого эксперта:**

1. **Определение пробела:**
   - Эксперт определяет, что ему нужно изучить
   - Фокус на технологиях и трендах 2025 года

2. **Исследование:**
   - Поиск и анализ новой информации
   - Формулирование 1-2 глубоких инсайтов

3. **Сохранение знаний:**
   - Инсайты сохраняются в БД как `knowledge_nodes`
   - Привязываются к домену эксперта
   - Метаданные: имя эксперта, цикл обучения

4. **Совет Экспертов (если confidence ≥ 0.9):**
   - Важные знания проверяются другими экспертами
   - Обсуждение и консенсус
   - Повышение качества знаний

5. **Обновление метрик:**
   - `last_learned_at` обновляется для конкретного эксперта
   - Запись в `expert_learning_logs`
   - Статистика обучения

### **3. Защита от дублей:**

- Эксперт не обучается дважды за 24 часа
- Автоматическая проверка времени последнего обучения
- Пропуск экспертов, которые уже обучались сегодня
