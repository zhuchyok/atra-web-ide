## 🎯 Обзор

Система торговых сигналов включает команды разного уровня опасности. Некоторые команды могут привести к необратимым последствиям, поэтому мы оптимизировали список команд BotFather для максимальной безопасности.

## ⚠️ **ОПАСНЫЕ КОМАНДЫ (УБРАНЫ ИЗ BOTFATHER)**

### 🔴 **`close_all` - Закрыть все позиции**

#### ❌ **Почему убрали:**

- **Высокий риск** случайного нажатия
- **Необратимые последствия** - все позиции закрываются
- **Возможные убытки** при неблагоприятном рынке
- **Нет подтверждения** - команда выполняется сразу

#### 🎯 **Альтернативы:**

```
/close SYMBOL - Закрыть конкретную позицию
/close SYMBOL PRICE - Закрыть по цене
/close SYMBOL PRICE QTY - Закрыть часть позиции
```

#### 🔧 **Для администраторов (если нужно):**

- Команда остается в коде для экстренных случаев
- Доступна только через прямой вызов функции
- Требует дополнительного подтверждения

### 🔴 **`confirm_close_all` - Подтвердить закрытие всех позиций**

#### ❌ **Почему убрали:**

- **Связана с опасной операцией** закрытия всех позиций
- **Может быть вызвана случайно** после подготовки
- **Высокий риск** финансовых потерь
- **Требует специального контекста** для использования

#### 🎯 **Безопасная альтернатива:**

- Использование кнопки "🔒 Подтвердить закрытие всех" в интерфейсе
- Команда доступна только через кнопки, не через BotFather

## 📋 **РЕКОМЕНДАЦИИ ПО ИСПОЛЬЗОВАНИЮ**

### ✅ **Безопасные практики:**

1. **Перед закрытием позиции:**
   - Проверьте текущую цену через `/positions`
   - Убедитесь в правильности символа
   - Рассчитайте возможные убытки

2. **При принятии сигналов:**
   - Проверьте баланс через `/balance`
   - Убедитесь в достаточности средств
   - Проверьте настройки риска

3. **Регулярный мониторинг:**
   - Используйте `/positions` для просмотра открытых позиций
   - Проверяйте `/signal_stats` для анализа эффективности
   - Мониторьте `/balance` для контроля средств

### ⚠️ **Что делать в экстренных случаях:**

1. **Если нужно закрыть все позиции:**
   - Используйте кнопку "🔒 Закрыть все позиции" в `/positions`
   - Подтвердите действие кнопкой "🔒 Подтвердить закрытие всех"
   - Или используйте команду `/close SYMBOL` для каждой позиции отдельно
   - Проверьте результат через `/positions`

2. **При технических проблемах:**
   - Используйте `/status` для проверки состояния
   - Обратитесь к администратору через `/help`
