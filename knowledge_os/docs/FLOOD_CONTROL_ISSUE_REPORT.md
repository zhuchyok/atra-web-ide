# ОТЧЕТ: ПРОБЛЕМА С FLOOD CONTROL TELEGRAM

## 🔍 Проблема

**Ошибка:** `Flood control exceeded. Retry in 599 seconds`

**Причина:** Telegram блокирует отправку сообщений пользователю 958930260 на 10 минут из-за слишком частых сообщений.

**Результат:** Второй пользователь не получает торговые сигналы, хотя система корректно обрабатывает всех пользователей.

```python
async def notify_user_with_flood_control(user_id, message, max_retries=3):
    """Отправка сообщения с обработкой Flood Control"""
    for attempt in range(max_retries):
        try:
            result = await notify_user(user_id, message)
            if result:
                return True
        except Exception as e:
            if "Flood control" in str(e):
                print(f"[FLOOD] Пользователь {user_id} заблокирован на 10 минут")
                # Сохраняем в кэш для пропуска
                FLOOD_CONTROL_CACHE[user_id] = time.time() + 600
                return False
            elif attempt < max_retries - 1:
                await asyncio.sleep(2 ** attempt)  # Экспоненциальная задержка
    return False
```

#### B. Кэш заблокированных пользователей

```python
FLOOD_CONTROL_CACHE = {}

def is_user_flood_controlled(user_id):
    """Проверяет, заблокирован ли пользователь Flood Control"""
    if user_id in FLOOD_CONTROL_CACHE:
        if time.time() < FLOOD_CONTROL_CACHE[user_id]:
            return True
        else:
            del FLOOD_CONTROL_CACHE[user_id]
    return False
```
