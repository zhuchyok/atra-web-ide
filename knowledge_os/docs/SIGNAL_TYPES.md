# 📊 Типы сигналов и их отличия

## 📋 Обзор типов сигналов

В системе есть **3 основных типа сигналов**, которые пользователь может легко различить по заголовку и содержимому сообщения:

## 🟢 1. НОВЫЕ ТОРГОВЫЕ СИГНАЛЫ (LONG/SHORT)

### Заголовок:

```
🟢 НОВЫЙ ТОРГОВЫЙ СИГНАЛ
```

### Структура сообщения:

```
🟢 НОВЫЙ ТОРГОВЫЙ СИГНАЛ

СИГНАЛ: BTCUSDT
Цена: 45000.00
TP1: 45450.00 (+1.0%)
TP2: 45900.00 (+2.0%)
Риск: 2.50%
BTC тренд: 🟢 БЫЧИЙ
Режим фильтров: strict
Режим торговли: futures

Если кнопка не работает, просто нажмите на команду ниже для принятия сигнала:
/accept BTCUSDT 2024-01-15T14:30
```

### Отличительные признаки:

- ✅ **Эмодзи в заголовке**: 🟢 для LONG, 🔴 для SHORT
- ✅ **Слово "НОВЫЙ"** в заголовке
- ✅ **Простая структура** - только цена, TP1, TP2
- ✅ **Нет информации об усреднениях**
- ✅ **Нет средней цены**

## 🎯 Как пользователь определяет тип сигнала

### 1. По заголовку:

- **"НОВЫЙ ТОРГОВЫЙ СИГНАЛ"** = Новая позиция
- **"СИГНАЛ УСРЕДНЕНИЯ"** = Дополнение к существующей позиции

### 2. По эмодзи:

- **🟢** = LONG позиция (покупка)
- **🔴** = SHORT позиция (продажа)

### 3. По содержимому:

- **Простая структура** = Новая позиция
- **Подробная информация** = Усреднение
- **Новостная секция** = Новостной сигнал

### 4. По контексту:

- **Новая позиция**: Открытие новой сделки
- **Усреднение**: Дополнение к убыточной позиции
- **Новостной**: Основан на новостях

## 🔄 Логика работы системы

### Новые сигналы:

1. **Технический анализ** определяет условия входа
2. **BTC тренд** фильтрует сигналы
3. **Пользователь получает** сигнал на открытие позиции

### Усреднения:

1. **Существующая позиция** в убытке
2. **Цена достигла** уровня для DCA
3. **Система рассчитывает** новый объём и среднюю цену
4. **Пользователь получает** сигнал на усреднение

### Технические сигналы с новостным усилением:

1. **Технический анализ** определяет условия входа
2. **Новости проверяются** для усиления сигнала
3. **Позитивные новости** усиливают LONG сигналы
4. **Негативные новости** усиливают SHORT сигналы (только для фьючерсов)
5. **Пользователь получает** технический сигнал с новостным контекстом

## ⚙️ Настройки пользователя

### Влияют на сигналы:

- **trade_mode**: spot/futures (влияет на доступность SHORT)
- **leverage**: плечо (влияет на объёмы)
- **risk_pct**: процент риска
- **filter_mode**: strict/soft (влияет на чувствительность)
- **news_filter_mode**: conservative/aggressive/technical_only/news_only

### Не влияют на сигналы:

- **trading_hours**: только фильтрует время отправки
- **deposit**: влияет на расчёты, но не на тип сигнала

## 🎯 Рекомендации для пользователей

### Для новых сигналов:

- ✅ **Анализируйте** технические условия
- ✅ **Проверяйте** BTC тренд
- ✅ **Учитывайте** риск и плечо

### Для усреднений:

- ✅ **Проверяйте** среднюю цену
- ✅ **Анализируйте** историю входов
- ✅ **Контролируйте** общий риск

### Для сигналов с новостным усилением:

- ✅ **Анализируйте** технические условия
- ✅ **Читайте** новостную информацию для контекста
- ✅ **Проверяйте** источник новости
- ✅ **Учитывайте** настроение рынка

## 🎯 Заключение

Система предоставляет **четкие и понятные сигналы** с легко различимыми типами:

- ✅ **Новые сигналы** - для открытия позиций на основе технического анализа
- ✅ **Усреднения** - для дополнения убыточных позиций
- ✅ **Сигналы с новостным усилением** - технические сигналы, усиленные новостным контекстом

Каждый тип имеет **уникальные характеристики** и **отличительные признаки**, что позволяет пользователям быстро понимать суть сигнала и принимать обоснованные решения.
