## ✅ Основные файлы системы (ОБЯЗАТЕЛЬНО)

### 🎯 Главные файлы:

- **`main.py`** - главный файл запуска системы
- **`signal_live.py`** - основная логика генерации сигналов
- **`telegram_bot.py`** - Telegram бот и все команды
- **`config.py`** - конфигурация системы
- **`ohlc_utils.py`** - работа с OHLC данными
- **`cache_utils.py`** - система кэширования
- **`performance_monitor.py`** - мониторинг производительности
- **`shared_utils.py`** - общие утилиты
- **`user_utils.py`** - управление пользователями
- **`manage_users.py`** - админские функции
- **`db.py`** - база данных
- **`exchange_api.py`** - API бирж

### 📦 Зависимости:

- **`requirements.txt`** - список Python пакетов

### 🔧 Конфигурация:

- **`.env`** - переменные окружения (создать на сервере)

## 🚀 Команды для деплоя:

### 1. Загрузите файлы на сервер

### 2. Создайте .env файл:

```bash
TELEGRAM_TOKEN=ваш_токен_бота
TELEGRAM_TOKEN_DEV=ваш_токен_для_разработки
TELEGRAM_CHAT_IDS=ваши_chat_id
CRYPTOPANIC_API_KEY=ваш_ключ
NEWSDATA_API_KEY=ваш_ключ
```

### 3. Установите зависимости:

```bash
pip3 install -r requirements.txt
```

### 4. Создайте папки:

```bash
mkdir logs backups user_data_backups
```

### 5. Запустите систему:

```bash
python3 main.py
```

### 6. Для работы в фоне:

```bash
nohup python3 main.py > bot.log 2>&1 &
```
