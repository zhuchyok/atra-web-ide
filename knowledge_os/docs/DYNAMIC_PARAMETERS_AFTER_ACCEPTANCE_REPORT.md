if free_deposit > 0:

## 🎯 **ПРЕИМУЩЕСТВА**

### **1. Точный расчет риска**

- ✅ Риск рассчитывается от **свободных средств**
- ✅ Учитываются **все открытые позиции**
- ✅ Показывается **актуальный баланс**

### **2. Прозрачность**

- ✅ Пользователь видит **сколько занято**
- ✅ Пользователь видит **сколько свободно**
- ✅ Пользователь понимает **откуда берется сумма входа**

### **3. Безопасность**

- ✅ Невозможно превысить **лимит депозита**
- ✅ Система учитывает **все обязательства**
- ✅ Защита от **переторговли**

## 📊 **ЛОГИКА РАБОТЫ**

### **1. Расчет свободных средств:**

```
Свободные средства = Общий депозит - Сумма всех открытых позиций
```

### **2. Расчет риска для новой позиции:**

```
Риск = Свободные средства × Процент риска / 100
```

### **3. Учет плеча (фьючерсы):**

```
Финальный риск = Риск × Плечо
```
