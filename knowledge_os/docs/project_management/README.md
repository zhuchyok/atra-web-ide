# 🎯 Project Management — Автоматизированное управление проектом

## Обзор

Система автоматизированного управления проектом ATRA Trading Bot. PM работает автономно, анализирует производительность, оптимизирует параметры и принимает решения на основе данных.

## Структура

```
docs/project_management/
├── pm_framework.md          # Framework управления проектом
├── strategy_roadmap.md      # Стратегический план развития
└── README.md                # Этот файл

scripts/
├── pm_coordinator.py        # Главный координатор PM
├── pm_daily_check.py        # Ежедневная проверка
└── pm_auto_optimize.py      # Автоматическая оптимизация

infrastructure/cron/
└── pm_daily.cron            # Cron задачи для автоматического запуска
```

## Быстрый старт

### 1. Ручной запуск ежедневной проверки

```bash
cd /root/atra
python3 scripts/pm_daily_check.py
```

### 2. Ручной запуск оптимизации

```bash
cd /root/atra
python3 scripts/pm_auto_optimize.py
```

### 3. Полный цикл PM

```bash
cd /root/atra
python3 scripts/pm_coordinator.py
```

### 4. Настройка автоматического запуска

```bash
# Установить cron задачи
crontab infrastructure/cron/pm_daily.cron
```

## Компоненты

### PM Coordinator

Главный координатор, который:

- Запускает ежедневные проверки
- Анализирует производительность
- Оптимизирует параметры
- Генерирует отчёты

### Daily Check

Ежедневная проверка:

- Финансовые метрики (PnL, win rate, profit factor)
- Операционные метрики (fill rate, timeout rate)
- Качество кода (линтер, тесты)
- Риски и проблемы

### Auto Optimizer

Автоматическая оптимизация:

- Анализ производительности за 7 дней
- Оптимизация параметров сигналов
- Оптимизация параметров исполнения
- Оптимизация риск-менеджмента

## Метрики

### Финансовые

- **Win Rate:** Цель > 55%
- **Average Profit per Trade:** Цель > 1.5%
- **Sharpe Ratio:** Цель > 2.0
- **Sortino Ratio:** Цель > 2.5
- **Max Drawdown:** Цель < 10%

### Операционные

- **Limit Fill Rate:** Цель > 90%
- **Timeout Rate:** Цель < 10%
- **Market Fallback Rate:** Цель < 5%
- **SL/TP Coverage:** Цель 100%

## Отчёты

### Ежедневные отчёты

Сохраняются в: `docs/project_management/daily_reports/daily_report_YYYYMMDD.json`

### Оптимизации

Сохраняются в: `docs/project_management/optimizations/optimization_YYYYMMDD.json`

## Процесс работы

1. **Ежедневно (00:00 UTC):**
   - Запуск PM Coordinator
   - Проверка метрик
   - Анализ проблем
   - Генерация рекомендаций

2. **При обнаружении проблем:**
   - Автоматическая оптимизация
   - Применение критических исправлений
   - Генерация отчёта

3. **Еженедельно:**
   - Полный анализ производительности
   - Стратегическое планирование
   - Обновление roadmap
