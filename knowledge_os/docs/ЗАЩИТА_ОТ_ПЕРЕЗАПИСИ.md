## ❌ НИКОГДА НЕ ДЕЛАЙТЕ

### 🚫 Опасные команды:

```bash
git reset --hard          # ❌ УДАЛЯЕТ ВСЕ изменения!
git push --force          # ❌ Перезаписывает историю!
git clean -fdx            # ❌ Удаляет все файлы!
```

### ⚠️ Если случайно сделали `git reset --hard`:

```bash
# 1. Смотрим историю всех действий
git reflog

# 2. Находим нужный коммит (например: abc1234)

# 3. Восстанавливаем
git reset --hard abc1234
```

## 📞 ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК

### Сценарий 1: Забыл закоммитить, есть конфликты

```bash
git stash              # Спрятать изменения
git pull               # Тянуть обновления
git stash pop          # Вернуть изменения
# Решить конфликты
git add .
git commit -m "Merged"
```

### Сценарий 2: Сделал `git reset --hard`

```bash
git reflog                    # Найти потерянный коммит
git reset --hard <commit>     # Восстановить
```

### Сценарий 3: После pull что-то сломалось

```bash
python3 verify_all_fixes.py   # Проверить исправления

# Если что-то не так:
git reflog                    # Найти последний рабочий коммит
git reset --hard <commit>     # Откатиться
```
