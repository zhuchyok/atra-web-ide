## 🔧 ЛОГИКА РАБОТЫ

### **Пороги настроений:**

- **STRICT режим:** `±0.4` (более строгий)
- **SOFT режим:** `±0.6` (более мягкий)

### **Логика блокировки:**

```
LONG сигнал:
  - Блокируется если sentiment_score < -threshold
  - Разрешается если sentiment_score >= -threshold

SHORT сигнал:
  - Блокируется если sentiment_score > threshold
  - Разрешается если sentiment_score <= threshold
```

### **Примеры:**

- **Позитивные настроения (0.5):** Блокируют SHORT сигналы, разрешают LONG
- **Негативные настроения (-0.5):** Блокируют LONG сигналы, разрешают SHORT
- **Нейтральные настроения (0.0):** Разрешают все сигналы
