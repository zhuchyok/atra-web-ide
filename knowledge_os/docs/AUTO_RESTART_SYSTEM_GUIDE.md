# 🔄 Система автоматического перезапуска торгового бота

## ✅ **Что было реализовано:**

Создана полная система автоматического перезапуска торгового бота, которая решает проблему с остановкой работы после оптимизации параметров.

## 🚀 **Функции системы:**

### **1. Автоматический перезапуск при:**

- ✅ **Изменении config.py** (после оптимизации параметров)
- ✅ **Получении сигнала от системы оптимизации**
- ✅ **Аварийном завершении работы бота**
- ✅ **Любых других сбоях в работе**

### **2. Мониторинг состояния:**

- 🔍 **Проверка работы бота** каждые 10 секунд
- 📝 **Отслеживание изменений** в конфигурации
- 📊 **Детальное логирование** всех операций
- 🚨 **Уведомления об ошибках**

### **3. Безопасное управление процессами:**

- 🛑 **Корректная остановка** старых процессов
- ⏱️ **Timeout для завершения** (10 секунд)
- 🔒 **Управление группами процессов**
- 📦 **Работа в виртуальном окружении**

## 📋 **Файлы системы:**

### **Основные компоненты:**

- `start_bot_with_autorestart.py` - главный скрипт запуска
- `auto_restart_bot.py` - система мониторинга и перезапуска
- `auto_optimization_scheduler.py` - модифицирована для создания сигналов
- `bot_restart_signal.txt` - файл-сигнал для перезапуска (создается автоматически)

### **Логи:**

- `logs/bot_restart.log` - логи системы перезапуска
- `logs/` - папка со всеми логами

## 🎯 **Как использовать:**

### **1. Запуск бота с автоматическим перезапуском:**

```bash
python3 start_bot_with_autorestart.py
```

### **2. Запуск системы оптимизации:**

```bash
# В отдельном терминале
source .venv/bin/activate
python3 start_auto_optimization.py
```

### **3. Остановка системы:**

```bash
# В терминале с ботом
Ctrl+C
```

## 🔧 **Алгоритм работы:**

### **1. При запуске:**

1. Проверка виртуального окружения
2. Проверка наличия config.py
3. Создание папки для логов
4. Запуск торгового бота
5. Инициализация мониторинга

### **2. Цикл мониторинга (каждые 10 секунд):**

1. **Проверка состояния бота** - работает ли процесс
2. **Проверка сигнала перезапуска** - есть ли файл `bot_restart_signal.txt`
3. **Проверка изменений config.py** - изменилось ли время модификации
4. **Перезапуск при необходимости**

### **3. При перезапуске:**

1. Остановка текущего процесса бота
2. Ожидание завершения (до 10 секунд)
3. Принудительное завершение при необходимости
4. Запуск нового процесса бота

## 📊 **Интеграция с системой оптимизации:**

### **Автоматический цикл:**

1. **Система оптимизации** работает по расписанию
2. **Находит лучшие параметры** для 50 монет
3. **Применяет их к config.py**
4. **Создает файл-сигнал** `bot_restart_signal.txt`
5. **Система перезапуска** обнаруживает сигнал
6. **Перезапускает бота** с новыми параметрами
7. **Удаляет файл-сигнал**

### **Логирование:**

```
2025-08-05 18:00:00 - INFO - 🔄 Обнаружен сигнал для перезапуска бота
2025-08-05 18:00:01 - INFO - 🛑 Остановка торгового бота...
2025-08-05 18:00:04 - INFO - ✅ Бот остановлен
2025-08-05 18:00:05 - INFO - 🚀 Запуск торгового бота...
2025-08-05 18:00:07 - INFO - ✅ Бот запущен с PID: 12345
```

## ⚙️ **Настройки системы:**

### **В `auto_restart_bot.py`:**

```python
self.check_interval = 10          # Интервал проверки (секунды)
self.restart_on_config_change = True  # Перезапуск при изменении config.py
```

### **Таймауты:**

- **Ожидание завершения:** 10 секунд
- **Интервал проверки:** 10 секунд
- **Время на запуск:** 3 секунды

## 🚨 **Обработка ошибок:**

### **Типы ошибок:**

1. **Ошибка запуска бота** - логируется, повторная попытка
2. **Ошибка остановки бота** - принудительное завершение
3. **Ошибка чтения файлов** - логируется, продолжение работы
4. **Системные ошибки** - логируются, graceful shutdown

### **Автоматическое восстановление:**

- При сбое бота - автоматический перезапуск
- При ошибке остановки - принудительное завершение + перезапуск
- При системных ошибках - логирование + продолжение работы
