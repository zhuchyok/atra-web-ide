# 🎯 СИСТЕМА ТЕЙК ПРОФИТОВ И ПЕРЕСЧЕТА БАЛАНСА

## 📋 Обзор системы

После срабатывания тейк профита система автоматически:

1. **Отправляет уведомления** пользователям о достижении TP1/TP2
2. **Пересчитывает баланс** и риски
3. **Обновляет стадии позиций** для отслеживания прогресса
4. **Предоставляет рекомендации** по дальнейшим действиям

## 🔄 Автоматическая проверка тейк профитов

### Функция `check_take_profits()`

Система каждые 5 минут проверяет все открытые позиции пользователей:

```python
async def check_take_profits():
    # 1. Загружает данные всех пользователей
    # 2. Получает текущие цены для всех символов с позициями
    # 3. Проверяет достижение TP1/TP2 для каждой позиции
    # 4. Отправляет уведомления при достижении
    # 5. Обновляет стадии позиций
```

### Логика проверки

**Для LONG позиций:**

- TP1 достигнут: `current_high >= tp1`
- TP2 достигнут: `current_high >= tp2`

**Для SHORT позиций:**

- TP1 достигнут: `current_low <= tp1`
- TP2 достигнут: `current_low <= tp2`

## 📊 Стадии позиций

### Стадии отслеживания:

1. **`open`** - позиция открыта, TP не достигнуты
2. **`tp1_reached`** - достигнут TP1, ожидается TP2
3. **`tp2_reached`** - достигнут TP2, рекомендуется закрытие

## 💰 Пересчет баланса и рисков

### Функция `recalculate_balance_and_risks()`

После каждого закрытия позиции автоматически вызывается:

```python
def recalculate_balance_and_risks(user_data):
    # 1. Пересчитывает общий баланс с учетом прибыли/убытков
    # 2. Обновляет риски по оставшимся позициям
    # 3. Рассчитывает свободные средства
    # 4. Обновляет данные пользователя
```

### Что пересчитывается:

#### 📈 Баланс:

- **Депозит**: `deposit + total_profit`
- **Общая прибыль**: сумма всех закрытых сделок
- **Свободные средства**: `deposit - total_risk_amount`

#### ⚠️ Риски:

- **Risk amount** для каждой открытой позиции
- **Общий риск**: сумма всех открытых позиций
- **Глобальный лимит**: `deposit * GLOBAL_RISK_LIMIT_PCT / 100`

#### 🔄 Плечи (для futures):

- **Динамические плечи** пересчитываются на основе волатильности
- **Ликвидационные цены** обновляются при изменении плеча

## 🎛️ Динамические параметры

### Тейк профиты:

- **TP1**: 0.5-10% (зависит от волатильности)
- **TP2**: 1-15% (зависит от волатильности)
- **Адаптация**: более высокие TP при высокой волатильности

### Риски:

- **Динамический риск**: 1-5% (зависит от тренда и волатильности)
- **Базовый риск**: настраивается пользователем
- **Максимальный риск**: `MAX_RISK_PCT` от депозита

### Плечи:

- **Базовое плечо**: настраивается пользователем
- **Динамическое плечо**: 1-10x (зависит от волатильности)
- **Ограничения**: не превышает максимальное плечо биржи

## 🔧 Технические детали

### Интеграция в main_loop:

```python
async def main_loop():
    while True:
        # 1. Генерация сигналов
        signal_history = await check_and_send_signals(signal_history)

        # 2. Проверка тейк профитов
        await check_take_profits()

        # 3. Ожидание следующего цикла
        await asyncio.sleep(CYCLE_MINUTES * 60)
```

### Сохранение данных:

- **user_data.json**: обновляется после каждого TP
- **trade_history**: записываются все закрытые сделки
- **signals_log**: логируются все сигналы и TP

## 🎯 Рекомендации по использованию

### Для консервативных трейдеров:

- Закрывать 50% позиции при TP1
- Закрывать остаток при TP2
- Использовать строгие фильтры

### Для агрессивных трейдеров:

- Дожидаться TP2 для максимальной прибыли
- Использовать усреднения при просадках
- Применять высокие плечи в трендовых условиях

### Управление рисками:

- Не превышать глобальный лимит риска
- Диверсифицировать по нескольким монетам
- Регулярно выводить прибыль
