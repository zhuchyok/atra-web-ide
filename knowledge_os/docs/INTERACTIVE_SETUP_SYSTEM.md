# 🚀 ИНТЕРАКТИВНАЯ СИСТЕМА НАСТРОЙКИ БОТА

## 📋 **ОПИСАНИЕ СИСТЕМЫ:**

При первом запуске команды `/start` бот автоматически проведет пользователя через пошаговую настройку основных параметров.

## 🎯 **ПОШАГОВАЯ НАСТРОЙКА:**

### **💰 Шаг 1: Установка депозита**

```
🚀 ДОБРО ПОЖАЛОВАТЬ В ТОРГОВЫЙ БОТ!

Для начала работы нужно настроить основные параметры.

💰 Шаг 1: Установите начальный депозит
Введите сумму в USDT (например: 1000):
```

**Пользователь вводит:** число (например: 1000)

### **📈 Шаг 2: Выбор режима торговли**

```
✅ Депозит установлен: 1000 USDT

💰 Шаг 2: Выберите режим торговли

💵 SPOT - торговля без плеча
⚡ FUTURES - торговля с плечом

Выберите режим: [💵 SPOT] [⚡ FUTURES]
```

**Пользователь выбирает:** кнопкой SPOT или FUTURES

### **🎯 Шаг 3: Выбор режима фильтров**

```
✅ Режим торговли: SPOT

🎯 Шаг 3: Выберите режим фильтров

🔴 Строгий - меньше сигналов, но качественные
🟡 Мягкий - больше сигналов, более активная торговля

Выберите режим: [🔴 Строгий] [🟡 Мягкий]
```

**Пользователь выбирает:** кнопкой Строгий или Мягкий

### **✅ Завершение настройки**

```
✅ НАСТРОЙКА ЗАВЕРШЕНА!

💰 Депозит: 1000 USDT
📈 Режим: SPOT
🎯 Фильтры: Строгий

🚀 Бот готов к работе!

📋 Основные команды:
• /balance - ваш баланс
• /positions - открытые позиции
• /help - все команды

⚠️ Риск и плечо рассчитываются автоматически
📡 Сигналы будут приходить автоматически
```

## 🔧 **ТЕХНИЧЕСКАЯ РЕАЛИЗАЦИЯ:**

### **Файлы изменены:**

- `telegram_bot.py` - основная логика настройки

### **Функции обновлены:**

- `start()` - интерактивная настройка
- `button()` - обработка callback'ов настройки
- `handle_message()` - обработка ввода депозита

### **Новые callback'и:**

- `setup_trade_mode_spot` - выбор SPOT режима
- `setup_trade_mode_futures` - выбор FUTURES режима
- `setup_filter_mode_strict` - выбор строгого режима
- `setup_filter_mode_soft` - выбор мягкого режима

### **Автоматические настройки:**

- **Риск:** 2.0% (пересчитывается динамически)
- **Плечо:** 1x (пересчитывается динамически)
- **Новости:** conservative для строгого, aggressive для мягкого

## 🎯 **ПРЕИМУЩЕСТВА:**

1. **📱 Простота** - пошаговая настройка без сложных команд
2. **🎨 Интуитивность** - кнопки вместо текстовых команд
3. **⚡ Быстрота** - 3 шага вместо множества команд
4. **🛡️ Безопасность** - проверка ввода и валидация
5. **🎯 Фокус** - только необходимые настройки

## 🔄 **ПОВТОРНАЯ НАСТРОЙКА:**

Если пользователь уже настроен, команда `/start` покажет приветственное сообщение с текущими настройками.
