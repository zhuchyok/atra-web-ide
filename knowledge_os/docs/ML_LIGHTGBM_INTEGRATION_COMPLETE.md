## 📊 КАК РАБОТАЕТ ML ФИЛЬТР

### Логика проверки:

1. **Собираются данные**:
   - Индикаторы (RSI, EMA, MACD, BB, ATR, ADX)
   - Рыночные условия (BTC trend, volume_ratio, volatility)
   - Параметры сигнала (entry_price, tp1, tp2, risk_pct, leverage)

2. **Делается предсказание**:
   - Классификатор: вероятность успеха (0-100%)
   - Регрессор: ожидаемая прибыль в процентах
   - Комбинированный score: `success_prob * expected_profit`

3. **Проверяются пороги**:
   - `success_probability >= 0.6` (60%)
   - `expected_profit_pct >= 0.5%`
   - `combined_score >= 0.3`

4. **Принимается решение**:
   - ✅ Если все пороги пройдены → сигнал проходит
   - ❌ Если хотя бы один порог не пройден → сигнал блокируется

## ⚙️ НАСТРОЙКА ПОРОГОВ

Пороги можно изменить в функции `check_ml_filter()` (строки 4604-4606):

```python
min_success_prob = 0.6      # Минимальная вероятность успеха (60%)
min_expected_profit = 0.5   # Минимальная ожидаемая прибыль (0.5%)
min_combined_score = 0.3    # Минимальный комбинированный score
```

**Рекомендации:**

- Для более строгой фильтрации: увеличьте пороги
- Для более мягкой фильтрации: уменьшите пороги
- Начните с текущих значений и корректируйте на основе результатов

## ⚠️ ВАЖНЫЕ ЗАМЕЧАНИЯ

### 1. **Graceful Degradation**

Если модели не обучены или LightGBM недоступен:

- Система продолжит работать без ML фильтра
- Сигналы не будут блокироваться
- В логах будет предупреждение: `⚠️ LightGBM предсказатель доступен, но модели не обучены`

### 2. **Fail-Safe**

При ошибке в ML фильтре:

- Сигнал **НЕ блокируется** (fail-safe)
- Ошибка логируется
- Система продолжает работу
