# 🚀 Динамическое плечо (Dynamic Leverage)

## 📋 Описание

Система теперь поддерживает **динамическое плечо** для каждого пользователя, что позволяет точно рассчитывать объемы позиций и риски в зависимости от выбранного кредитного плеча.

## 🔧 Как это работает

### Принцип работы

```python
# Формула расчета объема с учетом плеча
base_qty = deposit * risk_pct / 100 * leverage / price
max_risk = deposit * MAX_RISK_PCT / 100 * leverage
```

### Автоматическое определение плеча

```python
leverage = user_data.get('leverage', 1) if user_data.get('trade_mode', 'spot') == 'futures' else 1
```

## 🎯 Преимущества

### 1. Точный расчет рисков

- ✅ Учитывается реальное плечо пользователя
- ✅ Корректный расчет максимального риска
- ✅ Правильные объемы позиций

### 2. Гибкость настроек

- ✅ Каждый пользователь может выбрать свое плечо
- ✅ Автоматическое переключение между spot/futures
- ✅ Динамическое обновление расчетов

### 3. Безопасность

- ✅ Лимиты риска учитывают плечо
- ✅ Защита от превышения лимитов
- ✅ Контроль максимального риска

## ⚠️ Важные моменты

### Безопасность

- **Максимальное плечо**: 125x (ограничение бирж)
- **Рекомендуемое плечо**: 1-10x для начинающих
- **Риск-менеджмент**: Учитывайте эффективный риск

### Ограничения

- **Spot торговля**: Плечо всегда = 1
- **Futures торговля**: Плечо от 1 до 125
- **Лимиты риска**: Автоматически учитывают плечо

### Мониторинг

- **Эффективный риск**: Показывается в сообщениях
- **Лимиты**: Автоматически контролируются
- **Предупреждения**: При приближении к лимитам
