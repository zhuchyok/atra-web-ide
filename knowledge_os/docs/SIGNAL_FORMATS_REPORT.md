# 📊 ОТЧЕТ: ФОРМАТЫ СИГНАЛОВ В СИСТЕМЕ ATRA

## 🎯 **ОБЗОР ТИПОВ СИГНАЛОВ**

В системе ATRA есть три основных типа сигналов:

1. **🟢 НОВЫЙ ТОРГОВЫЙ СИГНАЛ** - для новых позиций
2. **🔄 DCA ТОРГОВЫЙ СИГНАЛ** - для усреднения позиций
3. **✅ ПРИНЯТЫЙ СИГНАЛ** - подтверждение принятия

## 1️⃣ **НОВЫЙ ТОРГОВЫЙ СИГНАЛ**

### **Назначение:**

- Отправляется пользователям БЕЗ открытых позиций
- Предлагает новую торговую возможность
- Содержит полный технический анализ

### **Формат сообщения:**

```
🟢 <b>НОВЫЙ ТОРГОВЫЙ СИГНАЛ</b> 📰

📊 Символ: BTCUSDT
💰 Цена входа: 45678.50
📈 Сторона: LONG
🔧 Режим: Строгий (futures)

📊 <b>ТЕХНИЧЕСКИЙ АНАЛИЗ:</b>
• RSI: 45.2 (🟡 Нейтральный)
• MACD: 🟢 Бычий
• Объем: 🟢 Выше среднего
• EMA: 🟢 Бычий
• BB: Средняя зона
• BTC тренд: 🟢 БЫЧИЙ

📋 <b>ДАННЫЕ ДЛЯ ВХОДА:</b>
• 💰 Цена входа: 45678.50
• 🎯 TP1: 46890.25 (+2.6%)
• 🚀 TP2: 48120.75 (+5.3%)
• ⚡ Плечо: x3.5
• ⚠️ Риск: 2.00%
• 📊 Режим: FUTURES

💡 <b>БЫСТРЫЕ КОМАНДЫ:</b>
• Принятие сигнала:
<code>/accept BTCUSDT 2025-08-14T22:38 45678.50000 1.0 long 2.0 3.5</code>
• Активные позиции: <code>/positions</code>
• История сделок: <code>/trade_history</code>
```

### **Особенности:**

- ✅ **Полный технический анализ** (RSI, MACD, Volume, EMA, BB)
- ✅ **BTC тренд фильтр** (если включен)
- ✅ **Динамическое плечо** для фьючерсов
- ✅ **Кнопка "Принять"** для быстрого принятия
- ✅ **Команда /accept** как альтернатива
- ✅ **Индикатор новостей** 📰 (если есть)

- Предлагает усреднение существующей позиции

## 3️⃣ **ПРИНЯТЫЙ СИГНАЛ**

### **Назначение:**

- Подтверждение принятия сигнала
- Информация о текущем состоянии счета
- Расчет рисков и сумм входа

### **Формат сообщения:**

```
✅ Сигнал принят!
Ваш текущий депозит: 10000.00 USDT.
Открытых позиций: 3 на 1500.00 USDT.
Свободно для новых сделок: 8500.00 USDT.
Риск на сделку: 2.00% (170.00 USDT).
Используемое плечо: x3.5
Сумма входа с учётом плеча: <b>170.00 USDT</b>.
```

### **Особенности:**

- ✅ **Текущий депозит** и свободные средства
- ✅ **Количество открытых позиций** и их стоимость
- ✅ **Расчет риска** на сделку
- ✅ **Сумма входа** с учетом плеча
- ✅ **Предупреждения** при недостатке средств

## 📋 **КОМАНДЫ ДЛЯ ПРИНЯТИЯ**

### **Полный формат команды /accept:**

```
/accept <symbol> <timestamp> <entry_price> <qty> <side> <risk_pct> <leverage>
```

### **Пример:**

```
/accept BTCUSDT 2025-08-14T22:38 45678.50000 1.0 long 2.0 3.5
```

### **Параметры:**

- **symbol** - символ торговой пары (BTCUSDT)
- **timestamp** - время сигнала (2025-08-14T22:38)
- **entry_price** - цена входа (45678.50000)
- **qty** - количество (обычно 1.0)
- **side** - сторона (long/short)
- **risk_pct** - процент риска (2.0)
- **leverage** - плечо (3.5)

### **Упрощенный формат для DCA:**

```
/accept <symbol> <timestamp>
```

## 🎛️ **КНОПКИ И ИНТЕРФЕЙС**

### **Кнопка "Принять":**

- 🟢 **Автоматическое принятие** сигнала
- 📋 **Callback data** с параметрами
- ⚡ **Быстрое действие** без ввода команд

### **Альтернативные команды:**

- 📊 **/positions** - просмотр активных позиций
- 📈 **/trade_history** - история сделок
- 💰 **/balance** - текущий баланс
- ⚙️ **/settings** - настройки пользователя

## 🔧 **ТЕХНИЧЕСКИЕ ДЕТАЛИ**

### **Форматирование цен:**

- **Динамическая точность** в зависимости от символа
- **Формат:** `{:.{price_precision}f}`
- **Пример:** BTCUSDT = 2 знака, мелкие монеты = 6-8 знаков

### **Эмодзи индикаторы:**

- 🟢 **Зеленый** - положительный/бычий
- 🔴 **Красный** - отрицательный/медвежий
- 🟡 **Желтый** - нейтральный
- ⚪ **Белый** - нейтральный

### **HTML разметка:**

- `<b>текст</b>` - жирный шрифт
- `<code>команда</code>` - моноширинный шрифт для команд
- `<i>курсив</i>` - курсив (редко используется)
