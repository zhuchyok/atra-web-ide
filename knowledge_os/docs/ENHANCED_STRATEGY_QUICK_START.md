# 🚀 Быстрый старт: Расширенная стратегия Bollinger Bands

## 📋 Что добавлено

Новая стратегия включает в себя все запрошенные элементы:

### **A. Пробой полос Боллинджера** ✅

- Пробой верхней полосы + золотой крест (EMA7 > EMA25) = LONG
- Пробой нижней полосы + смертельный крест (EMA7 < EMA25) = SHORT
- Подтверждение RSI > 50 для лонга / < 50 для шорта
- Подтверждение объемом

### **B. Возврат к средней** ✅

- Касание верхней/нижней полосы + возврат внутрь канала
- RSI > 70 для шорта / < 30 для лонга
- Фильтрация по глобальному тренду (EMA50)

### **C. Фильтрация тренда** ✅

- Только покупки, если цена выше EMA50
- Только продажи, если цена ниже EMA50

### **D. Механика управления** ✅

- ATR-базированные стоп-лоссы (адаптируются к волатильности)
- Динамическая корректировка размера позиции
- Автоматическая оптимизация параметров

### **E. Дополнительно** ✅

- Не открываем позиции при сужении полос (squeeze)
- Ждем расширения и подтверждения объемом

---

## 🔧 Как включить

### **1. Включить стратегию**

```python
# В config.py
ENHANCED_BOLLINGER_STRATEGY = True
```

### **2. Настроить режимы**

```python
# Включить нужные компоненты
ENHANCED_STRATEGY_MODES = {
    "breakout": {"enabled": True},      # Пробой полос
    "mean_reversion": {"enabled": True}, # Возврат к средней
    "squeeze_breakout": {"enabled": True} # Пробой после squeeze
}
```

### **3. Для пользователей**

```python
# Установить новый режим фильтров
filter_mode = "enhanced_bollinger"
```

## 🎯 Как работает

### **Приоритет сигналов:**

1. **Пробой полос** (высший приоритет)
2. **Возврат к средней** (средний приоритет)
3. **Пробой после squeeze** (дополнительный)

### **Автоматическая интеграция:**

- Если обычная стратегия не дала сигнала → проверяем расширенную
- ATR стоп-лоссы применяются автоматически
- Корректировка размера позиции по волатильности
