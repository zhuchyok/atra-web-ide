## 🔧 **ИСПРАВЛЕНИЯ:**

### **📝 1. Исправление отображения позиций:**

#### **Было:**

```python
pos_str = f"• <code>{symbol}</code> | Вход: <code>{entry_price:.6f}</code> | 🎯 TP1: <code>{tp1:.6f}</code> | 🚀 TP2: <code>{tp2:.6f}</code> | Стадия: <code>{stage}</code>"

    pos_str += f" | Плечо: x<code>{pos_leverage}</code>"
text += pos_str + "\n"

# Создаем кнопку для закрытия позиции
keyboard = InlineKeyboardMarkup(
    [[InlineKeyboardButton(f"Закрыть {symbol}", callback_data=f"choose_close_price|{symbol}")]]
)
await update.message.reply_text(pos_str, reply_markup=keyboard)  # ← ПРОБЛЕМА
```

#### **Стало:**

```python
side_emoji = "🟢" if side == "long" else "🔴"

pos_str = f"{side_emoji} <code>{symbol}</code> {side.upper()}\n"
pos_str += f"   💰 Вход: <code>{entry_price:.6f}</code>\n"
pos_str += f"   🎯 TP1: <code>{tp1:.6f}</code> | 🚀 TP2: <code>{tp2:.6f}</code>\n"
pos_str += f"   📊 Объём: <code>{qty:.4f}</code> | Стадия: <code>{stage}</code>"

if pos_leverage:
    pos_str += f" | Плечо: x<code>{pos_leverage}</code>"

text += pos_str + "\n\n"  # ← Все в одном сообщении
```
