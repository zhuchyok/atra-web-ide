# 👥 АНАЛИЗ КОМАНДЫ: DATA-DRIVEN BOTTOM-UP ПОДХОД

## 📚 ЧТО ТАКОЕ DATA-DRIVEN BOTTOM-UP?

### Определение:

**Data-Driven Bottom-Up** - это подход, при котором:

1. **Data-Driven**: Решения принимаются на основе реальных данных, а не теоретических предположений
2. **Bottom-Up**: Анализ начинается с отдельных элементов (монет) и строится снизу вверх к портфелю

### Принципы:

- ✅ Анализ каждой монеты индивидуально
- ✅ Использование реальных исторических данных
- ✅ Оптимизация параметров для каждой монеты
- ✅ Агрегация результатов снизу вверх
- ✅ Формирование портфеля на основе данных, а не предположений
