## 🔄 ПРОЦЕСС ОБУЧЕНИЯ

### **Для новых сотрудников:**

1. **Автоматическая инициализация:**

   ```
   - Создается база знаний: scripts/{name}_knowledge.md
   - Создается программа обучения: scripts/learning_programs/{name}_program.md
   - Интегрируется в систему самообучения
   ```

2. **Программа обучения:**
   - Определяется на основе роли
   - Включает материалы для изучения
   - Содержит план обучения на 6-12 недель
   - Автоматически обновляется

3. **Постоянное обучение:**
   - После каждой задачи обновляется база знаний
   - Интегрируются новые знания из ретроспектив
   - Обновляется программа обучения

### **Для всех сотрудников:**

1. **Ежедневное обновление:**
   - Сбор новых знаний из ретроспектив
   - Обновление индивидуальных баз знаний
   - Интеграция lessons learned

2. **Еженедельный цикл:**
   - Анализ прогресса обучения
   - Обновление программ обучения
   - Отчеты о метриках обучения
