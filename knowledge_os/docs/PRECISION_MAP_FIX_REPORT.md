## **🔍 ИСХОДНАЯ ПРОБЛЕМА**

Пользователь сообщил о проблеме с сокращением TP1, TP2 и цены входа в уведомлениях:

```
✅ Сигнал принят!
🔸 Символ: TUTUSDT
🔸 Цена входа: 0.11
🔸 TP1: 0.11 (+0.79% / +3.95% с плечом)  ← Должно быть 0.11079
🔸 TP2: 0.11 (+0.99% / +4.94% с плечом)  ← Должно быть 0.11099
```

**Причина:** Символ `TUTUSDT` отсутствовал в `precision_map`, поэтому использовалась стандартная точность 2 знака, из-за чего TP1 и TP2 округлялись до цены входа.
