## 🔧 Технические детали

### Использованные технологии:

1. **CSS Media Queries** - для адаптивности
2. **Relative Units (rem)** - для масштабируемости
3. **CSS Grid** - для гибкой сетки
4. **Flexbox** - для выравнивания
5. **viewport meta tag** - для мобильных устройств

### Примеры кода:

```css
/* Адаптивный базовый размер шрифта */
html {
  font-size: 16px;
}

@media (max-width: 1200px) {
  html {
    font-size: 15px;
  }
}

@media (max-width: 992px) {
  html {
    font-size: 14px;
  }
}

@media (max-width: 768px) {
  html {
    font-size: 13px;
  }
}

@media (max-width: 576px) {
  html {
    font-size: 12px;
  }
}

/* Все размеры в rem - автоматически масштабируются */
.header h1 {
  font-size: 2.5rem; /* 40px на desktop, 30px на mobile */
}

.stat-value {
  font-size: 2rem; /* 32px на desktop, 24px на mobile */
}
```
