# ✅ ИСПРАВЛЕНИЕ: STABLECOIN_SYMBOLS как глобальная константа

## 🎯 ПРОБЛЕМА

**Ошибка:** `cannot import name 'STABLECOIN_SYMBOLS' from 'config'`

**Причина:**

- Импорт происходил внутри функций, и при ошибке импорта переменная не была доступна
- Try-except блоки внутри функций не всегда работали правильно

## ✅ РЕШЕНИЕ

**Добавлено глобальное определение STABLECOIN_SYMBOLS в начале файла:**

```python
# Определение STABLECOIN_SYMBOLS (fallback если не определен в config)
try:
    from config import STABLECOIN_SYMBOLS
except ImportError:
    STABLECOIN_SYMBOLS = [
        "USDTUSDT", "USDCUSDT", "BUSDUSDT", "FDUSDUSDT", "TUSDUSDT",
        "USDDUSDT", "USDEUSDT", "DAIUSDT", "FRAXUSDT", "LUSDUSDT",
        "USTCUSDT", "USTUSDT", "MIMUSDT", "ALGUSDT", "EURSUSDT", "USD1USDT"
    ]
```

**Преимущества:**

- ✅ STABLECOIN_SYMBOLS доступен глобально во всем файле
- ✅ Fallback значение гарантирует, что переменная всегда определена
- ✅ Не нужно оборачивать каждый импорт в try-except
