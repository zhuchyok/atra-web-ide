# Отчет о временных рамках расчетов параметров

## **📋 АНАЛИЗ ВОПРОСА**

**Вопрос:** "Все рассчитывается на момент принятия?"

**Ответ:** **НЕТ, не все!** Есть важные различия в том, когда рассчитываются разные параметры.

## **🕐 ВРЕМЕННЫЕ РАМКИ РАСЧЕТОВ**

### **1. 📊 МОМЕНТ ГЕНЕРАЦИИ СИГНАЛА (signal_live.py)**

**Рассчитывается на момент генерации:**

- ✅ **Динамические риски** - `get_dynamic_risk_pct(df, current_index)`
- ✅ **Динамические плечи** - `get_dynamic_leverage(df, current_index, base_leverage)`
- ✅ **Динамические TP проценты** - `get_dynamic_tp_levels(df, current_index, side)`
- ✅ **Цена входа** - `signal_price` (цена на момент генерации)
- ✅ **Технический анализ** - все индикаторы на момент генерации

**Код:**

```python
# Динамический расчет риска
current_index = len(df) - 1
risk_pct = get_dynamic_risk_pct(df, current_index)

# Динамическое плечо для фьючерсов
dynamic_leverage = get_dynamic_leverage(df, current_index, base_leverage)

# Динамические тейк-профиты
tp1_pct, tp2_pct = get_dynamic_tp_levels(df, current_index, signal_type.lower())
```

### **2. 🎯 МОМЕНТ ПРИНЯТИЯ СИГНАЛА (telegram_bot.py)**

**Рассчитывается на момент принятия:**

- ✅ **Актуальная цена** - получается заново через API
- ✅ **Объем позиции** - пересчитывается на основе актуальной цены
- ✅ **Свободные средства** - текущее состояние депозита
- ✅ **Новая средняя цена (DCA)** - пересчитывается с актуальной ценой
- ✅ **Финальные TP уровни** - рассчитываются на основе актуальной цены

**Код:**

```python
# Получаем актуальную цену
ohlc = get_ohlc_binance_sync(symbol, interval="1m", limit=1)
if ohlc and len(ohlc) > 0:
    current_price = ohlc[-1]["close"]

# Рассчитываем объем на основе актуальной цены
qty = risk_amount / current_price * dynamic_leverage

# Рассчитываем TP на основе актуальной цены
tp1 = current_price * (1 + dynamic_tp1_pct / 100)
tp2 = current_price * (1 + dynamic_tp2_pct / 100)
```

## **🚨 КРИТИЧЕСКИЕ РАЗЛИЧИЯ**

### **ПРОБЛЕМА ДО ИСПРАВЛЕНИЯ:**

**В новых сигналах:**

- **TP проценты** рассчитывались на момент генерации
- **TP уровни** рассчитывались на основе цены генерации
- **Объем** рассчитывался на основе актуальной цены принятия

**Это приводило к несоответствию!**

### **РЕШЕНИЕ ПОСЛЕ ИСПРАВЛЕНИЯ:**

**Теперь все расчеты на момент принятия:**

- ✅ **TP проценты** - передаются из генерации (динамические)
- ✅ **TP уровни** - рассчитываются на основе актуальной цены
- ✅ **Объем** - рассчитывается на основе актуальной цены
- ✅ **Средняя цена (DCA)** - рассчитывается на основе актуальной цены
