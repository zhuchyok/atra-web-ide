## 🔧 Основные Компоненты

### 1. Динамическая Адаптация TP/SL

#### `calculate_dynamic_tp_sl()`

```python
def calculate_dynamic_tp_sl(self, df: pd.DataFrame, current_index: int,
                           base_tp1: float = 1.5, base_tp2: float = 3.0,
                           base_sl: float = 25.0) -> Dict[str, float]:
```

**Функциональность:**

- Рассчитывает волатильность актива
- Вычисляет ATR (Average True Range)
- Адаптирует TP/SL уровни на основе рыночных условий
- Ограничивает значения для безопасности

**Алгоритм:**

1. **Волатильность**: Стандартное отклонение ценовых изменений
2. **ATR**: Средний истинный диапазон для дополнительной адаптации
3. **Множители**: Комбинированный множитель на основе волатильности и ATR
4. **Адаптация**: TP увеличивается с волатильностью, SL уменьшается
