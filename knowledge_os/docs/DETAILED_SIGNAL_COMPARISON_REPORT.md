## 🎨 ВИЗУАЛЬНЫЕ ОТЛИЧИЯ

### Цветовая схема:

- **🟢 LONG сигналы** - зеленые эмодзи (бычий тренд)
- **🔴 SHORT сигналы** - красные эмодзи (медвежий тренд)
- **🔄 DCA сигналы** - синие эмодзи (усреднение)

### Технический анализ:

- **RSI**: с эмодзи статуса (🟢/🟡/🔴)
- **MACD**: с эмодзи направления (🟢/🔴)
- **Объем**: с эмодзи активности (🟢/🟡)
- **EMA**: с эмодзи тренда (🟢/🔴)
- **BB**: позиция в полосах Боллинджера
- **BTC тренд**: с эмодзи (🟢/🔴)

### Дополнительные элементы:

- **🪙 Иконка монеты** перед символом
- **📅 Поле "Создан"** с датой и временем
- **🎯 Тейк профиты** с процентами
- **📊 Детальная информация** о позиции

## 🔧 ТЕХНИЧЕСКИЕ ДЕТАЛИ

### Команды принятия:

- **Новые сигналы**: `/accept <symbol> <timestamp> <price> <qty> <side> <risk> <leverage>`
- **DCA сигналы**: `/accept <symbol> <timestamp>`

### Форматирование:

- **HTML разметка** для жирного текста и кода
- **Эмодзи** для визуального разделения
- **Точность цен** в зависимости от символа
- **Процентные значения** для TP

### Интеграция:

- **Технические индикаторы** из `shared_utils.py`
- **BTC тренд фильтр** из `config.py`
- **Данные китов** из `whale_tracker.py`
- **Динамические TP** из `shared_utils.py`

## 📝 ЗАКЛЮЧЕНИЕ

Все типы сигналов теперь имеют **единообразный формат** с полным техническим анализом, включая:

✅ **Полный технический анализ** с эмодзи для всех типов
✅ **BTC тренд фильтр** для всех сигналов
✅ **Данные о китах** для всех сигналов
✅ **Иконка монеты** и поле "Создан"
✅ **Тейк профиты** в ответах после принятия
✅ **Визуальные различия** между LONG/SHORT/DCA
✅ **Детальная информация** для принятия решений

Система обеспечивает **максимальную информативность** при сохранении **читаемости** и **удобства использования**.
