## 🎯 КРИТЕРИИ ОПТИМИЗАЦИИ

Оптимизация ищет комбинацию параметров, которая максимизирует:

1. **Win Rate** - процент прибыльных сделок
2. **Profit Factor** - отношение прибыли к убыткам
3. **Return/сигнал** - доходность на один сигнал
4. **Количество сделок** - для статистической значимости

**Формула оценки:**

```
Score = Win Rate × Profit Factor × Return/сигнал × Количество сделок
```
