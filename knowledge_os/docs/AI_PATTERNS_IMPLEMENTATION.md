## 🔄 АЛГОРИТМ УМНОЙ ОЧИСТКИ

### При достижении 30K паттернов:

```
33156 паттернов  → АВТООЧИСТКА → ~20000-25000 паттернов
```

### Приоритеты сохранения:

1. **🏆 КРИТИЧНЫЕ** (Приоритет 1)
   - Все WIN паттерны
   - Все LOSS паттерны
   - Без ограничения по возрасту
   - **Важно**: учимся на успехах и ошибках

2. **🕐 ВАЖНЫЕ** (Приоритет 2)
   - Свежие паттерны (<60 дней)
   - Актуальные рыночные условия
   - Сортировка: новые первыми

3. **💎 РЕДКИЕ СИМВОЛЫ** (Приоритет 3)
   - Символы с <100 паттернами
   - Диверсификация обучения
   - Избегаем перекоса на популярные монеты

4. **📊 НЕЙТРАЛЬНЫЕ** (Приоритет 4)
   - Заполняют оставшееся место
   - Самые свежие из старых
   - Удаляются при нехватке места

### Что удаляется:

- ❌ Старые нейтральные (>60 дней)
- ❌ Частые символы с низкой важностью
- ❌ Дубликаты похожих условий

## 🎯 АВТОМАТИЗАЦИЯ

### Когда срабатывает очистка:

1. **При старте системы**
   - Если паттернов >30K
   - Автоматическая очистка до оптимального размера
   - Логируется статистика

2. **Каждые 1000 новых паттернов**
   - Проверка лимита
   - Умная очистка при необходимости
   - Непрерывная оптимизация

3. **Пример**:

```
Паттернов: 29000 → добавляем 1000 → 30000 ✅ OK
Паттернов: 30000 → добавляем 1000 → 31000 → АВТООЧИСТКА → 25000
```

## 📈 МЕТРИКИ КАЧЕСТВА

### Функция `calculate_pattern_importance(pattern)`:

Рассчитывает важность от 0.0 до 1.0:

- **Результат сделки**: 40% веса
  - WIN: +0.4
  - LOSS: +0.4
  - Высокая прибыль (>5%): +0.1
  - Большой убыток (>3%): +0.1

- **Свежесть**: 30% веса
  - <7 дней: +0.3
  - 7-30 дней: +0.2
  - 30-60 дней: +0.1

- **Редкость символа**: 20% веса
  - <50 паттернов: +0.2
  - 50-100 паттернов: +0.1

- **Уникальные условия**: 10% веса
  - Экстремальная волатильность: +0.05
  - Сильный тренд (>70%): +0.05
