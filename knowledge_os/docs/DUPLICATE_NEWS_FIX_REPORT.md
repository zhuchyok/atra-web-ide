## 🔧 РЕШЕНИЕ

### **✅ ОПТИМИЗИРОВАННАЯ АРХИТЕКТУРА:**

1. **Создана единая функция** `check_news_for_symbol(symbol)`
2. **Один вызов** `get_news_multi_source` для обоих фильтров
3. **Кэширование результатов** для избежания повторных запросов
4. **Оптимизированные функции** используют общий результат

### **📝 НОВАЯ ЛОГИКА:**

```python
# ПОСЛЕ ИСПРАВЛЕНИЯ:
async def check_news_for_symbol(symbol):
    """Оптимизированная функция для проверки новостей"""
    # Получаем новости только один раз
    news_list = await get_news_multi_source(symbol)

    # Проверяем и негативные, и позитивные новости
    has_negative, negative_data, has_positive, positive_data = process_news(news_list)

    return has_negative, negative_data, has_positive, positive_data

async def is_negative_news(symbol):
    """Использует общий результат"""
    has_negative, negative_data, _, _ = await check_news_for_symbol(symbol)
    return has_negative, negative_data

async def is_positive_news(symbol):
    """Использует общий результат"""
    _, _, has_positive, positive_data = await check_news_for_symbol(symbol)
    return has_positive, positive_data
```
