## 🔧 **ТЕХНИЧЕСКИЕ ДЕТАЛИ**

### **Поток данных аномалий:**

1. **Расчет аномалий** → `calculate_anomaly_circles_with_fallback()`
2. **Создание строки** → `anomalies_line = f"• Аномалии: {emoji} {circles_text}\n"`
3. **Передача в билдер** → `build_new_signal_message(anomalies_line=anomalies_line)`
4. **Добавление в сообщение** → `parts.append(anomalies_line)`

### **Возможные причины проблемы:**

1. **Ошибки в расчете аномалий** - таймауты, ошибки API
2. **Неправильная передача данных** - `anomalies_line` не передается
3. **Проблемы в билдере** - `anomalies_line` не добавляется в сообщение
4. **Фильтрация сигналов** - аномалии блокируются фильтрами
