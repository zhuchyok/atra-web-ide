### Обработка ошибок отправки сообщений

В handlers.py используются защитные блоки для игнорирования ошибок при отправке сообщений об ошибках:

```python
except (TelegramError, BadRequest, RuntimeError):
    # Игнорируем ошибки отправки сообщений об ошибках
    pass
```

Это правильная практика, так как:

- Если отправка сообщения об ошибке сама падает, мы не должны пытаться отправить еще одно сообщение об ошибке ошибки
- Это предотвращает бесконечные циклы ошибок
- Специфичные исключения (TelegramError, BadRequest) ловят только ошибки Telegram API
