## 📊 Как работает динамический расчет риска

### **1. Базовая формула расчета размера позиции:**

```python
def calculate_optimized_position_size(df, i, balance, entry_price, stop_loss):
    # Базовый размер на основе риска
    risk_pct = config["position_sizing_risk"]  # 1.2% из конфигурации
    risk_amount = balance * (risk_pct / 100)   # Риск в USDT от текущего баланса

    # Расчет размера позиции
    risk_per_share = abs(entry_price - stop_loss)
    position_size = risk_amount / risk_per_share

    # Корректировка по волатильности
    position_size = get_volatility_adjusted_position_size(df, i, position_size)

    return position_size
```

### **2. Динамический процент риска:**

```python
def get_dynamic_risk_pct(df, i):
    # Базовый риск: 5.0%
    base_risk = 5.0

    # Динамическая корректировка на основе волатильности и тренда
    volatility = closes.std() / closes.mean()
    trend = (sma20_now - sma20_prev) / sma20_prev

    # Формула: увеличиваем риск при тренде, уменьшаем при высокой волатильности
    dynamic_risk = base_risk * (1 + 2 * trend) / (1 + 5 * volatility)

    # Ограничиваем от 1.5% до 12%
    dynamic_risk = max(1.5, min(dynamic_risk, 12.0))

    return dynamic_risk
```

### **3. Корректировка по волатильности:**

```python
def get_volatility_adjusted_position_size(df, i, base_size=1.0):
    volatility_pct = df["volatility_pct"].iloc[i]

    # Уменьшаем размер позиции при высокой волатильности
    if volatility_pct > 5.0:
        adjustment = 0.7  # -30%
    elif volatility_pct > 3.0:
        adjustment = 0.85  # -15%
    elif volatility_pct < 1.0:
        adjustment = 1.2  # +20% при низкой волатильности
    else:
        adjustment = 1.0

    return base_size * adjustment
```

## 🎯 Почему настройки такие консервативные

### **1. Цель: высокий винрейт (65-75%)**

#### **Строгие условия входа:**

```python
# LONG сигнал - очень строгие условия:
long_conditions = [
    # Точное касание нижней полосы (0.995-1.005)
    current_price >= bb_lower * 0.995 and current_price <= bb_lower * 1.005,

    # Цена значительно ниже средней полосы
    current_price < bb_middle * 0.99,

    # Экстремальная перепроданость
    rsi < 20,  # Очень строго!

    # 5 свечей подряд восходящих
    i >= 5 and all(df["close"].iloc[j] > df["close"].iloc[j-1] for j in range(i-4, i+1)),

    # Всплеск объема
    volume_ratio > 2.5,

    # Сила возврата > 1.5%
    (bb_middle - current_price) / current_price * 100 > 1.5,
]
```

#### **Множественные фильтры:**

- **Ширина полос Боллинджера**: 2.0-15.0%
- **Волатильность ATR**: 0.8-8.0%
- **Сила тренда**: максимум 5.0%
- **Минимальное движение**: 0.3% за час, 0.8% за 4 часа
- **История сигналов**: максимум 3 за 10 свечей

### **2. Ограничения для качества сигналов**

#### **Максимум сделок в день: 2**

```python
"max_daily_trades": 2  # Только 2 сделки в день
```

**Причина**: Качественные сигналы редки. Лучше пропустить 10 плохих сигналов, чем взять 1 плохой.

#### **Интервал между сделками: 6+ часов**

```python
"min_trade_interval_hours": 6  # Минимум 6 часов между сделками
```

**Причина**:

- Избегаем эмоциональных решений
- Даем время на анализ результатов
- Снижаем корреляцию между сделками

#### **Максимум позиций в портфеле: 5**

```python
"portfolio_max_positions": 5  # Максимум 5 позиций одновременно
```

**Причина**: Диверсификация и управление рисками.

### **3. Консервативные настройки риска**

#### **Риск на позицию: 1.2%**

```python
"position_sizing_risk": 1.2  # Всего 1.2% риска на сделку
```

**Причина**:

- При 5 позициях максимум: 5 × 1.2% = 6% общего риска
- При винрейте 65-75% это обеспечивает стабильную прибыль
- Защита от серии убытков

#### **Динамический диапазон риска: 1.5-12%**

```python
dynamic_risk = max(1.5, min(dynamic_risk, 12.0))  # От 1.5% до 12%
```

**Причина**: Адаптация к рыночным условиям.

## 📈 Почему мы "пропускаем все сигналы"

### **1. Качество vs Количество**

#### **Статистика фильтрации:**

- **Всего потенциальных сигналов**: ~50-100 в день
- **Прошедших строгие фильтры**: ~2-5 в день
- **Финальных сигналов**: ~1-2 в день

#### **Пример фильтрации:**

```python
# Из 100 потенциальных сигналов:

# 1. Фильтр по ширине полос (2-15%): отсеивает 60%
# Остается: 40 сигналов

# 2. Фильтр по объему (>2.5x): отсеивает 70%
# Остается: 12 сигналов

# 3. Фильтр по RSI (экстремальные уровни): отсеивает 80%
# Остается: 2-3 сигнала

# 4. Фильтр по силе движения: отсеивает 50%
# Остается: 1-2 сигнала

# 5. Фильтр по истории сигналов: отсеивает 30%
# Финальный результат: 1-2 качественных сигнала
```

### **2. Преимущества строгой фильтрации**

#### **Высокий винрейт:**

- **Обычные стратегии**: 40-50% винрейт
- **Наша стратегия**: 65-75% винрейт

#### **Стабильная прибыльность:**

- **Меньше сделок** = меньше комиссий
- **Качественные сигналы** = больше прибыли
- **Меньше эмоций** = лучшее исполнение

#### **Защита от убытков:**

- **Строгие стоп-лоссы** на основе ATR
- **Ограничение позиций** снижает риск
- **Динамическая корректировка** размера позиции
