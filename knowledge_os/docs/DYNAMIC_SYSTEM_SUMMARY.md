### 📈 Алгоритмы динамических параметров

#### 1. Динамический риск:

```python
dynamic_risk = base_risk * (1 + 2 * trend) / (1 + 5 * volatility)
```

- **Базовый риск**: 2%
- **Тренд**: изменение SMA20 за 10 периодов
- **Волатильность**: стандартное отклонение за 20 периодов
- **Результат**: 1-5%

#### 2. Динамическое плечо:

```python
trend_factor = 1 + abs(trend) * 2  # до 3x при сильном тренде
volatility_factor = 1 / (1 + volatility * 3)  # уменьшаем при высокой волатильности
dynamic_leverage = base_leverage * trend_factor * volatility_factor
```

- **Базовое плечо**: настраивается пользователем (1-20x)
- **Результат**: 1-20x с ограничениями

#### 3. Динамические TP/SL:

```python
volatility_factor = 1 + volatility * 2  # увеличиваем при высокой волатильности
dynamic_tp1 = base_tp1_pct * volatility_factor
dynamic_sl = base_sl_pct * volatility_factor
```

- **Адаптация**: под волатильность рынка
- **Безопасность**: ограничения максимальных значений
