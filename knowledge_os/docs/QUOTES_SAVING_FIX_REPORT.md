## ✅ **РЕШЕНИЕ**

### 1. **Добавлено сохранение котировок в BinanceAPI**

**Файл:** `exchanges/binance_api.py`

```python
async def get_price(symbol):
    item = data_dict.get(symbol)
    if item:
        bid = float(item["bidPrice"])
        ask = float(item["askPrice"])

        # Сохраняем котировки в базу данных
        try:
            from db import Database
            db = Database()
            db.save_quote('binance', symbol, bid, ask)
        except Exception as e:
            logging.warning(f"Не удалось сохранить котировку для {symbol}: {e}")

        return symbol, {
            "bid": bid,
            "ask": ask,
            "last": ask,
        }
```
