## 🎯 **ЛОГИКА РАБОТЫ**

### **Контрарианский подход:**

1. **Экстремальная жадность (80-100):** рынок перекуплен → блокируем LONG
2. **Экстремальный страх (0-20):** рынок перепродан → блокируем SHORT
3. **Умеренный страх (20-40):** хорошие условия для LONG
4. **Умеренная жадность (60-80):** хорошие условия для SHORT
5. **Нейтральные значения (40-60):** стандартная торговля

### **Компоненты расчета:**

```python
# Взвешенная сумма всех компонентов
fear_greed = (
    volatility_score * 0.25 +    # Волатильность
    momentum_score * 0.25 +      # RSI (инвертированный)
    volume_score * 0.15 +        # Объем
    trend_score * 0.25 +         # Тренд EMA
    strength_score * 0.10        # Позиция в BB
)
```
