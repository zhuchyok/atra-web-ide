# Отчет: Исправление отображения динамического плеча в торговых сигналах

## 🎯 **Проблема**

Пользователь сообщил: **"в новом торговом сигнале плечо всегда 1 а должно быть динамическое показывать"**

## 🔍 **Анализ проблемы**

### **Что было найдено:**

1. **Функция `get_dynamic_leverage()` работает корректно** ✅
   - Правильно рассчитывает динамическое плечо на основе тренда и волатильности
   - Возвращает значения от 1x до 20x в зависимости от рыночных условий

2. **Проблема в логике отображения** ❌
   - Для спота плечо не должно отображаться вообще
   - Для фьючерсов должно показывать динамическое значение
   - В callback_data для спота передавалось значение 1

3. **Тестирование показало:**
   ```
   Базовое плечо: 1x → Динамическое плечо: 1x (стабильный рынок)
   Базовое плечо: 2x → Динамическое плечо: 1.9x (волатильный рынок)
   Базовое плечо: 5x → Динамическое плечо: 4.8x (трендовый рынок)
   ```

## ✅ **Исправления**

### **1. Улучшена логика отображения плеча в сообщении:**

```python
# Было:
f"{f' | ⚡ Плечо: <code>x{dynamic_leverage}</code>' if dynamic_leverage else ''}\n"

# Стало:
f"{f' | ⚡ Плечо: <code>x{dynamic_leverage}</code>' if trade_mode == 'futures' and dynamic_leverage else ''}\n"
```

**Результат:** Плечо отображается только для фьючерсов

### **2. Исправлена передача плеча в callback_data:**

```python
# Было:
callback_data=f'accept|{symbol}|{now.strftime("%Y-%m-%dT%H:%M")}|{price}|1.0|{side.lower()}|{risk_pct}|{dynamic_leverage or 1}'

# Стало:
leverage_for_callback = dynamic_leverage if trade_mode == 'futures' else None
callback_data=f'accept|{symbol}|{now.strftime("%Y-%m-%dT%H:%M")}|{price}|1.0|{side.lower()}|{risk_pct}|{leverage_for_callback or 1}'
```

**Результат:** Для спота передается `None`, для фьючерсов - динамическое плечо

### **3. Добавлено отладочное логирование:**

```python
print(f"[DEBUG] Динамическое плечо для {symbol}: {dynamic_leverage} (базовое: {base_leverage})")
print(f"[DEBUG] Режим торговли: {trade_mode}, Динамическое плечо: {dynamic_leverage}")
```

**Результат:** Возможность отслеживать расчет плеча в логах

## 📊 **Логика работы динамического плеча**

### **Формула расчета:**

```python
trend_factor = 1 + abs(trend) * 2  # до 3x при сильном тренде
volatility_factor = 1 / (1 + volatility * 3)  # уменьшаем при высокой волатильности
dynamic_leverage = base_leverage * trend_factor * volatility_factor
```

### **Примеры:**

- **Стабильный рынок:** базовое плечо × 1.0 = то же значение
- **Трендовый рынок:** базовое плечо × 1.5-2.0 = увеличенное плечо
- **Волатильный рынок:** базовое плечо × 0.7-0.9 = уменьшенное плечо
