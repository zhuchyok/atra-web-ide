## ✅ РЕАЛЬНЫЕ ДАННЫЕ ИЗ БД

### **1. PnL (Profit & Loss) - РЕАЛЬНЫЕ ДАННЫЕ ✅**

- **Источник:** `trading.db` → таблица `signals_log`
- **Запрос:** Все закрытые сигналы с результатами (TP1, TP2, SL, SL_BE)
- **Расчет:** Реальный PnL с учетом DCA и пересчета стоп-лосса
- **Кэширование:** Обновляется раз в сутки (24 часа)
- **Fallback:** Если БД недоступна → использует Binance API (рыночные индикаторы)

**В БД:** 2694 записи с результатами

---

### **2. Win Rate - РЕАЛЬНЫЕ ДАННЫЕ ✅**

- **Источник:** `trading.db` → таблица `signals_log`
- **Запрос:** Статистика по результатам (wins/losses)
- **Расчет:** Реальный Win Rate от всех закрытых сигналов
- **Кэширование:** Обновляется раз в сутки (24 часа)
- **Fallback:** Если БД недоступна → возвращает 0%

**В БД:** 765 wins, 22 losses

## ⚠️ ДАННЫЕ С BINANCE API (НЕ ИЗ БД)

### **3. Статистика сигналов - ДАННЫЕ С BINANCE API ⚠️**

- **Источник:** Binance API (24h volume)
- **Метод:** `get_binance_24h_volume()`
- **Что показывает:** Топ монеты по объему (НЕ реальные сигналы системы)
- **Fallback:** Если API недоступен → демо данные

**Почему:** Защита БД - не нагружает БД частыми запросами

---

### **4. Последние сигналы - ДАННЫЕ С BINANCE API ⚠️**

- **Источник:** Binance API (24h volume)
- **Метод:** `get_recent_signals()`
- **Что показывает:** Топ монеты по объему (НЕ реальные сигналы системы)
- **Fallback:** Если API недоступен → демо сигналы

**Почему:** Защита БД - не нагружает БД частыми запросами

## 🔄 DEMO ДАННЫЕ (ТОЛЬКО ПРИ ОШИБКАХ)

### **Когда используются демо данные:**

1. **Ошибка БД:** Если `trading.db` недоступна
2. **Ошибка API:** Если Binance API недоступен
3. **Ошибка импорта:** Если модули недоступны
4. **Общая ошибка:** При любых исключениях

### **Какие демо данные:**

- `get_demo_stats()` - демо статистика
- `get_demo_signals()` - демо сигналы
- `get_demo_filter_stats()` - демо статистика фильтров
- `get_demo_data_quality()` - демо качество данных
- `get_demo_optimization_data()` - демо оптимизация
- `get_demo_performance_data()` - демо производительность
