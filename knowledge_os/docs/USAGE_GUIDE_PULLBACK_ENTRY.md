# 📖 РУКОВОДСТВО ПО ИСПОЛЬЗОВАНИЮ: НОВАЯ ЛОГИКА ВХОДА НА ОТКАТЕ

**Версия:** 1.0  
**Дата:** 17 ноября 2025

---

## 🎯 ОБЗОР

Новая логика входа на откате (`Pullback Entry`) заменяет устаревший EMA кроссовер на современный подход с:

- Входом на откате к поддержке/сопротивлению
- Проверкой структуры рынка (тренд/флэт)
- Оценкой качества входа (свечные паттерны, объем, уровни, импульс)
- Использованием Volume Profile для определения зон высокой ликвидности

---

## ⚙️ КОНФИГУРАЦИЯ

### Включение/отключение

```python
# config.py
USE_PULLBACK_ENTRY = True  # Включить новую логику
USE_PULLBACK_ENTRY = False  # Отключить (использовать старую логику EMA кроссовер)
```

Или через переменную окружения:

```bash
export USE_PULLBACK_ENTRY=true   # Включить
export USE_PULLBACK_ENTRY=false  # Отключить
```

### Настройки параметров

```python
# config.py
PULLBACK_ENTRY_CONFIG = {
    "min_quality_score": 0.7,  # Минимальная оценка качества входа (0.0-1.0)
    "require_trend": True,     # Требовать тренд для входа
    "support_tolerance_pct": 0.8,      # Допустимое отклонение от поддержки (%)
    "resistance_tolerance_pct": 0.8,   # Допустимое отклонение от сопротивления (%)
}
```

### Рекомендуемые значения:

**Консервативный подход (меньше сделок, выше качество):**

```python
PULLBACK_ENTRY_CONFIG = {
    "min_quality_score": 0.75,
    "require_trend": True,
    "support_tolerance_pct": 0.6,
    "resistance_tolerance_pct": 0.6,
}
```

**Агрессивный подход (больше сделок, ниже качество):**

```python
PULLBACK_ENTRY_CONFIG = {
    "min_quality_score": 0.65,
    "require_trend": False,  # Разрешить входы в флэте
    "support_tolerance_pct": 1.0,
    "resistance_tolerance_pct": 1.0,
}
```

**Сбалансированный подход (рекомендуется):**

```python
PULLBACK_ENTRY_CONFIG = {
    "min_quality_score": 0.7,
    "require_trend": True,
    "support_tolerance_pct": 0.8,
    "resistance_tolerance_pct": 0.8,
}
```

## 🔍 КАК РАБОТАЕТ НОВАЯ ЛОГИКА

### Для LONG (покупка):

1. **Проверка структуры рынка:**
   - Рынок должен быть в режиме `TREND_UP` или `RANGE`
   - ADX > 20 для трендовых рынков

2. **Проверка отката к поддержке:**
   - Цена должна находиться вблизи уровня поддержки (в пределах `support_tolerance_pct`)
   - Поддержка определяется через:
     - Локальные минимумы
     - EMA (быстрая/медленная)
     - Уровни Фибоначчи
     - Volume Profile (POC, Value Area)

3. **Проверка свечных паттернов:**
   - Бычье поглощение (Bullish Engulfing)
   - Хаммер (Hammer)
   - Пронзающая линия (Piercing Line)

4. **Оценка качества входа:**
   - Расстояние от локального экстремума (ATR-based)
   - Подтверждение объемом
   - Привязка к уровням (поддержка/сопротивление)
   - Подтверждение импульса (RSI, MACD, Momentum, ROC)

5. **Общая оценка:**
   - Должна быть >= `min_quality_score` (по умолчанию 0.7)

### Для SHORT (продажа):

Аналогично, но:

- Рынок должен быть в режиме `TREND_DOWN` или `RANGE`
- Цена должна быть вблизи сопротивления
- Проверяются медвежьи паттерны

---

## 📊 КОМПОНЕНТЫ ОЦЕНКИ КАЧЕСТВА ВХОДА

Оценка качества входа состоит из 5 компонентов:

1. **Distance (0.16)** - Расстояние от локального экстремума
   - Идеальное расстояние: 0.5-1.5 ATR от экстремума

2. **Pattern (0.16)** - Свечные паттерны
   - Бычьи/медвежьи паттерны подтверждают направление

3. **Volume (0.16)** - Подтверждение объемом
   - Высокий объем на движении в нужном направлении

4. **Level (0.16)** - Привязка к уровням
   - Близость к поддержке/сопротивлению
   - Использование Volume Profile для точности

5. **Momentum (0.20)** - Импульс движения
   - RSI, MACD, Momentum, ROC
   - Подтверждение направления движения

**Общая оценка = взвешенная сумма всех компонентов**

## 🔄 FALLBACK МЕХАНИЗМ

Если новая логика не проходит проверку, система автоматически переключается на старую логику (EMA кроссовер) как fallback. Это обеспечивает:

- Обратную совместимость
- Непрерывность работы системы
- Плавный переход на новую логику

## 📈 МОНИТОРИНГ И ЛОГИРОВАНИЕ

### Логи новой логики:

```
✅ [PULLBACK ENTRY] SYMBOL: Вход на откате к поддержке (Quality=0.75, Regime=TREND_UP)
⏭️ [PULLBACK ENTRY] SYMBOL: Не прошел проверку (Низкое качество входа: 0.65 < 0.7), пробуем EMA кроссовер
```

### Метрики для отслеживания:

1. **Количество сигналов:**
   - Сколько сигналов генерирует новая логика
   - Сколько сигналов генерирует старая логика (fallback)

2. **Win Rate:**
   - Процент прибыльных сделок
   - Сравнение: новая логика vs старая логика

3. **PnL:**
   - Общая прибыль/убыток
   - Средняя прибыль на сделку

4. **Quality Score:**
   - Средняя оценка качества входа
   - Распределение оценок

## 🛠️ ОТЛАДКА И НАСТРОЙКА

### Проблема: Слишком мало сигналов

**Решение:**

1. Уменьшить `min_quality_score` (например, с 0.7 до 0.65)
2. Увеличить `support_tolerance_pct` и `resistance_tolerance_pct` (например, с 0.8 до 1.0)
3. Отключить `require_trend` (разрешить входы в флэте)

### Проблема: Слишком много сигналов с низким Win Rate

**Решение:**

1. Увеличить `min_quality_score` (например, с 0.7 до 0.75)
2. Уменьшить `support_tolerance_pct` и `resistance_tolerance_pct` (например, с 0.8 до 0.6)
3. Включить `require_trend` (требовать тренд)

### Проблема: Сигналы генерируются слишком поздно

**Решение:**

1. Увеличить `support_tolerance_pct` и `resistance_tolerance_pct` (более широкие зоны)
2. Уменьшить `min_quality_score` (менее строгие требования)

## ❓ FAQ

**Q: Можно ли использовать обе логики одновременно?**  
A: Нет, система использует либо новую, либо старую логику. Новая логика имеет приоритет, старая работает как fallback.

**Q: Как быстро можно переключиться обратно на старую логику?**  
A: Просто установите `USE_PULLBACK_ENTRY = False` в config.py и перезапустите систему.

**Q: Влияет ли новая логика на другие фильтры?**  
A: Нет, все существующие фильтры (тренды, RSI, новые фильтры) применяются к новой логике так же, как и к старой.

**Q: Можно ли настроить параметры для разных символов?**  
A: В текущей версии параметры глобальные. Для индивидуальной настройки требуется дополнительная разработка.
