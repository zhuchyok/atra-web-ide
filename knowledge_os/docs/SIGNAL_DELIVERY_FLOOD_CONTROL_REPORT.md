### **🔍 Диагностика проблемы:**

**Проблема:** Telegram API ограничивает количество сообщений (Flood Control).

**Причины:**

1. **Слишком частые сообщения** - Telegram ограничивает отправку
2. **Множественные попытки** - система пытается отправить много сообщений подряд
3. **Отсутствие задержек** - нет достаточных пауз между сообщениями

**Ограничения Telegram:**

- **20 сообщений в минуту** для обычных ботов
- **30 сообщений в секунду** для каналов
- **Flood Control** активируется при превышении лимитов

```python
async def notify_user(user_id, text, **kwargs):
    import asyncio

    # Добавляем задержку между сообщениями для предотвращения flood control
    await asyncio.sleep(0.2)  # 200ms задержка

    # Retry механизм с экспоненциальной задержкой
    max_retries = 3
    for attempt in range(max_retries):
        try:
            from telegram import Bot
            bot = Bot(token=TOKEN)
            await bot.send_message(chat_id=user_id, text=text, parse_mode="HTML", **kwargs)
            await bot.close()
            print(f"[notify_user] ✅ Сообщение успешно отправлено пользователю {user_id}")
            return True
        except Exception as e:
            print(f"[notify_user] ❌ Попытка {attempt + 1}/{max_retries} - Ошибка отправки пользователю {user_id}: {e}")

            # Если это flood control, добавляем экспоненциальную задержку
            if "Flood control" in str(e):
                wait_time = 2 ** attempt  # 1, 2, 4 секунды
                print(f"[notify_user] 🚨 Flood control для пользователя {user_id}, ожидание {wait_time} секунд...")
                await asyncio.sleep(wait_time)
            else:
                break

    print(f"[notify_user] ❌ Не удалось отправить сообщение пользователю {user_id} после {max_retries} попыток")
    return False
```
