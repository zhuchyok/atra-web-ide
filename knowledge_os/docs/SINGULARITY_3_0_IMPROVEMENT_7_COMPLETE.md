## 📦 СОЗДАННЫЕ ФАЙЛЫ

### **1. `knowledge_os/db/migrations/add_knowledge_links_table.sql`** (150+ строк)

**Схема БД:**

- Таблица `knowledge_links` с полями:
  - `source_node_id`, `target_node_id` - связанные узлы
  - `link_type` - тип связи (6 типов)
  - `strength` - сила связи (0.0 - 1.0)
  - `metadata` - дополнительные данные
- Индексы для производительности
- Представление `knowledge_graph_view` для удобного доступа
- Функция `get_related_nodes()` для рекурсивного поиска
- Триггеры для автоматического создания обратных связей

**Типы связей:**

- `depends_on` - зависит от (односторонняя)
- `contradicts` - противоречит (односторонняя)
- `enhances` - улучшает/расширяет (двусторонняя)
- `related_to` - связано с (двусторонняя)
- `supersedes` - заменяет (односторонняя)
- `part_of` - является частью (односторонняя)

### **2. `knowledge_os/app/knowledge_graph.py`** (400+ строк)

**Основные классы:**

1. **LinkType** - Enum для типов связей
2. **KnowledgeLink** - Dataclass для представления связи
3. **KnowledgeGraph** - Главный класс для работы с графом

**Методы:**

- `create_link()` - создание связи
- `get_links()` - получение связей узла
- `get_related_nodes()` - рекурсивный поиск связанных узлов
- `delete_link()` - удаление связи
- `get_graph_stats()` - статистика графа
- `auto_detect_links()` - автоматическое обнаружение связей

## 🔗 ИСПОЛЬЗОВАНИЕ

### **1. Создание связи вручную:**

```python
# Через MCP
create_knowledge_link(
    source_id="uuid-1",
    target_id="uuid-2",
    link_type="depends_on",
    strength=0.9
)
```

### **2. Получение связей:**

```python
# Все связи узла
get_knowledge_links(node_id="uuid-1")

# Только исходящие связи
get_knowledge_links(node_id="uuid-1", direction="outgoing")

# Только связи определенного типа
get_knowledge_links(node_id="uuid-1", link_type="enhances")
```

### **3. Рекурсивный поиск связанных узлов:**

```python
# Найти все связанные узлы (глубина 2)
get_related_knowledge(
    node_id="uuid-1",
    max_depth=2,
    min_strength=0.5
)
```

## 🔄 АВТОМАТИЧЕСКОЕ ОБНАРУЖЕНИЕ СВЯЗЕЙ

**Алгоритм:**

1. Находит узлы без связей
2. Вычисляет семантическое сходство (cosine similarity)
3. Если similarity >= threshold (0.8), создает связь:
   - Если узлы в одном домене → `related_to`
   - Если в разных доменах → `enhances`
4. Сила связи = similarity score

**Ограничения:**

- Максимум 10 похожих узлов на узел
- Threshold = 0.8 (настраивается)
- Rate limiting: 0.5 сек между узлами
