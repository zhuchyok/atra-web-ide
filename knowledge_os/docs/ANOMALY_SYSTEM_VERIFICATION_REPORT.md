## 🔧 РЕКОМЕНДАЦИИ ПО ИСПРАВЛЕНИЮ

### **1. Исправить функцию `get_anomaly_emoji`:**

```python
def get_anomaly_emoji(score: float) -> str:
    """Эмодзи для визуализации аномалии."""
    try:
        # score = circles_count / 5.0 (0.0 - 1.0)
        if score >= 0.8:  # 4-5 кружков
            return "🔥"  # Высокая аномалия
        elif score >= 0.6:  # 3 кружка
            return "⚠️"  # Средняя аномалия
        elif score >= 0.2:  # 1-2 кружка
            return "📈"  # Низкая аномалия
        else:  # 0 кружков
            return "✅"  # Нормальная активность
    except (TypeError, ValueError):
        return ""
```

### **2. Включить фильтр аномалий:**

```python
# Изменить в signal_live.py:
USE_ANOMALY_FILTER = True  # Включить фильтр аномалий
```

### **3. Добавить логику блокировки:**

```python
if USE_ANOMALY_FILTER:
    circles_gate_count, _, _, anomaly_data_ok = await calculate_anomaly_circles_with_fallback(symbol, signal_type)

    # Блокируем сигналы с критическими аномалиями (4-5 кружков)
    if anomaly_data_ok and circles_gate_count and circles_gate_count >= 4:
        print(f"[ANOMALY FILTER] {symbol}: Блокирован из-за критической аномалии ({circles_gate_count} кружков)")
```
