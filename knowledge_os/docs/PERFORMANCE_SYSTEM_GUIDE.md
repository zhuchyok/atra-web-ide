# 📊 Система производительности торгового бота

## 🎯 Обзор

Комплексная система для тестирования, мониторинга и оптимизации производительности торгового бота включает в себя:

1. **Тестирование на исторических данных** - проверка эффективности стратегий

## 🔧 Конфигурация системы

### Основные параметры

Файл `comprehensive_performance_system.py` содержит класс `PerformanceConfig` с настройками:

```python
@dataclass
class PerformanceConfig:
    # Параметры бэктеста
    start_balance: float = 10000
    fee: float = 0.001
    slippage: float = 0.0005
    risk_per_trade: float = 0.02

    # Параметры мониторинга
    monitoring_window: int = 30  # дней
    min_trades_for_analysis: int = 10
    performance_threshold: float = 0.6

    # Параметры оптимизации
    optimization_trials: int = 50
    optimization_window: int = 90  # дней

    # Параметры сигналов
    default_tp_mult: float = 2.5
    default_sl_mult: float = 1.2
    default_ema_short: int = 7
    default_ema_long: int = 25
    default_rsi_period: int = 14
    default_atr_period: int = 14
```

### Настройка параметров

Для изменения параметров создайте экземпляр конфигурации:

```python
from comprehensive_performance_system import PerformanceConfig

config = PerformanceConfig(
    start_balance=5000,
    risk_per_trade=0.01,
    optimization_trials=100
)
```

## 📊 Интерпретация результатов

### Рейтинг производительности

- **Отлично** - ≥70% успешных сделок и положительная прибыль
- **Хорошо** - ≥60% успешных сделок и положительная прибыль
- **Удовлетворительно** - ≥50% успешных сделок
- **Требует улучшения** - <50% успешных сделок

### Ключевые метрики

1. **Win Rate** - процент прибыльных сделок
2. **Profit Factor** - отношение общей прибыли к общим убыткам
3. **Sharpe Ratio** - отношение доходности к волатильности
4. **Max Drawdown** - максимальная просадка капитала

### Рекомендации по улучшению

- **Низкий Win Rate** - требуется оптимизация фильтров входа
- **Низкий Profit Factor** - необходимо улучшить управление рисками
- **Высокая просадка** - уменьшить размер позиций или улучшить стоп-лоссы

## 🔄 Автоматическая оптимизация

### Алгоритм оптимизации

Система использует библиотеку Optuna для поиска оптимальных параметров:

1. **Параметры для оптимизации:**
   - EMA короткая (5-15)
   - EMA длинная (20-50)
   - RSI период (10-20)
   - RSI максимум (60-80)
   - ATR период (10-20)
   - TP множитель (1.5-4.0)
   - SL множитель (0.8-2.0)
   - Минимальный объем (1.0-2.0)

2. **Целевая функция:**
   ```python
   score = (
       win_rate * 0.4 +
       min(profit_factor, 5) / 5 * 0.3 +
       (1 - max_drawdown) * 0.2 +
       min(sharpe_ratio, 2) / 2 * 0.1
   )
   ```

### Применение оптимизированных параметров

После получения оптимальных параметров:

1. Протестируйте их на исторических данных
2. Сравните с текущими результатами
3. Примените постепенно, начиная с малых сумм
4. Мониторьте результаты в реальном времени

## 🔍 Диагностика проблем

### Частые ошибки

1. **"Недостаточно данных для анализа"**
   - Увеличьте `min_trades_for_analysis`
   - Подождите накопления торговых данных

2. **"Ошибка загрузки исторических данных"**
   - Проверьте подключение к интернету
   - Убедитесь в корректности символа

3. **"Ошибка оптимизации"**
   - Уменьшите количество испытаний
   - Проверьте доступность данных
