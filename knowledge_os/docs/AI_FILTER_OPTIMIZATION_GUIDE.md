## 🎯 ЧТО ЭТО?

**Система автоматической оптимизации параметров фильтров** на основе исторических результатов торговли.

AI анализирует каждые 6 часов:

- ✅ Win Rate (процент успешных сделок)
- ✅ Profit Factor (соотношение прибыли к убыткам)
- ✅ Max Drawdown (максимальная просадка)
- ✅ Sharpe Ratio (риск-скорректированная доходность)

И автоматически **корректирует параметры фильтров** для максимальной эффективности!

## 📊 КАКИЕ ПАРАМЕТРЫ ОПТИМИЗИРУЮТСЯ?

### **1. Пороги оценки сигналов**

```
SOFT:   50 → динамически (45-70)
STRICT: 55 → динамически (50-75)
```

### **2. ADX фильтры (сила тренда)**

```
SOFT ADX BB:   20 → динамически (18-28)
STRICT ADX BB: 24 → динамически (22-30)
SOFT ADX Entry:   18 → динамически (15-26)
STRICT ADX Entry: 21 → динамически (18-28)
```

### **3. BB Epsilon (точность входа)**

```
SOFT:   0.11 → динамически (0.07-0.15)
STRICT: 0.07 → динамически (0.04-0.10)
```

### **4. MTF Score (подтверждение на таймфреймах)** 🆕

```
SOFT:   60 → динамически (50-75)
STRICT: 70 → динамически (60-85)
```

### **5. Volume Ratio (объемный фильтр)** 🆕

```
SOFT:   1.3x → динамически (1.1-1.8x)
STRICT: 1.5x → динамически (1.2-2.0x)
```

### **6. Confluence (согласованность индикаторов)** 🆕

```
SOFT:   3/5 → динамически (2-4/5)
STRICT: 4/5 → динамически (3-5/5)
```

### **7. Volatility Range (диапазон волатильности)** 🆕

```
SOFT Min:   0.015 → динамически (0.01-0.025)
SOFT Max:   0.08  → динамически (0.06-0.12)
STRICT Min: 0.02  → динамически (0.015-0.03)
STRICT Max: 0.06  → динамически (0.04-0.10)
```

## 🔄 КАК РАБОТАЕТ ОПТИМИЗАЦИЯ?

### **Алгоритм:**

```
1. Анализ последних 7 дней торговли
   ├─ Минимум 20 сделок для оптимизации
   ├─ Расчет Win Rate, Profit Factor, Drawdown, Sharpe
   └─ Оценка текущей производительности (0-100%)

2. Определение направления корректировки
   ├─ Win Rate < 65% → УЖЕСТОЧАЕМ фильтры (+5%)
   ├─ Win Rate > 80% и мало сделок → ОСЛАБЛЯЕМ (-5%)
   ├─ Оценка > 75% → минимальная корректировка (+1%)
   └─ Средняя производительность → стандартная (+2%)

3. Применение корректировок
   ├─ Score thresholds: увеличиваем при низком WR
   ├─ ADX thresholds: увеличиваем при низком WR
   ├─ BB epsilon: уменьшаем при низком WR (точнее входы)
   ├─ Volume ratio: увеличиваем при низком WR
   ├─ MTF min: увеличиваем при низком WR
   ├─ Confluence: увеличиваем при низком WR
   └─ Volatility range: сужаем при низком WR

4. Сохранение оптимизированных параметров
   └─ ai_learning_data/filter_parameters.json
```
