# 🔍 ПОЛНАЯ ЛОГИКА АНОМАЛИЙ И КРУЖКОВ

## 📊 Основная формула

```
volume_to_cap_ratio = volume_24h / market_cap
```

## 🎯 Логика количества кружков (0-5)

### 📈 Уровни аномалии по соотношению volume/cap:

| Соотношение | Кружков | Описание               | Эмодзи |
| ----------- | ------- | ---------------------- | ------ |
| **≥ 0.8**   | **5**   | Максимальная аномалия  | 🔴     |
| **≥ 0.5**   | **4**   | Критическая активность | 🔴     |
| **≥ 0.2**   | **3**   | Аномальная активность  | 🟠     |
| **≥ 0.1**   | **2**   | Высокая активность     | 🟡     |
| **≥ 0.04**  | **1**   | Повышенная активность  | 🟡     |
| **< 0.04**  | **0**   | Нормальная активность  | ⚪     |

## 🎨 Логика закрашивания кружков

### 🟢 LONG сигналы:

```
# Зеленые кружки для LONG с разными оттенками в зависимости от уровня аномалии
if circles_count >= 4:  # 4-5 кружков - максимальная аномалия
    circle_filled = "🟢"  # Ярко-зеленый
elif circles_count >= 3:  # 3 кружка - высокая аномалия
    circle_filled = "🟢"  # Зеленый
elif circles_count >= 2:  # 2 кружка - средняя аномалия
    circle_filled = "🟢"  # Зеленый
elif circles_count >= 1:  # 1 кружок - низкая аномалия
    circle_filled = "🟢"  # Зеленый
else:  # 0 кружков - нормальная активность
    circle_filled = "⚪"  # Серый
circle_empty = "⚪"  # Серые для неактивности
```

### 🔴 SHORT сигналы:

```
# Красные кружки для SHORT с разными оттенками в зависимости от уровня аномалии
if circles_count >= 4:  # 4-5 кружков - максимальная аномалия
    circle_filled = "🔴"  # Ярко-красный
elif circles_count >= 3:  # 3 кружка - высокая аномалия
    circle_filled = "🔴"  # Красный
elif circles_count >= 2:  # 2 кружка - средняя аномалия
    circle_filled = "🔴"  # Красный
elif circles_count >= 1:  # 1 кружок - низкая аномалия
    circle_filled = "🔴"  # Красный
else:  # 0 кружков - нормальная активность
    circle_filled = "⚪"  # Серый
circle_empty = "⚪"  # Серые для неактивности
```

## 📋 Формирование текста кружков

```python
circles_text = circle_filled * circles_count + circle_empty * (5 - circles_count)
```

### Примеры:

- **5 кружков LONG**: 🟢🟢🟢🟢🟢 (максимальная аномалия)
- **3 кружка SHORT**: 🔴🔴🔴⚪⚪ (аномальная активность)
- **1 кружок LONG**: 🟢⚪⚪⚪⚪ (повышенная активность)
- **0 кружков**: ⚪⚪⚪⚪⚪ (нормальная активность)

## 🔥 Логика эмодзи аномалий

```python
score = circles_count / 5.0  # 0.0 - 1.0

if score >= 0.8:    # 4-5 кружков
    return "🔴"     # Красный кружок - критическая аномалия
elif score >= 0.6:  # 3 кружка
    return "🟠"     # Оранжевый кружок - высокая аномалия
elif score >= 0.2:  # 1-2 кружка
    return "🟡"     # Желтый кружок - низкая аномалия
else:               # 0 кружков
    return "⚪"     # Серый кружок - нормальная активность
```

## 📊 Примеры для TRXUSDT

### Данные:

- **volume_24h**: 61,830,317.48
- **market_cap**: 6,183,031.75
- **ratio**: 10.0000

### Результат:

- **Кружков**: 5 (≥ 0.8)
- **Описание**: "Максимальная аномалия"
- **LONG**: 🟢🟢🟢🟢🟢
- **SHORT**: 🔴🔴🔴🔴🔴
- **Эмодзи**: 🔴
- **Итоговая строка**: `• Аномалии: 🔴 🟢🟢🟢🟢🟢`

## 🔧 Полный алгоритм

1. **Получаем данные** из 15 источников
2. **Рассчитываем ratio** = volume_24h / market_cap
3. **Определяем кружки** по таблице выше
4. **Закрашиваем кружки** по типу сигнала (LONG/SHORT)
5. **Выбираем эмодзи** по количеству кружков
6. **Формируем строку**: `• Аномалии: {emoji} {circles_text}`

## 🎯 Итоговая логика

**Количество кружков = f(volume_to_cap_ratio)**

- Чем выше соотношение volume/cap, тем больше кружков
- Максимум 5 кружков при ratio ≥ 0.8
- Минимум 0 кружков при ratio < 0.04

**Цвет кружков = f(signal_type)**

- LONG → 🟢 (зеленые)
- SHORT → 🔴 (красные)

**Эмодзи = f(circles_count)**

- 4-5 кружков → 🔴 (красный кружок)
- 3 кружка → 🟠 (оранжевый кружок)
- 1-2 кружка → 🟡 (желтый кружок)
- 0 кружков → ⚪ (серый кружок)
