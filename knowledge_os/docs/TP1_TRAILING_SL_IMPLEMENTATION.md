## 🔧 ЛОГИКА РАБОТЫ

### **Алгоритм подтягивания к TP1:**

1. **Расчет прогресса к TP1:**

   ```python
   progress = (current_price - entry_price) / (tp1_price - entry_price)
   ```

2. **Активация:**
   - Только при `progress >= 0.5` (50% пути к TP1)
   - Только если цена еще не достигла TP1

3. **Расчет нового SL:**

   ```python
   sl_progress = progress * 0.3  # 30% от пройденного пути
   new_sl = entry_price + (tp1_price - entry_price) * sl_progress
   ```

4. **Ограничения:**
   - Минимум: безубыток + комиссии (entry_price \* 1.002)
   - Минимум: текущая_цена - ATR \* 2.0
   - Стоп только улучшается (никогда не ухудшается)

5. **Обновление:**
   - В trailing manager
   - В БД (signals_log, accepted_signals, active_positions)
   - Логирование с деталями

## 📊 ПРИМЕР РАБОТЫ

### **Сценарий: LONG позиция**

```
Вход: 100.00 USDT
Начальный SL: 98.00 USDT (-2%)
TP1: 102.75 USDT (+2.75%)
ATR: 0.50 USDT

Движение цены:
1. Цена: 101.00 USDT (+1.0%)
   Прогресс: (101-100)/(102.75-100) = 36.4% → НЕ активируется (< 50%)

2. Цена: 101.38 USDT (+1.38%)
   Прогресс: (101.38-100)/(102.75-100) = 50.2% → ✅ АКТИВИРУЕТСЯ
   SL прогресс: 50.2% * 0.3 = 15.06%
   Новый SL: 100 + (102.75-100) * 0.1506 = 100.41 USDT
   Минимум: max(100.41, 100.20, 101.38-1.0) = 100.41 USDT
   ✅ SL обновлен: 98.00 → 100.41 USDT

3. Цена: 101.75 USDT (+1.75%)
   Прогресс: (101.75-100)/(102.75-100) = 63.6%
   SL прогресс: 63.6% * 0.3 = 19.1%
   Новый SL: 100 + (102.75-100) * 0.191 = 100.52 USDT
   Минимум: max(100.52, 100.20, 101.75-1.0) = 100.52 USDT
   ✅ SL обновлен: 100.41 → 100.52 USDT

4. Цена: 102.00 USDT (+2.0%)
   Прогресс: (102-100)/(102.75-100) = 72.7%
   SL прогресс: 72.7% * 0.3 = 21.8%
   Новый SL: 100 + (102.75-100) * 0.218 = 100.60 USDT
   Минимум: max(100.60, 100.20, 102.00-1.0) = 101.00 USDT
   ✅ SL обновлен: 100.52 → 101.00 USDT (ограничение ATR)
```
