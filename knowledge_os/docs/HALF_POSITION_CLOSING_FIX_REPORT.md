# 🛠️ ОТЧЕТ: ИСПРАВЛЕНИЕ ПРОБЛЕМЫ С ЗАКРЫТИЕМ ПОЗИЦИЙ НА 50%

## 📋 **ПРОБЛЕМА**

Пользователь сообщил, что при нажатии кнопки "💰 Закрыть 50%" позиция закрывается полностью, а не на 50% как ожидается.

## 🔍 **АНАЛИЗ ПРОБЛЕМЫ**

### **Найденная ошибка:**

Проблема была в логике сравнения чисел с плавающей точкой в функции `close_position`:

```python
# ПРОБЛЕМНАЯ ЛОГИКА (было):
if actual_qty >= qty:
    # Закрываем всю позицию
    open_positions = [p for p in open_positions if p["symbol"] != symbol]
else:
    # Закрываем часть позиции
    remaining_qty = qty - actual_qty
    pos["qty"] = remaining_qty
```

**Проблема:** При закрытии 50% позиции, `actual_qty = qty / 2`. Из-за особенностей представления чисел с плавающей точкой, условие `actual_qty >= qty` могло быть истинным, что приводило к закрытию всей позиции вместо 50%.

## ✅ **ВЫПОЛНЕННЫЕ ИСПРАВЛЕНИЯ**

### **1. Исправлена логика сравнения для закрытия позиций**

**Файл:** `telegram_bot.py` (строка ~1850)

**Было:**

```python
if actual_qty >= qty:
    # Закрываем всю позицию
    open_positions = [p for p in open_positions if p["symbol"] != symbol]
else:
    # Закрываем часть позиции
    remaining_qty = qty - actual_qty
    pos["qty"] = remaining_qty
```

**Стало:**

```python
if close_qty == "all" or actual_qty >= qty * 0.999:  # Используем небольшой допуск для сравнения float
    # Закрываем всю позицию
    open_positions = [p for p in open_positions if p["symbol"] != symbol]
    print(f"[button] Закрыта вся позиция {symbol}: {actual_qty:.6f} из {qty:.6f}")
else:
    # Закрываем часть позиции
    remaining_qty = qty - actual_qty
    pos["qty"] = remaining_qty
    print(f"[button] Закрыта часть позиции {symbol}: {actual_qty:.6f} из {qty:.6f}, осталось {remaining_qty:.6f}")
```

### **2. Улучшено сообщение о закрытии позиции**

**Файл:** `telegram_bot.py` (строка ~1920)

**Добавлено:**

```python
# Определяем тип закрытия
if close_qty == "all" or actual_qty >= qty * 0.999:
    close_type = "ВСЯ ПОЗИЦИЯ"
elif close_qty == "half":
    close_type = "50% ПОЗИЦИИ"
else:

msg = (
```
