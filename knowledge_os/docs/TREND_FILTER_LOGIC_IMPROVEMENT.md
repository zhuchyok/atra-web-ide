## ❓ ВОПРОС

**Если монета коррелирует с BTC/ETH/SOL, нужно ли проверять все три тренда или только тот, с которым коррелирует монета?**

---

## 📊 ТЕКУЩАЯ ЛОГИКА

### **Сейчас:**

- ✅ Проверяются **ВСЕ ТРИ** тренда (BTC, ETH, SOL) для **ВСЕХ** монет
- ❌ Независимо от корреляционной группы

**Пример:**

- `BONKUSDT` → группа `SOL_HIGH` (корреляция к SOL = 0.85)
- Но проверяются: BTC тренд + ETH тренд + SOL тренд
- Если хотя бы один блокирует → сигнал не проходит

---

## 🎯 ПРЕДЛАГАЕМАЯ ЛОГИКА

### **Логичнее:**

- ✅ Проверять **только тренд того актива, с которым монета коррелирует**
- ✅ Если монета в группе `BTC_HIGH` → проверять только BTC тренд
- ✅ Если монета в группе `ETH_HIGH` → проверять только ETH тренд
- ✅ Если монета в группе `SOL_HIGH` → проверять только SOL тренд

**Пример:**

- `BONKUSDT` → группа `SOL_HIGH` (корреляция к SOL = 0.85)
- Проверяется **только SOL тренд**
- BTC и ETH тренды **не проверяются**

---

## ✅ ПРЕИМУЩЕСТВА НОВОЙ ЛОГИКИ

1. **Более логично:**
   - Если монета движется вместе с SOL, зачем проверять BTC тренд?
   - Корреляция показывает, какой актив влияет на монету

2. **Меньше блокировок:**
   - Сейчас: если BTC медвежий, а монета коррелирует с SOL → сигнал блокируется
   - С новой логикой: проверяется только SOL тренд → больше сигналов

3. **Более точная фильтрация:**
   - Фокус на том, что действительно влияет на монету
   - Игнорирование нерелевантных факторов

4. **Соответствие корреляции:**
   - Если корреляция к SOL = 0.85, значит монета следует за SOL
   - Логично проверять только SOL тренд

## 🔧 РЕАЛИЗАЦИЯ

### **Изменение в `signal_live.py`:**

```python
async def check_all_trend_alignments(symbol: str, signal_type: str, df: pd.DataFrame = None) -> bool:
    """
    Проверяет соответствие сигнала тренду коррелирующего актива

    Логика:
    - Определяет корреляционную группу (BTC_HIGH, ETH_HIGH, SOL_HIGH)
    - Проверяет только тренд того актива, с которым монета коррелирует
    """
    try:
        # Определяем корреляционную группу
        if CORRELATION_MANAGER_AVAILABLE and correlation_manager:
            symbol_group = await correlation_manager.get_symbol_group_async(symbol, df)

            # Извлекаем базовый актив из группы (BTC, ETH, SOL)
            if symbol_group.startswith('BTC_'):
                # Проверяем только BTC тренд
                return await check_btc_alignment(symbol, signal_type)
            elif symbol_group.startswith('ETH_'):
                # Проверяем только ETH тренд
                return await check_eth_alignment(symbol, signal_type)
            elif symbol_group.startswith('SOL_'):
                # Проверяем только SOL тренд
                return await check_sol_alignment(symbol, signal_type)
            else:
                # Если группа не определена, проверяем все три (fallback)
                logger.debug("⚠️ [%s] Группа не определена (%s), проверяем все тренды", symbol, symbol_group)
                return (
                    await check_btc_alignment(symbol, signal_type) and
                    await check_eth_alignment(symbol, signal_type) and
                    await check_sol_alignment(symbol, signal_type)
                )
        else:
            # Если correlation_manager недоступен, проверяем все три (fallback)
            logger.debug("⚠️ [%s] CorrelationManager недоступен, проверяем все тренды", symbol)
            return (
                await check_btc_alignment(symbol, signal_type) and
                await check_eth_alignment(symbol, signal_type) and
                await check_sol_alignment(symbol, signal_type)
            )
    except Exception as e:
        logger.warning("⚠️ Ошибка проверки трендов для %s: %s, проверяем все тренды", symbol, e)
        # Fallback: проверяем все три
        return (
            await check_btc_alignment(symbol, signal_type) and
            await check_eth_alignment(symbol, signal_type) and
            await check_sol_alignment(symbol, signal_type)
        )
```

## 📋 ПРИМЕРЫ

### **Пример 1: SOL_HIGH монета**

- `BONKUSDT` → `SOL_HIGH` (корреляция к SOL = 0.85)
- **Проверяется:** только SOL тренд
- **Не проверяется:** BTC тренд, ETH тренд

### **Пример 2: BTC_HIGH монета**

- `LINKUSDT` → `BTC_HIGH` (корреляция к BTC = 0.80)
- **Проверяется:** только BTC тренд
- **Не проверяется:** ETH тренд, SOL тренд

### **Пример 3: Группа не определена**

- `UNKNOWNUSDT` → группа не определена
- **Проверяется:** все три тренда (BTC, ETH, SOL) - fallback

## ⚠️ ВАЖНЫЕ МОМЕНТЫ

1. **Fallback логика:**
   - Если корреляция не определена → проверяем все три тренда
   - Это безопаснее, чем пропускать проверку

2. **BTC всегда важен:**
   - Можно добавить опцию: всегда проверять BTC тренд (даже для ETH/SOL монет)
   - Потому что BTC влияет на весь рынок

3. **Гибридный подход:**
   - Проверять основной тренд (по корреляции) + BTC тренд (всегда)
   - Это компромисс между точностью и безопасностью

## 🎯 РЕКОМЕНДАЦИЯ

- Проще, логичнее, меньше блокировок

**Вариант 2: Гибридный подход**

- Проверять коррелирующий тренд + BTC тренд (всегда)
- Безопаснее, но больше блокировок

**Вариант 3: Оставить как есть**

- Проверять все три тренда всегда
- Максимально безопасно, но много блокировок
