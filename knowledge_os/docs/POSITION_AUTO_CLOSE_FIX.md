# 🛠️ ИСПРАВЛЕНИЕ: Автоматическое закрытие позиций для manual режима

**Дата:** 2025-11-06 19:10 MSK  
**Статус:** ✅ **ИСПРАВЛЕНО**

## 🎯 ПРОБЛЕМА

Пользователь сообщил, что позиции закрываются автоматически через 2-3 минуты после открытия с сообщением:

```
✅ АЛЕРТ
✅ Позиция закрыта
├ Символ: ETHFIUSDT
└ Закрыта на бирже (автосинхронизация)
```

### Причина:

- Система синхронизирует позиции с биржей каждые 2 минуты
- Если позиция не найдена на бирже, она закрывается локально
- Пользователь использует бота только как **сигнал-провайдер** (не открывает позиции на бирже реально)
- Система думает, что позиция должна быть на бирже, и когда не находит её, закрывает локально

## ✅ РЕШЕНИЕ

Добавлена проверка режима пользователя перед автоматическим закрытием позиции:

### Изменения в `main.py` (строки 1240-1279):

**Было:**

```python
# Закрываем локально те символы, которые более не числятся открытыми на бирже
try:
    local_open = set(await adb_local.get_user_active_symbols(uid))
    to_close = local_open - open_symbols_remote
    for sym in to_close:
        await adb_local.close_active_position_by_symbol(uid, sym)
        # ... закрытие позиции
```

**Стало:**

```python
# Закрываем локально те символы, которые более не числятся открытыми на бирже
# ВАЖНО: Для пользователей в manual режиме НЕ закрываем позиции автоматически,
# так как они используют бота только как сигнал-провайдер и не открывают позиции на бирже
try:
    local_open = set(await adb_local.get_user_active_symbols(uid))
    to_close = local_open - open_symbols_remote

    # Проверяем режим пользователя
    user_mode = await adb_local.get_user_mode(uid)

    for sym in to_close:
        # Для manual режима НЕ закрываем позиции автоматически
        # Пользователи в manual режиме используют бота только как сигнал-провайдер
        if user_mode == 'manual':
            logger.debug(
                "⏭️ Пропущено авто-закрытие позиции %s для пользователя %d "
                "(manual режим - сигнал-провайдер)",
                sym, uid
            )
            continue

        # Для auto режима закрываем позиции, если они не найдены на бирже
        await adb_local.close_active_position_by_symbol(uid, sym)
        # ... закрытие позиции
```

- ✅ Позиции закрываются, если не найдены на бирже (как и раньше)

## 🔍 ТЕХНИЧЕСКИЕ ДЕТАЛИ

### Функция проверки режима:

- Используется `adb_local.get_user_mode(uid)` из `acceptance_database.py`
- По умолчанию возвращает `'manual'` если режим не установлен
- Режим хранится в таблице `user_settings` в поле `trade_mode`

### Логика работы:

1. Система проверяет позиции на бирже каждые 2 минуты
2. Находит позиции, которые есть локально, но нет на бирже
3. **Перед закрытием** проверяет режим пользователя:
   - Если `manual` → пропускает закрытие
   - Если `auto` → закрывает позицию
