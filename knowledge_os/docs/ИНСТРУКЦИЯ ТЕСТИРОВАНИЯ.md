# ИНСТРУКЦИЯ ТЕСТИРОВАНИЯ КНОПКИ "ПРИНЯТЬ"

## 🎯 ЦЕЛЬ ТЕСТИРОВАНИЯ

Проверить, что кнопка "Принять" теперь выводит детальные данные вместо простого "Сигнал принят!"

## 📱 КАК ТЕСТИРОВАТЬ

### 1. **Дождитесь сигнала**

- Система запущена и работает
- Дождитесь появления торгового сигнала в Telegram

### 2. **Нажмите кнопку "Принять"**

- В сигнале нажмите кнопку "Принять"
- Обратите внимание на ответное сообщение

### 3. **Проверьте детальное сообщение**

Должно появиться сообщение вида:

```
✅ Сигнал принят!
📅 Принят: [дата и время]
Ваш текущий депозит: [сумма] USDT.
Открытых позиций: [количество] на [сумма] USDT.
Свободно для новых сделок: [сумма] USDT.
Риск на сделку: [процент]% ([сумма] USDT).
Используемое плечо: x[число]
Сумма входа с учётом плеча: [сумма] USDT.

📊 ПОЗИЦИЯ [СИМВОЛ]:
• Цена входа: [цена]
• Объём: [объем]
• TP1: [цена] (+[процент]%)
• TP2: [цена] (+[процент]%)
```

## 🔍 ЛОГИ ДЛЯ ОТЛАДКИ

При нажатии кнопки в логах должны появиться:

```
[BUTTON] 🔍 DEBUG: callback_data = 'accept|...'
[BUTTON] 🔍 DEBUG: data = ['accept', '...']
[BUTTON] 🔍 DEBUG: action = 'accept'
[BUTTON] 🎯 Обработка действия ACCEPT
[BUTTON] Преобразовали индекс DataFrame в текущее время: ...
[BUTTON] Используем базовые параметры: риск=...%, плечо=...x, TP=...%
```

- [ ] Кнопка "Принять" работает без ошибок
- [ ] Выводится детальное сообщение с параметрами
- [ ] Отображается время принятия сигнала
- [ ] Показывается информация о депозите и позициях
- [ ] Отображаются динамические параметры (риск, плечо, TP)
- [ ] В логах нет ошибок
