## 🚀 ИСПОЛЬЗОВАНИЕ

### Автоматическое использование:

Система автоматически применяет компенсацию проскальзывания:

- При расчете размера позиции в `signal_live.py`
- При создании ордеров в `order_manager.py`
- При записи реального проскальзывания после исполнения

### Ручной контроль:

```python
from slippage_manager import get_slippage_manager

slippage_manager = get_slippage_manager()

# Получить статистику
stats = slippage_manager.get_symbol_statistics('SOLUSDT')

# Проверить, нужен ли limit ордер
decision = slippage_manager.should_use_limit_order(
    symbol='SOLUSDT',
    side='buy',
    current_price=141.00,
    volume_24h=500_000_000,
    order_size_usd=1000
)
```
