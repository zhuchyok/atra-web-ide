# 🔧 ИСПРАВЛЕНИЕ: DCA КНОПКИ ЗАБЛОКИРОВАНЫ

## ❌ **ПРОБЛЕМА:**

DCA кнопки не работали на старые сигналы (например, сигнал от 00:30), потому что проверка на дубликаты блокировала их.

---

## 🔍 **ПРИЧИНА:**

Проверка на дубликаты срабатывала **ДО** определения типа сигнала (DCA или обычный), поэтому она блокировала все повторные нажатия по одному и тому же символу, включая легитимные DCA сигналы.

**Старый код:**

```python
# Проверка ДО определения типа
if signal_key in accepted_signals:
    return "Уже принят"

if is_dca:
    # DCA логика
else:
    # Обычный сигнал
```

---

## ✅ **РЕШЕНИЕ:**

Переместил проверку на дубликаты **ПОСЛЕ** определения типа сигнала и применяю её **только для обычных (не DCA) сигналов**.

**Новый код:**

```python
if pl['is_dca']:
    # DCA логика - проверка НЕ применяется
    is_dca_signal = True
else:
    # Обычный сигнал
    is_dca_signal = False

    # Проверка на дубликаты ТОЛЬКО для обычных сигналов
    if signal_key in accepted_signals:
        await query.edit_message_text(
            "✅ Сигнал уже принят\n"
            "💡 Используйте кнопку DCA для усреднения позиции"
        )
        return
```

---

## 🎯 **РЕЗУЛЬТАТ:**

✅ **DCA сигналы** - работают для любых сигналов (новых и старых), усредняют позицию
✅ **Обычные сигналы** - защищены от случайного двойного принятия
✅ **Информативное сообщение** - если пользователь пытается принять обычный сигнал повторно, система подсказывает использовать DCA
