# 👥 АНАЛИЗ КОМАНДЫ: Логика точек входа и выхода

## 📊 ТЕКУЩАЯ ЛОГИКА

### 1. **ТОЧКА ВХОДА (Entry Point)**

**Текущая реализация:**

```python
# signal_live.py, строка 2209
signal_price = current_price  # Используется close цена текущей свечи
```

**Проблемы:**

- ❌ Используется `close` цена свечи, которая уже закрылась
- ❌ Нет учета проскальзывания (slippage)
- ❌ Нет учета спреда (spread)
- ❌ Нет оптимизации входа (лимитные ордера vs рыночные)
- ❌ Нет учета времени входа (волатильность в разное время суток)

**Где используется:**

- `_generate_signal_impl()` - генерация сигналов
- Все паттерны (classic_ema, alternative_1, alternative_2, etc.)
- Используется `df['close'].iloc[-1]` как точка входа

### 2. **ТОЧКА ВЫХОДА (Exit Point)**

**Текущая реализация:**

#### **Take Profit (TP):**

```python
# src/signals/risk.py, get_dynamic_tp_levels()
# Базовые значения: TP1 = 2%, TP2 = 4%
# Динамические на основе ATR:
tp1 = atr_pct * 1.5  # Для LONG
tp2 = atr_pct * 3.0  # Для LONG
```

#### **Stop Loss (SL):**

```python
# src/signals/risk.py, get_dynamic_sl_level()
# Базовое значение: 2%
# Динамическое на основе ATR:
sl = atr_pct * 2.0  # Для LONG и SHORT
# Ограничения: 1-8%
```

**Проблемы:**

- ❌ TP/SL рассчитываются на основе ATR, но не учитывают:
  - Уровни поддержки/сопротивления
  - Психологические уровни (круглые числа)
  - Объемные профили
  - Структуру рынка (тренд/флэт)
- ❌ Нет адаптации к волатильности рынка
- ❌ Нет учета комиссий при расчете минимального TP
- ❌ TP1 trailing SL работает, но может быть оптимизирован

## 🔍 ГИПОТЕЗЫ ДЛЯ УЛУЧШЕНИЯ

### **ГИПОТЕЗА 1: Оптимизация точки входа**

**Проблема:** Использование `close` цены может быть неоптимальным

**Гипотезы:**

1. **H1.1: Использование high/low для входа**
   - Для LONG: использовать `low` свечи (лучшая цена входа)
   - Для SHORT: использовать `high` свечи (лучшая цена входа)
   - **Ожидаемый результат:** Улучшение средней цены входа на 0.1-0.3%

2. **H1.2: Учет проскальзывания**
   - Добавить реалистичное проскальзывание (0.05-0.15% для ликвидных монет)
   - Использовать `close * (1 + slippage)` для LONG
   - Использовать `close * (1 - slippage)` для SHORT
   - **Ожидаемый результат:** Более реалистичные результаты бектеста

3. **H1.3: Оптимизация времени входа**
   - Анализ волатильности по часам
   - Вход в периоды низкой волатильности (меньше проскальзывание)
   - **Ожидаемый результат:** Снижение проскальзывания на 20-30%

4. **H1.4: Использование лимитных ордеров**
   - Вместо рыночного входа использовать лимитный ордер
   - Для LONG: лимит на уровне `low` свечи или ниже
   - Для SHORT: лимит на уровне `high` свечи или выше
   - **Ожидаемый результат:** Улучшение цены входа на 0.2-0.5%

### **ГИПОТЕЗА 2: Оптимизация точки выхода (TP)**

**Проблема:** TP рассчитывается только на основе ATR, не учитывает структуру рынка

**Гипотезы:**

1. **H2.1: Учет уровней поддержки/сопротивления**
   - Анализ локальных максимумов/минимумов
   - TP1 на уровне ближайшего сопротивления (для LONG)
   - TP2 на уровне следующего сопротивления
   - **Ожидаемый результат:** Увеличение Win Rate на 3-5%

2. **H2.2: Учет психологических уровней**
   - Круглые числа (100, 150, 200)
   - Уровни Фибоначчи
   - **Ожидаемый результат:** Улучшение точности TP на 2-3%

3. **H2.3: Адаптивные TP на основе волатильности**
   - Высокая волатильность → большие TP
   - Низкая волатильность → меньшие TP
   - **Ожидаемый результат:** Улучшение Profit Factor на 0.1-0.3

4. **H2.4: Динамические TP на основе структуры рынка**
   - Тренд → большие TP (TP1=3%, TP2=6%)
   - Флэт → меньшие TP (TP1=1.5%, TP2=3%)
   - **Ожидаемый результат:** Улучшение PnL на 5-10%

### **ГИПОТЕЗА 3: Оптимизация точки выхода (SL)**

**Проблема:** SL фиксированный на основе ATR, не адаптируется к условиям

**Гипотезы:**

1. **H3.1: Учет уровней поддержки/сопротивления для SL**
   - SL ниже ближайшей поддержки (для LONG)
   - SL выше ближайшего сопротивления (для SHORT)
   - **Ожидаемый результат:** Снижение ложных срабатываний SL на 10-15%

2. **H3.2: Адаптивный SL на основе волатильности**
   - Высокая волатильность → больший SL (3-4%)
   - Низкая волатильность → меньший SL (1-1.5%)
   - **Ожидаемый результат:** Улучшение Win Rate на 2-4%

3. **H3.3: Учет структуры рынка для SL**
   - Тренд → более широкий SL (2.5-3%)
   - Флэт → более узкий SL (1.5-2%)
   - **Ожидаемый результат:** Снижение преждевременных закрытий

### **ГИПОТЕЗА 4: Комбинированные улучшения**

**Гипотезы:**

1. **H4.1: Оптимизация входа + адаптивные TP**
   - Комбинация H1.1 + H2.4
   - **Ожидаемый результат:** Улучшение PnL на 10-15%

2. **H4.2: Полная оптимизация (вход + выход)**
   - Комбинация всех улучшений
   - **Ожидаемый результат:** Улучшение PnL на 15-25%, Win Rate +3-5%
