## 🔄 Новые режимы фильтров

### 🔴 СТРОГИЙ режим (`strict`)

**Описание**: Высокое качество сигналов, меньше количество

**Условия для LONG**:

- Мягкое касание нижней полосы Боллинджера (≤ 1.04)
- Слабый восходящий тренд (EMA7 > EMA25 × 0.998)
- Не перекуплено (RSI < 60)
- Достаточный объем (volume_ratio > 0.6)
- Минимальная волатильность (> 0.2)
- Не сильный нисходящий momentum (> -0.08)
- Минимальный тренд (trend_strength > 0.02)

**Условия для SHORT**:

- Мягкое касание верхней полосы Боллинджера (≥ 0.96)
- Слабый нисходящий тренд (EMA7 < EMA25 × 1.002)
- Не перепродано (RSI > 40)
- Достаточный объем (volume_ratio > 0.6)
- Минимальная волатильность (> 0.2)
- Не сильный восходящий momentum (< 0.08)
- Минимальный тренд (trend_strength > 0.02)

### 🟡 МЯГКИЙ режим (`soft`)

**Описание**: Больше сигналов, умеренное качество

**Условия для LONG**:

- Мягкое касание нижней полосы Боллинджера (≤ 1.05)
- Слабый восходящий тренд (EMA7 > EMA25 × 0.998)
- Умеренная перепроданость (RSI < 55)
- Низкий объем (volume_ratio > 0.5)
- Низкая волатильность (> 0.5)
- Слабый momentum (> -0.1)
- Слабый тренд (trend_strength > 0.05)

**Условия для SHORT**:

- Мягкое касание верхней полосы Боллинджера (≥ 0.95)
- Слабый нисходящий тренд (EMA7 < EMA25 × 1.002)
- Умеренная перекупленность (RSI > 45)
- Низкий объем (volume_ratio > 0.5)
- Низкая волатильность (> 0.5)

## 📋 Команды управления

### Установка режимов

```
/set_filter_mode strict  - установить строгий режим
/set_filter_mode soft    - установить мягкий режим
```

### Быстрые команды

```
/set_filter_balanced     - быстрая установка строгого режима
/set_filter_soft         - быстрая установка мягкого режима
```

## 🛡️ Автоматические настройки

### Связка режимов

- **Строгий режим** → автоматически устанавливает **Консервативный** режим новостей
- **Мягкий режим** → автоматически устанавливает **Агрессивный** режим новостей

### Режимы новостей

- **Консервативный**: блокирует сигналы по новостям, усиливает по новостям
- **Агрессивный**: не блокирует сигналы, усиливает по новостям
