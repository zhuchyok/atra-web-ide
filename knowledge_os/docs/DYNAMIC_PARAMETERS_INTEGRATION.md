### 1. **Интеграция динамических параметров в новые сигналы** ✅

#### **Динамические тейк-профиты:**

```python
# Старый код (статические значения):
tp1 = price * 1.01  # +1%
tp2 = price * 1.02  # +2%

# Новый код (динамические значения):
tp1_pct, tp2_pct = get_dynamic_tp_levels(df, current_index, side.lower())
tp1 = price * (1 + tp1_pct / 100)
tp2 = price * (1 + tp2_pct / 100)
```

#### **Динамический Stop Loss (для фьючерсов):**

```python
# Добавлен динамический Stop Loss:
if trade_mode == 'futures':
    sl_pct = get_dynamic_sl_level(df, current_index, side.lower())
    sl_price = price * (1 - sl_pct / 100) if side == "LONG" else price * (1 + sl_pct / 100)
```
