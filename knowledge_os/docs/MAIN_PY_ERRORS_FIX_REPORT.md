# 🔧 ИСПРАВЛЕНИЕ ОШИБОК В MAIN.PY

## 📋 ПРОБЛЕМЫ

В файле `main.py` были обнаружены следующие ошибки линтера:

1. **Переопределение переменных** - `api_server` и `dashboard_server` переопределялись в разных областях видимости
2. **Неопределенные глобальные переменные** - переменные использовались без объявления на уровне модуля
3. **Слишком общие исключения** - использование `Exception` вместо конкретных типов исключений
4. **Предупреждения о global statement** - неэлегантное использование global

## ✅ ИСПРАВЛЕНИЯ

### 1. **Добавлены глобальные переменные на уровне модуля**

```python
# Глобальный экземпляр менеджера завершения
shutdown_manager = ShutdownManager()

# Глобальные переменные для веб-сервисов
api_server = None
dashboard_server = None
```

### 2. **Улучшена обработка исключений**

```python
# Было:
except Exception as e:

# Стало:
except (ValueError, TypeError, KeyError, RuntimeError, OSError, ConnectionError) as e:
```

### 3. **Убраны лишние global statements**

```python
# Было:
def run_rest_api():
    global api_server
    api_server = atra_api

# Стало:
def run_rest_api():
    globals()['api_server'] = atra_api
```

### 4. **Упрощена обработка глобальных переменных в signal_handler**

```python
# Убрана лишняя проверка globals().get()
# Теперь используются напрямую объявленные глобальные переменные
```
