# Ограничения по количеству открытых позиций - Подробное описание

## 📋 Обзор системы ограничений

В нашей торговой системе есть **два уровня ограничений** по количеству позиций:

1. **Максимум позиций на символ** - сколько позиций можно открыть по одному активу
2. **Максимум позиций в портфеле** - общее количество позиций по всем активам

## 🎯 Текущие настройки ограничений

### В `config.py`:

```python
"profit_distribution_config": {
    "max_positions_per_symbol": 1,    # Максимум 1 позиция на символ
    "portfolio_max_positions": 8,     # Максимум 8 позиций в портфеле (увеличено с 5 до 8 для интрадей)
}
```

### В `signal_live.py`:

```python
MAX_POSITIONS = 4  # Устаревшая константа (не используется)
```

## 🔍 Как работают ограничения

### 1. **Ограничение на символ (max_positions_per_symbol = 1)**

**Логика:**

- По каждому символу (BTCUSDT, ETHUSDT, XRPUSDT и т.д.) можно открыть **только 1 позицию**
- Если позиция уже открыта, новые сигналы по этому символу **НЕ генерируются**
- DCA сигналы **генерируются** для существующих позиций

**Пример:**

```
✅ Открыта позиция BTCUSDT LONG
❌ Новые сигналы BTCUSDT LONG/SHORT НЕ генерируются
✅ DCA сигналы BTCUSDT генерируются для усреднения
```

### 2. **Ограничение на портфель (portfolio_max_positions = 8)**

**Логика:**

- Общее количество открытых позиций по всем символам не может превышать **8**
- При достижении лимита новые сигналы **НЕ генерируются**
- DCA сигналы **продолжают генерироваться** для существующих позиций

**Пример:**

```
Открытые позиции:
1. BTCUSDT LONG
2. ETHUSDT SHORT
3. XRPUSDT LONG
4. ADAUSDT LONG
5. DOGEUSDT SHORT
6. SOLUSDT LONG
7. LINKUSDT LONG
8. AVAXUSDT SHORT

❌ Новые сигналы НЕ генерируются (достигнут лимит 8)
✅ DCA сигналы продолжают генерироваться для всех 8 позиций
```

## 🔄 Генерация сигналов и ограничения

### **Новые торговые сигналы:**

**Проверки при генерации:**

1. ✅ Есть ли уже открытая позиция по символу
2. ✅ Не превышен ли лимит портфеля (8 позиций)
3. ✅ Выполнены ли технические условия
4. ✅ Нет ли дублирующих сигналов

**Если ограничения нарушены:**

- Сигнал **НЕ генерируется**
- В логах появляется сообщение о пропуске

### **DCA сигналы:**

**Проверки при генерации:**

1. ✅ Есть ли открытая позиция по символу
2. ✅ Достигнута ли просадка для DCA
3. ✅ Выполнены ли технические условия (90%)
4. ✅ Не превышены ли лимиты DCA (максимум 5 DCA)

**Важно:** DCA сигналы **НЕ зависят** от лимита портфеля!


## 📈 Преимущества системы ограничений

### 1. **Управление риском**

- Ограничивает максимальный риск на портфель
- Предотвращает концентрацию в одном активе

### 2. **Диверсификация**

- Принуждает к диверсификации по разным активам
- Снижает корреляционный риск

### 3. **Управление капиталом**

- Контролирует распределение капитала
- Предотвращает чрезмерное использование депозита

### 4. **Оптимизация для интрадей**

- 8 позиций позволяют активно торговать
- 1 позиция на символ предотвращает конфликты

## ✅ Заключение

**Система ограничений работает следующим образом:**

1. **Новые сигналы** генерируются только если:
   - Нет открытой позиции по символу
   - Не превышен лимит портфеля (8 позиций)

2. **DCA сигналы** генерируются независимо от лимита портфеля для:
   - Усреднения существующих позиций
   - Управления риском

3. **Ограничения защищают** от:
   - Чрезмерного риска
   - Концентрации в одном активе
   - Неэффективного использования капитала
