### 4. **Добавлена поддержка частичного закрытия**

Теперь система корректно определяет тип закрытия:

- **"ПОЗИЦИЯ ЗАКРЫТА"** - полное закрытие
- **"ПОЗИЦИЯ ЗАКРЫТА 50%"** - закрытие половины
- **"ПОЗИЦИЯ ЗАКРЫТА XX.X%"** - частичное закрытие

## 🔧 Технические изменения

### 1. **Удалено время принятия**

- Убрано поле "📅 Принят: dd.mm.yyyy hh:mm" из обычных сигналов
- Время остается только в DCA сигналах

### 2. **Изменен заголовок TP**

- **Было:** `📊 ПОЗИЦИЯ {symbol}:`
- **Стало:** `🎯 ТЕЙК ПРОФИТЫ:`

### 3. **Упрощена структура сообщения**

- Убрана избыточная информация о цене входа и объеме
- Оставлены только ключевые данные: TP1 и TP2

### 4. **Добавлена информация о балансе**

- Показывается обновленный депозит после закрытия
- Отображается свободный баланс для новых сделок
