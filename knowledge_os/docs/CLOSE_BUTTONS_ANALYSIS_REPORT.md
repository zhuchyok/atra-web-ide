## 🔍 **АНАЛИЗ ФУНКЦИОНАЛЬНОСТИ:**

### **📋 Доступные кнопки закрытия:**

#### **1. 🔴 Закрыть (все позиции):**

```python
callback_data=f"close_position|{symbol}|current|all"
```

- **Действие:** Закрывает всю позицию по текущей рыночной цене
- **Режим:** Автоматический
- **Цена:** Получается автоматически с биржи через `get_ohlc_binance_sync`

#### **2. 💰 Закрыть 50%:**

```python
callback_data=f"close_position|{symbol}|current|half"
```

- **Действие:** Закрывает половину позиции по текущей рыночной цене
- **Режим:** Автоматический
- **Цена:** Получается автоматически с биржи

#### **3. 📊 Детали позиции:**

```python
callback_data=f"position_details|{symbol}"
```

- **Действие:** Показывает детальную информацию о позиции
- **Режим:** Информационный
- **Включает:** P&L, текущую цену, TP1, TP2

#### **4. 📈 Обновить P&L:**

```python
callback_data=f"refresh_position|{symbol}"
```

- **Действие:** Обновляет P&L позиции по текущей цене
- **Режим:** Автоматический
- **Цена:** Получается автоматически с биржи

## 🔧 **ТЕХНИЧЕСКАЯ РЕАЛИЗАЦИЯ:**

### **📝 Обработчик кнопки `close_position`:**

```python
elif action == "close_position":
    symbol = data[1]
    close_price = data[2]  # "current" или конкретная цена
    close_qty = data[3]    # "all", "half" или количество

    # АВТОМАТИЧЕСКОЕ получение цены
    if close_price == "current":
        from exchange_api import get_ohlc_binance_sync
        ohlc = get_ohlc_binance_sync(symbol, interval="1m", limit=1)
        if not ohlc or len(ohlc) == 0:
            await query.message.reply_text(f"❌ Не удалось получить цену для {symbol}.")
            return
        close_price = ohlc[-1]["close"]  # ← АВТОМАТИЧЕСКАЯ цена

    # АВТОМАТИЧЕСКИЙ расчет прибыли
    profit = (
        (close_price - entry_price) * actual_qty if side == "long"
        else (entry_price - close_price) * actual_qty
    )

    # АВТОМАТИЧЕСКОЕ сохранение в историю
    user_data["trade_history"].append({
        "symbol": symbol,
        "side": side,
        "entry_price": entry_price,
        "close_price": close_price,
        "qty": actual_qty,
        "profit": profit,
        "close_time": datetime.now().isoformat(),
        "trade_mode": user_data.get("trade_mode", "spot"),
        "leverage": pos.get("leverage", 1)
    })

    # АВТОМАТИЧЕСКИЙ пересчет баланса
    balance_update = recalculate_balance_and_risks(user_data)
    save_user_data(context)
```
