# 📊 ОТЧЕТ: ИСПРАВЛЕНИЕ РАСЧЕТА СРЕДНЕЙ ЦЕНЫ В DCA

## 🎯 **ПРОБЛЕМА**

Пользователь сообщил о неправильном расчете средней цены в DCA позициях:

### **Пример проблемы:**

```
✅ Сигнал принят!
🔸 Символ: NEARUSDT
🔸 Сторона: LONG
🔸 Цена входа: 3.056
🔸 Количество: 84.645926

📈 DCA позиция добавлена!
🔸 Символ: NEARUSDT
🔸 DCA #3
🔸 Цена входа: 3.005
🔸 Количество: 82.519038
🔸 Средняя цена: 3.022  ← НЕПРАВИЛЬНО
```

**Проблема:** Бот показывал среднюю цену 3.022, но на бирже реальная средняя цена 3.039.

---

## 🔍 **АНАЛИЗ ПРОБЛЕМЫ**

### **Найденная причина:**

В функции `handle_dca_button` в файле `telegram_handlers.py` использовалась **старая средняя цена** вместо **новой средней цены** после добавления DCA позиции.

### **Проблемный код:**

```python
# Строка 2037 - использовалась старая средняя цена
f"🔸 Средняя цена: <code>${safe_format_price(avg_price, symbol)}</code>\n\n"
```

**Где:**

- `avg_price` - рассчитывалась на строке 1941 как средняя цена **до** добавления DCA
- `avg_price_new` - рассчитывалась на строке 1994 как средняя цена **после** добавления DCA

---

## ✅ **РЕШЕНИЕ**

### **1. Исправлен расчет средней цены в сообщении**

**Файл:** `telegram_handlers.py`  
**Строки:** 2028-2038

**БЫЛО:**

```python
dca_text = (
    # ... другие поля ...
    f"🔸 Средняя цена: <code>${safe_format_price(avg_price, symbol)}</code>\n\n"
    # ...
)
```

**СТАЛО:**

```python
# Используем правильную среднюю цену после DCA
try:
    # Пересчитываем среднюю цену с учетом всех позиций включая новую DCA
    positions = user_data.get('positions', []) or []
    symbol_positions = [p for p in positions if p.get('symbol') == symbol and p.get('status', 'open') == 'open']
    total_qty_new = sum(float(p.get('qty', 0)) for p in symbol_positions)
    avg_price_new = sum(float(p.get('entry_price', 0)) * float(p.get('qty', 0)) for p in symbol_positions) / max(1e-9, total_qty_new)
except (ValueError, TypeError, ZeroDivisionError):
    avg_price_new = avg_price  # Fallback на старую среднюю цену

dca_text = (
    # ... другие поля ...
    f"🔸 Средняя цена: <code>${safe_format_price(avg_price_new, symbol)}</code>\n"
    # ...
)
```

### **2. Добавлена информация о новых TP уровнях**

**Файл:** `telegram_handlers.py`  
**Строки:** 2040-2075

```python
# Получаем новые TP уровни для отображения
try:
    tp1_price_new = None
    tp2_price_new = None
    for p in symbol_positions:
        if p.get('tp1') and p.get('tp2'):
            tp1_price_new = p.get('tp1')
            tp2_price_new = p.get('tp2')
            break
except (ValueError, TypeError, KeyError):
    tp1_price_new = None
    tp2_price_new = None

# Добавляем информацию о TP если они рассчитаны
if tp1_price_new and tp2_price_new:
    tp1_pct = ((tp1_price_new - avg_price_new) / avg_price_new * 100) if avg_price_new > 0 else 0
    tp2_pct = ((tp2_price_new - avg_price_new) / avg_price_new * 100) if avg_price_new > 0 else 0
    dca_text += (
        f"🔸 TP1: <code>${safe_format_price(tp1_price_new, symbol)}</code> (+{tp1_pct:.2f}%)\n"
        f"🔸 TP2: <code>${safe_format_price(tp2_price_new, symbol)}</code> (+{tp2_pct:.2f}%)\n\n"
    )
```
