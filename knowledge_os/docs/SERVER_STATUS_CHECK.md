## 🔧 РЕШЕНИЕ

### Вариант 1: Установить переменные окружения

```bash
export TELEGRAM_TOKEN="PROD_TOKEN_REDACTED"
export TELEGRAM_TOKEN_DEV="DEV_TOKEN_REDACTED"
```

### Вариант 2: Создать .env файл

```bash
cd /root/atra
cat > .env << EOF
TELEGRAM_TOKEN=PROD_TOKEN_REDACTED
TELEGRAM_TOKEN_DEV=DEV_TOKEN_REDACTED
ATRA_ENV=prod
EOF
```

### Вариант 3: Проверить config.py

- Убедиться, что токены правильно загружаются из переменных окружения
