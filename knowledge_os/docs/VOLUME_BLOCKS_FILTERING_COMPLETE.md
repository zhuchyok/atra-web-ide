## 🚀 Что было добавлено

### 1. ✅ Система настраиваемой фильтрации

- **3 режима фильтрации:** STRICT, SOFT, ULTRA_SOFT
- **Настраиваемые пороги:** Отклонение, ослабление, усиление
- **Автоматическая привязка** к режимам сигналов

### 2. ✅ Логика отклонения сигналов

- **Отклонение противоречивых сигналов** при сильном несоответствии блоков
- **Ослабление сигналов** при умеренном противоречии
- **Усиление сигналов** при подтверждении блоками

### 3. ✅ Интеграция во все режимы

- **strict_entry_signal** → STRICT фильтрация
- **soft_entry_signal** → SOFT фильтрация
- **ultra_soft_entry_signal** → ULTRA_SOFT фильтрация


## 🔧 Технические детали

### Настройки фильтрации:

```python
BLOCK_FILTER_SETTINGS = {
    "strict": {
        "reject_threshold": 1.5,      # Отклонение при противоречии >50%
        "weaken_threshold": 1.2,      # Ослабление при противоречии >20%
        "strengthen_threshold": 0.8,  # Усиление при подтверждении >20%
    },
    "soft": {
        "reject_threshold": 2.0,      # Отклонение при противоречии >100%
        "weaken_threshold": 1.5,      # Ослабление при противоречии >50%
        "strengthen_threshold": 0.7,  # Усиление при подтверждении >30%
    },
    "ultra_soft": {
        "reject_threshold": 3.0,      # Отклонение при очень сильном противоречии
        "weaken_threshold": 2.0,      # Ослабление при сильном противоречии
        "strengthen_threshold": 0.6,  # Усиление при сильном подтверждении
    }
}
```

### Логика фильтрации:

1. **Расчет соотношения сил** блоков
2. **Применение порогов** в зависимости от режима
3. **Принятие решения:** отклонение/ослабление/усиление/нейтрально
4. **Логирование результата** с объяснением
