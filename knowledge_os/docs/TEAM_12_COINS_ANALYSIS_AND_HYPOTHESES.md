### Вариант 3: Адаптивные параметры по волатильности

**Идея**: Для монет с низкой волатильностью использовать более мягкие параметры.

**Реализация**:

```python
def get_adaptive_params(symbol, volatility):
    if volatility < 0.02:  # Низкая волатильность
        return {"rsi_oversold": 15, "rsi_overbought": 85, "ai_score_threshold": 2.0, "min_confidence": 55}
    elif volatility < 0.05:  # Средняя волатильность
        return {"rsi_oversold": 20, "rsi_overbought": 80, "ai_score_threshold": 3.0, "min_confidence": 60}
    else:  # Высокая волатильность
        return {"rsi_oversold": 25, "rsi_overbought": 75, "ai_score_threshold": 5.0, "min_confidence": 65}
```

**Плюсы**: Учитывает особенности каждой монеты
**Минусы**: Требует расчета волатильности
