# АНАЛИЗ ЛОГИКИ КОМАНДЫ /START

## 🎯 **КОГДА ПОЛЬЗОВАТЕЛЬ ИСПОЛЬЗУЕТ /START**

### ✅ **Сценарии использования команды /start:**

1. **🆕 Первый раз** - новый пользователь
2. **💰 Изменение депозита** - пользователь хочет изменить сумму
3. **📊 Смена режима торговли** - SPOT ↔ FUTURES
4. **🎯 Смена режима фильтров** - STRICT ↔ SOFT
5. **🔄 Полная перенастройка** - пользователь хочет все изменить

---

## 🔧 **ТЕКУЩАЯ ЛОГИКА ЗАЩИТЫ**

### ✅ **Что защищается (правильно):**

- **💰 Депозит**: Не перезаписывается на 0 или None
- **⚡ Плечо**: Не перезаписывается на 0 или None

### ⚠️ **Что НЕ должно защищаться (по логике):**

- **📊 Режим торговли**: Пользователь может захотеть сменить SPOT ↔ FUTURES
- **🎯 Режим фильтров**: Пользователь может захотеть сменить STRICT ↔ SOFT
- **🔧 Шаг настройки**: Должен сбрасываться для новой настройки

---

## 🎯 **ПРАВИЛЬНАЯ ЛОГИКА /START**

### ✅ **Команда /start должна:**

1. **🔄 Сбросить шаг настройки** на "deposit"
2. **💰 Позволить изменить депозит** (но защитить от 0)
3. **📊 Позволить изменить режим торговли** (SPOT/FUTURES)
4. **🎯 Позволить изменить режим фильтров** (STRICT/SOFT)
5. **⚡ Пересчитать плечо** на основе новых настроек

### ✅ **Что должно защищаться:**

- **💰 Депозит**: Только от установки в 0 или None
- **⚡ Плечо**: Только от установки в 0 или None
- **📈 Прибыль/убытки**: Не должны сбрасываться
- **📊 История торгов**: Не должна сбрасываться

- **⚡ Плечо**: Не должен случайно сброситься в 0
