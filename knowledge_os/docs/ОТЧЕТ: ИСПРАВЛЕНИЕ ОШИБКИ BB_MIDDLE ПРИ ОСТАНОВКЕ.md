## 🔍 ПРОБЛЕМА

Пользователь сообщил, что ошибка `[FearGreed] Ошибка расчета индекса: 'bb_middle'` возникает при остановке системы. Это происходило потому, что:

1. **При остановке системы** данные могут быть неполными
2. **Колонки индикаторов** могут отсутствовать в DataFrame
3. **Функция `calculate_fear_greed_index`** не проверяла существование колонок
4. **Ошибки выводились в лог** при остановке, засоряя его

## 🛠️ РЕШЕНИЕ

### 1. Создана безопасная версия функции

Заменили функцию `calculate_fear_greed_index` на более безопасную версию, которая:

- ✅ Проверяет существование всех колонок перед обращением к ним
- ✅ Обрабатывает исключения при остановке системы
- ✅ Использует fallback значения для всех индикаторов
- ✅ Не выводит ошибки в лог при остановке

### 2. Добавлены проверки данных

```python
# Безопасное получение индикаторов с проверкой существования колонок
try:
    bb_upper = df['bb_upper'].iloc[i] if 'bb_upper' in df.columns and not pd.isna(df['bb_upper'].iloc[i]) else current_price
    bb_lower = df['bb_lower'].iloc[i] if 'bb_lower' in df.columns and not pd.isna(df['bb_lower'].iloc[i]) else current_price
    bb_middle = df['bb_middle'].iloc[i] if 'bb_middle' in df.columns and not pd.isna(df['bb_middle'].iloc[i]) else current_price
    rsi = df['rsi'].iloc[i] if 'rsi' in df.columns and not pd.isna(df['rsi'].iloc[i]) else 50.0
    ema7 = df['ema7'].iloc[i] if 'ema7' in df.columns and not pd.isna(df['ema7'].iloc[i]) else current_price
    ema25 = df['ema25'].iloc[i] if 'ema25' in df.columns and not pd.isna(df['ema25'].iloc[i]) else current_price
except (IndexError, KeyError):
    return 50.0
```

### 3. Обработка исключений

```python
except Exception as e:
```

### 4. Fallback значения для всех компонентов

- **Волатильность**: 50.0 если ATR недоступен
