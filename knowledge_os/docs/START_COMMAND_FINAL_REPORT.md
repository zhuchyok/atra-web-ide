## 🔧 **ПРАВИЛЬНАЯ ЛОГИКА КОМАНДЫ /START**

### ✅ **Когда пользователь использует /start:**

1. **🔄 "Я хочу перенастроить бота"**
   - Сброс шага настройки на "deposit"
   - Возможность изменить все параметры

2. **💰 "Я хочу изменить депозит"**
   - Ввод нового депозита
   - Пересчет плеча

3. **📊 "Я хочу сменить режим торговли"**
   - Выбор SPOT или FUTURES
   - Автоматический пересчет плеча

4. **🎯 "Я хочу сменить режим фильтров"**
   - Выбор STRICT или SOFT
   - Изменение количества сигналов

---

## 🛡️ **ЗАЩИТА КРИТИЧЕСКИ ВАЖНЫХ ДАННЫХ**

### ✅ **Что защищается (от случайной потери):**

- **💰 Депозит**: Не перезаписывается на 0 или None
- **⚡ Плечо**: Не перезаписывается на 0 или None

### ✅ **Что НЕ защищается (сознательное изменение):**

- **📊 Режим торговли**: Пользователь может сменить SPOT ↔ FUTURES
- **🎯 Режим фильтров**: Пользователь может сменить STRICT ↔ SOFT
- **🔧 Шаг настройки**: Сбрасывается для новой настройки
