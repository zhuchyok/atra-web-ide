## 🚀 Инструкция деплоя

### 1. Загрузите файлы на сервер

### 2. Создайте `.env` файл:

```bash
TELEGRAM_TOKEN=ваш_токен_бота
TELEGRAM_TOKEN_DEV=ваш_токен_для_разработки
TELEGRAM_CHAT_IDS=ваши_chat_id
CRYPTOPANIC_API_KEY=ваш_ключ
NEWSDATA_API_KEY=ваш_ключ
```

### 3. Установите зависимости:

```bash
pip3 install -r requirements.txt
```

### 4. Создайте папки:

```bash
mkdir logs backups user_data_backups
```

### 5. Запустите систему:

```bash
python3 main.py
```

### 6. Для работы в фоне:

```bash
nohup python3 main.py > bot.log 2>&1 &
```

## 📊 Режимы сигналов

- **Строгий** (`balanced`) - меньше сигналов, но качественные
- **Мягкий** (`soft`) - больше сигналов для активной торговли
- **Ультра мягкий** (`ultra_soft`) - тестовый режим
