# 📊 ОБНОВЛЕНИЕ СТАТУСА ФИЛЬТРОВ

## 📅 Дата: 2024

## ⚠️ ОТКЛЮЧЕНЫ НЕЭФФЕКТИВНЫЕ ФИЛЬТРЫ

### 🔴 MOMENTUM FILTER

**Статус:** ❌ **ОТКЛЮЧЕН**

**Причина:**

- Не блокирует сигналы (0% блокировок)
- Не улучшает результат
- Фильтр слишком мягкий и не работает

**Параметры:**

- MFI: < 50.0 (LONG), > 50.0 (SHORT)
- Stoch RSI: < 50.0 (LONG), > 50.0 (SHORT)
- В мягком режиме: достаточно одного подтверждения

**Решение:** Отключен в `config.py` по умолчанию

---

### 🔴 TREND STRENGTH FILTER

**Статус:** ❌ **ОТКЛЮЧЕН**

**Причина:**

- Блокирует 70% сигналов
- Ухудшает return на -78.7%
- Фильтр слишком строгий, блокирует хорошие сигналы

**Параметры:**

- ADX: > 15.0 (мягкий режим, было 20.0)
- TSI: подтверждение направления
- В мягком режиме: достаточно ADX направления ИЛИ TSI

**Решение:** Отключен в `config.py` по умолчанию

## ✅ АКТИВНЫЕ ФИЛЬТРЫ

### 🟢 Volume Profile Filter

- **Статус:** ✅ Включен
- **Эффективность:** Блокирует 3.2% сигналов, улучшает return на +0.35%

### 🟢 VWAP Filter

- **Статус:** ✅ Включен
- **Эффективность:** Работает в комбинации с VP

### 🟢 Order Flow Filter

- **Статус:** ✅ Включен
- **Параметры:** `required_confirmations: 0, pr_threshold: 0.6`
- **Эффективность:** Ослабленные параметры, меньше блокировок

### 🟢 Microstructure Filter

- **Статус:** ✅ Включен
- **Параметры:** `tolerance_pct: 3.0, min_strength: 0.15, lookback: 40`
- **Эффективность:** Блокирует 86.5% сигналов ПОСЛЕ baseline

## 📝 КОНФИГУРАЦИЯ

**Файл:** `config.py`

```python
# Momentum фильтр - ОТКЛЮЧЕН
USE_MOMENTUM_FILTER = os.getenv("USE_MOMENTUM_FILTER", "false").lower() in ("1", "true", "yes")

# Trend Strength фильтр - ОТКЛЮЧЕН
USE_TREND_STRENGTH_FILTER = os.getenv("USE_TREND_STRENGTH_FILTER", "false").lower() in ("1", "true", "yes")
```

**Примечание:** Можно включить через переменные окружения при необходимости:

```bash
export USE_MOMENTUM_FILTER=true
export USE_TREND_STRENGTH_FILTER=true
```
