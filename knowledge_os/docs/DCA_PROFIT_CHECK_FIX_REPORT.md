# Отчет об исправлении логики DCA сигналов

## Проблема

Пользователь сообщил: **"и дца шлешь даже если у нас монета в плюсе"**

DCA сигналы отправлялись **всегда**, когда у пользователя была открытая позиция, независимо от того, была ли позиция в прибыли или в убытке. Это неправильно - DCA должен отправляться только при просадке позиции.

## Анализ проблемы

### ❌ Было:

- DCA сигналы отправлялись **автоматически** при наличии открытой позиции
- **НЕ проверялась** просадка позиции
- **НЕ использовалась** функция `should_dca()`
- DCA отправлялся даже когда позиция была в **+5%, +10%, +20%** прибыли

### ✅ Стало:

- DCA сигналы отправляются **только при просадке** позиции
- **Добавлена проверка** функции `should_dca()`
- DCA отправляется только когда позиция в **убытке более 2%**

## Исправления

### 1. ✅ DCA LONG сигналы (строка ~2486)

**Файл:** `signal_live.py`

**Добавлена проверка просадки:**

```python
# Проверяем, нужно ли отправлять DCA сигнал (только при просадке)
avg_entry_price = sum(q * p for q, p in zip(qtys, entry_prices)) / sum(qtys)
dca_pct = 2.0  # DCA при просадке 2%

# Для LONG позиции: DCA только если цена упала ниже средней цены входа на dca_pct%
if not should_dca("long", last['close'], avg_entry_price, dca_pct):
    print(f"[DEBUG] {symbol}: DCA LONG не нужен - позиция в плюсе или просадка меньше {dca_pct}%")
    continue

print(f"[DEBUG] {symbol}: DCA LONG нужен - просадка больше {dca_pct}%")
```

## Логика функции should_dca()

```python
def should_dca(side, last_close, stop_loss, dca_pct):
    """
    Возвращает True, если нужно предложить DCA:
    - для long: если цена <= stop_loss * (1 - dca_pct/100)
    - для short: если цена >= stop_loss * (1 + dca_pct/100)
    """
    if side == "long":
        return last_close <= stop_loss * (1 - dca_pct / 100)
    else:
        return last_close >= stop_loss * (1 + dca_pct / 100)
```

### Примеры работы:

**LONG позиция:**

- Средняя цена входа: $100
- DCA процент: 2%
- DCA сработает при цене ≤ $98 (просадка ≥ 2%)

**SHORT позиция:**

- Средняя цена входа: $100
- DCA процент: 2%
- DCA сработает при цене ≥ $102 (просадка ≥ 2%)
