## 🔍 3. ВЫЯВЛЕННЫЕ СЛАБЫЕ МЕСТА

### Проблема №1: Устаревший ML стек

- **Текущее**: GradientBoostingRegressor из sklearn
- **Проблема**: Медленнее LightGBM, хуже работает с категориальными признаками
- **Решение**: Переход на LightGBM

### Проблема №2: Только классификация

- **Текущее**: Предсказание только "успех/неудача"
- **Проблема**: Не учитывается размер прибыли
- **Решение**: Добавить регрессию для предсказания profit_pct

### Проблема №3: Статические параметры фильтров

- **Текущее**: Фиксированные пороги (min_volume_ratio = 1.2)
- **Проблема**: Не адаптируются к рыночным условиям
- **Решение**: Динамическая оптимизация через ML

### Проблема №4: Неполное использование features

- **Текущее**: Используется ~12 features
- **Проблема**: Много данных не используется (quality_score, mtf_score, sector и т.д.)
- **Решение**: Расширить feature engineering

## 🎯 5. ТОЧКИ РОСТА И ЗАДАЧИ

### Задача №1: Внедрение LightGBM классификатора

- **Цель**: Предсказание вероятности успеха сигнала (0-100%)
- **Ожидаемый результат**: Точность > 60%, Precision > 65%
- **Критерии успешности**:
  - ROC-AUC > 0.70
  - F1-score > 0.60
  - Улучшение win rate на 5-10%

### Задача №2: Внедрение LightGBM регрессора

- **Цель**: Предсказание размера прибыли в процентах
- **Ожидаемый результат**: MAE < 2%, R² > 0.30
- **Критерии успешности**:
  - Средняя ошибка < 2%
  - Корреляция предсказаний с реальностью > 0.50

### Задача №3: Комбинированная система оценки

- **Цель**: Объединение классификации и регрессии для итоговой оценки
- **Ожидаемый результат**: Combined Score = success_prob \* expected_profit
- **Критерии успешности**:
  - Улучшение Sharpe Ratio на 10-15%
  - Снижение количества ложных сигналов на 20%

### Задача №4: Feature Engineering

- **Цель**: Расширить набор признаков до 30-40
- **Ожидаемый результат**: Улучшение качества предсказаний
- **Критерии успешности**:
  - Feature importance анализ
  - Улучшение метрик на 5-10%

### Задача №5: Адаптивная оптимизация параметров

- **Цель**: Динамическая настройка фильтров на основе ML предсказаний
- **Ожидаемый результат**: Адаптация к рыночным условиям
- **Критерии успешности**:
  - Улучшение win rate в разных режимах рынка
  - Снижение просадок
