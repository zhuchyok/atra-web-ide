### 1. **Функции расчета плеча в `telegram_bot.py`**

#### **`calculate_base_leverage(deposit)`**

```python
def calculate_base_leverage(deposit):
    """
    Рассчитывает базовое плечо в зависимости от размера депозита
    """
    if deposit <= 0:
        return 1

    # Логика расчета базового плеча в зависимости от депозита
    if deposit < 100:
        return 1      # Маленький депозит - консервативное плечо
    elif deposit < 500:
        return 2      # Небольшой депозит - умеренное плечо
    elif deposit < 1000:
        return 3      # Средний депозит - стандартное плечо
    elif deposit < 5000:
        return 5      # Большой депозит - повышенное плечо
    elif deposit < 10000:
        return 8      # Очень большой депозит - высокое плечо
    else:
        return 10     # Максимальное плечо для крупных депозитов
```

#### **`calculate_risk_based_leverage(deposit, risk_tolerance)`**

```python
def calculate_risk_based_leverage(deposit, risk_tolerance="moderate"):
    """
    Рассчитывает плечо с учетом риск-менеджмента
    """
    base_leverage = calculate_base_leverage(deposit)

    # Множители в зависимости от риск-толерантности
    risk_multipliers = {
        "conservative": 0.5,    # Консервативный - уменьшаем плечо
        "moderate": 1.0,        # Умеренный - оставляем как есть
        "aggressive": 1.5       # Агрессивный - увеличиваем плечо
    }

    multiplier = risk_multipliers.get(risk_tolerance, 1.0)
    leverage = base_leverage * multiplier

    # Ограничиваем плечо от 1 до 20
    return max(1, min(leverage, 20))
```

#### **`calculate_user_leverage(deposit, trade_mode, filter_mode)`**

```python
def calculate_user_leverage(deposit, trade_mode, filter_mode):
    """
    Рассчитывает плечо для пользователя на основе его настроек
    """
    if trade_mode == "spot":
        # Для SPOT торговли плечо всегда 1
        return 1

    # Определяем риск-толерантность на основе режима фильтров
    if filter_mode == "soft":
        risk_tolerance = "aggressive"  # Мягкие фильтры = агрессивная торговля
    elif filter_mode == "balanced":
        risk_tolerance = "moderate"    # Сбалансированные фильтры = умеренная торговля
    else:
        risk_tolerance = "conservative"  # Строгие фильтры = консервативная торговля

    # Рассчитываем динамическое плечо
    return calculate_risk_based_leverage(deposit, risk_tolerance)
```

## 🔄 Логика расчета

### **Для SPOT торговли:**

- Плечо всегда = 1x (без плеча)

### **Для FUTURES торговли:**

1. **Базовое плечо** = f(депозит)
2. **Риск-множитель** = f(режим фильтров)
3. **Итоговое плечо** = базовое плечо × риск-множитель
4. **Ограничения:** от 1x до 20x

### **Связь режима фильтров с риск-толерантностью:**

- **Мягкие фильтры** → Агрессивная торговля (1.5x)
- **Сбалансированные фильтры** → Умеренная торговля (1.0x)
- **Строгие фильтры** → Консервативная торговля (0.5x)

- Показывает рассчитанное плечо пользователю
- Объясняет логику расчета
