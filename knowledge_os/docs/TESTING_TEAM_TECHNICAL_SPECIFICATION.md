### Процедура при обнаружении критических ошибок:

1. **Немедленно уведомить команду**
   - Создать сообщение в общем чате
   - Указать критичность и описание проблемы
   - Приложить логи и скриншоты

2. **Остановить тестирование** на проблемном модуле
   - Зафиксировать состояние
   - Сохранить логи
   - Не продолжать тестирование до исправления

3. **Создать детальный баг-репорт** с логами

   ```markdown
   # КРИТИЧЕСКАЯ ОШИБКА: [Название]

   ## Описание:

   ...

   ## Шаги воспроизведения:

   1. ...
   2. ...

   ## Ожидаемое поведение:

   ...

   ## Фактическое поведение:

   ...

   ## Логи:
   ```

   [Логи здесь]

   ```

   ## Скриншоты:
   [Если применимо]

   ## Окружение:
   - ОС: ...
   - Python: ...
   - Версия бота: ...
   - Режим: DEV/PROD
   ```

4. **Координировать с разработчиком** для исправления
   - Обсудить приоритет исправления
   - Согласовать сроки
   - Проверить исправление после внедрения

### Критические ошибки (требуют немедленного внимания):

- Падение бота без возможности восстановления
- Потеря данных (сигналы, позиции, ордера)
- Невозможность подключения к бирже
- Некорректное исполнение ордеров (неправильные суммы, цены)
- Утечки памяти, приводящие к падению системы
- Потеря связи с БД

## 📎 ПРИЛОЖЕНИЯ

### Приложение A: Структура БД

Основные таблицы:

- `signals_log` - все сгенерированные сигналы
- `accepted_signals` - принятые сигналы
- `rejected_signals` - отклоненные сигналы
- `order_audit_log` - аудит ордеров
- `active_positions` - активные позиции
- `filter_performance` - метрики фильтров
- `system_settings` - настройки системы
- `performance_metrics` - метрики производительности
- `user_settings` - настройки пользователей
- `signal_acceptance_log` - лог принятия сигналов

### Приложение C: Полезные SQL запросы

```sql
-- Количество сигналов за последние 24 часа
SELECT COUNT(*) FROM signals_log
WHERE created_at > datetime('now', '-24 hours');

-- Статистика по фильтрам
SELECT filter_name, COUNT(*) as count,
       AVG(passed) as pass_rate
FROM filter_performance
GROUP BY filter_name;

-- Активные позиции
SELECT * FROM active_positions
WHERE status = 'active';

-- Последние ордера
SELECT * FROM order_audit_log
ORDER BY created_at DESC
LIMIT 10;
```
