## 🛠️ **ИНСТРУКЦИИ ПО ИСПОЛЬЗОВАНИЮ**

### **1. Запуск с мониторингом:**

```bash
python3 start_with_monitor.py
```

### **2. Диагностика проблем:**

```bash
python3 diagnose_system.py
```

### **3. Установка systemd сервиса:**

```bash
# Копируем сервис
sudo cp atra.service /etc/systemd/system/

# Включаем автозапуск
sudo systemctl enable atra.service

# Запускаем сервис
sudo systemctl start atra.service

# Проверяем статус
sudo systemctl status atra.service
```

### **4. Мониторинг логов:**

```bash
# Логи основной системы
tail -f system_improved.log

# Логи мониторинга
tail -f monitor.log

# Логи systemd
sudo journalctl -u atra.service -f
```

## 🚀 **РЕКОМЕНДАЦИИ ПО ИСПОЛЬЗОВАНИЮ**

### **1. Настройка на сервере:**

```bash
# Установка зависимостей
pip3 install psutil

# Настройка systemd
sudo systemctl daemon-reload
sudo systemctl enable atra.service
sudo systemctl start atra.service
```

### **2. Мониторинг:**

```bash
# Проверка статуса
sudo systemctl status atra.service

# Просмотр логов
sudo journalctl -u atra.service -f

# Диагностика
python3 diagnose_system.py
```

### **3. Устранение проблем:**

```bash
# Перезапуск сервиса
sudo systemctl restart atra.service

# Просмотр ошибок
sudo journalctl -u atra.service --since "1 hour ago"

# Ручной запуск для отладки
python3 start_with_monitor.py
```
