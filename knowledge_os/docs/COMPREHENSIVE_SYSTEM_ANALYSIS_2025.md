   - Множественные сбои API (5-8 failures)
   - Rate limiting активен (1.8с - 6.6с ожидания)
   - **Причина:** Высокая нагрузка на Binance API
   - **Рекомендация:** Оптимизировать частоту запросов

2. **Отсутствие сигналов:**
   - Сигналы блокируются фильтрами
   - BTC в бычьем тренде → SHORT блокируются
   - Символы в медвежьем тренде → LONG блокируются
   - **Причина:** Строгие фильтры качества
   - **Рекомендация:** Проверить параметры фильтров
