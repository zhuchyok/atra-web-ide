## 📋 ТЕКУЩЕЕ СОСТОЯНИЕ ФИЛЬТРОВ

### **1. MACD ФИЛЬТР**

#### **Текущие параметры:**

```python
# src/core/config.py
"macd": {
    "fast_period": 12,
    "slow_period": 26,
    "signal_period": 9
}

# В коде используется min_strength: 0.005 (0.5%)
```

#### **Рекомендация:**

- `fast_period`: 12 → 8
- `slow_period`: 26 → 21
- `signal_period`: 9 → 5
- `min_strength`: 0.005 → 0.002
- Добавить `histogram_min`: 0.001

#### **Оценка:** ⚠️ **ТРЕБУЕТ ТЕСТИРОВАНИЯ**

**Плюсы:**

- ✅ Более быстрая реакция на изменения (8/21/5 быстрее чем 12/26/9)
- ✅ Меньше требований к силе расхождения (0.002 vs 0.005)
- ✅ Лучше для интрадей торговли

**Риски:**

- ⚠️ Более чувствительный = больше ложных сигналов
- ⚠️ Меньший период = больше шума
- ⚠️ Требует тестирования на исторических данных

**Рекомендация:**

- ✅ **Внедрить с осторожностью** - начать с тестирования
- ⚠️ **Сохранить старые параметры** как fallback
- ✅ **Добавить histogram_min** - хорошая идея

### **📊 АНАЛИЗ СТАТИСТИКИ**

#### **🔴 Критические проблемы:**

1. **RSI фильтр блокирует 71.65% сигналов:**
   - **Причина:** Требует вход в экстремальную зону (RSI < 25 для LONG, RSI > 75 для SHORT)
   - **Проблема:** Условие `prev_rsi >= rsi_oversold` и `prev_rsi <= rsi_overbought` слишком строгое
   - **Решение:** Ослабить условие входа или разрешить нахождение в зоне

2. **AI Volatility фильтр блокирует 14.81% сигналов:**
   - **Причина:** Волатильность вне допустимого диапазона
   - **Проблема:** Может быть слишком строгим для крипто
   - **Решение:** Расширить диапазон волатильности

3. **AI Score фильтр блокирует 11.16% сигналов:**
   - **Причина:** AI Score < 15.0 (порог для soft режима)
