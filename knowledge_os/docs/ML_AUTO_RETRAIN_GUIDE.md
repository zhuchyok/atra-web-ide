# 🤖 АВТОМАТИЧЕСКОЕ ПЕРЕОБУЧЕНИЕ LIGHTGBM

## 📋 ОПИСАНИЕ

Система автоматически переобучает LightGBM модели на сервере в фоновом режиме, используя новые данные из `trading_patterns.json`.

---

## ⚙️ КАК РАБОТАЕТ

### Условия для переобучения:

1. **Время**: Прошло минимум **7 дней** (168 часов) с последнего переобучения
2. **Данные**: Накопилось минимум **1000 новых паттернов** с результатами

### Процесс переобучения:

1. ✅ Проверяет условия (каждый час)
2. 💾 Создает backup текущих моделей
3. 🎯 Переобучает классификатор и регрессор
4. 💾 Сохраняет новые модели
5. 📊 Логирует метрики качества

---

## ⚙️ НАСТРОЙКА

### Параметры (в `lightgbm_auto_retrain.py`):

```python
LightGBMAutoRetrain(
    retrain_interval_hours=168,  # Интервал переобучения (7 дней)
    min_new_patterns=1000,        # Минимум новых паттернов
    model_dir="ai_learning_data/lightgbm_models",
    patterns_file="ai_learning_data/trading_patterns.json"
)
```

### Изменение интервала:

**Для более частого переобучения** (например, раз в 3 дня):

```python
retrain_interval_hours=72  # 3 дня
```

**Для более редкого переобучения** (например, раз в 2 недели):

```python
retrain_interval_hours=336  # 14 дней
```

### Изменение минимума паттернов:

**Для более строгого требования**:

```python
min_new_patterns=2000  # Нужно минимум 2000 новых паттернов
```

**Для более мягкого требования**:

```python
min_new_patterns=500   # Достаточно 500 новых паттернов
```

**Расположение:**


## ⚠️ ВАЖНЫЕ ЗАМЕЧАНИЯ

### 1. **Работает в фоне**

- Не блокирует основную работу системы
- Проверяет условия каждый час
- Переобучение происходит асинхронно

### 2. **Fail-Safe**

- При ошибке переобучения старые модели остаются
- Система продолжает работать со старыми моделями
- Ошибки логируются

### 3. **Ресурсы**

- Переобучение занимает ~5-10 секунд
- Использует CPU во время обучения
- Не требует дополнительной памяти

### 4. **Автоматическое обновление**

- После переобучения модели автоматически перезагружаются
- Не требуется перезапуск системы
- Новые предсказания используют обновленные модели
