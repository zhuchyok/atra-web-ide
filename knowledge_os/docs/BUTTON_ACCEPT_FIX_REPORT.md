## 🔍 **ДИАГНОСТИКА ПРОБЛЕМЫ**

### **❌ Обнаруженная проблема:**

Несоответствие формата `callback_data` между созданием кнопки и обработчиком.

### **🔍 Анализ кода:**

1. **В форматтере (`src/telegram/formatters.py`):**

   ```python
   # СТАРЫЙ ФОРМАТ (НЕПРАВИЛЬНЫЙ)
   "callback_data": f"accept_{symbol}_{entry_price}_{signal_type}"
   ```

2. **В обработчике (`telegram_handlers.py`):**
   ```python
   # ОЖИДАЕМЫЙ ФОРМАТ
   parts = data.split('_')
   symbol = parts[1]        # Символ
   entry_price = float(parts[2])  # Цена входа
   tp_price = float(parts[3])     # Take Profit
   side = parts[4]          # Сторона (LONG/SHORT)
   ```

### **🎯 Проблема:**

- Форматтер создавал: `accept_BTCUSDT_50000.0_LONG`
- Обработчик ожидал: `accept_BTCUSDT_50000.0_52000.0_LONG`
- Отсутствовал параметр `take_profit_1` в callback_data

---

## 🔧 **ИСПРАВЛЕНИЕ**

### **✅ Исправленный код в форматтере:**

```python
def create_signal_buttons(self, signal_data: Dict[str, Any]) -> List[List[Dict[str, Any]]]:
    """Создание кнопок для сигнала"""
    try:
        symbol = signal_data.get('symbol', 'UNKNOWN')
        signal_type = signal_data.get('signal', 'LONG')
        entry_price = signal_data.get('entry_price', 0)
        take_profit_1 = signal_data.get('take_profit_1', entry_price)  # ДОБАВЛЕНО

        buttons = [
            [
                {
                    "text": f"✅ Принять {signal_type}",
                    "callback_data": f"accept_{symbol}_{entry_price}_{take_profit_1}_{signal_type}"  # ИСПРАВЛЕНО
                },
                {
                    "text": "❌ Отклонить",
                    "callback_data": f"reject_{symbol}_{entry_price}"
                }
            ],
            [
                {
                    "text": "📊 Детали",
                    "callback_data": f"details_{symbol}_{entry_price}"
                },
                {
                    "text": "🔄 Обновить",
                    "callback_data": f"refresh_{symbol}"
                }
            ]
        ]

        return buttons

    except Exception as e:
        return []
```

### **🎯 Изменения:**

1. ✅ Добавлен параметр `take_profit_1` из данных сигнала
2. ✅ Исправлен формат `callback_data` для кнопки "Принять"
3. ✅ Теперь формат соответствует ожиданиям обработчика
