# 📋 РЕАЛЬНО РЕАЛИЗОВАННЫЕ КОМАНДЫ В СИСТЕМЕ

## ✅ Команды, которые РЕАЛЬНО работают:

### 🎯 Основные команды:

```
start - Запуск бота
help - Список команд
balance - Баланс и настройки
positions - Открытые позиции
status - Статус системы
last_signal - Последний сигнал
open_trades - Открытые позиции
report - Отчет
report_week - Недельный отчет
```

### 📊 Торговые команды:

```
trade_history - История сделок
active_signals - Активные сигналы
signal_stats - Статистика сигналов
accept - Принять сигнал
close - Закрыть позицию
clear_positions - Очистить позиции
confirm_close_all - Подтвердить закрытие всех позиций
```

### ⚙️ Настройки:

```
set_trade_mode - Режим торговли (spot/futures)
set_trade_mode_spot - Установить режим SPOT
set_trade_mode_futures - Установить режим FUTURES
set_filter_mode - Режим фильтров (balanced/soft/ultra_soft)
set_filter_balanced - Строгий режим (качество)
set_filter_soft - Мягкий режим (количество)
btc_filter - Фильтр BTC тренда
set_trading_hours - Установить торговые часы
set_balance - Установить баланс
set_risk - Установить риск
```

### 🧪 Тестирование:

```
test_signal - Тестовый сигнал
health - Проверка здоровья системы
ml_report - ML отчет
```

### 👥 Управление пользователями:

```
add_user - Добавить пользователя
remove_user - Удалить пользователя
list_users - Список пользователей
```

### 📈 Дополнительные:

```
pending_dca - Ожидающие DCA
pending_trades - Ожидающие сделки
complete_trade - Завершить сделку
stats - Статистика
myreport - Мой отчет
```

backup_users - Резервная копия пользователей
