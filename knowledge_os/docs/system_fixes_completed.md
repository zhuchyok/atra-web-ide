### **2. ✅ ИСПРАВЛЕНА ЛОГИКА DCA УСРЕДНЕНИЯ**

**Файл:** `dca_improvements.py`

#### **БЫЛО:**

```python
avg_entry_price = sum(p * q for p, q in zip(entry_prices, qtys)) / sum(qtys)
```

#### **СТАЛО:**

```python
# Правильный расчет средней цены для DCA
if not entry_prices or not qtys or len(entry_prices) != len(qtys):
    avg_entry_price = current_price
else:
    total_cost = sum(p * q for p, q in zip(entry_prices, qtys))
    total_qty = sum(qtys)
    avg_entry_price = total_cost / total_qty if total_qty > 0 else current_price
```

**РЕЗУЛЬТАТ:** DCA усреднение работает корректно!
