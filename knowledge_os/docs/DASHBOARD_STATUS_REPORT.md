2. **Статистические карточки**
   - Всего сигналов

   - Общий P&L с цветовой индикацией
   - Винрейт %

3. **Список сигналов (20 последних)**
   - Символ криптовалюты
   - Тип сигнала (LONG/SHORT/CLOSED)
   - Цена входа
   - **Количество** (изменено - теперь показывается перед TP1)
   - **TP1** (изменено - теперь показывается после количества)
   - TP2
   - Статус
   - Время создания

4. **Интерактивные графики (Chart.js)**
   - График цен входа по символам
   - Круговая диаграмма топ-5 символов

5. **Адаптивная верстка**
   - ✅ Desktop: Полная функциональность
   - ✅ Tablet (< 1024px): Одноколоночная верстка для основного контента
   - ✅ Mobile (< 768px): 2 колонки для деталей сигналов
   - ✅ Small Mobile (< 480px): 1 колонка для деталей сигналов

6. **Автообновление**
   - Каждые 30 секунд
   - Обновляет сигналы, статистику и графики

7. **Кнопка ручного обновления**
   - Позволяет обновить данные по требованию
