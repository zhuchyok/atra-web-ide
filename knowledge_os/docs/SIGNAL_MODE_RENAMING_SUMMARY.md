Переименование режимов сигналов для лучшего понимания пользователями:

- **balanced** → **"Строгий"** (меньше сигналов, но качественные)

## 🎯 Команды для пользователей

### Быстрые команды:

- `/set_filter_balanced` - быстрая установка **Строгого** режима
- `/set_filter_soft` - быстрая установка **Мягкого** режима

### Команды с параметрами:

- `/set_filter_mode balanced|soft` - установка режима через команду

### BotFather команды:

```
set_filter_mode - Режим фильтров (balanced/soft/ultra_soft)
set_filter_balanced - Строгий режим (качество)
set_filter_soft - Мягкий режим (количество)
```

## 🔧 Логика режимов

### Строгий (balanced):

- Меньше сигналов, но качественные
- Более безопасная торговля
- Оптимальное количество для большинства пользователей

### Мягкий (soft):

- Больше сигналов
- Более активная торговля
- Для опытных трейдеров

### Ультра мягкий (ultra_soft):

- Тестовый режим
- Максимальное количество сигналов
- Только для тестирования
