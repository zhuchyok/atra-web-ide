# 📋 Управление пользователями торговой системы

## 🎯 Обзор системы

Торговая система поддерживает **многопользовательский режим**, где каждый пользователь может иметь свои индивидуальные настройки:

- 💰 **Депозит** - сумма для расчета позиций
- 📈 **Режим торговли** - spot или futures
- 🔧 **Режим фильтров** - strict, soft, enhanced
- 📰 **Режим новостей** - conservative, aggressive, technical_only, news_only
- ⚡ **Базовое плечо** - основа для динамического расчета плеча
- 🎯 **Динамические параметры** - риск, плечо, TP/SL рассчитываются автоматически

## 🔧 Управление через скрипт

### Установка и запуск

```bash
# Активируем виртуальное окружение
source .venv/bin/activate

# Показываем справку
python3 manage_users.py help
```

### Основные команды

#### 1. Добавление пользователя

```bash
# Простое добавление с настройками по умолчанию
python3 manage_users.py add 123456789

# Добавление с полными настройками
python3 manage_users.py add 123456789 2000 futures enhanced aggressive 5
```

**Параметры:**

- `user_id` - ID пользователя Telegram
- `deposit` - депозит в USDT (по умолчанию 1000)
- `trade_mode` - режим торговли: spot/futures (по умолчанию spot)
- `filter_mode` - режим фильтров: strict/soft/enhanced (по умолчанию strict)
- `news_mode` - режим новостей: conservative/aggressive/technical_only/news_only (по умолчанию conservative)
- `base_leverage` - базовое плечо для futures (по умолчанию 1)

#### 2. Просмотр списка пользователей

```bash
python3 manage_users.py list
```

#### 3. Обновление настроек пользователя

```bash
# Изменение депозита
python3 manage_users.py update 123456789 deposit 2500

# Изменение риска
python3 manage_users.py update 123456789 risk_pct 5

# Изменение режима торговли
python3 manage_users.py update 123456789 trade_mode futures
```

#### 4. Удаление пользователя

```bash
python3 manage_users.py remove 123456789
```

## 📊 Режимы фильтров

### 🔒 Strict (Строгий)

- **Описание:** Максимально консервативные условия входа
- **Применение:** Для начинающих трейдеров
- **Риск:** Низкий

### 🔓 Soft (Мягкий)

- **Описание:** Более мягкие условия входа
- **Применение:** Для опытных трейдеров
- **Риск:** Средний

### 🚀 Enhanced (Улучшенный)

- **Описание:** Продвинутые алгоритмы с множественными индикаторами
- **Применение:** Для профессиональных трейдеров
- **Риск:** Высокий

## 📰 Режимы новостей

### 🛡️ Conservative (Консервативный)

- **Блокировка по негативным новостям:** ✅ Да
- **Генерация LONG по позитивным:** ✅ Да
- **Блокировка SHORT при позитивных:** ✅ Да
- **Описание:** Полный новостной фон

### ⚡ Aggressive (Агрессивный)

- **Блокировка по негативным новостям:** ❌ Нет
- **Генерация LONG по позитивным:** ✅ Да
- **Блокировка SHORT при позитивных:** ❌ Нет
- **Описание:** Только позитивные новости

### 🔧 Technical Only (Только технический анализ)

- **Блокировка по негативным новостям:** ❌ Нет
- **Генерация LONG по позитивным:** ❌ Нет
- **Блокировка SHORT при позитивных:** ❌ Нет
- **Описание:** Игнорирует все новости

### 📰 News Only (Только новости)

- **Блокировка по негативным новостям:** ✅ Да
- **Генерация LONG по позитивным:** ✅ Да
- **Блокировка SHORT при позитивных:** ✅ Да
- **Описание:** Только новостные сигналы

## 🔄 Автоматическое добавление пользователей

### Через Telegram бота (для администраторов)

В Telegram боте доступны команды для управления пользователями:

- `/add_user <user_id> [deposit] [risk_pct] [trade_mode]` - добавление пользователя
- `/remove_user <user_id>` - удаление пользователя
- `/list_users` - просмотр списка пользователей

**Пример:**

```
/add_user 123456789 2000 3 futures
```

## 📁 Структура данных

Данные пользователей хранятся в файле `user_data.json`:

```json
{
  "123456789": {
    "trade_mode": "futures",
    "deposit": 2000,
    "risk_pct": 3,
    "filter_mode": "strict",
    "news_filter_mode": "conservative",
    "open_positions": [],
    "accepted_signals": []
  }
}
```

## ⚠️ Важные замечания

1. **ID пользователя** - это числовой ID из Telegram
2. **Депозит** используется для расчета размера позиций
3. **Динамический риск** - рассчитывается автоматически на основе волатильности и тренда (1-5%)
4. **Динамическое плечо** - рассчитывается на основе базового плеча, тренда и волатильности (1-20x)
5. **Динамические TP/SL** - адаптируются под волатильность рынка
6. **Режим торговли** определяет доступные типы сигналов:
   - `spot` - только LONG сигналы
   - `futures` - LONG и SHORT сигналы
7. **Фильтры** влияют на частоту и качество сигналов
8. **Новости** могут блокировать или усиливать сигналы

## 🔧 Устранение неполадок

### Проблема: Пользователь не получает сигналы

**Решение:**

1. Проверьте, что пользователь добавлен в систему: `python3 manage_users.py list`
2. Убедитесь, что ID пользователя корректный
3. Проверьте настройки торговых часов пользователя

### Проблема: Ошибка при добавлении пользователя

**Решение:**

1. Проверьте формат ID (должен быть числом)
2. Убедитесь, что пользователь не существует: `python3 manage_users.py list`
3. Проверьте корректность параметров

### Проблема: Система не видит новых пользователей

**Решение:**

1. Перезапустите основную систему: `python3 main.py`
2. Проверьте права доступа к файлу `user_data.json`
3. Убедитесь, что файл не поврежден

При возникновении проблем:

2. Убедитесь в корректности настроек
