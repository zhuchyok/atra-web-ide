# Удаление стоп-лосса из сигналов (DCA стратегия)

## 📋 Описание

Успешно удален стоп-лосс из всех торговых сигналов в соответствии с DCA (Dollar-Cost Averaging) стратегией. Система теперь фокусируется на усреднении позиций, а не на стоп-лоссах.

## 🎯 Логика DCA стратегии

### Основные принципы:

1. **Усреднение позиций** - покупка дополнительных лотов при падении цены
2. **Отсутствие стоп-лосса** - позиции не закрываются по стоп-лоссу
3. **Фокус на тейк-профитах** - выход только по достижению TP1 или TP2
4. **Динамические параметры** - TP и риск рассчитываются динамически

### Преимущества DCA:

- **Снижение среднего входа** - усреднение улучшает точку входа
- **Устойчивость к волатильности** - позиции не закрываются преждевременно
- **Потенциал большей прибыли** - возможность дождаться разворота тренда
- **Психологическая стабильность** - меньше эмоциональных решений

## 🔄 Логика усреднения

### Условия для DCA:

```python
def should_dca(side, last_close, stop_loss, dca_pct):
    """
    Определяет, нужно ли усреднение позиции
    - для long: если цена <= stop_loss * (1 - dca_pct/100)
    - для short: если цена >= stop_loss * (1 + dca_pct/100)
    """
    if side == "long":
        return last_close <= stop_loss * (1 - dca_pct / 100)
    else:
        return last_close >= stop_loss * (1 + dca_pct / 100)
```
