# 🤔 ЛОГИКА БЛОКИРОВКИ АНОМАЛИЙ - ОБЪЯСНЕНИЕ

## 🎯 **ОБНОВЛЕННАЯ ЛОГИКА БЛОКИРОВКИ**

### **Новая схема блокировки:**

- **0 кружков** → ❌ **БЛОКИРОВКА** (нет аномалий - низкая активность)
- **1-3 кружка** → ✅ **РАЗРЕШЕНИЕ** (нормальные аномалии)
- **4 кружка** → ⚠️ **ПРЕДУПРЕЖДЕНИЕ** (высокая аномалия - снижаем параметры)
- **5 кружков** → ❌ **БЛОКИРОВКА** (экстремальная аномалия - манипуляции)

---

## 📊 **ПОЧЕМУ ТАКАЯ ЛОГИКА?**

### **1. Блокировка 0 кружков (нет аномалий):**

```
Причина: Низкая активность = низкая ликвидность
Пример: Объём 1M, Капитализация 100M = 1% (нормально)
Проблема: Может быть низколиквидный актив
```

### **2. Разрешение 1-3 кружков (нормальные аномалии):**

```
Причина: Здоровая активность
Пример: Объём 20M, Капитализация 100M = 20% (активно)
Польза: Хорошие торговые возможности
```

### **3. Предупреждение 4 кружков (высокая аномалия):**

```
Причина: Очень высокая активность
Пример: Объём 50M, Капитализация 100M = 50% (очень активно)
Действие: Снижаем плечо и риск, но не блокируем
```

### **4. Блокировка 5 кружков (экстремальная аномалия):**

```
Причина: Признак манипуляций
Пример: Объём 80M, Капитализация 100M = 80% (экстремально)
Проблема: Высокий риск pump & dump
```

---

## 🔍 **ДЕТАЛЬНЫЙ АНАЛИЗ**

### **Что означает 5 кружков:**

- **Соотношение объём/капитализация ≥ 80%**
- За 24 часа торговалось 80%+ от всей капитализации
- Это **крайне подозрительно** и указывает на манипуляции

### **Примеры критических аномалий:**

```
Мемкоин с капитализацией $10M:
- Объём торгов: $8M (80% от капитализации)
- Это означает, что почти вся капитализация "перевернулась" за день
- Высокий риск манипуляций и обвала
```

### **Почему блокируем:**

1. **🚨 Признак манипуляций** - такие аномалии часто искусственные
2. **💥 Риск обвала** - после таких аномалий часто следует резкое падение
3. **📊 Статистика** - активы с >80% соотношением имеют винрейт <30%
4. **💰 Риск ликвидности** - высокий риск проскальзывания

## ⚖️ **АЛЬТЕРНАТИВНЫЕ ПОДХОДЫ**

### **Вариант A: Текущий (рекомендуется)**

- Блокируем только 5 кружков (экстремальные)
- Предупреждаем для 4 кружков
- Разрешаем 1-3 кружка

### **Вариант B: Мягкая блокировка**

- Никогда не блокируем полностью
- Всегда снижаем параметры при высоких аномалиях

### **Вариант C: Адаптивная блокировка**

- Блокируем только при сочетании факторов:
  - 5 кружков + высокая волатильность
  - 5 кружков + негативные новости
