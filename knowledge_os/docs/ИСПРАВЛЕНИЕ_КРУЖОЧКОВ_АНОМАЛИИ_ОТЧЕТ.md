## ✅ РЕШЕНИЕ

### **Исправления внесены в файл `signal_live.py`:**

#### **1. Функция `get_anomaly_emoji` (строка 4562):**

```python
def get_anomaly_emoji(circles_count):
    """
    Возвращает эмодзи для индикатора аномалии
    """
    emoji_map = {
        0: "⚪",  # Без кружков - белый кружок (ИСПРАВЛЕНО)
        1: "🟢",  # 1 кружок
        2: "🟢🟢",  # 2 кружка
        3: "🟢🟢🟢",  # 3 кружка
        4: "🟢🟢🟢🟢",  # 4 кружка
        5: "🟢🟢🟢🟢🟢"  # 5 кружков
    }
    return emoji_map.get(circles_count, "⚪")  # Fallback тоже исправлен
```

#### **2. Изменения:**

- **Было**: `0: ""` → **Стало**: `0: "⚪"`
- **Было**: `return emoji_map.get(circles_count, "")` → **Стало**: `return emoji_map.get(circles_count, "⚪")`
