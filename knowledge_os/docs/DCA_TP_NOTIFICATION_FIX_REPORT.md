> но уведомления о тп1 и тп2 не приходили"

## 🔍 Диагностика

### Причина проблемы:

После принятия DCA сигнала система:

1. ✅ **Правильно** рассчитывает новую среднюю цену
2. ✅ **Правильно** рассчитывает новые TP1 и TP2 от новой средней цены
3. ✅ **Правильно** обновляет `tp1` и `tp2` в позиции
4. ❌ **НЕ сбрасывает** флаг `tp1_notified` и `stage` после обновления TP

Это означает, что функция `check_take_profits()` проверяет флаг `tp1_notified` и `stage`, и если они уже установлены (от предыдущих TP), то уведомления не отправляются.

### Код проверки TP1 в `signal_live.py`:

```python
if (
    tp1_reached
    and pos.get("stage") == "open"  # Проверка stage
    and not bool(pos.get("tp1_notified"))  # Проверка флага
):
```

## ✅ Исправление

### Файл: `telegram_handlers.py`, строки 1977-1991

**БЫЛО:**

```python
# Обновляем TP во всех открытых позициях символа
for p in symbol_positions:
    p['tp1'] = tp1_price_new
    p['tp2'] = tp2_price_new
```

**СТАЛО:**

```python
# Обновляем TP во всех открытых позициях символа
for p in symbol_positions:
    old_tp1 = p.get('tp1')
    old_tp2 = p.get('tp2')
    p['tp1'] = tp1_price_new
    p['tp2'] = tp2_price_new
    # КРИТИЧЕСКИ ВАЖНО: сбрасываем флаги и stage для отслеживания новых TP
    p['tp1_notified'] = False  # Сбрасываем флаг уведомления TP1
    p['stage'] = 'open'  # Сбрасываем stage на 'open' для отслеживания новых TP
    logging.info(f"[DCA] {symbol}: Обновлены TP после усреднения: "
                 f"TP1: {old_tp1:.6f} → {tp1_price_new:.6f}, "
                 f"TP2: {old_tp2:.6f} → {tp2_price_new:.6f}, "
                 f"Средняя цена: {avg_price_new:.6f}")
```

### Что изменилось:

1. ✅ **Добавлен сброс флага `tp1_notified`** - флаг теперь сбрасывается на `False`, чтобы система могла отправить уведомление о новом TP1
2. ✅ **Добавлен сброс `stage`** - stage теперь сбрасывается на `'open'`, чтобы система могла отслеживать новые TP
3. ✅ **Добавлено логирование** - система теперь логирует обновление TP для отладки

## 🎯 Ожидаемый результат после исправления
