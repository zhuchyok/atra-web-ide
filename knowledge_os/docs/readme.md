# Автоматизированный портфельный крипто-бэктестер PiuX_Trade

## Описание

Профессиональный Python-проект для автоматического отбора монет, портфельного бэктеста и анализа стратегий mean-reversion на крипторынке с интеграцией в Telegram.

- **Автоматический выбор монет**: расширенный фильтр по объёму, тренду, волатильности (до 50 монет).
- **Портфельный бэктест**: одновременное управление несколькими позициями, корреляционный фильтр, риск-менеджмент.
- **Визуализация**: автоматическое построение equity curve.
- **Telegram-отчёт**: отправка итоговых метрик и графика в Telegram-бота.

---

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone ...
   cd piux_trade
   ```
2. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

   (Для визуализации: `pip install matplotlib`)

3. Укажите токен и chat_id Telegram-бота в `config.py` или через переменные окружения.

---

## Запуск

```bash
python main.py
```

- Автоматически выберет лучшие монеты, проведёт портфельный бэктест, построит график equity curve и отправит отчёт и график в Telegram.
- График equity curve сохраняется в `equity_curve_portfolio_meanrev.png`.

---

## Структура проекта

- `main.py` — основной pipeline: запуск бэктеста, визуализация, Telegram-отчёт.
- `backtest.py` — портфельный бэктест, фильтрация монет.
- `exchange_api.py` — функции для получения данных с биржи и фильтрации монет.
- `utils_visualization.py` — построение графиков equity curve.
- `telegram_bot.py` — отправка сообщений и графиков в Telegram.
- `requirements.txt` — зависимости.

## 🧪 Тестирование

1. **Установка pytest:**

   ```bash
   pip install pytest
   ```

2. **Запуск всех тестов:**

   ```bash
   pytest
   ```

   или для конкретного файла:

   ```bash
   pytest test_signal_generation.py
   ```

3. **Если тесты лежат в папке tests/:**

   ```bash
   pytest tests/
   ```

4. **Что делать, если тест не проходит:**
   - Внимательно прочитайте ошибку в выводе pytest.
   - Обычно будет показано, какая функция и с какими параметрами дала сбой.
   - Исправьте код или тест, затем снова запустите pytest.

5. **Как добавить новый тест:**
   - Создайте функцию с именем, начинающимся на test* в любом файле test*\*.py.
   - Используйте обычные assert для проверки условий.
   - Пример:
     ```python
     def test_my_function():
         assert my_function(2, 2) == 4
     ```

6. **(Опционально) Для сложных тестов используйте фикстуры, mock, parametrize — см. [документацию pytest](https://docs.pytest.org/ru/stable/).**

## 📊 Профилирование и мониторинг производительности

### Автоматическое профилирование

Система автоматически профилирует время выполнения ключевых функций:

- `main_loop` - основной цикл обработки сигналов
- `check_and_send_signals` - проверка и отправка сигналов
- `get_ohlc_binance_sync` / `get_ohlc_bybit_sync` - получение OHLC данных
- `button` - обработка кнопок Telegram
- `myreport_cmd` - генерация отчётов
- `run_telegram_bot` - запуск Telegram бота
- `get_filtered_top_usdt_pairs` - фильтрация торговых пар
- `send_signals_report` - отправка отчётов
- `get_daily_stats` - получение дневной статистики

