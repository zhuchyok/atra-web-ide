# Исправление формата TP в сигналах

## 🎯 Проблема

Пользователь заметил неправильный формат отображения TP в сигналах:

- **Было**: `🎯 🎯 TP1: 3.3762 (+2.0%) | 🚀 TP2: 3.4437 (+4.1%)`
- **Должно быть**: `🎯 TP1: 186.47 (+2.9%)\n🚀 TP2: 188.60 (+4.1%)`

## ❌ Что было неправильно:

- **Дублирование эмодзи**: `🎯 🎯` вместо `🎯`
- **Неправильный разделитель**: `|` вместо переноса строки `\n`
- **Отсутствие HTML форматирования**: нет тегов `<code>`

## ✅ Исправления

### 1. Исправлен формат в накопленных DCA сигналах (строка 5303)

**Было:**

```python
tp_info = f"🎯 TP1: <code>{fmt.format(tp1)}</code> ({'+' if side == 'long' else '-'}{tp1_pct:.1f}%) | 🚀 TP2: <code>{fmt.format(tp2)}</code> ({'+' if side == 'long' else '-'}{tp2_pct:.1f}%)"
```

**Стало:**

```python
tp_info = f"🎯 TP1: <code>{fmt.format(tp1)}</code> (+{tp1_pct:.1f}%)\n🚀 TP2: <code>{fmt.format(tp2)}</code> (+{tp2_pct:.1f}%)"
```

### 2. Исправлен формат в обычных сигналах (строка 4497)

**Было:**

```python
tp_info = f"TP1: {fmt.format(tp1)} (+{tp1_pct:.1f}%)\n🚀 TP2: {fmt.format(tp2)} (+{tp2_pct:.1f}%)"
```

**Стало:**

```python
tp_info = f"🎯 TP1: <code>{fmt.format(tp1)}</code> (+{tp1_pct:.1f}%)\n🚀 TP2: <code>{fmt.format(tp2)}</code> (+{tp2_pct:.1f}%)"
```

## 🔧 Технические изменения

### 1. Единообразный формат

- **Эмодзи**: `🎯` для TP1, `🚀` для TP2
- **HTML теги**: `<code>` для цен
- **Разделитель**: `\n` (перенос строки) вместо `|`
- **Процент**: всегда `+` для прибыли

### 2. Структура отображения

```
🎯 TP1: <code>186.47</code> (+2.9%)
🚀 TP2: <code>188.60</code> (+4.1%)
```
