## 🔧 Добавленное логирование

### 1. **Логирование отправки сигналов**

#### **Начало отправки:**

```python
print(f"[DEBUG] Начинаем отправку {len(signals)} сигналов пользователям...")
```

#### **Обработка каждого сигнала:**

```python
print(f"[DEBUG] Обрабатываем сигнал {side} для {symbol} пользователю {target_user_id}")
```

#### **Проверка пользователя:**

```python
if not user_data:
    print(f"[DEBUG] ❌ Пользователь {target_user_id} не найден в user_data")
    continue

print(f"[DEBUG] ✅ Пользователь {target_user_id} найден, режим торговли: {user_data.get('trade_mode', 'spot')}")
```

#### **Проверка режима торговли:**

```python
if side == "short" and trade_mode != 'futures':
    print(f"[DEBUG] ❌ Пропускаем SHORT сигнал для пользователя {target_user_id} (режим: {trade_mode})")
    continue

print(f"[DEBUG] ✅ Режим торговли подходит для сигнала {side}")
```

#### **Проверка торговых часов:**

```python
trading_hours_check = check_user_trading_hours(user_data)
print(f"[DEBUG] Проверка торговых часов для пользователя {target_user_id}: {trading_hours_check}")
if not trading_hours_check:
    print(f"[DEBUG] ❌ Пропускаем сигнал для пользователя {target_user_id} (вне торговых часов)")
    continue

print(f"[DEBUG] ✅ Торговые часы подходят")
```

#### **Отправка сигнала:**

```python
print(f"[DEBUG] 🚀 Отправляем сигнал {side} для {symbol} пользователю {target_user_id}...")
result = await notify_user(int(target_user_id), msg, reply_markup=keyboard)

if result:
    print(f"[DEBUG] ✅ Сигнал {side} для {symbol} успешно отправлен пользователю {target_user_id}")
else:
    print(f"[DEBUG] ❌ Сигнал {side} для {symbol} НЕ отправлен пользователю {target_user_id} (ошибка в notify_user)")
```

### 2. **Логирование функции notify_user**

#### **Начало отправки:**

```python
print(f"[notify_user] 🚀 Начинаем отправку сообщения пользователю {user_id}")
print(f"[notify_user] 📝 Длина текста: {len(text)} символов")
```

#### **Попытки отправки:**

```python
print(f"[notify_user] 🔄 Попытка {attempt + 1}/{max_retries} отправки пользователю {user_id}")
```

### 3. **Логирование торговых часов**

#### **Проверка настроек:**

```python
if not th:
    print(f"[check_user_trading_hours] ✅ Торговые часы не установлены - разрешаем торговлю")
    return True
```

#### **Текущее время:**

```python
print(f"[check_user_trading_hours] 🕐 Текущий час: {hour}, торговые часы: {start}-{end}")
```

#### **Результат проверки:**

```python
# Обычный случай
result = start <= hour < end
print(f"[check_user_trading_hours] 📅 Обычный случай: {start} <= {hour} < {end} = {result}")

# Переход через полночь
result = hour >= start or hour < end
print(f"[check_user_trading_hours] 🌙 Переход через полночь: {hour} >= {start} or {hour} < {end} = {result}")
```

## 🎯 Возможные проблемы и их диагностика

### **1. Пользователь не найден:**

```
[DEBUG] ❌ Пользователь 123456789 не найден в user_data
```

**Решение:** Проверить `user_data.json`, добавить пользователя

### **2. Неподходящий режим торговли:**

```
[DEBUG] ❌ Пропускаем SHORT сигнал для пользователя 958930260 (режим: spot)
```

**Решение:** Переключить пользователя на futures режим

### **3. Вне торговых часов:**

```
[check_user_trading_hours] 🕐 Текущий час: 23, торговые часы: 9-18
[check_user_trading_hours] 📅 Обычный случай: 9 <= 23 < 18 = False
[DEBUG] ❌ Пропускаем сигнал для пользователя 958930260 (вне торговых часов)
```

**Решение:** Настроить торговые часы или отключить их

### **4. Ошибка отправки:**

```
[notify_user] ❌ Попытка 1/3 - Ошибка отправки пользователю 958930260: Chat not found
[DEBUG] ❌ Сигнал long для ADAUSDT НЕ отправлен пользователю 958930260 (ошибка в notify_user)
```

**Решение:** Проверить токен бота, права доступа
