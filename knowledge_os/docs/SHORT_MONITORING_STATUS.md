## 📝 ПРИМЕЧАНИЯ

1. **SHORT паттерны генерируются только при определенных условиях:**
   - Медвежий тренд (цена ниже EMA)
   - EMA кроссовер (ema_fast < ema_slow)
   - RSI не перепродан (RSI > 30)
   - Высокий объем (для альтернативных паттернов)

2. **SHORT сигналы работают только для `trade_mode=futures`:**
   - Для пользователей с `trade_mode=spot` SHORT паттерны будут блокироваться
   - Это ожидаемое поведение (SHORT доступен только на фьючерсах)

3. **Текущий BTC тренд:** BEAR (медвежий)
   - Это способствует генерации SHORT паттернов
   - BUY сигналы блокируются BTC фильтром
