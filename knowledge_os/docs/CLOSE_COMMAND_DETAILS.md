# 🔴 КОМАНДА `/close` - ЗАКРЫТИЕ ПОЗИЦИЙ

## 📅 Дата: 27 июля 2025

## 🎯 Обзор

Команда `/close` - это безопасная и гибкая система для закрытия торговых позиций с подтверждением и детальным расчетом прибыли/убытков.

## 📋 **ФОРМАТЫ КОМАНДЫ**

### 🎯 **Основные варианты:**

```
/close                           - Показать список позиций с кнопками
/close SYMBOL                    - Закрыть по текущей цене
/close SYMBOL PRICE              - Закрыть по указанной цене
/close SYMBOL PRICE QTY          - Закрыть часть позиции
/close all                       - Закрыть все позиции (безопасно)
```

### 📝 **Примеры использования:**

```
/close                           - Показать все позиции для выбора
/close BTCUSDT                   - Закрыть BTC по текущей цене
/close ETHUSDT 2500              - Закрыть ETH по цене 2500
/close SOLUSDT 100 0.5           - Закрыть 0.5 SOL по цене 100
/close all                       - Закрыть все позиции
```

## 🔄 **ПРОЦЕСС ВЫПОЛНЕНИЯ**

### 📊 **2. Анализ команды с параметрами**

**Что происходит:**

- Парсинг аргументов команды
- Проверка существования позиции
- Валидация параметров (цена, количество)
- Получение текущей цены с биржи (если не указана)

**Пример:**

```python
# Команда: /close BTCUSDT 45000 0.5
symbol = "BTCUSDT"
close_price = 45000
close_qty = 0.5
```

### 🧮 **2. Расчет прибыли**

**Формулы расчета:**

```python
# Для LONG позиций
profit = (close_price - entry_price) * actual_qty

# Для SHORT позиций
profit = (entry_price - close_price) * actual_qty
```

**Пример расчета:**

```
LONG BTCUSDT:
- Цена входа: 44000
- Цена закрытия: 45000
- Количество: 0.5
- Прибыль: (45000 - 44000) * 0.5 = 500 USDT
```

## 📊 **ОБРАБОТКА РАЗНЫХ СЦЕНАРИЕВ**

### 🎯 **Закрытие всей позиции:**

**Что происходит:**

1. Удаление позиции из `open_positions`
2. Сохранение в `trade_history`
3. Пересчет баланса и рисков

**Код:**

```python
if actual_qty >= qty:
    # Закрываем всю позицию
    open_positions = [p for p in open_positions if p["symbol"] != symbol]
```

### 🔄 **Закрытие части позиции:**

**Что происходит:**

1. Уменьшение количества в позиции
2. Сохранение частичной сделки в историю
3. Обновление оставшейся позиции

**Код:**

```python
else:
    # Закрываем часть позиции
    remaining_qty = qty - actual_qty
    pos["qty"] = remaining_qty
```

### 📈 **Закрытие всех позиций:**

**Что происходит:**

1. Вызов безопасной функции `close_all_positions_safe_cmd`
2. Показ списка всех позиций
3. Подтверждение через кнопку "🔒 Подтвердить закрытие всех"
