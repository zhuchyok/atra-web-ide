## 🎯 Проблема

Пользователь сообщил, что форматы сообщений **после принятия** сигналов должны соответствовать тому, какой сигнал был принят:

- **Если принят НОВЫЙ сигнал** → показывать формат "✅ Сигнал принят!"
- **Если принят DCA сигнал** → показывать формат "✅ DCA сигнал принят!"

## ✅ Исправления

### 1. **Добавлена логика определения типа сигнала**

**Файл:** `telegram_bot.py`
**Функция:** `button()`
**Обработчик:** `action == "accept"`

```python
# Определяем тип сигнала (новый или DCA)
open_positions = user_data.get("open_positions", [])
existing_position = next((p for p in open_positions if p["symbol"] == symbol), None)
is_dca_signal = existing_position is not None
```

### 2. **Обновлена логика создания позиции**

#### Для DCA сигналов:

```python
if is_dca_signal:
    # DCA сигнал - обновляем существующую позицию
    old_qty = existing_position.get("qty", 0)
    old_price = existing_position.get("entry_price", 0)
    new_qty = existing_position.get("risk_amount", 0) / current_price if current_price > 0 else 0

    if old_qty > 0 and old_price > 0:
        total_qty = old_qty + new_qty
        avg_price_new = (old_qty * old_price + new_qty * current_price) / total_qty
    else:
        total_qty = new_qty
        avg_price_new = current_price

    # Обновляем позицию
    existing_position["qty"] = total_qty
    existing_position["entry_price"] = avg_price_new
    existing_position["n_dca"] = existing_position.get("n_dca", 0) + 1
```

## 📊 Логика определения типа сигнала

### 🔍 **Как определяется тип сигнала:**

1. **Проверка существующих позиций:**

   ```python
   existing_position = next((p for p in open_positions if p["symbol"] == symbol), None)
   ```

2. **Определение типа:**
   - **Если `existing_position` найден** → это **DCA сигнал**
   - **Если `existing_position` не найден** → это **новый сигнал**

3. **Логика обработки:**
   - **DCA сигнал** → обновляет существующую позицию
   - **Новый сигнал** → создает новую позицию
