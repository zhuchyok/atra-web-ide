# АУДИТ ГЕНЕРАЦИИ СИГНАЛОВ в signal_live.py

## 📊 Обзор генерации сигналов

### Основные компоненты:

#### 1. **Функции генерации сигналов:**

- **`check_and_send_signals(signal_history)`** - Главная функция обработки сигналов
- **`enhanced_entry_signal(df, i)`** - Улучшенная логика входа (мягкие условия)
- **`strict_entry_signal(df, i)`** - Строгая логика входа (жесткие условия)
- **`soft_entry_signal(df, i)`** - Мягкая логика входа
- **`get_entry_signal_by_mode(df, i, filter_mode)`** - Выбор режима генерации

#### 2. **Режимы фильтрации:**

- **strict**: Строгие условия, высокое качество, мало сигналов
- **balanced**: Оптимальный баланс качества и количества
- **soft**: Мягкие условия, больше сигналов, ниже качество

#### 3. **Система кэширования:**

- **`SENT_SIGNALS_CACHE`** - Предотвращение дублирования сигналов (TTL 60 сек)
- **`ANOMALY_CACHE`** - Кэширование данных об аномалиях (TTL 600 сек)
- **`NEWS_CACHE`** - Кэширование новостных данных (TTL 3600 сек)
- **OHLC кэш** - Кэширование исторических данных

### 🔧 Анализ логики генерации сигналов:

#### **Улучшенная логика (`enhanced_entry_signal`):**

```python
# LONG условия:
long_conditions = [
    current_price <= bb_lower * 1.02,  # Касание нижней полосы BB
    ema7 > ema25,                       # Восходящий тренд
    rsi < 50,                          # Не перекуплено
    volume_ratio > 0.8,                # Повышенный объем
    volatility > 1,                    # Достаточная волатильность
    momentum > -0.05,                  # Не сильный нисходящий momentum
    trend_strength > 0.1               # Есть тренд
]
```

#### **Строгая логика (`strict_entry_signal`):**

```python
# LONG условия (более жесткие):
long_conditions = [
    current_price <= bb_lower * 1.010,  # Строгое касание BB
    ema7 > ema25 * 1.002,              # Сильный тренд
    rsi < 42,                          # Сильная перепроданость
    volume_ratio > 1.2,                # Высокий объем
    volatility > 2.4,                  # Высокая волатильность
    momentum > 0.0,                    # Положительный momentum
    trend_strength > 0.40              # Сильный тренд
]
```
