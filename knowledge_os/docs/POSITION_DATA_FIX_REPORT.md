# Отчет: Исправление отображения данных позиций

## 🚨 Проблема

Команда `/positions` показывала некорректные данные:

- **Цена входа**: "Ожидает входа" (вместо реальной цены)
- **Текущая цена**: "Недоступна" (вместо актуальной цены с биржи)
- **Объём**: "Не установлен" (вместо рассчитанного объема)
- **TP1/TP2**: "Не установлен" (вместо рассчитанных take profit)

## 🔍 Диагностика

### Причина проблемы

При принятии сигнала в функции `button` позиция создавалась с пустыми значениями:

```python
new_position = {
    "symbol": symbol,
    "entry_price": None,  # ← Проблема: не сохранялась реальная цена
    "tp1": None,          # ← Проблема: не рассчитывались TP
    "tp2": None,          # ← Проблема: не рассчитывались TP
    "stage": "open",
    "risk_amount": risk_amount,
    "risk_pct": risk_pct,
    "leverage": leverage if trade_mode == "futures" else None,
    "side": side,
}
```

### Логика до исправления:

1. **Принятие сигнала**: Позиция создавалась с `entry_price: None`
2. **Отображение позиций**: Функция `positions_cmd` не могла показать данные
3. **Результат**: Все поля показывали "Недоступно" или "Не установлено"

## ✅ Исправление

### Изменения в функции `button`:

**Было:**

```python
new_position = {
    "symbol": symbol,
    "entry_price": None,
    "tp1": None,
    "tp2": None,
    "stage": "open",
    "risk_amount": risk_amount,
    "risk_pct": risk_pct,
    "leverage": leverage if trade_mode == "futures" else None,
    "side": side,
}
```

**Стало:**

```python
# Рассчитываем объем позиции
if trade_mode == "futures" and leverage:
    qty = risk_amount / entry_price
else:
    qty = risk_amount / entry_price

# Рассчитываем TP1 и TP2
if side == "long":
    tp1 = entry_price * 1.01  # +1%
    tp2 = entry_price * 1.02  # +2%
else:  # short
    tp1 = entry_price * 0.99  # -1%
    tp2 = entry_price * 0.98  # -2%

new_position = {
    "symbol": symbol,
    "entry_price": entry_price,  # Используем актуальную цену
    "tp1": tp1,
    "tp2": tp2,
    "qty": qty,  # Добавляем объем
    "stage": "open",
    "risk_amount": risk_amount,
    "risk_pct": risk_pct,
    "leverage": leverage if trade_mode == "futures" else None,
    "side": side,
}
```

## 🔧 Технические детали

### Расчет объема позиции:

```python
qty = risk_amount / entry_price
```

- **Для фьючерсов**: `risk_amount` уже учитывает плечо
- **Для спота**: `risk_amount` = сумма входа

### Расчет Take Profit:

```python
# Для LONG позиций:
tp1 = entry_price * 1.01  # +1%
tp2 = entry_price * 1.02  # +2%

# Для SHORT позиций:
tp1 = entry_price * 0.99  # -1%
tp2 = entry_price * 0.98  # -2%
```

### Загрузка текущих цен:

Функция `positions_cmd` уже правильно загружает актуальные цены с биржи:

```python
from ohlc_utils import get_ohlc_binance_sync
ohlc = get_ohlc_binance_sync(symbol, interval="1m", limit=1)
if ohlc and len(ohlc) > 0:
    current_price = ohlc[-1]["close"]
```

## 📝 Заключение

Проблема была в том, что при создании позиции не сохранялись важные данные:

- **Цена входа** (была `None`, стала реальной ценой)
- **Take Profit уровни** (были `None`, стали рассчитанными значениями)
- **Объем позиции** (не рассчитывался, теперь рассчитывается)

Исправление обеспечивает:

1. **Полные данные позиций** при создании
2. **Корректное отображение** в команде `/positions`
3. **Точный расчет P&L** на основе актуальных цен
4. **Правильные take profit уровни** для управления позициями
