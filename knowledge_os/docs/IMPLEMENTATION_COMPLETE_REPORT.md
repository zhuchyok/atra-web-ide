## 🚀 Инструкции по запуску

### 1. Установка зависимостей:

```bash
pip install aiohttp aiofiles numpy pandas scikit-learn
```

### 2. Запуск системы:

```bash
# Обычный запуск (автоматически использует улучшенные системы)
python main.py

# Проверка статуса через CLI
python improved_cli.py status

# Генерация отчета
python improved_cli.py report --type comprehensive
```

### 3. Мониторинг:

```bash
# Мониторинг качества данных
python improved_cli.py monitor data --duration 300

# Анализ производительности
python improved_cli.py analyze performance --hours 24

# Управление алертами
python improved_cli.py alerts list
```
