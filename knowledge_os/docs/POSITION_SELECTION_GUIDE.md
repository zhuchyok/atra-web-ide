## 📅 Дата: 27 июля 2025

## 🎯 Обзор

Команда `/close` требует указания символа позиции. Есть несколько способов узнать, какие позиции у вас открыты и как их закрыть.

```

Режим торговли: FUTURES

💡 Выберите позицию для закрытия:

Цена входа: 44000.00
Текущая цена: 45000.00
Объём: 1.0000
P&L: 1000.00 USDT (+2.27%)
Режим: FUTURES
Плечо: x2

[🔴 Закрыть всю] [💰 Закрыть 50%]
[📊 Детали] [📈 Обновить P&L]
```

### 🎯 **Кнопки для каждой позиции:**

1. **🔴 Закрыть всю** - закрыть всю позицию по текущей цене
2. **💰 Закрыть 50%** - закрыть половину позиции по текущей цене
3. **📊 Детали** - показать подробную информацию
4. **📈 Обновить P&L** - обновить расчет прибыли/убытков

## 🔴 **СПОСОБ 2: Команда `/close` с указанием символа**

### 📝 **Форматы команды:**

```
/close BTCUSDT              - Закрыть BTC по текущей цене
/close ETHUSDT 2500         - Закрыть ETH по цене 2500
/close SOLUSDT 100 0.5      - Закрыть 0.5 SOL по цене 100
/close all                  - Закрыть все позиции
```

### ⚠️ **Если символ не указан:**

```
❌ Укажите символ или 'all' для закрытия всех позиций:

Примеры:
• /close BTCUSDT - закрыть по текущей цене
• /close BTCUSDT 45000 - закрыть по цене 45000
• /close BTCUSDT 45000 0.5 - закрыть 0.5 BTC
• /close all - закрыть все позиции
```

### ❌ **Если позиции нет:**

```
❌ Нет открытой позиции по BTCUSDT.
```

## 🎯 **ПОШАГОВЫЙ АЛГОРИТМ ВЫБОРА ПОЗИЦИИ**

### 📋 **Шаг 1: Посмотреть позиции для закрытия**

```
/close
```

### 📊 **Шаг 2: Выбрать способ закрытия**

#### 🎯 **Вариант A: Через кнопки (САМЫЙ УДОБНЫЙ)**

1. Нажать **🔴 Закрыть всю** под нужной позицией
2. Подтвердить закрытие кнопкой **✅ Закрыть**
3. Готово!

#### 🎯 **Вариант B: Частичное закрытие**

1. Нажать **💰 Закрыть 50%** для половины позиции
2. Подтвердить закрытие кнопкой **✅ Закрыть**

#### 🎯 **Вариант C: Через команду с символом**

1. Скопировать символ из списка (например, `BTCUSDT`)
2. Ввести команду: `/close BTCUSDT`
3. Подтвердить закрытие кнопкой **✅ Закрыть**

#### 🎯 **Вариант D: Через команду `/positions`**

1. Ввести: `/positions`
2. Нажать **🔴 Закрыть** под нужной позицией
3. Подтвердить закрытие

## 🛡️ **БЕЗОПАСНОСТЬ И ПОДТВЕРЖДЕНИЯ**

### ✅ **Всегда требуется подтверждение:**

1. **Кнопки в `/positions`:**
   - Нажатие кнопки → Показ деталей → Подтверждение

2. **Команда `/close`:**
   - Ввод команды → Показ деталей → Подтверждение

3. **Закрытие всех позиций:**
   - `/close all` → Список позиций → Дополнительное подтверждение

### 🔒 **Защита от ошибок:**

- **Проверка существования** позиции
- **Валидация параметров** (цена, количество)
- **Возможность отмены** на любом этапе
- **Детальная информация** перед закрытием

## 📊 **ПОЛЕЗНЫЕ КОМАНДЫ ДЛЯ РАБОТЫ С ПОЗИЦИЯМИ**

### 📋 **Основные команды:**

```
/positions          - Просмотр всех открытых позиций
/close SYMBOL       - Закрыть конкретную позицию
/close all          - Закрыть все позиции
/balance            - Просмотр баланса и свободных средств
/trade_history      - История закрытых сделок
```

### 📈 **Аналитические команды:**

```
/signal_stats       - Статистика сигналов
/stats              - Общая статистика торговли
/report             - Подробный отчет
```

## 🎯 **РЕКОМЕНДАЦИИ ПО ИСПОЛЬЗОВАНИЮ**

### ✅ **Лучшие практики:**

1. **Используйте `/close`** для быстрого просмотра и закрытия позиций
2. **Используйте кнопки** для быстрого закрытия (самый удобный способ)
3. **Проверяйте P&L** перед закрытием
4. **Используйте частичное закрытие** для фиксации прибыли
5. **Проверяйте баланс** после закрытия

### ⚠️ **Что избегать:**

- ❌ Закрытие без проверки позиции
- ❌ Использование неправильного символа
- ❌ Закрытие всех позиций без необходимости
- ❌ Игнорирование подтверждений

## 🎉 **ЗАКЛЮЧЕНИЕ**

**Для выбора позиции используйте:**

3. **📝 `/close SYMBOL`** - если знаете символ
4. **📊 `/positions`** - альтернативный способ просмотра
5. **🛡️ Подтверждения** - всегда проверяйте детали
