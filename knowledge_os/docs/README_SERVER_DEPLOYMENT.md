7. ✅ **Перезагрузится systemd** - очистка кэша
8. ✅ **Запустится новая система** - стабильная работа

## 📊 **УПРАВЛЕНИЕ СИСТЕМОЙ:**

```bash
# Запустить систему
./atra_server.sh start

# Остановить систему
./atra_server.sh stop

# Показать статус
./atra_server.sh status

# Перезапустить систему
./atra_server.sh restart
```

## 🔍 **ПРОВЕРКА РАБОТЫ:**

```bash
# Статус системы
./atra_server.sh status

# Процессы
ps aux | grep python

# Логи
tail -f logs/system.log.1

# Systemd сервисы (должны быть отключены)
sudo systemctl status myproject.service
```

## 🚨 **ВАЖНО:**

После выполнения **systemd НЕ будет** автоматически перезапускать систему!

Используйте **ТОЛЬКО** новую систему управления:

- `./atra_server.sh start` - запуск
- `./atra_server.sh stop` - остановка
- `./atra_server.sh status` - статус
