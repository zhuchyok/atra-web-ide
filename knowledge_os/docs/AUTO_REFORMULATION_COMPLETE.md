## 📝 ПРИМЕРЫ РАБОТЫ

### **Пример 1: Торговая стратегия**

**Запрос пользователя:**

```
"Что ты думаешь о новой стратегии DCA?"
```

**Автоматическая переформулировка:**

```
"Какие эксперты из команды должны обсудить стратегию DCA?
Что бы сказали Павел (Trading Strategy Developer), Мария (Risk Manager) и Максим (Data Analyst)?
Какие аргументы они приведут за и против?"
```

**Ответ от экспертов:**

- Павел: С точки зрения торговой стратегии...
- Мария: С точки зрения управления рисками...
- Максим: Анализ данных показывает...

---

### **Пример 2: Техническая проблема**

**Запрос пользователя:**

```
"Почему система работает медленно?"
```

**Автоматическая переформулировка:**

```
"Какая группа специалистов подходит для анализа производительности?
Что бы сказали Ольга (Performance Engineer), Игорь (Backend Developer) и Сергей (DevOps)?
Какие метрики они проанализируют и какие решения предложат?"
```

**Ответ от экспертов:**

- Ольга: С точки зрения производительности...
- Игорь: В коде могут быть узкие места...
- Сергей: На уровне инфраструктуры...
