**Дата:** 2025-12-14

---

## ❓ ЧТО ТАКОЕ `.team_data`?

`.team_data` — это **опциональная** директория для синхронизации данных команды между проектами через Git.

---

## ✅ ДЛЯ РАБОТЫ КОМАНДЫ ДОСТАТОЧНО:

### **Минимальный вариант (рекомендуется для начала):**

```bash
# Только один файл!
cp /path/to/atra/.cursorrules /path/to/new-project/.cursorrules
```

**Этого достаточно!** Команда из 22 экспертов будет работать автоматически.

---

## 🔄 КОГДА НУЖЕН `.team_data`?

`.team_data` нужен **ТОЛЬКО** если вы хотите:

1. **Синхронизировать данные команды** между несколькими проектами
2. **Хранить базы знаний** в центральном репозитории
3. **Обновлять данные команды** автоматически через Git

**Если у вас один проект — `.team_data` НЕ НУЖЕН!**

---
