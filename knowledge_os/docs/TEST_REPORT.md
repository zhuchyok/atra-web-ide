## 🔧 Рекомендации по улучшению

### 1. Оптимизация фильтров

- **Усилить строгие фильтры** для лучшего качества сигналов
- **Добавить дополнительные индикаторы** (ADX, Volume Profile)
- **Улучшить фильтрацию по времени** (избегать низколиквидных периодов)

### 2. Управление рисками

- **Снизить базовое плечо** для фьючерсов (с 3-5x до 1-2x)
- **Уменьшить динамический риск** (с 1-5% до 0.5-2%)
- **Добавить максимальный размер позиции** (не более 5% от баланса)

### 3. Динамические параметры

- **Оптимизировать расчет TP/SL** под волатильность
- **Улучшить адаптацию плеча** к рыночным условиям
- **Добавить trailing stop** для защиты прибыли
