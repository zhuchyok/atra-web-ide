# 📊 Подробное сравнение торговых режимов

## 🎯 **Обзор режимов**

В системе есть **4 режима фильтрации сигналов**:

1. **🔴 СТРОГИЙ** (`strict`) - Высокое качество, мало сигналов
2. **🟡 СБАЛАНСИРОВАННЫЙ** (`balanced`) - Оптимальное соотношение качества и количества
3. **🟢 МЯГКИЙ** (`soft`) - Больше сигналов, умеренное качество
4. **🔵 УЛЬТРА МЯГКИЙ** (`ultra_soft`) - Максимальное количество сигналов

---

## 🔴 **СТРОГИЙ РЕЖИМ** (`strict`)

### **🎯 Характеристики:**

- **Качество сигналов**: ⭐⭐⭐⭐⭐ (5/5)
- **Количество сигналов**: 🔴 Мало (1-3 в день)
- **Риск**: 🔴 Высокий (но качественные сигналы)
- **Рекомендация**: Для опытных трейдеров с большим депозитом

### **📋 Условия для LONG сигнала:**

```python
long_conditions = [
    current_price <= bb_lower * 1.01,    # Строгое касание нижней полосы Боллинджера
    ema7 > ema25 * 1.001,                # Сильный восходящий тренд
    rsi < 40,                            # Сильная перепроданость
    volume_ratio > 1.2,                  # Высокий объем
    volatility > 2,                      # Высокая волатильность
    momentum > 0,                        # Положительный momentum
    trend_strength > 0.5                 # Сильный тренд
]
```

### **📋 Условия для SHORT сигнала:**

```python
short_conditions = [
    current_price >= bb_upper * 0.99,    # Строгое касание верхней полосы Боллинджера
    ema7 < ema25 * 0.999,                # Сильный нисходящий тренд
    rsi > 60,                            # Сильная перекупленность
    volume_ratio > 1.2,                  # Высокий объем
    volatility > 2,                      # Высокая волатильность
    momentum < 0,                        # Отрицательный momentum
    trend_strength > 0.5                 # Сильный тренд
]
```

### **💡 Особенности:**

- **Требует сильных движений** рынка
- **Высокие требования к объему** (>1.2x среднего)
- **Строгие условия RSI** (RSI < 40 для LONG, RSI > 60 для SHORT)
- **Высокая волатильность** (>2%)
- **Сильный тренд** (>0.5)

---

## 🟡 **СБАЛАНСИРОВАННЫЙ РЕЖИМ** (`balanced`)

### **🎯 Характеристики:**

- **Качество сигналов**: ⭐⭐⭐⭐ (4/5)
- **Количество сигналов**: 🟡 Умеренно (3-8 в день)
- **Риск**: 🟡 Средний
- **Рекомендация**: Для большинства трейдеров (режим по умолчанию)

### **📋 Условия для LONG сигнала (СМЯГЧЕННЫЕ):**

```python
long_conditions = [
    current_price <= bb_lower * 1.04,    # Мягкое касание нижней полосы
    ema7 > ema25 * 0.998,                # Слабый восходящий тренд
    rsi < 60,                            # Не перекуплено (СМЯГЧЕНО: 55 → 60)
    volume_ratio > 0.6,                  # Достаточный объем
    volatility > 0.2,                    # Минимальная волатильность (СМЯГЧЕНО: 0.3 → 0.2)
    momentum > -0.08,                    # Не сильный нисходящий momentum
    trend_strength > 0.02                # Минимальный тренд
]
```

### **📋 Условия для SHORT сигнала (СМЯГЧЕННЫЕ):**

```python
short_conditions = [
    current_price >= bb_upper * 0.96,    # Мягкое касание верхней полосы
    ema7 < ema25 * 1.002,                # Слабый нисходящий тренд
    rsi > 40,                            # Не перепродано (СМЯГЧЕНО: 45 → 40)
    volume_ratio > 0.6,                  # Достаточный объем
    volatility > 0.2,                    # Минимальная волатильность (СМЯГЧЕНО: 0.3 → 0.2)
    momentum < 0.08,                     # Не сильный восходящий momentum
    trend_strength > 0.02                # Минимальный тренд
]
```

### **💡 Особенности:**

- **Баланс между качеством и количеством**
- **Умеренные требования к объему** (>0.6x среднего)
- **Смягченные условия RSI** (RSI < 60 для LONG, RSI > 40 для SHORT)
- **Низкая волатильность** (>0.2%)
- **Слабый тренд** (>0.02)

## 🎯 **Рекомендации по выбору режима**

### **🔴 СТРОГИЙ режим подходит для:**

- ✅ Опытных трейдеров
- ✅ Больших депозитов (>$10,000)
- ✅ Торговли в высоковолатильные периоды
- ✅ Когда важнее качество, чем количество

### **🟡 СБАЛАНСИРОВАННЫЙ режим подходит для:**

- ✅ Большинства трейдеров
- ✅ Средних депозитов ($1,000-$10,000)
- ✅ Регулярной торговли
- ✅ Баланса между качеством и количеством

### **🟢 МЯГКИЙ режим подходит для:**

- ✅ Начинающих трейдеров
- ✅ Малых депозитов (<$1,000)
- ✅ Обучения торговле
- ✅ Когда важнее количество возможностей

### **🔵 УЛЬТРА МЯГКИЙ режим подходит для:**

- ✅ Тестирования стратегий
- ✅ Очень малых депозитов (<$500)
- ✅ Изучения рынка
- ✅ Когда нужны частые сигналы

## 📈 **Статистика по режимам**

### **Ожидаемая доходность:**

- **Строгий**: 70-80% прибыльных сделок, но мало сделок
- **Сбалансированный**: 60-70% прибыльных сделок, умеренное количество
- **Мягкий**: 50-60% прибыльных сделок, много сделок
- **Ультра Мягкий**: 40-50% прибыльных сделок, очень много сделок

### **Риск-менеджмент:**

- **Строгий**: Высокий риск на сделку, но качественные сигналы
- **Сбалансированный**: Средний риск, оптимальное соотношение
- **Мягкий**: Низкий риск, больше возможностей
- **Ультра Мягкий**: Очень низкий риск, максимальные возможности

**Выбор режима зависит от вашего опыта, размера депозита и торговых целей!** 🎯
