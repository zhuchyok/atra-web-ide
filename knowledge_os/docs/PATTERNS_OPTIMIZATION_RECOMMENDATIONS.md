### 🔧 **Вместо увеличения - ОПТИМИЗИРОВАТЬ качество**

#### 1. **Улучшить баланс данных** ✅ КРИТИЧНО

**Проблема:** Слишком много WIN, мало LOSS

**Решение:**

- ✅ Приоритет LOSS паттернам при сохранении
- ✅ Удалить часть NEUTRAL паттернов (они не очень полезны)
- ✅ Сбалансировать WIN/LOSS соотношение (цель: 60/40 или 70/30)

**Реализация:**

```python
# В auto_manage_patterns() добавить балансировку
def balance_patterns(patterns, target_win_ratio=0.65):
    wins = [p for p in patterns if p.result == "WIN"]
    losses = [p for p in patterns if p.result == "LOSS"]

    # Если слишком много WIN, удаляем менее успешные
    if len(wins) > len(losses) * 2:
        # Оставляем только топ-успешные WIN
        wins_sorted = sorted(wins, key=lambda x: x.profit_pct, reverse=True)
        wins = wins_sorted[:int(len(losses) * 1.5)]

    return wins + losses
```
