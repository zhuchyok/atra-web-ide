# 🔍 ЛОГИКА АНОМАЛИЙ И ЗАКРАШИВАНИЯ КРУЖКОВ

## 📊 ОБЩАЯ СХЕМА РАБОТЫ

### 🎯 **Основная функция:** `calculate_anomaly_circles_with_fallback()`

**Входные параметры:**

- `symbol` - торговый символ (например, "BTCUSDT")
- `signal_type` - тип сигнала ("LONG" или "SHORT")

**Возвращает:**

- `circles_count` - количество закрашенных кружков (0-5)
- `activity_description` - описание активности
- `circles_text` - визуальное представление кружков
- `data_available` - доступность данных

---

## 🔄 АЛГОРИТМ РАБОТЫ

### **1. Получение данных**

```python
data = await get_anomaly_data_with_fallback(symbol)
v24 = data.get("volume_24h") or 0  # 24-часовой объём
mc = data.get("market_cap") or 0   # Рыночная капитализация
```

### **2. Проверка доступности данных**

```python
if data.get("available") and v24 > 0 and mc > 0:
    # Данные доступны - рассчитываем аномалии
else:
    # Данных нет - не блокируем сигналы
    return None, "Нет данных аномалий (fallback)", "", False
```

### **3. Расчёт уровня аномалии**

```python
volume_to_cap_ratio = volume_24h / market_cap
```

**Пороговые значения:**

- `≥ 0.8` → **5 кружков** - "Максимальная аномалия"
- `≥ 0.5` → **4 кружка** - "Критическая активность"
- `≥ 0.2` → **3 кружка** - "Аномальная активность"
- `≥ 0.1` → **2 кружка** - "Высокая активность"
- `≥ 0.04` → **1 кружок** - "Повышенная активность"
- `< 0.04` → **0 кружков** - "Нормальная активность"

### **4. Определение направления (цвета кружков)**

```python
# Анализ EMA7 vs EMA25 для определения тренда
ema7 = ta.trend.EMAIndicator(close, window=7).ema_indicator()
ema25 = ta.trend.EMAIndicator(close, window=25).ema_indicator()

if ema7 > ema25:
    sign_dir = 1   # Бычий тренд
elif ema7 < ema25:
    sign_dir = -1  # Медвежий тренд
else:
    sign_dir = 0   # Нейтральный
```

### **5. Закрашивание кружков**

```python
circle_empty = "⚪"  # Пустой кружок

if sign_dir > 0:
    circle_filled = "🟢"  # Зелёный для бычьего тренда
elif sign_dir < 0:
    circle_filled = "🔴"  # Красный для медвежьего тренда
else:
    circle_filled = "⚪"  # Серый для нейтрального

# Создание строки кружков
circles_text = circle_filled * circles_count + circle_empty * (5 - circles_count)
```

## 🎨 ВИЗУАЛЬНОЕ ПРЕДСТАВЛЕНИЕ

### **Примеры кружков:**

| Уровень аномалии | Соотношение V/C | Кружки     | Описание               |
| ---------------- | --------------- | ---------- | ---------------------- |
| 5                | ≥ 0.8           | 🟢🟢🟢🟢🟢 | Максимальная аномалия  |
| 4                | ≥ 0.5           | 🟢🟢🟢🟢⚪ | Критическая активность |
| 3                | ≥ 0.2           | 🟢🟢🟢⚪⚪ | Аномальная активность  |
| 2                | ≥ 0.1           | 🟢🟢⚪⚪⚪ | Высокая активность     |
| 1                | ≥ 0.04          | 🟢⚪⚪⚪⚪ | Повышенная активность  |
| 0                | < 0.04          | ⚪⚪⚪⚪⚪ | Нормальная активность  |

### **Цветовая схема:**

- **🟢 Зелёные кружки** - бычий тренд (EMA7 > EMA25)
- **🔴 Красные кружки** - медвежий тренд (EMA7 < EMA25)
- **⚪ Серые кружки** - нейтральный тренд или отсутствие аномалий

circles_count, activity_description, circles_text, data_ok = await calculate_anomaly_circles_with_fallback(symbol, "LONG")
