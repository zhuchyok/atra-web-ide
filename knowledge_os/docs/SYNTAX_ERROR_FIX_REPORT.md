## 🔍 **АНАЛИЗ ПРИЧИНЫ**

Проблема была в неправильных числовых литералах с избыточными нулями:

- `0.9900000000` - слишком много нулей
- `1.0100000000` - слишком много нулей
- `1.0500000000` - слишком много нулей
- `0.9500000000` - слишком много нулей

Python не может корректно интерпретировать такие числа, что приводит к `SyntaxError: invalid syntax`.
