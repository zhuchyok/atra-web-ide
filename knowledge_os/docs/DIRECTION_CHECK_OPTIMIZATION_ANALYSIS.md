### 1. ❌ АДАПТИВНЫЕ RSI ПОРОГИ ДЛЯ РЫНОЧНЫХ РЕЖИМОВ

**Предложение:**

```python
BULL_TREND: BUY RSI < 60 (вместо 50)
BEAR_TREND: BUY RSI < 45 (более строгий)
RANGE: BUY RSI < 50 (стандарт)
```

**Анализ:**

- ✅ У нас уже есть `MarketRegimeDetector`
- ✅ Режимы определяются: BULL_TREND, BEAR_TREND, HIGH_VOL_RANGE, LOW_VOL_RANGE, CRASH
- ❌ **ПРОБЛЕМА:** RSI < 50 не проходит в 100% случаев - это НЕ проблема порога, а состояние рынка
- ❌ **РИСК:** Ослабление до RSI < 60 в BULL_TREND → входы на пике → больше убытков

**Вердикт:** ❌ **НЕ НУЖНО**

- Текущий порог RSI < 50 правильный
- Ослабление ухудшит качество сигналов
- Рынок перекуплен - это факт, не нужно это игнорировать
