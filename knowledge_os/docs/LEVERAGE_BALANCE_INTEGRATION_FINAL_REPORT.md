# Финальный отчет: Исправление проблемы с плечом и интеграция с балансом

## Проблема

Пользователь сообщил, что при настройке FUTURES режима система показывает плечо 1x вместо минимального плеча для фьючерсов, и нужно привязать плечо к балансу из команды `/myreport`.

## Диагностика проблем

### 1. Ошибки импорта `os`

**Проблема**: `local variable 'os' referenced before assignment` в различных функциях.

**Причина**: Локальные переменные `os` перекрывали глобальный импорт в функциях, которые используют `os.path.isfile()`.

### 2. Некорректный расчет плеча для FUTURES

**Проблема**: При депозите 0 система возвращала плечо 1x для всех режимов.

**Причина**: Функция `calculate_user_leverage()` не учитывала минимальное плечо для FUTURES режима.

### 3. Конфликт экземпляров бота

**Проблема**: `Conflict: terminated by other getUpdates request; make sure that only one bot instance is running`

**Причина**: Запущено несколько экземпляров бота одновременно.

## Выполненные исправления

### 1. Исправление импорта `os`

Добавлены локальные импорты `os` в функции:

- `save_user_data_to_file()` - добавлен `import os` и `import json`
- `button()` - добавлен `import os` и `import json`

### 2. Исправление расчета плеча для FUTURES

Добавлена проверка для FUTURES режима с минимальным плечом 2x:

#### В функции `setup_trade_mode_futures`:

```python
# Если депозит равен 0, используем минимальное плечо для FUTURES
if deposit <= 0:
    user_data["leverage"] = 2  # Минимальное плечо для FUTURES
else:
    user_data["leverage"] = calculate_user_leverage(deposit, "futures", filter_mode)
```

#### В функции `setup_filter_mode_balanced`:

```python
# Если депозит равен 0 и режим FUTURES, используем минимальное плечо
if deposit <= 0 and trade_mode == "futures":
    user_data["leverage"] = 2  # Минимальное плечо для FUTURES
else:
    user_data["leverage"] = calculate_user_leverage(deposit, trade_mode, "balanced")
```

#### В функции `setup_filter_mode_soft`:

```python
# Если депозит равен 0 и режим FUTURES, используем минимальное плечо
if deposit <= 0 and trade_mode == "futures":
    user_data["leverage"] = 2  # Минимальное плечо для FUTURES
else:
    user_data["leverage"] = calculate_user_leverage(deposit, trade_mode, "soft")
```

### 3. Интеграция с балансом из `/myreport`

Система теперь использует баланс из команды `/myreport` для расчета плеча:

- **Для депозита 0**: Установлено минимальное плечо 2x для FUTURES режима
- **Для депозита > 0**: Сохранен динамический расчет на основе размера депозита и режима фильтров
- **Интеграция с `recalculate_balance_and_risks()`**: Плечо рассчитывается с учетом актуального баланса

### 4. Устранение конфликта экземпляров

- Остановлены все конфликтующие процессы бота
- Удален файл блокировки `atra.lock`
- Создан скрипт управления `bot_manager.sh` для предотвращения подобных проблем
