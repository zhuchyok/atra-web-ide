# Launchd-джобы ATRA — карта и владелец

> **Аудиторам и автономным агентам:** перед выгрузкой/удалением джобы проверь
> этот список. Каждая джоба здесь — часть конвейера, дубликатом быть не может.

| Джоба                         | Расписание    | Что делает                                                   | Не трогать, потому что                                                                                       |
| ----------------------------- | ------------- | ------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------ |
| `com.atra.db-backup`          | 03:30         | pg_dump knowledge_os + ротация 14 + оффсайт iCloud           | **Единственный создатель дампов.** gdrive-sync (04:45) переносит ГОТОВЫЕ дампы — это конвейер, а не дубликат |
| `com.atra.dashboard-smoke`    | 09:15         | Смоук-тест дашборда 8501, алерт при регрессе                 | Единственная проверка UI                                                                                     |
| `com.atra.security-responder` | каждые 10 мин | high-инциденты → задача на разбор + Telegram                 | Единственная автоматическая реакция на атаки                                                                 |
| `com.atra.self-dev`           | каждые 2 ч    | Патчер: dev_loop-задачи → diff → проверки → auto/dev-loop    | Не работает ночью 01:00–06:00 (окно battles) — это норма                                                     |
| `com.atra.self-improvement`   | вс 11:00      | Сигналы недели → предложения улучшений → dev_loop-задачи     | Источник идей для self-dev                                                                                   |
| `com.atra.self-dev-digest`    | пт 18:00      | Сводка патчей + AI-ревью → Telegram                          | Механизм человеческого ревью                                                                                 |
| `com.atra.watchdog-jobs`      | каждый час    | Проверяет ЭТУ таблицу; незагруженные джобы перезагружает сам | Сторож сторожей                                                                                              |

Правило: если джоба кажется дубликатом — сначала сверься с этой таблицей,
затем обсуди с владельцем. История инцидента 03.10: «дедупликация» выгрузила
создателя дампов → сутки без бэкапов. Watchdog теперь перезагружает такие
джобы автоматически.
