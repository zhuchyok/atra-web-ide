# Умное перераспределение на Ollama при перегрузке MLX

**Дата:** 2026-01-26  
**Статус:** ✅ **РЕАЛИЗОВАНО**

## 🎯 Цель

При перегрузке MLX API Server автоматически перераспределять простые задачи на Ollama модели для снижения нагрузки.

## 📊 Доступные Ollama модели

- **phi3.5:3.8b** (2.5 GB) - быстрая модель для простых задач
- **moondream** (1.6 GB) - быстрая, легкая vision модель
- **llava:7b** (4.7 GB) - универсальная vision модель для PDF

## ✅ Что реализовано

### 1. Определение простых задач (`local_router.py`)

**Метод:** `_is_simple_task()`

Простые задачи:

- Короткие промпты (< 500 символов)
- Простые категории: `fast`, `simple_query`, `text_summarization`, `grammar_correction`
- Простой чат (без сложной логики)
- Не требуют reasoning

### 2. Проверка загрузки MLX (`local_router.py`)

**Метод:** `_is_mlx_overloaded()`

MLX перегружен если:

- Все слоты заняты (`active_requests >= max_concurrent`)
- Есть очередь (`queue_size > 0`)

### 3. Умное перераспределение (`local_router.py`)

**Логика:**

```python
if is_simple_task and mlx_overloaded:
    # Простая задача → Ollama (phi3.5:3.8b)
    use_ollama_for_simple = True
```

**Приоритет узлов:**

1. Ollama (для простых задач при перегрузке MLX)
2. MLX (для сложных задач или если не перегружен)
3. Fallback на Ollama (если MLX недоступен)

### 4. Task Distribution (`react_agent.py`)

**Логика для ReActAgent:**

- Проверяет загрузку MLX через очередь
- Если простая задача и MLX перегружен → использует Ollama
- Для Ollama использует `phi3.5:3.8b` (быстрая модель)

## 📊 Как это работает

### Сценарий 1: MLX не перегружен

```
Запрос → MLX API Server (приоритет)
```

### Сценарий 2: MLX перегружен, простая задача

```
Простая задача → Ollama (phi3.5:3.8b)
Сложная задача → MLX (ждет в очереди)
```

### Сценарий 3: MLX недоступен

```
Любая задача → Ollama (fallback)
```

## 🎯 Преимущества

1. ✅ **Снижение нагрузки на MLX** - простые задачи идут на Ollama
2. ✅ **Быстрая обработка простых задач** - не ждут в очереди MLX
3. ✅ **MLX для сложных задач** - reasoning, архитектура, стратегия
4. ✅ **Автоматическое перераспределение** - без ручного вмешательства

## 🔧 Конфигурация

### Ollama модели (`OLLAMA_MODELS`)

```python
OLLAMA_MODELS = {
    "fast": "phi3.5:3.8b",      # Быстрая модель (2.5 GB)
    "vision": "moondream",      # Vision модель (1.6 GB)
    "vision_pdf": "llava:7b",    # Vision для PDF (4.7 GB)
    "coding": "phi3.5:3.8b",    # Для простого кода
    "reasoning": "phi3.5:3.8b", # Для простого reasoning
    "default": "phi3.5:3.8b"    # По умолчанию
}
```

### Пороги перегрузки

- **MLX перегружен:** `active_requests >= max_concurrent` или `queue_size > 0`
- **Task Distribution:** `queue_size > 3` для простых задач

## 📝 Примеры использования

### Простая задача (чат)

```
Промпт: "Привет, как дела?" (20 символов)
→ Простая задача
→ Если MLX перегружен → Ollama (phi3.5:3.8b)
```

### Сложная задача (reasoning)

```
Промпт: "Подумай о архитектуре системы..." (500+ символов)
→ Сложная задача
→ MLX (даже если перегружен, ждет в очереди)
```

### Vision задача

```
Промпт: "Что на этом изображении?" + изображение
→ Vision задача
→ Ollama (moondream или llava:7b)
```
