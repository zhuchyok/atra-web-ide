## 👩‍💻 ВЕРОНИКА - ЧТО ОНА ДЕЛАЕТ

### ✅ Статус: **РАБОТАЕТ НОРМАЛЬНО**

**Вероника** — это **Web Researcher** и **Локальный агент-исполнитель** корпорации ATRA.

### 🎯 Основные функции:

1. **Веб-поиск и исследования**
   - Ищет информацию в интернете через DuckDuckGo
   - Анализирует результаты локальными моделями (без токенов!)
   - Обогащает знания корпорации

2. **Выполнение задач от Виктории**
   - Получает задачи через HTTP API (`/run`)
   - Планирует выполнение (planner: deepseek-r1:7b)
   - Выполняет задачи (executor: qwen2.5-coder:7b)

3. **Работа с файлами и кодом**
   - `read_file` - чтение файлов проекта
   - `list_directory` - просмотр директорий
   - `grep_search` - поиск в коде
   - `apply_patch` - применение изменений

4. **Выполнение команд**
   - `run_terminal_cmd` - локальные команды
   - `ssh_run` - команды на серверах (с ограничениями безопасности)

5. **Веб-поиск**
   - `web_search` - поиск в интернете
   - Анализ результатов локальными моделями
   - Сохранение знаний в Knowledge OS

### 🔧 Инструменты Вероники:

```python
- read_file          # Чтение файлов проекта
- run_terminal_cmd   # Локальные команды
- ssh_run           # Команды на серверах (с ограничениями)
- list_directory     # Просмотр директорий
- web_search        # Поиск в интернете
- grep_search       # Поиск в коде
- apply_patch       # Применение изменений
```

### 🛡️ Правила безопасности (от Марии, Risk Manager):

1. **Приоритет локальности:**
   - Сначала использует локальные файлы
   - Запрещено использовать `ssh_run` для файлов проекта

2. **Безопасность:**
   - Запрещено: `apt-get`, `pip install`, `pip uninstall` на серверах
   - Запрещено удалять или изменять системные конфиги

3. **Анти-плейсхолдер:**
   - Никогда не использует `table_name`, `your_command` в командах
   - Сначала находит точные имена, потом выполняет
