## 🔍 ВЫЯВЛЕННЫЕ ПРОБЛЕМЫ

1. **Подключение из Docker к Ollama**
   - Проблема: Ollama возвращает 404 для `/api/generate`
   - Причина: Ollama слушает только на `localhost:11434`
   - Решение: Настроить `OLLAMA_HOST=0.0.0.0:11434`

2. **Использование fallback ответов**
   - Чат использует текстовые fallback вместо реальных моделей
   - Причина: Не удается подключиться к Ollama из Docker
