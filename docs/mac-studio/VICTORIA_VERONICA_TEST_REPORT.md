**Как работает:**

1. Задача поступает в Victoria
2. Категоризация задачи (`_categorize_task()`)
3. Выбор эксперта по категории (`select_expert_for_task()`)

5. Формирование промпта с контекстом эксперта
6. Планирование (или пропуск для простых задач)
7. Выполнение шагов
8. Сбор результатов

## ⚠️ НАЙДЕННЫЕ ПРОБЛЕМЫ

### 1. Ollama недоступен (192.168.1.43:11434)

**Проблема:** Victoria не может подключиться к Ollama на Mac Studio

**Ошибка:**

```
Ollama HTTP 404
Cannot connect to host 192.168.1.43:11434 ssl:default [Connect call failed]
```

**Статус:** ⚠️ **ТРЕБУЕТСЯ ИСПРАВЛЕНИЕ**

**Решение:**

- Проверить доступность Ollama на Mac Studio
- Убедиться, что `OLLAMA_BASE_URL` правильный
- Проверить сеть между контейнером и хостом
- Возможно использовать `host.docker.internal:11434` вместо IP

**Влияние:** Все задачи возвращают ошибку "Ollama HTTP 404", но логика работы (выбор экспертов, планирование, кэширование) работает корректно.

**Решение:**

- Ollama доступен на `localhost:11434` (6 моделей)
- Victoria пытается подключиться к `192.168.1.43:11434` (Mac Studio)
- Нужно изменить `OLLAMA_BASE_URL` на `http://host.docker.internal:11434` или использовать localhost
