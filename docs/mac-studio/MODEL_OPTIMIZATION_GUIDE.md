## 🎯 Методы оптимизации

### 1. Prompt Caching (Кэширование промптов)

**Что это:**

- Кэширование ответов на повторяющиеся промпты
- Экономия до 90% времени и токенов
- Автоматическое использование для всех моделей

**Как работает:**

```python
from knowledge_os.app.prompt_cache import PromptCache

cache = PromptCache()

# Проверяем кэш перед генерацией
cached = await cache.get_cached_response(prompt, model_name)
if cached:
    return cached  # Мгновенный ответ!

# Если нет в кэше - генерируем и сохраняем
response = await model.generate(prompt)
await cache.save_cached_response(prompt, model_name, response)
```

**Эффект:**

- ✅ До 90% экономии токенов на повторяющихся запросах
- ✅ Мгновенные ответы на знакомые вопросы
- ✅ Снижение нагрузки на модели

### 3. Batch Processing (Батчинг)

**Когда использовать:**

- ✅ Маленькие модели (3-7B): batch_size = 4-8
- ✅ Tiny модели (1-2B): batch_size = 8-16
- ❌ Большие модели (70B+): batch_size = 1 (не батчить)

**Эффект:**

- ✅ Ускорение на 2-4x для маленьких моделей
- ✅ Лучшее использование GPU/Neural Engine
- ✅ Параллельная обработка нескольких запросов
