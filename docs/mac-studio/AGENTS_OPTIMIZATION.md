## 🎯 ПРОБЛЕМА

Агенты (Victoria и Veronica) всегда использовали planner для всех задач, даже для простых команд типа "скажи привет" или "покажи файлы". Это приводило к:

- Излишней задержке выполнения
- Ненужному использованию ресурсов
- Усложнению процесса для простых задач

---

## ✅ РЕШЕНИЕ

Добавлена логика определения простых задач и пропуск планирования для них.

### Критерии простой задачи:

1. **Содержит ключевые слова:**
   - "скажи"
   - "привет"
   - "покажи файлы"
   - "выведи список"
   - "список файлов"

2. **Короткая задача:** не более 10 слов

### Реализация:

```python
async def run(self, goal: str, max_steps: int = 30) -> str:
    # Простые задачи не требуют планирования
    simple_tasks = ["скажи", "привет", "покажи файлы", "выведи список", "список файлов"]
    goal_lower = goal.lower()

    if any(task in goal_lower for task in simple_tasks) and len(goal.split()) <= 10:
        # Для простых задач пропускаем planner
        enhanced = f"ВЫПОЛНИ ЗАДАЧУ: {goal}\n\nВАЖНО: Выполняй ТОЧНО то что просят, ничего лишнего!"
    else:
        # Для сложных задач используем planner
        raw_plan = await self.plan(goal)
        enhanced = f"ТВОЙ ПЛАН:\n{raw_plan}\n\nПРИСТУПАЙ К ВЫПОЛНЕНИЮ: {goal}"

    return await super().run(enhanced, max_steps)
```
