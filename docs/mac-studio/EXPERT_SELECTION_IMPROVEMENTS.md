## ✅ РЕШЕНИЕ

### 1. Поиск всех кандидатов

**Было:**

```python
# Находил только первого
for expert_name, expert_data in self.expert_team.items():
    if expert_data.get('role') == target_role:
        return expert_name, expert_data
```

**Стало:**

```python
# Находит ВСЕХ экспертов с подходящими ролями
candidates = []
for expert_name, expert_data in self.expert_team.items():
    expert_role = expert_data.get('role', '')
    if expert_role in target_roles:  # Расширенный список ролей
        candidates.append((expert_name, expert_data))
```

---

### 2. Система оценки экспертов

**Оценка по критериям:**

1. **Соответствие роли** (0-20 баллов)
   - Основная роль категории: 20 баллов
   - Дополнительные роли: меньше баллов

2. **Специализация** (0-5 баллов)
   - Совпадение department с ключевыми словами задачи

3. **Опыт** (0-∞ баллов)
   - Количество выполненных задач × 0.5

4. **Успешность** (0-10 баллов)
   - Процент завершенных задач × 10

5. **Загрузка** (штраф)
   - Активные задачи × -2 (меньше загрузка = лучше)

6. **Metadata специализация** (0-3 балла)
   - Совпадение specialization в metadata

**Итоговый score:**

```python
score = role_priority_score + specialization_score + experience_score +
        success_rate_score - workload_penalty + metadata_score
```

---

### 3. Выбор лучшего эксперта

```python
best_expert = None
best_score = -1

for expert_name, expert_data in candidates:
    score = calculate_expert_score(expert_name, expert_data, goal, pool)
    if score > best_score:
        best_score = score
        best_expert = expert_name
        best_data = expert_data
```

### 4. Дополнительные эксперты для сложных задач

- Выбирается основной эксперт (лучший)
