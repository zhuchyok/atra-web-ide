# 💬 Victoria Chat в терминале

**Дата:** 2026-01-25

---

## 🚀 Быстрый старт

```bash
python3 scripts/victoria_chat.py
```

---

## 📋 Описание

Интерактивный чат с Victoria в терминале. Автоматически подключается к локальной или удаленной Victoria.

---

## 🔧 Использование

### Базовое использование

```bash
# Запуск чата
python3 scripts/victoria_chat.py
```

### С переменными окружения

```bash
# Использовать удаленную Victoria
VICTORIA_REMOTE_URL=http://185.177.216.15:8010 python3 scripts/victoria_chat.py

# Использовать локальную Victoria
VICTORIA_URL=http://localhost:8010 python3 scripts/victoria_chat.py
```

---

## 💡 Команды

- `/status` - показать статус Victoria
- `/health` - проверить здоровье Victoria
- `/project <name>` - изменить контекст проекта (atra-web-ide, atra, и т.д.)
- `/help` - показать справку по командам
- `exit` или `выход` - выйти из чата

---

## 🌐 Автоматическое подключение

Скрипт автоматически определяет доступную Victoria:

1. **Приоритет 1:** Локальная Victoria (`http://localhost:8010`)
2. **Приоритет 2:** Удаленная Victoria (`http://185.177.216.15:8010`)

Если ни одна не доступна, скрипт выведет инструкции по запуску.

## 🆕 Новые возможности (2026-01-26)

### Поддержка контекста проекта:

- ✅ Автоматически передает `project_context` в запросах
- ✅ По умолчанию: `atra-web-ide`
- ✅ Можно изменить через команду `/project <name>`

### Память чата:

- ✅ Автоматически сохраняет историю чата (последние 20 сообщений)
- ✅ Передает историю в Victoria для контекста
- ✅ Уникальный `session_id` для каждой сессии

### Примеры:

```bash
# Переключить проект на atra
/project atra

# Вернуться к atra-web-ide
/project atra-web-ide
```

## ⚠️ Требования

- Python 3.7+
- Установленный `requests`: `pip install requests`
- Запущенная Victoria (локально или удаленно)

## 🐛 Устранение проблем

### Victoria недоступна

```bash
# Проверьте статус Victoria
curl http://localhost:8010/health

# Запустите Victoria если нужно
docker-compose -f knowledge_os/docker-compose.yml up -d victoria-agent
```

### Ошибка импорта requests

```bash
pip install requests
```
