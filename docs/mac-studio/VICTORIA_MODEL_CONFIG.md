# Конфигурация модели для Victoria Agent

**Victoria** — Team Lead корпорации ATRA, должна использовать самую мощную модель для максимального качества работы.

## 🎯 Доступные модели на Mac Studio

| Модель                          | Размер | Скорость  | Качество                | Рекомендация                 |
| ------------------------------- | ------ | --------- | ----------------------- | ---------------------------- |
| `deepseek-r1-distill-llama:70b` | 70B    | Медленная | ⭐⭐⭐⭐⭐ Максимальное | **Для Victoria (Team Lead)** |
| `llama3.3:70b`                  | 70B    | Медленная | ⭐⭐⭐⭐⭐ Максимальное | Альтернатива                 |
| `qwen2.5-coder:32b`             | 32B    | Средняя   | ⭐⭐⭐⭐ Высокое        | По умолчанию (баланс)        |
| `phi3.5:3.8b`                   | 3.8B   | Быстрая   | ⭐⭐⭐ Хорошее          | Для planner                  |

## ⚙️ Конфигурация

### Способ 1: Переменные окружения в docker-compose.yml

Отредактируйте `docker-compose.yml`:

```yaml
victoria:
  environment:
    # Использовать самую мощную модель DeepSeek R1 (70B)
    - VICTORIA_MODEL=deepseek-r1-distill-llama:70b
    # Planner остается быстрым для планирования
    - VICTORIA_PLANNER_MODEL=phi3.5:3.8b
```

### Способ 2: .env файл

Создайте `.env` файл в корне проекта:

```bash
# Victoria использует самую мощную модель
VICTORIA_MODEL=deepseek-r1-distill-llama:70b
VICTORIA_PLANNER_MODEL=phi3.5:3.8b
```

### Способ 3: При запуске

```bash
VICTORIA_MODEL=deepseek-r1-distill-llama:70b docker-compose up -d victoria
```

## 🚀 Применение изменений

После изменения конфигурации:

```bash
# Пересобрать и перезапустить Victoria
docker-compose up -d --build victoria

# Проверить логи
docker logs atra-victoria-agent --tail 20
```

## 📊 Рекомендации

### Для максимального качества (Team Lead):

```bash
VICTORIA_MODEL=deepseek-r1-distill-llama:70b
```

- ✅ Лучшее качество ответов
- ✅ Меньше галлюцинаций
- ⚠️ Медленнее (30-60 секунд на ответ)

### Для баланса скорости/качества:

```bash
VICTORIA_MODEL=qwen2.5-coder:32b  # По умолчанию
```

- ✅ Хорошее качество
- ✅ Быстрее (10-20 секунд)
- ⚠️ Может галлюцинировать на сложных задачах

### Для быстрого тестирования:

```bash
VICTORIA_MODEL=phi3.5:3.8b
```

- ✅ Очень быстро (3-5 секунд)
- ⚠️ Меньше качество, больше галлюцинаций

## 🔍 Проверка текущей конфигурации

```bash
# Проверить переменные окружения контейнера
docker exec atra-victoria-agent env | grep VICTORIA

# Проверить логи запуска
docker logs atra-victoria-agent | grep -i model
```

## ⚠️ Важные замечания

1. **Большие модели (70B) требуют много памяти** — убедитесь что Mac Studio имеет достаточно RAM
2. **Медленные ответы** — модели 70B могут отвечать 30-60 секунд
3. **Таймауты** — увеличены до 180 секунд в коде, но для очень медленных моделей может потребоваться больше
