## 🔄 АВТОМАТИЧЕСКИЕ ПРОЦЕССЫ

### ✅ **Работают:**

1. **Victoria Agent** — готова к выполнению задач
   - Принимает задачи через `/run` endpoint
   - Использует планировщик (phi3.5) и исполнитель (qwen2.5-coder:32b)
   - Инструменты: read_file, run_terminal_cmd, ssh_run, list_directory, web_search

2. **Veronica Agent** — готова к веб-исследованиям
   - Веб-поиск + локальные модели
   - Принимает задачи через HTTP API

### ⚠️ **Не работают (требуют настройки):**

1. **Knowledge OS Worker**
   - Ошибки подключения к БД или другим сервисам
   - Не может обрабатывать фоновые задачи
   - Не может обучать экспертов

2. **Автоматическое обучение экспертов**
   - Требует работающую БД с данными
   - Требует Knowledge OS Worker

3. **Nightly Learner**
   - Не запущен (не найден в контейнерах)
   - Должен работать по расписанию для обучения экспертов

4. **Системы улучшений агентов** (менторство, A/B тестирование, KPI)
   - Требуют работающую БД с данными экспертов
   - Запускаются каждые 6 часов (если настроены)

5. **Ежедневные отчёты**
   - Запускаются в 09:00 UTC
   - Требуют работающую БД
