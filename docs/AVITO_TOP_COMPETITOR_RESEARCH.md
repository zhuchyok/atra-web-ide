# Ресёрч: как заполняют объявления топ-оконщики на Авито (ноябрь 2026)

Собрано 3 субагентами: Москва/СПб, Поволжье/Чувашия, контент-приёмы по РФ.
Метод: сниппеты проиндексированных объявлений + кейсы агентств (vc.ru, CMDigital, eLama, LiteLab, SV Digital, Workspace).

## Чек-лист идеального объявления оконщика (итог ресёрча)

1. **Заголовок ≤50-60 зн.** = главный ключ в начале + один максимальный оффер («под ключ», «от производителя», «гарантия 5 лет»). Город — в поле адреса, не в тексте.
2. **Первая строка описания** = оффер + снятие риска: «от производителя, замер бесплатный и ни к чему не обязывает», «рассрочка 0%». Скидки — НЕ в заголовке (модерация), а в первых 2 строках (в XL-объявлении видны в превью выдачи).
3. **Структура описания**: боль вопросом («Дует? Потеют стёкла?») → УТП с цифрами (свое производство, стаж N лет, ГОСТ) → что входит / откуда цена → пакеты Эконом/Стандарт/Премиум → FAQ (снимает возражения до контакта) → гарантия/сроки → CTA («Пишите в чат — замерщик сегодня»).
4. **Цена**: не пустая; низкая «от»-цена (от 2 250–9 100 ₽) для входа в сортировку «сначала дешёвые» и фильтры; расшифровка в тексте. Альтернатива: +10–15% и «торг уместен».
5. **Обложка-инфографика**: реальное фото + крупный оффер («Тёплый балкон за 3 дня», «от 8 900 ₽», «Рассрочка 0%»), 3–5 иконок-преимуществ, 1920×1440. В галерее: до/после, тепловизор, склад/завод, видео монтажа (редкость у конкурентов → плюс).
6. **Матрица объявлений**: широкие ключи → общие карточки; размеры/бренды/модели → товарные («Пластиковое окно 600\*300», «окна Veka/Rehau»); отдельные под «остекление балкона», «замена окон», «отделка». Ключи из Аналитики спроса Авито.
7. **Гео**: в категории «Услуги» одно объявление можно в несколько городов (официально). Область даёт до 30% сделок.
8. **Сервис**: правка/обновление каждые 3 дня вручную в пиковые часы (вечер будней, день выходных), геометка по району, ответ в чате 1–3 минуты, 5+ отзывов с фото, рейтинг 4.5+ (открывает Молл).
9. **Промо связкой**: «выделение цветом + XL + продвижение x2/x15/x20» — по отдельности слабо, связкой работает.

## Ключевые цифры кейсов

- Топ-конверсия просмотр→контакт 7,25% (средняя по категории 4,95%) — достигается «оффер в превью + инфографика + автобиддер топ-20».
- Цена контакта: 87–466 ₽ в оконной нише.
- «ЧУДО ОКНА» (продавец №1 категории СПб): рейтинг 4.9, ~440 отзывов, сезонные бонусы (летом сетка, зимой подоконник), связка промо-инструментов.
