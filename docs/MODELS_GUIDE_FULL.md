# 🧠 Модели ИИ в корпорации ATRA (Mac Studio M4 Max)

Этот документ является единым источником истины для всех агентов (Victoria, Veronica), оркестраторов и экспертов. Он описывает, какую модель и когда использовать для достижения максимальной скорости и качества.

---

## 🚀 Основные рабочие модели (Ollama)

### 1. qwen3-coder-next:latest (51 GB)

- **Роль**: "Главный Архитектор / Senior Developer"
- **Для чего**: Самые сложные задачи по программированию, проектирование систем с нуля, глубокий рефакторинг, поиск сложнейших багов.
- **Когда использовать**: Когда качество критичнее скорости. Это самая мощная модель в нашем распоряжении.
- **Сильные стороны**: Понимает сложнейшие логические связи, пишет чистый и современный код.

### 2. qwen2.5-coder:32b (19 GB)

- **Роль**: "Ведущий Инженер / Основной Исполнитель"
- **Для чего**: Написание кода, создание API, написание тестов, техническая документация.
- **Когда использовать**: **Стандарт по умолчанию** для всех технических задач. Идеальный баланс скорости и интеллекта.
- **Сильные стороны**: Высокая скорость генерации, отличное следование инструкциям.

### 3. qwq:32b (19 GB)

- **Роль**: "Логик / Аналитик" (Reasoning Model)
- **Для чего**: Задачи на логику, математические расчеты, планирование сложных многошаговых операций, когда нужно "подумать перед тем как сказать".
- **Когда использовать**: Для этапа `understand_goal` и сложных стратегий.
- **Сильные стороны**: Использует внутреннюю цепочку рассуждений (Chain of Thought), минимизирует логические ошибки.

### 4. glm-4.7-flash:q8_0 (31 GB)

- **Роль**: "Универсальный Помощник / Креатив"
- **Для чего**: Общие вопросы, написание текстов, суммаризация, быстрые ответы на сложные темы.
- **Когда использовать**: Когда нужен "свежий взгляд" или альтернативное мнение в дебатах экспертов.
- **Сильные стороны**: Очень быстрая для своего размера, отличный русский язык.

---

## 👁️ Специализированные модели

### 5. moondream:latest (1.7 GB)

- **Роль**: "Глаза системы" (Vision)
- **Для чего**: Анализ скриншотов, распознавание текста на картинках, описание UI.
- **Когда использовать**: Всегда, когда пользователь присылает изображение.
- **Сильные стороны**: Невероятная скорость, работает почти мгновенно.

### 6. llava:7b (4.7 GB)

- **Роль**: "Старший Визуальный Аналитик"
- **Для чего**: Сложный анализ изображений, где moondream не справляется.
- **Когда использовать**: Глубокий анализ графиков, схем, архитектурных диаграмм.

---

## 🛠️ Служебные модели

### 7. nomic-embed-text:latest (274 MB)

- **Роль**: "Библиотекарь" (Embeddings)
- **Для чего**: Поиск по базе знаний (RAG), индексация файлов проекта.
- **Когда использовать**: Используется автоматически системой при поиске информации.

### 8. tinyllama:1.1b-chat (637 MB)

- **Роль**: "АварийныйFallback"
- **Для чего**: Простейшие проверки связи, когда GPU перегружен.
- **Когда использовать**: Только в случае критических сбоев основных моделей.

---

## 🔄 Логика выбора (Для Агентов и Оркестраторов)

1.  **Простой чат / Приветствие** -> Fast Path (без модели) или `qwen2.5-coder:32b`.
2.  **Написание кода** -> `qwen2.5-coder:32b` (быстро) или `qwen3-coder-next` (максимальное качество).
3.  **Сложный анализ / Планирование** -> `qwq:32b`.
4.  **Картинка в чате** -> `moondream` (первичный анализ) -> `qwen2.5-coder` (выполнение задачи).
