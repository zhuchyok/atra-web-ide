# Setki21: правила контента для конверсии (Чебоксары и Новочебоксарск)

**Для кого:** все страницы сайта (главная, продукт: москитная / Антимошка / Ультравью / Антикошка / Антипыль / VSN, ремонт, контакты, доставка).  
**Цель:** максимум заявок и звонков из Чебоксар и Новочебоксарска.

---

## 1. География — везде явно и без дыр

- В каждом блоке, где по смыслу нужен город, писать **«Чебоксары»**, **«Новочебоксарск»** или **«Чебоксары и Новочебоксарск»** — не оставлять пустое «в » или «в .».
- Проверить все шаблоны: подстановка города/региона не должна давать пустую строку (иначе «Точный замер сделает специалист в .» и «Цена в ?» выглядят как ошибка и режут доверие).
- В title, description и первом абзаце страницы гео должна быть в первых 1–2 предложениях.

**Правило:** ни одной фразы вида «…в » или «…в ?» без названия города.

---

## 2. Заголовки (title, H1)

- **Title:** до 55–60 символов, иначе обрежется в выдаче. Формула: **[продукт/услуга] + [гео] + [цена или срок] + | Сетки 21**.  
  Примеры: «Москитные сетки от 850₽ в Чебоксарах | Сетки 21», «Сетка Ультравью от 1000₽ в Чебоксарах | Сетки 21».
- **H1:** одна главная мысль — выгода или продукт + гео. Не только «Прозрачность и защита», а «Сетка Ультравью в Чебоксарах — прозрачность без затемнения» или «Ультравью — прозрачная сетка на окно в Чебоксарах».

**Правило:** в каждом title и H1 есть либо Чебоксары/Новочебоксарск, либо явный призыв/выгода.

---

## 3. Первый экран (лид-текст)

- Первое предложение: **что это, для кого, гео, цена или срок.** Без длинных перечислений в первом абзаце.
- Второе предложение: усилить выгоду или призыв (замер, расчёт, заказ).
- Избегать сухих «Особенности: …» в самом верху — лучше «Сетка Ультравью в Чебоксарах и Новочебоксарске от 1000₽ за 2 дня. Прозрачность и защита от мошек без затемнения окна.»

**Правило:** за 2–3 секунды читатель понимает: что, где, сколько, за сколько.

---

## 4. Призывы к действию (CTA)

- На каждой странице выше сгиба — один явный CTA: «Рассчитать стоимость», «Заказать замер», «Позвонить» (с номером).
- Номер телефона и «Звоните» / «Оставьте заявку» повторять в конце основных блоков (после плюсов, после блока про доставку).
- Кнопки: формулировки действия («Рассчитать», «Заказать замер», «Позвонить»), не общие («Подробнее» без контекста).

**Правило:** без прокрутки виден хотя бы один способ оставить заявку или позвонить.

---

## 5. Доверие и конкретика

- Где уместно: срок изготовления, «металлокрепёж в комплекте», «замер за 1 день» / «за 2 дня», режим работы, доставка по Чебоксарам и Новочебоксарску.
- Избегать общих фраз без цифр («быстро», «качественно») — лучше «изготовление за 2 дня», «доставка в день заказа по Чебоксарам».

**Правило:** каждое обещание подкреплять конкретикой (срок, цена, гео).

---

## 6. Единый чеклист по каждой странице

Перед публикацией или правками проверить:

| Проверка                                     | Да/нет |
| -------------------------------------------- | ------ |
| В title есть гео или цена/срок?              |        |
| В H1 есть гео или явная выгода?              |        |
| Нет пустых «в », «в ?» в тексте и FAQ?       |        |
| Первый абзац: что, где, цена/срок?           |        |
| Есть CTA выше сгиба?                         |        |
| Телефон/заявка повторены после блоков выгод? |        |
| Указаны срок изготовления и доставка по гео? |        |

---

Эти правила можно применять ко всем разделам: главная, Ультравью, Антимошка, Антикошка, Антипыль, вставные VSN, ремонт, контакты, доставка. Если нужно, могу вынести в отдельный файл только список «что заменить по шаблону» (например, для Nuxt/конфига тенанта) без лишнего текста.
