## 🎯 ОБЩИЕ ЗНАНИЯ КОМАНДЫ

### История проекта ATRA:

- Начало: 2023 год
- Рефакторинг: 2024 год (Clean Architecture)
- Критические инциденты: ноябрь 2024 (импорты, stub функции)
- Текущий статус: стабильная работа, постоянные улучшения

### Технический стек:

- **Язык:** Python 3.10+
- **Фреймворки:** python-telegram-bot, pandas, numpy
- **ML:** LightGBM, scikit-learn
- **База данных:** SQLite
- **Биржи:** Binance, Bybit, MEXC
- **Инфраструктура:** Linux, Git, GitHub

### Архитектура:

- **Clean Architecture:** Domain, Application, Infrastructure, Presentation
- **Модульная структура:** `src/telegram/`, `src/signals/`, `src/filters/`
- **Dependency Injection:** через конструкторы
- **Fallback механизмы:** graceful degradation

### Типичные проблемы:

- Импорты: `ModuleNotFoundError`, неправильные пути
- Stub функции: когда импорт падает
- Async/await: `await on None`, блокирующие вызовы
- База данных: `NoneType has no attribute 'execute'`
- Логирование: отсутствие структурированных логов
