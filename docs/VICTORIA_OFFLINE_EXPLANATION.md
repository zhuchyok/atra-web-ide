# Victoria Offline - Объяснение

**Дата:** 26.01.2026

---

## 🔍 Ситуация

Victoria показывает статус **"Offline"** в интерфейсе.

---

## ✅ Это НЕ критично!

**Чат работает через Ollama fallback!**

### Как это работает:

1. **Попытка подключения к Victoria:**
   - Backend пытается подключиться к Victoria Agent на порту 8010
   - Если Victoria недоступна → используется fallback

2. **Fallback на Ollama:**
   - Backend автоматически использует Ollama для генерации ответов
   - Ollama работает и доступен на порту 11434
   - Чат полностью функционален!

3. **Отображение в UI:**
   - Статус показывает "AI: Ollama (Fallback)" или "AI: Ollama (Victoria Offline)"
   - Это означает, что чат работает, просто через другой сервис

## 🔧 Если нужна Victoria

### Запуск Victoria (опционально):

1. **Запустить Docker Desktop:**

   ```bash
   open -a Docker
   ```

2. **Дождаться запуска Docker** (несколько секунд)

3. **Запустить Victoria:**

   ```bash
   cd /Users/bikos/Documents/atra-web-ide
   docker-compose -f knowledge_os/docker-compose.yml up -d victoria-agent
   ```

4. **Проверить статус:**

   ```bash
   curl http://localhost:8010/health
   ```

5. **Обновить страницу** в браузере - статус обновится автоматически
