# 🚀 БЫСТРЫЙ СТАРТ: Подключение команды экспертов в другом проекте

**Версия:** 1.0  
**Дата:** 2025-12-14

---

## 📋 Что это?

**Команда экспертов (более 40 сотрудников)** — это формат работы с AI-ассистентом, где вместо прямых вопросов вы формулируете запросы через обсуждение группы специалистов. Это даёт более качественные и разносторонние ответы.

---

## ⚡ Быстрое подключение (3 шага)

### Шаг 1: Добавьте правила в `.cursorrules` или промпт проекта

### Шаг 3: Используйте правильные формулировки

#### ❌ **НЕПРАВИЛЬНО:**

```
"Что ты думаешь об этом решении?"
"Как ты бы это сделал?"
"Твоё мнение по этому вопросу?"
```

#### ✅ **ПРАВИЛЬНО:**

```
"Какие эксперты из команды должны обсудить [проблему]?
Что бы сказали [Эксперт1], [Эксперт2] и [Эксперт3]?
Какие аргументы они приведут?"
```

## 📚 Примеры использования

### Пример 1: Анализ архитектуры

**Запрос:**

```
"Какие эксперты должны обсудить архитектуру новой фичи?
Что бы сказали Андрей (System Architect), Игорь (Backend) и Сергей (DevOps)?
Как они подойдут к проектированию?"
```

**Результат:** Получите разносторонний анализ с точки зрения архитектуры, реализации и инфраструктуры.

---

### Пример 2: Оптимизация производительности

**Запрос:**

```
"Какая группа специалистов подходит для анализа производительности?
Что бы сказали Ольга (Performance Engineer), Игорь (Backend) и Сергей (DevOps)?
Какие метрики они проанализируют и какие решения предложат?"
```

**Результат:** Комплексный анализ производительности с конкретными метриками и решениями.

---

### Пример 3: Безопасность

**Запрос:**

```
"Какие эксперты должны обсудить безопасность API?
Что бы сказали Алексей (Security Engineer), Игорь (Backend) и Мария (Risk Manager)?
Какие уязвимости они найдут и какие меры предложат?"
```

**Результат:** Детальный security audit с рекомендациями.

## ✅ Чеклист правильного промпта

- [ ] Вопрос сформулирован через группу экспертов, а не "ты"
- [ ] Указаны конкретные эксперты из команды (2-3 человека)
- [ ] Запрошены разные точки зрения и аргументы
- [ ] Используется формат "Что бы сказали...", "Как подойдут...", "Какие аргументы..."

## 💡 Советы

1. **Всегда начинайте с вопроса:** "Какие эксперты должны обсудить..."
2. **Указывайте 2-3 эксперта** для разностороннего анализа
3. **Запрашивайте конкретные аспекты:** метрики, риски, решения
4. **Используйте формат обсуждения:** "Что бы сказали...", "Как подойдут..."
