# GOAL: Устранение зацикливания и оптимизация производительности (Singularity 24.7)

## Описание проблемы
1. **Зацикливание:** В логах `victoria-agent` постоянно опрашивается статус задачи `d8707d50-8c08-464f-9aed-265bebf5375e` (status=processing, output_len=0). При этом задача отсутствует в базе данных PostgreSQL. Необходимо принудительно очистить `_run_task_store` в памяти сервера или перезапустить сервис.
2. **Перегрузка Ollama:** Наблюдаются частые ошибки `HTTP 503: server busy`. Это замедляет работу RAG и диалогов. Нужно проверить загруженные модели и применить политику выгрузки (aggressive unload).
3. **Медленный RAG:** В логах gateway фиксируются запросы к `knowledge_nodes` длительностью до 10 секунд. Проверить индексы и нагрузку на БД.
4. **Приложение opencode:** Пользователь жалуется на отзывчивость в `atra-web-ide`. Проверить цепочку: Frontend -> Backend -> Victoria.

## Ожидаемый результат
- Логи `victoria-agent` чисты от опросов несуществующих задач.
- Ollama отвечает стабильно, лишние модели выгружены.
- RAG-запросы выполняются в пределах допустимых таймаутов.
- Victoria в приложении `opencode` (atra-web-ide) отвечает корректно и быстро.
