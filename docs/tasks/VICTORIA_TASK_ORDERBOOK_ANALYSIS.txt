ИЗВЕСТНАЯ СХЕМА (24.4 млн записей):
- time: TIMESTAMP WITH TIME ZONE
- ticker: VARCHAR (330 тикеров: SBER, GAZP, LKOH, NVTK, ROSN, BRJ6 и др.)
- msg_type: VARCHAR (O/T/L/H)
- payload: VARCHAR (формат зависит от msg_type)
- sequence: UBIGINT

ФОРМАТЫ PAYLOAD:
- O (снэпшот стакана, 19.2М записей): ticker:bid1price,bid1qty|bid2price,...:ask1price,ask1qty|...:nanotimestamp
- T (сделка, 3.9М записей): ticker:price:side(+1=buy/-1=sell):qty:nanotimestamp
- L (last price, 1.1М): ticker:price:nanotimestamp
- H (heartbeat, 32К): пустой payload

ИНСТРУМЕНТ: python3 из /Users/bikos/Documents/atra-web-ide/knowledge_os/.venv/bin/python3 с duckdb

ЗАДАЧИ (выполнить по порядку, каждую через отдельный python3 скрипт):

1. АНАЛИЗ СДЕЛОК (T-сообщения):
   - Распарси поля price, side, qty через SPLIT_PART
   - Посчитай buy_volume и sell_volume по каждому тикеру (топ-20 по суммарному объёму)
   - Вычисли buy/sell ratio. Флаги: ratio > 2.0 = давление покупателей (кит-бык), ratio < 0.5 = давление продавцов (кит-медведь)
   - Найди топ-5 сделок по объёму (крупнейшие единичные транзакции)

2. АНОМАЛИИ ЦЕНЫ:
   - Используй LAG() по тикеру для вычисления % изменения между соседними L-сообщениями
   - Найди все движения > 0.5% за один тик — это flash crash или spike
   - Выведи: время, тикер, цену до/после, % изменение

3. АНАЛИЗ СТАКАНА (O-сообщения для SBER и GAZP):
   - Извлеки best_bid = первое значение до первого ':' после ticker (первый уровень bids)
   - Извлеки best_ask = первый уровень asks
   - Вычисли spread = best_ask - best_bid
   - Найди топ-10 моментов с наибольшим спредом (аномальная ликвидность)
   - Найди средний спред за день и периоды расширения (признак ухода маркет-мейкеров)

4. АКТИВНОСТЬ ПО ВРЕМЕНИ:
   - Кол-во сделок по часам (07:00-18:00 МСК)
   - Топ-5 самых активных минут дня
   - Сравни объём первого часа (07:00-08:00) и последнего (17:00-18:00) — это признаки открытия/закрытия

5. ИТОГОВЫЙ ОТЧЁТ:
   На основе всех данных сформируй профессиональный аналитический отчёт:
   - Общий характер дня (бычий/медвежий/нейтральный)
   - Какие тикеры показали признаки активности китов
   - Поведение маркет-мейкеров (были ли периоды ухода из стакана)
   - Аномальные события и их вероятные причины
   - Топ-3 инсайта о скрытых мотивах участников рынка
