2. **opencode (atra-web-ide, порт 3000/8080):** Нет ответа.

## Задачи для Виктории
1. **Диагностика MLX/Ollama:** Проверить `active_requests` в MLX (порт 11435) и статус Ollama (порт 11434). Если есть зависшие запросы — сбросить.
2. **Аудит интерфейсов:**
   - **Open WebUI:** Проверить логи контейнера `open-webui` и связь с `victoria-agent`.
   - **opencode:** Проверить логи `atra-web-ide-backend` и `gateway`.
   - **Telegram:** Проверить статус контейнера `telegram-notifications` и логи обработки сообщений.
   - **Terminal:** Проверить `POST /run` и `POST /api/chat/stream` напрямую через curl.
3. **Оптимизация ресурсов:** Применить `aggressive unload` для Ollama и проверить RAM на Mac Studio.
4. **Устранение зацикливания:** Убедиться, что в памяти сервера нет "задач-призраков".
