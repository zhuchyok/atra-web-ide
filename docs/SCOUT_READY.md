## 🚀 КАК ЗАПУСТИТЬ

### Через дашборд:

1. Откройте `http://localhost:8501/#biznes-razvedka-analiz-rynkov`
2. Введите:
   - **Компания:** например, "Столичные окна"
   - **Локация:** например, "Чебоксары и Новочебоксарск"
3. ✅ **Включите "Enhanced разведку"** (чекбокс)
4. (Опционально) Укажите дополнительных конкурентов
5. Нажмите **"🕵️ Запустить максимальную разведку"**

### Что произойдет:

1. Дашборд запустит `enhanced_scout_researcher.py` через docker exec
2. Скрипт соберет 50-100+ источников данных
3. Выполнит глубокий анализ через локальную модель
4. Сохранит детальный отчет в БД
5. Отчет появится в разделе "Последние отчеты разведки" через 5-10 минут
