# TinyLlama - Только для коммуникации агентов

**Дата:** 2026-01-27  
**Статус:** ✅ **НАСТРОЕНО**

## 🎯 Назначение TinyLlama

**TinyLlama (1.1B параметров, 637 MB)** НЕ используется для генерации ответов пользователям.

### ✅ Правильное использование:

- **Роутинг запросов** между агентами
- **Классификация задач** для выбора модели
- **Передача информации** между сотрудниками и агентами
- **Быстрая обработка метаданных**
- **Внутренняя коммуникация** в системе

### ❌ НЕ используется для:

- Генерации ответов пользователям
- Создания контента
- Решения сложных задач
- Финализации результатов

## 📊 Мировые практики

### Исследования показывают:

1. **Модели 1-3B параметров** (как TinyLlama) оптимальны для:
   - Функций/инструментов/API вызовов (до 65.74% точности)
   - Роутинга и классификации задач
   - Легковесного принятия решений

2. **Архитектура агентского роутинга:**
   - Использует LLM классификаторы для определения назначения задач
   - Легковесные модели для роутинга, мощные для генерации
   - Разделение ответственности: роутинг ≠ генерация

3. **Multi-LLM Routing:**
   - Маленькие модели для классификации и роутинга
   - Большие модели для финальной генерации
   - Оптимизация ресурсов и скорости

## 🔧 Конфигурация в системе

### Исключено из ответов:

- ❌ `react_agent.py` - fallback модели
- ❌ `extended_thinking.py` - fallback модели
- ❌ `victoria_enhanced.py` - fallback модели
- ❌ `local_router.py` - OLLAMA_MODELS
- ❌ `mlx_api_server.py` - CATEGORY_TO_MODEL (fast)
- ❌ `backend/app/routers/chat.py` - выбор модели для чата

### Используется только для:

- ✅ Внутренняя коммуникация агентов
- ✅ Роутинг задач
- ✅ Классификация запросов
- ✅ Передача метаданных

## 📝 Примеры использования

### ✅ Правильно (внутренняя коммуникация):

```python
# Роутинг задачи
task_category = await tinyllama.classify_task(prompt)

# Передача информации между агентами
message = await tinyllama.format_agent_message(data)

# Классификация для выбора модели
model_choice = await tinyllama.select_model(task_type)
```

### ❌ Неправильно (генерация ответов):

```python
# НЕ использовать для ответов пользователям
response = await tinyllama.generate(prompt)  # ❌

# НЕ использовать для финализации
final_answer = await tinyllama.synthesize(results)  # ❌
```

## 🎯 Преимущества подхода

1. ✅ **Скорость** - быстрая обработка метаданных
2. ✅ **Эффективность** - не тратит ресурсы на генерацию
3. ✅ **Качество** - мощные модели для ответов
4. ✅ **Масштабируемость** - легковесный роутинг
