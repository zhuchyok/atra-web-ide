## Рекомендации

1. **Дебаты:** Добавить в дашборд отображение дебатов (expert council): запрос к `knowledge_nodes` по `metadata->>'cycle' LIKE 'nightly_council%'` и вывод списка/карточек.
2. **Стратегия → Финансы и ROI:** Добавить миграцию с `ALTER TABLE experts ADD COLUMN IF NOT EXISTS virtual_budget FLOAT DEFAULT 0`, `ADD COLUMN IF NOT EXISTS performance_score FLOAT` или обернуть запрос в try/except и показывать «N/A» при ошибке.
3. **Инструменты → Симулятор:** Добавить миграцию для таблицы `simulations` (id, idea, result, created_at) или создавать таблицу при первом запуске.
4. **Интеллект → Синтез Знаний:** Усилить импорт VictoriaEnhanced: попробовать `from victoria_enhanced import ...` затем `from app.victoria_enhanced import ...`.
5. **Обзор → Пульс (Безопасность):** Либо применить миграцию `add_anomaly_detection_logs.sql`, либо обернуть запрос в try/except и не скрывать ошибку (логировать или показывать «Таблица недоступна»).

После этих шагов все пункты на каждой вкладке либо работают, либо дают явное сообщение при отсутствии таблиц/сервисов.
