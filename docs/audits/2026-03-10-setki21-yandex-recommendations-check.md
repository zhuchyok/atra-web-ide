# Проверка рекомендаций Яндекса для setki21.ru (самостоятельная)

**Дата:** 10 марта 2026  
**Источник:** проверка по живым данным (сайт, Карты), не только выгрузка API Вебмастера.

---

## 1. Метрика (Яндекс.Метрика)

**Проверка:** загрузка https://www.setki21.ru/ и поиск в HTML признаков счётчика.

**Результат:**

- В `<head>` есть **preconnect** и **dns-prefetch** на `https://mc.yandex.ru` — сайт готов подгружать скрипты с домена Метрики.
- Кода инициализации счётчика (`ym(..., "init")` или явного `script` с номером счётчика) в статическом HTML не видно — он может быть в JS-бандле (`_nuxt/*.js`), который не разбирался.

**Вывод:** Подключение к домену Метрики есть; сам счётчик либо подгружается из бандла (и тогда рекомендация NO_METRIKA_COUNTER в Вебмастере в состоянии ABSENT логична), либо не установлен — в последнем случае имеет смысл добавить счётчик и привязать его в Вебмастере для учёта посещаемости и улучшения подсказок.

---

## 2. Справочник (Яндекс.Карты / организации)

**Проверка:** поиск в Яндекс.Картах (Чебоксары): «Сетки 21 Гражданская», «Сетки 21 москитные».

**Результат:**

- Найдена организация **«Mosquito nets»** по адресу **Гражданская, 53к2, этаж 3**, Чебоксары. В карточке указано: «Сетки 21 Чебоксары», «Москитные сетки на пластиковые и деревянные окна» — соответствует setki21.ru (на сайте: ул. Гражданская, 53).
- Отдельно есть **«Setka21»** (ул. Матросова, 12) — другая компания (ограждения, сетки), не москитные сетки.

**Вывод:** Организация **уже есть в Справочнике** (карточка по Гражданской 53). В диагностике Вебмастера NOT_IN_SPRAV = ABSENT — требования «добавить в Справочник» нет. При желании можно проверить в кабинете, что в карточке указан сайт https://www.setki21.ru и актуальные контакты.

---

## 3. Регион (география сайта)

**Проверка:** настройка «Регион» задаётся только в кабинете Яндекс.Вебмастера (раздел «Настройки индексирования» → «Регион»). По открытым данным (сайт, API) я не могу увидеть, какой регион выбран.

**Результат:** NO_REGIONS в диагностике = ABSENT — либо регион указан, либо проверка не срабатывает.

**Рекомендация:** В кабинете Вебмастера для https://www.setki21.ru проверить, что в «Регионе» указана Россия или Чувашская Республика / Чебоксары (в зависимости от доступных опций).
