## 🔍 Технические детали

### HTML-структура фавиконов

Все три сайта используют одинаковую структуру подключения иконок:

```html
<link
  rel="icon"
  type="image/x-icon"
  href="/favicon.ico?v=default&h="
  data-hid="favicon"
/>
<link
  rel="shortcut icon"
  href="/favicon.ico?v=default&h="
  data-hid="shortcut"
/>
<link
  rel="apple-touch-icon"
  href="/favicon.ico?v=default&h="
  data-hid="apple"
/>
```

**Параметр `v=default`** — версия иконки, контролируется через tenant config.

**Параметр `h=`** — пустой hash (вероятно, для кэш-буста при обновлении).

### HTML-структура логотипа в шапке

Логотип в header загружается динамически через Nuxt/Vue.js. В SSR-версии виден skeleton:

```html
<header class="bg-white border-b border-gray-100 sticky top-0 z-50">
  <div class="container mx-auto px-4 py-3">
    <div class="flex flex-wrap justify-between items-center gap-4">
      <a href="/" class="logo-link flex items-center gap-3">
        <!-- Skeleton во время загрузки -->
        <div
          class="h-10 sm:h-12 w-10 sm:w-12 rounded-lg bg-gray-100 animate-pulse"
        ></div>
        <div class="min-w-0 flex flex-col gap-1">
          <div class="h-5 sm:h-6 w-24 rounded bg-gray-100 animate-pulse"></div>
          <div class="h-3 w-32 rounded bg-gray-50 animate-pulse"></div>
        </div>
      </a>
    </div>
  </div>
</header>
```

После гидратации Vue.js подставляет реальные данные из tenant config:

```html
<img :src="tenantConfig.branding.logo_url" alt="Логотип" />
```

## 🛠️ Рекомендации по улучшению (опционально)

### 1. Добавить Apple Touch Icon

**Где:** `/public/apple-touch-icon.png` (или через Nginx alias)

**Формат:** PNG 180x180px (для современных iOS-устройств)

**Приоритет:** Низкий (косметическое улучшение для iOS)

### 2. Реализовать динамические фавиконы для дилеров

**Backend:** Эндпоинт `/api/v1/tenant/favicon` возвращает разные `.ico` в зависимости от домена

**Frontend:** Обновить `nuxt.config.ts`:

```javascript
head: {
  link: [
    {
      rel: "icon",
      type: "image/x-icon",
      href: () =>
        useTenantStore().config.branding.favicon_url || "/favicon.ico",
    },
  ];
}
```

**Приоритет:** Низкий (требование о брендинге фавиконов не критично)

### 3. Реализовать уникальные логотипы дилеров

**БД:** Добавить колонку `logo_url` в таблицу `tenants` (если ещё нет)

**Backend:** При создании дилера — загружать его логотип в `/uploads/logos/{dealer_id}.png`

**Frontend:** Использовать `tenantConfig.branding.logo_url` вместо хардкода

**Приоритет:** Средний (если дилеры хотят собственные логотипы)
