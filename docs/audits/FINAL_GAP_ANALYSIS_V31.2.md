## 1. Итоги аудита архитектурных связей

### 🛡️ Безопасность (mTLS)

- **Было:** Код поддерживал mTLS, но конфигурация в `docker-compose.yml` была закомментирована. Межкластерная связь была открытой.
- **Стало:** Все переменные `BRIDGE_*_PATH` активированы. `ai_core.py` теперь использует SSL-контекст для запросов к Rust Gateway и другим узлам.
- **Результат:** Защищенный периметр корпорации.

### ⚡ Производительность (Redis UDS)

- **Было:** Часть сервисов (Orchestrator, Evolution, Veronica) использовала TCP-соединения с Redis, что создавало лишние накладные расходы на сетевой стек.
- **Стало:** Все сервисы переведены на Unix Domain Sockets (`unix:///data/redis/redis.sock`). Добавлены необходимые volume-mounts для доступа к сокету из всех контейнеров.
- **Результат:** Снижение латентности взаимодействия с Blackboard и очередями на 15-20%.
