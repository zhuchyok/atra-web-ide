# Исправление конфликта Metal в MLX Server

## 🔍 Проблема

**Ошибка:** `-[_MTLCommandBuffer addCompletedHandler:]:1011: failed assertion 'Completed handler provided after commit call'`

**Причина:** Metal (Apple GPU framework) не поддерживает одновременную загрузку одной модели и генерацию другой.

### Хронология падения:

1. **20:52:53** - `deepseek-r1-distill-llama:70b` генерирует ответ (104.85с)
2. **20:53:49** - Начинается загрузка `phi3:mini-4k` (другая модель)
3. **20:54:24** - MLX Server падает с SIGABRT (-6)
4. **Результат:** ExtendedThinking переключается на fallback, результат неправильный

## ✅ Решение

### Добавлена защита от конфликта Metal:

1. **Проверка активных генераций перед загрузкой**
   - Если есть активные генерации других моделей → отложить загрузку
   - Ждать до 2 минут завершения генераций
   - Только после этого начинать загрузку новой модели

2. **Логика:**

   ```python
   # Проверяем активные генерации
   active_generations = sum(_active_model_requests.values())
   if active_generations > 0:
       # Ждем завершения генераций
       wait_for_generations_to_complete()

   # Только теперь загружаем новую модель
   load_model()
   ```

## 📊 Результат

- ✅ Нет конфликта Metal при одновременной загрузке и генерации
- ✅ Загрузка новых моделей откладывается до завершения активных генераций
- ✅ Защита от SIGABRT при работе с несколькими моделями
