## 🔍 ОБЪЯСНЕНИЕ ПРЕДУПРЕЖДЕНИЙ

### ⚠️ MLX Router недоступен

**Предупреждение:**

```
WARNING:mlx_router:⚠️ MLX недоступен: No module named 'mlx'
WARNING:mlx_router:⚠️ MLX Router недоступен (требуется Apple Silicon)
```

**Что это значит:**

- **MLX Router** - это локальный роутер, который требует модуль `mlx` (только на Apple Silicon)
- Это **НЕ критично** - это просто оптимизация для прямого использования MLX
- Система работает **БЕЗ** MLX Router

**Разница:**

- **MLX Router** (требует модуль mlx) - локальная оптимизация, НЕ обязательна
- **MLX API Server** (порт 11435) - отдельный HTTP сервер, НЕ требует модуль mlx в контейнере
