## 🔄 АВТОМАТИЧЕСКОЕ ОБНОВЛЕНИЕ

### Когда обновляются знания:

1. **При запуске Enhanced Orchestrator** - перед каждым циклом
2. **При запуске Victoria** - динамически при старте
3. **Вручную** - через `update_corporation_knowledge.py`

### Как запустить обновление:

```bash
# Вручную
python knowledge_os/app/update_corporation_knowledge.py

# Через Docker
docker exec knowledge_os_api python /app/update_corporation_knowledge.py
```
