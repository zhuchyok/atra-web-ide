## ✅ ЧТО VICTORIA УМЕЕТ ДЕЛАТЬ

### 🛠️ Инструменты Victoria Enhanced (ReAct Framework)

Victoria имеет доступ к следующим инструментам:

1. **read_file** - Чтение файлов
   - Параметры: `file_path` (путь к файлу)
   - Пример: `{"action": "read_file", "input": {"file_path": "test.py"}}`

2. **run_terminal_cmd** - Выполнение команд в терминале
   - Параметры: `command` (команда для выполнения)
   - Пример: `{"action": "run_terminal_cmd", "input": {"command": "ls -la"}}`

3. **list_directory** - Список файлов в директории
   - Параметры: `directory` или `path` (путь к директории)
   - Пример: `{"action": "list_directory", "input": {"directory": "/tmp"}}`

4. **create_file** - Создание файлов
   - Параметры: `file_path` (путь), `content` (содержимое)
   - Пример: `{"action": "create_file", "input": {"file_path": "test.txt", "content": "привет"}}`

5. **write_file** - Запись в файлы (создает или перезаписывает)
   - Параметры: `file_path` (путь), `content` (содержимое)
   - Пример: `{"action": "write_file", "input": {"file_path": "test.txt", "content": "новый текст"}}`

6. **search_knowledge** - Поиск в базе знаний
   - Параметры: `query` (поисковый запрос)
   - Пример: `{"action": "search_knowledge", "input": {"query": "как работает Victoria"}}`

7. **finish** - Завершение задачи
   - Параметры: `output` (результат задачи)
   - Пример: `{"action": "finish", "input": {"output": "Задача выполнена"}}`

## 🎯 КАК VICTORIA ВЫБИРАЕТ МЕТОД

Victoria Enhanced автоматически выбирает метод в зависимости от задачи:

### Simple метод (для простых вопросов):

- ✅ Быстрые ответы
- ✅ Использует MLX API Server (приоритет)
- ❌ НЕ использует инструменты (только генерация текста)

### ReAct метод (для задач с действиями):

- ✅ Использует ReAct Framework (Think → Act → Observe → Reflect)
- ✅ **ИСПОЛЬЗУЕТ ИНСТРУМЕНТЫ** (read_file, run_terminal_cmd, create_file и т.д.)
- ✅ Может выполнять команды, создавать файлы, читать файлы
- ✅ Автоматически выбирается для задач с ключевыми словами: "создай", "выполни", "прочитай", "напиши код"

### Extended Thinking (для reasoning задач):

- ✅ Глубокое рассуждение
- ❌ НЕ использует инструменты (только рассуждение)

### Swarm Intelligence (для сложных задач):

- ✅ Параллельная работа команды экспертов
- ✅ Может использовать инструменты через экспертов

## 🔍 ПРОБЛЕМА: Почему Victoria может не выполнять действия?

### Причина 1: Неправильная категоризация

**Проблема:** Простые задачи попадают в категорию "fast" → используется "simple" метод → нет инструментов

**Решение:** ✅ Исправлено - задачи с "создай", "выполни" теперь попадают в категорию "coding" → используется "react" метод

### Причина 2: ReActAgent не находит модели

**Проблема:** ReActAgent не может подключиться к MLX/Ollama из Docker контейнера

**Решение:** ✅ Исправлено - добавлена поддержка `host.docker.internal` для Docker

### Причина 3: ReActAgent использует заглушку для действий

**Проблема:** `_execute_action` была заглушкой (TODO)

**Решение:** ✅ Исправлено - интегрированы реальные инструменты (read_file, run_terminal_cmd, create_file, list_directory)
