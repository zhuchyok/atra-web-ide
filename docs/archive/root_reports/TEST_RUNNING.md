### Где найти результаты:

После завершения теста результаты будут сохранены в:

```bash
# HTML файл сайта
logs/website_YYYYMMDD_HHMMSS.html

# Текстовый файл с результатом
logs/website_result_YYYYMMDD_HHMMSS.txt

# JSON трейс
logs/task_trace_result_YYYYMMDD_HHMMSS.json

# Детальный лог
logs/task_trace_YYYYMMDD_HHMMSS.log
```

### Проверка статуса:

```bash
# Проверить последние файлы результатов
ls -lt logs/website*.html logs/website*.txt 2>/dev/null | head -5

# Проверить последний лог
tail -100 logs/task_trace_*.log | grep -E "(РЕЗУЛЬТАТ|COMPLETE|сайт)"
```
