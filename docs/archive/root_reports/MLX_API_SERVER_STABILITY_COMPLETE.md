## 🔄 ПОВЕДЕНИЕ ПРИ ПАДЕНИИ

### Автоматическое восстановление:

1. **Обнаружение падения**
   - Монитор проверяет процесс каждые 30 секунд
   - Проверяет доступность API каждые 30 секунд

2. **Автоматический перезапуск**
   - Убивает старый процесс (если есть)
   - Запускает новый процесс через `start_mlx_api_server.sh`
   - Проверяет доступность после запуска
   - Логирует результат

3. **Защита от бесконечных циклов**
   - Лимит 5 перезапусков в час
   - При достижении лимита требуется ручное вмешательство
   - Счетчик сбрасывается каждый час

## 🎯 РЕЗУЛЬТАТ

**✅ MLX API SERVER ТЕПЕРЬ УСТОЙЧИВ К ПАДЕНИЯМ!**

Сервер теперь:

- Не падает при ошибках загрузки моделей
- Корректно завершается при получении сигналов
- Логирует все ошибки для диагностики
- Имеет health check для мониторинга
- Автоматически перезапускается при падении
- Защищен от бесконечных циклов перезапуска

**Примечание:** MLX API Server **НЕ зависит от интернета** - он использует только локальные модели. Падения из-за потери интернета невозможны.
