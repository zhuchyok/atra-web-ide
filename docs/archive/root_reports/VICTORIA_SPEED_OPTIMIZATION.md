# Victoria Enhanced - Оптимизация скорости ответов

**Дата:** 2026-01-26  
**Статус:** ✅ Реализовано

## 🚀 Цель

Оптимизировать Victoria Enhanced для максимально быстрых ответов на простые задачи, сохраняя мощь корпорации для сложных задач.

## ✅ Реализовано

### 1. Умная категоризация задач

**Файл:** `knowledge_os/app/victoria_enhanced.py`

- ✅ **Быстрые задачи** определяются автоматически:
  - Короткие запросы (≤5 слов)
  - Простые вопросы (≤8 слов с "?")
  - Ключевые слова: "привет", "как дела", "скажи", "покажи", "список"
- ✅ **Категории задач:**
  - `fast` - простые задачи (максимальная скорость)
  - `reasoning` - сложные рассуждения
  - `planning` - планирование
  - `complex` - комплексные задачи
  - `coding` - программирование
  - `execution` - выполнение действий
  - `general` - общие задачи

### 2. Оптимизированный выбор метода

- ✅ **Быстрые задачи** → `simple` метод (прямая генерация, без Extended Thinking)
- ✅ **Сложные задачи** → Extended Thinking, Swarm, Consensus (мощные методы)
- ✅ **Код** → ReAct Framework или simple метод

### 3. Быстрый метод (Simple Mode)

**Для категории `fast`:**

- ✅ Использует **самые быстрые модели** (приоритет):
  1. `tinyllama:1.1b-chat` (~700MB, самый быстрый)
  2. `phi3:mini-4k` (~2GB)
  3. `qwen2.5:3b` (~2GB)
  4. `phi3.5:3.8b` (~2.5GB)

- ✅ **Короткий таймаут**: 10 секунд (вместо 120)
- ✅ **Ограничение токенов**: 200 (вместо 2048)
- ✅ **Прямая генерация** без промежуточных шагов
- ✅ **Оптимизированный промпт** для кратких ответов

### 4. Автоматический выбор модели

Victoria Enhanced автоматически выбирает модель:

| Категория     | Приоритет моделей                              | Метод               |
| ------------- | ---------------------------------------------- | ------------------- |
| **fast**      | tinyllama → phi3:mini-4k → qwen2.5:3b          | simple (⚡ быстрый) |
| **reasoning** | deepseek-r1 → llama3.3:70b → qwen2.5-coder:32b | extended_thinking   |
| **complex**   | command-r-plus → llama3.3:70b → deepseek-r1    | swarm/consensus     |
| **coding**    | qwen2.5-coder:32b → phi3.5:3.8b                | react/simple        |
| **general**   | qwen2.5-coder:32b → phi3.5:3.8b                | simple              |

## 🎯 Как это работает

### Процесс обработки:

1. **Анализ задачи** → определение категории (`fast`, `reasoning`, `complex`, etc.)
2. **Выбор метода** → `simple` для быстрых задач, мощные методы для сложных
3. **Выбор модели** → самая быстрая доступная модель для категории
4. **Генерация** → прямая генерация для `simple`, многошаговая для сложных задач

### Примеры:

**Простая задача:**

```
Запрос: "Привет! Как дела?"
→ Категория: fast
→ Метод: simple
→ Модель: tinyllama:1.1b-chat
→ Время: <2 секунды
```

**Сложная задача:**

```
Запрос: "Реши сложную математическую задачу с доказательством"
→ Категория: reasoning
→ Метод: extended_thinking
→ Модель: deepseek-r1-distill-llama:70b
→ Время: 10-30 секунд (глубокий анализ)
```

## 📊 Результаты оптимизации

- ✅ **Простые задачи**: <2 секунды (быстрый метод + tinyllama)
- ✅ **Сложные задачи**: 10-30 секунд (мощные методы + большие модели)
- ✅ **Автоматический выбор**: оптимальный баланс скорости и качества
- ✅ **Fallback**: если модель недоступна, используется следующая из списка
