## 📊 ЧТО БУДЕТ ОТСЛЕЖИВАТЬСЯ

### 1. Выбор моделей на каждом этапе:

- **Victoria** → выбирает модель для анализа задачи
- **Veronica** → распределяет задачи (не выбирает модель, только распределяет)
- **Сотрудники** → каждый выбирает модель для своей задачи

### 2. Промпты:

- Промпт Victoria для анализа задачи
- Промпт Victoria для Veronica (с распределением задач)
- Промпт для каждого сотрудника
- Промпт для валидации
- Промпт для синтеза

### 3. Движение задачи:

```
Victoria (получает задачу)
  ↓
Victoria (анализирует, выбирает модель)
  ↓
Victoria (создает промпт для Veronica)
  ↓
Veronica (распределяет по структуре)
  ↓
Сотрудники (каждый выбирает модель и выполняет)
  ↓
Управляющие (проверяют)
  ↓
Department Head (собирает)
  ↓
Veronica (собирает все)
  ↓
Victoria (синтезирует, выбирает модель)
```

## 📄 РЕЗУЛЬТАТЫ

### Логи:

- `logs/task_trace_YYYYMMDD_HHMMSS.log` - детальный лог
- `logs/task_trace_result_YYYYMMDD_HHMMSS.json` - JSON трейс

### В JSON будет:

- Все этапы с временными метками
- Все выборы моделей с причинами
- Все промпты
- Все решения
- Метрики выполнения
