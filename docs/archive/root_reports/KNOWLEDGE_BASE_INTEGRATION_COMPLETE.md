## 🔍 КАК ИСПОЛЬЗУЕТСЯ

### Автоматически:

1. **При каждом запросе к агенту:**
   - `_get_knowledge_context()` ищет релевантные знания
   - Контекст автоматически добавляется к промпту
   - Включает знания корпорации если релевантны

2. **Через инструменты:**
   - `search_knowledge("какие модели доступны")` - найдет модели
   - `search_knowledge("какие скрипты есть")` - найдет скрипты
   - `search_knowledge("что изменилось")` - найдет изменения

### Вручную:

```python
from app.main import search_knowledge, capture_knowledge

# Поиск
results = await search_knowledge("модели Ollama", domain="System")

# Сохранение
await capture_knowledge(
    "Новая информация",
    domain="System",
    metadata={"source": "manual", "type": "info"}
)
```
