## ✅ РЕШЕНИЕ

### 1. Скрипт автоматического переподключения Wi-Fi

**Файл:** `scripts/wifi_reconnect.sh`

**Функции:**

- ✅ `check_wifi_connected()` - проверка подключения к Wi-Fi
- ✅ `check_internet_via_wifi()` - проверка интернета через Wi-Fi
- ✅ `reconnect_wifi()` - автоматическое переподключение к Wi-Fi

**Логика работы:**

1. Проверяет, подключен ли Wi-Fi
2. Проверяет доступность интернета через Wi-Fi
3. Если Wi-Fi не подключен или интернет недоступен:
   - Выключает Wi-Fi
   - Включает Wi-Fi
   - Подключается к последней использованной сети
   - Проверяет доступность интернета
   - Ждет до 30 секунд для подключения

## 🛠️ ТЕХНИЧЕСКИЕ ДЕТАЛИ

### Команды macOS:

- `networksetup -setairportpower` - управление Wi-Fi
- `airport -I` - информация о Wi-Fi подключении
- `ping` - проверка интернета

### Проверка Wi-Fi:

```bash
# Проверка подключения
/System/Library/PrivateFrameworks/Apple80211.framework/Resources/airport -I | grep "SSID:"

# Получение SSID
/System/Library/PrivateFrameworks/Apple80211.framework/Resources/airport -I | grep " SSID:" | awk -F': ' '{print $2}'
```

### Управление Wi-Fi:

```bash
# Получение интерфейса Wi-Fi
WIFI_INTERFACE=$(networksetup -listallhardwareports | grep -A 1 "Wi-Fi" | grep "Device" | awk '{print $2}')

# Выключение Wi-Fi
networksetup -setairportpower "$WIFI_INTERFACE" off

# Включение Wi-Fi
networksetup -setairportpower "$WIFI_INTERFACE" on
```
