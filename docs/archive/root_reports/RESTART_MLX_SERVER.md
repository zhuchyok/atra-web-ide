# 🔄 Перезапуск MLX API Server

**Проблема:** Порт 11435 занят старым процессом  
**Решение:** Остановить старый процесс и перезапустить сервер

---

## 🛑 Остановка старого процесса

```bash
# Найти процесс
lsof -i :11435

# Остановить процесс (PID 37224)
kill 37224

# Или принудительно
kill -9 37224
```

---

## ✅ Изменения, которые применятся после перезапуска:

1. **Убрана предзагрузка `tinyllama`** - теперь предзагружаются только `default` и `fast`
2. **Увеличен rate limit** - с 30 до 100 запросов в минуту
3. **Добавлен fallback на Ollama** при 429/500 ошибках в `extended_thinking.py`
4. **Добавлен Anthropic-compatible endpoint** `/v1/messages`

---

## 🚀 Запуск нового сервера

```bash
cd knowledge_os
python3 -m uvicorn app.mlx_api_server:app --host 0.0.0.0 --port 11435 --reload
```

Или через скрипт:

```bash
./scripts/start_mlx_api_server.sh
```
