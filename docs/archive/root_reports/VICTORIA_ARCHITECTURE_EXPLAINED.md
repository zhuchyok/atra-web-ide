## ✅ ОТВЕТ: НЕТ, ЭТО ОДНА И ТА ЖЕ VICTORIA!

Victoria — это **один агент**, который работает на порту **8010**.  
К нему можно подключиться через **разные интерфейсы**.

## 🔍 ПОДРОБНОЕ ОБЪЯСНЕНИЕ

### 1. **Victoria Agent** (порт 8010)

- **Это ОДИН агент** — Team Lead корпорации
- Работает на порту **8010**
- Обрабатывает задачи и отвечает через API

### 2. **Frontend** (порт 3002)

- **Это веб-интерфейс** (браузер)
- **НЕ является Victoria**, это просто UI
- Отправляет запросы в **Backend** (порт 8080)
- Backend подключается к Victoria (порт 8010)

**Цепочка:** Frontend (3002) → Backend (8080) → Victoria (8010)

### 3. **Telegram Bot**

- **Это отдельный процесс** (Python скрипт)
- Подключается **напрямую** к Victoria (порт 8010)
- Не использует Backend

**Цепочка:** Telegram → Telegram Bot → Victoria (8010)

### 4. **Backend** (порт 8080)

- FastAPI сервер
- Получает запросы от Frontend
- Подключается к Victoria (порт 8010)
- Возвращает ответы Frontend

---

## 📋 КАК ЭТО РАБОТАЕТ

### Сценарий 1: Чат через веб (http://localhost:3002)

1. Пользователь открывает `http://localhost:3002` в браузере
2. Frontend отправляет запрос: `POST /api/chat/stream`
3. Backend получает запрос и отправляет в Victoria: `POST http://localhost:8010/run`
4. Victoria обрабатывает и отвечает
5. Backend получает ответ и отправляет в Frontend через SSE
6. Frontend показывает ответ пользователю

### Сценарий 2: Чат через Telegram

1. Пользователь отправляет сообщение в Telegram боту
2. Telegram Bot получает сообщение через Telegram API
3. Telegram Bot отправляет в Victoria: `POST http://localhost:8010/run`
4. Victoria обрабатывает и отвечает
5. Telegram Bot получает ответ и отправляет в Telegram
6. Пользователь видит ответ в Telegram

---

## ✅ ВЫВОД

**Это ОДНА И ТА ЖЕ Victoria!**

- **Веб (3002):** Frontend → Backend → Victoria (8010)
- **Telegram:** Telegram Bot → Victoria (8010)

Оба интерфейса используют **один и тот же агент Victoria** на порту 8010.

---

## 🔧 КОНФИГУРАЦИЯ

### Victoria URL в разных местах:

1. **Backend** (`.env` или `docker-compose.yml`):

   ```env
   VICTORIA_URL=http://victoria-agent:8000  # В Docker
   # или
   VICTORIA_URL=http://localhost:8010  # Локально
   ```

2. **Telegram Bot** (`.env`):

   ```env
   VICTORIA_URL=http://localhost:8010
   ```

3. **Frontend** (не настраивается напрямую):
   - Frontend использует Backend API (`/api/chat/stream`)
   - Backend сам подключается к Victoria
