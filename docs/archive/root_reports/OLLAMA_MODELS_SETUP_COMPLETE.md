## 🔄 Как работает система

### Приоритет использования:

#### Для текстовых задач:

1. **MLX API Server** (порт 11435) - приоритет 1
2. **Ollama** с `phi3.5:3.8b` (порт 11434) - fallback
3. **Облачные модели** - последний fallback

#### Для vision задач:

1. **Moondream Station** (MLX, порт 2020) - приоритет 1
2. **Ollama** с `moondream` - для обычных изображений
3. **Ollama** с `llava:7b` - для PDF документов
4. **Облачные модели** - последний fallback

    prompt="Привет!",
