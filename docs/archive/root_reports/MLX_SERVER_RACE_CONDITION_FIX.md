# Исправление Race Condition в MLX Server

## 🔍 Проблема

**Момент падения:** 20:05:26 - 20:05:31  
**Причина:** SIGABRT (-6) - аварийное завершение  
**Корневая причина:** Race condition при параллельной загрузке модели

### Анализ проблемы

1. **Модель не тяжелая?**
   - `deepseek-r1-distill-llama:70b` - это ~40GB модель (distilled версия)
   - Для Mac Studio M4 Max с 128GB RAM это не должно быть проблемой
   - **НО:** проблема не в размере одной модели!

2. **Реальная проблема: Race Condition**

   ```
   Запрос 1 → проверяет кэш → нет → начинает загрузку (40GB)
   Запрос 2 → проверяет кэш → нет → начинает загрузку (40GB)
   Результат: 80GB в памяти одновременно → OOM → SIGABRT
   ```

3. **Почему это происходило:**
   - Два запроса приходят одновременно для одной модели
   - Оба проходят проверку `if model_key in _models_cache` ДО загрузки
   - Оба начинают загружать модель одновременно
   - Блокировка `model_lock` защищает только внутри функции, но проверка кэша происходит ДО блокировки
   - Результат: двойная загрузка = 80GB вместо 40GB

## ✅ Исправление

### Изменения в `get_model()`:

1. **Проверка кэша ПЕРЕД добавлением в `_loading_models`**
   - Сначала проверяем, есть ли модель в кэше
   - Если есть - возвращаем сразу

2. **Проверка `_loading_models` перед загрузкой**
   - Если модель уже загружается другим запросом - ждем
   - Освобождаем блокировку и периодически проверяем кэш
   - Максимум 60 секунд ожидания

3. **Двойная проверка после ожидания**
   - После ожидания снова проверяем кэш
   - Если модель загрузилась - используем из кэша
   - Если нет - пытаемся загрузить сами

### Защита от параллельной загрузки:

```python
# 1. Проверка кэша ПЕРВОЙ (быстро)
if model_key in _models_cache:
    return _models_cache[model_key]

# 2. Проверка, не загружается ли уже
if model_key in _loading_models:
    # Ждем завершения загрузки другим запросом
    wait_for_loading_to_complete()
    if model_key in _models_cache:
        return _models_cache[model_key]

# 3. Только теперь начинаем загрузку
_loading_models.add(model_key)
load_model()
```

## 📊 Результат

- ✅ Нет двойной загрузки одной модели
- ✅ Параллельные запросы ждут завершения загрузки
- ✅ Экономия памяти: 40GB вместо 80GB
- ✅ Защита от OOM при параллельных запросах
