**Требуемые модели для лучшего качества:**

- ⚠️ phi3.5:3.8b (~2.5GB) - **НЕ ЗАГРУЖЕНА**
- ⚠️ qwen2.5:3b (~2GB) - **НЕ ЗАГРУЖЕНА**
- ⚠️ phi3:mini-4k (~2GB) - **НЕ ЗАГРУЖЕНА**

## ✅ Что уже сделано

1. **Приоритеты моделей обновлены:**
   - Для категории `fast`: phi3.5:3.8b → qwen2.5:3b → phi3:mini-4k → tinyllama:1.1b-chat
   - Система автоматически пробует более мощные модели сначала

2. **MLX API Server приоритет:**
   - Система пробует MLX API Server (11435) сначала
   - Fallback на Ollama (11434) если MLX недоступен

3. **Параметры оптимизированы:**
   - Таймаут: 15 секунд для fast задач
   - Макс токенов: 100 для приветствий, 150 для других fast задач
   - Температура: 0.4 для приветствий, 0.5 для других fast задач

## 🚀 Как загрузить более мощные модели

### Вариант 1: Загрузить в Ollama

```bash
# Загрузить phi3.5:3.8b (рекомендуется для простых ответов)
ollama pull phi3.5:3.8b

# Или qwen2.5:3b (хорошо понимает русский)
ollama pull qwen2.5:3b

# Или phi3:mini-4k (быстрая альтернатива)
ollama pull phi3:mini-4k
```

### Вариант 2: Использовать MLX API Server

Если MLX API Server запущен и содержит более мощные модели, система автоматически будет использовать их.
