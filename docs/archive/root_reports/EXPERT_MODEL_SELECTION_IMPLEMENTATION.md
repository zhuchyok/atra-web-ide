## 🔄 КАК ЭКСПЕРТ ВЫБИРАЕТ МОДЕЛЬ

### Вариант 1: Эксперт сам выбирает (expert_choice)

```python
# Эксперт получает промпт с рекомендациями
prompt = """
ЗАДАЧА: Создать API endpoint
РЕКОМЕНДУЕМЫЕ МОДЕЛИ: qwen2.5-coder:32b, phi3.5:3.8b (можешь выбрать сам)

Ты можешь:
1. Использовать рекомендованную модель
2. Выбрать свою модель из доступных
3. Выбрать модель на основе анализа задачи
"""

# Эксперт анализирует и выбирает
if expert_has_knowledge():
    selected_model = expert_select_model()  # Своя модель
else:
    selected_model = recommended_models[0]  # Рекомендация
```

### Вариант 2: Следовать рекомендациям (recommended)

```python
# Эксперт получает промпт с обязательными рекомендациями
prompt = """
ЗАДАЧА: Создать API endpoint
РЕКОМЕНДУЕМЫЕ МОДЕЛИ: qwen2.5-coder:32b, phi3.5:3.8b (используй эти модели)
"""

# Эксперт использует рекомендацию
selected_model = recommended_models[0]
```

### Вариант 3: Автоматический выбор (auto)

```python
# Система сама выбирает модель
selected_model = await auto_select_model(task.category)
```
