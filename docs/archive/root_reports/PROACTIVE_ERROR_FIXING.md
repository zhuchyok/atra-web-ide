### 1. **Автоматическое исправление в Enhanced Orchestrator** ✅

**Модуль:** `error_auto_fixer.py`

**Что исправляется автоматически:**

- ✅ Застрявшие задачи (in_progress > 1 дня) → возвращаются в pending

**Когда запускается:**

- Перед выполнением миграций

## 📋 ТИПИЧНЫЕ ОШИБКИ И ИХ ИСПРАВЛЕНИЯ

### 1. Застрявшие задачи

**Проблема:** Задачи в `in_progress` > 1 дня

**Автоисправление:**

```sql
UPDATE tasks
SET status = 'pending'
WHERE status = 'in_progress'
AND updated_at < NOW() - INTERVAL '1 day'
```

---

### 2. Задачи без экспертов

**Проблема:** Pending задачи без `assignee_expert_id`

**Автоисправление:**

- Запускается Enhanced Orchestrator для назначения экспертов
- Используется улучшенная логика с fallback

---

### 3. Ошибки миграций

**Проблема:** Foreign key constraints, отсутствующие таблицы

**Автоисправление:**

- Проверка существования перед созданием
- Удаление проблемных constraints
- Логирование для ручного исправления

---

### 4. Redis недоступен

**Проблема:** Connection errors к Redis

**Автоисправление:**

- Graceful degradation (работает без Redis)
- Автоматический поиск альтернативных URL
- Продолжение работы без блокировок

---

### 5. Отсутствующие таблицы

**Проблема:** `relation "table_name" does not exist`

**Автоисправление:**

- Проверка наличия таблиц
- Автоматический запуск миграций при необходимости
