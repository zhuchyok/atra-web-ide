## 🎯 Что такое Claude Code?

**Claude Code** - это **агентный инструмент для кодирования** от компании Anthropic (создатели Claude AI). Это не просто чат-бот, а полноценный **AI-ассистент в терминале**, который может:

### ✨ Что умеет Claude Code:

1. **📖 Читать код** - Анализировать весь проект, понимать структуру
2. **✏️ Модифицировать код** - Редактировать файлы, добавлять функции
3. **▶️ Выполнять код** - Запускать команды, тесты, скрипты
4. **🔍 Анализировать проекты** - Находить баги, предлагать улучшения
5. **📝 Писать код** - Создавать новые файлы, функции, модули

---

## 🤔 Зачем это НАМ в ATRA?

### Проблема сейчас:

**Victoria работает через API:**

- Вы отправляете задачу → Victoria думает → Возвращает ответ
- Нет прямого доступа к файлам проекта
- Нет возможности "видеть" весь контекст проекта сразу
- Нет интерактивного режима разработки

### Решение с Claude Code:

**Claude Code работает локально:**

- Открываете терминал в директории проекта
- Claude Code "видит" ВСЕ файлы проекта
- Может сразу читать, редактировать, выполнять
- Интерактивный режим - как работа с коллегой рядом

---

## 🔗 Как работает Claude Code + Ollama/MLX?

### Обычно Claude Code работает так:

```
Claude Code → Anthropic API (платно) → Claude Sonnet → Ответ
```

### С Ollama работает так:

```
Claude Code → Ollama (локально/бесплатно) → Ollama модель → Ответ
```

**Ollama эмулирует Anthropic API**, поэтому Claude Code думает, что работает с Anthropic, но на самом деле использует Ollama модели.

### С MLX API Server работает так (НОВОЕ!):

```
Claude Code → MLX API Server (локально/быстро) → MLX модель → Ответ
```

**MLX API Server теперь тоже эмулирует Anthropic API!** Теперь Claude Code может работать напрямую с нашими MLX моделями, которые быстрее на Apple Silicon!

## 💡 Преимущества для ATRA

### 1. **Локальная разработка**

- Не нужно отправлять код в облако
- Всё работает на вашем Mac Studio
- Приватность и безопасность

### 2. **Использование наших моделей**

- **MLX модели** (быстрее на Apple Silicon):
  - `qwen2.5-coder:32b` - специализированная coding модель
  - `phi3.5:3.8b` - быстрая модель
  - `tinyllama:1.1b-chat` - очень быстрая модель
- **Ollama модели**:
  - `qwen3-coder` - специализированная coding модель
  - `glm-4.7` - мощная reasoning модель
  - `gpt-oss:20b/120b` - максимальное качество (Cloud)
- **Бесплатно** (локально) или через Cloud

### 3. **Полный контекст проекта**

- Claude Code видит ВСЮ структуру проекта
- Понимает зависимости между файлами
- Может работать с несколькими файлами одновременно

### 4. **Интерактивный режим**

- Как работа с коллегой-программистом
- Задаете вопрос → Получаете ответ + код
- Можете уточнять, просить изменить

### 5. **Интеграция с Victoria**

- Victoria может планировать задачи
- Claude Code может выполнять их локально
- Комбинация: стратегия (Victoria) + тактика (Claude Code)

## 🛠️ Как настроить и использовать

### Шаг 1: Установить Claude Code

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

### Шаг 2: Настроить для работы с Ollama или MLX

**Вариант А: С MLX API Server (рекомендуется для Mac Studio)**

```bash
# Запустить MLX API Server
python3 -m uvicorn knowledge_os.app.mlx_api_server:app --host 0.0.0.0 --port 11435

# Настроить Claude Code для MLX
export ANTHROPIC_AUTH_TOKEN=ollama
export ANTHROPIC_API_KEY=""
export ANTHROPIC_BASE_URL=http://localhost:11435  # MLX API Server!
```

**Вариант Б: С Ollama (автоматически)**

```bash
ollama launch claude
```

**Вариант В: С Ollama (вручную)**

```bash
export ANTHROPIC_AUTH_TOKEN=ollama
export ANTHROPIC_API_KEY=""
export ANTHROPIC_BASE_URL=http://localhost:11434  # Ollama
```

### Шаг 3: Запустить Claude Code

```bash
# Перейти в директорию проекта
cd /Users/bikos/Documents/atra-web-ide

# С MLX моделью (быстрее на Mac Studio)
claude --model qwen2.5-coder:32b

# Или с Ollama моделью
claude --model qwen3-coder
```

### Шаг 4: Использовать!

```
Claude Code готов к работе!

Вы можете:
- Задать вопрос о коде
- Попросить добавить функцию
- Попросить исправить баг
- Попросить рефакторить код
- Попросить написать тесты
```

## 🎯 Когда использовать что?

### Используйте **Victoria** когда:

- ✅ Нужно планирование и координация
- ✅ Работаете через Telegram/Web интерфейс
- ✅ Нужна стратегия и архитектурные решения
- ✅ Работаете удаленно

### Используйте **Claude Code** когда:

- ✅ Нужно быстро исправить баг
- ✅ Работаете локально над кодом
- ✅ Нужен полный контекст проекта
- ✅ Хотите интерактивную разработку
