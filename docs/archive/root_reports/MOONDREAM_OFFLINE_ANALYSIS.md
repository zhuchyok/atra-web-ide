# ⚠️ Moondream Station - Анализ офлайн работы

**Дата:** 2026-01-27  
**Вопрос:** Будет ли Moondream Station работать без интернета?

---

## 🔍 Текущая ситуация

### ✅ Что установлено:

1. **Moondream Station CLI** - установлен
   - Путь: `/opt/homebrew/bin/moondream-station`
   - Версия: `0.1.9`
   - Расположение пакета: `/opt/homebrew/lib/python3.14/site-packages`

2. **Python пакет** - установлен
   - `moondream-station` доступен в системе

### ❌ Что НЕ установлено:

1. **Модели Moondream** - НЕ найдены в локальном кеше
   - HuggingFace кеш пуст для Moondream
   - Модели нужно скачать при первом запуске

---

## 🌐 Требования к интернету

### Первый запуск (ТРЕБУЕТ ИНТЕРНЕТ):

Moondream Station при первом запуске:

1. ✅ Скачивает модели с HuggingFace
2. ✅ Сохраняет их локально в кеш
3. ✅ Настраивает окружение

**Размер моделей:** ~1-2 GB (Moondream 3 Preview)

### Последующие запуски (ОФЛАЙН):

После первого запуска Moondream Station:

- ✅ **Может работать БЕЗ интернета**
- ✅ Использует локально скачанные модели
- ✅ Все вычисления происходят локально

Если отключить интернет сейчас:

- ❌ Moondream Station **НЕ БУДЕТ РАБОТАТЬ**
- ❌ Модели не найдены локально

## ✅ РЕШЕНИЕ

### Вариант 1: Скачать модели сейчас (РЕКОМЕНДУЕТСЯ)

```bash
# Запустить Moondream Station первый раз (пока есть интернет)
moondream-station

# Или через скрипт
bash scripts/start_moondream_station.sh
```

**Что произойдет:**

1. Moondream Station скачает модели (~1-2 GB)
2. Сохранит их в `~/.cache/huggingface/` или `~/.moondream/`
3. После этого будет работать офлайн

### Вариант 2: Использовать Ollama fallback

Если интернет отключится до скачивания моделей:

- VisionProcessor автоматически переключится на Ollama
- Но нужно установить `moondream` в Ollama:
  ```bash
  ollama pull moondream
  ```

## 📊 Сравнение вариантов

| **Moondream Station (MLX)** | Только первый раз | ~1-2 GB | ⚡⚡⚡ Быстро (MLX) | ⚠️ Нужно скачать |
| **Ollama moondream**        | Только первый раз | ~1.6 GB | ⚡⚡ Средне         | ❌ Не установлен |

## 🎯 РЕКОМЕНДАЦИЯ

**Сделайте СЕЙЧАС (пока есть интернет):**

```bash
# 1. Запустите Moondream Station первый раз
moondream-station

# 2. Дождитесь скачивания моделей
# 3. Проверьте, что модели скачаны:
ls -lh ~/.cache/huggingface/models--*moondream* 2>/dev/null

# 4. После этого Moondream Station будет работать офлайн!
```

**Или установите fallback в Ollama:**

```bash
ollama pull moondream
```
