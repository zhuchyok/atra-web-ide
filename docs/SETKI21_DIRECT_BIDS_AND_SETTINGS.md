# Setki21 Директ: ставки и настройки кампании

В репо пока нет готовых рекомендаций по цифрам (ставки, бюджет, стратегия). Ниже — **что проверить в кабинете** и куда записать целевые значения, когда их определит маркетолог/эксперт (Дарья, Марина или ответственный за Директ).

---

## Что проверить по настройкам кампании

В **direct.yandex.ru** → кампания Setki21 → **Настройки кампании** (или «Параметры»):

| Параметр           | Где смотреть                                            | Записать текущее | Целевое (если решили) |
| ------------------ | ------------------------------------------------------- | ---------------- | --------------------- |
| Дневной бюджет     | Настройки кампании                                      | \_\_\_ ₽         | \_\_\_ ₽              |
| Стратегия показа   | Оптимизация (ручная / авто / «Недельный бюджет» и т.д.) | \_\_\_           | \_\_\_                |
| Регионы показа     | Геотаргетинг                                            | \_\_\_           | \_\_\_                |
| Расписание показов | Время показа (круглосуточно / по дням и часам)          | \_\_\_           | \_\_\_                |

---

## Что проверить по ставкам (ключевые слова)

В кампании → **Группы объявлений** → группа → **Ключевые слова** (или в общем списке ключевых слов кампании):

| Что                                       | Где                                      | Записать                                   |
| ----------------------------------------- | ---------------------------------------- | ------------------------------------------ |
| Ставка по умолчанию (группа или кампания) | Настройки группы / кампании              | \_\_\_ ₽                                   |
| Ставки по отдельным фразам                | Таблица ключевых слов, столбец «Ставка»  | мин **_ / макс _** ₽ (или «все одинаково») |
| Рекомендации Директа                      | В интерфейсе «Подбор ставок» / подсказки | опционально сверять                        |

Целевые значения ставок (сколько готовы платить за клик по Чебоксарам / Новочебоксарску) лучше зафиксировать после решения ответственного за рекламу — тогда их можно добавить в этот документ или в конфиг.

---

## Выгрузка через API (когда заявка одобрена)

Скрипт **scripts/export_yandex_direct.py** выгружает в `docs/direct_export/` в том числе:

- **keywords.json** — ключевые слова и ставки (Bid), если API доступен.

Пока заявка на API не одобрена, ставки и настройки кампании смотрим только вручную в кабинете.

---

## Итог

- **Сейчас:** проверяй в кабинете дневной бюджет, стратегию, регионы, ставки по ключевым словам и при необходимости записывай в таблицы выше.
- **Потом:** когда будут целевые цифры от маркетолога — добавь их в этот док (или в YAML рядом с `setki21_direct_ads.yaml`) и можно будет сверять «как есть» vs «как надо».
