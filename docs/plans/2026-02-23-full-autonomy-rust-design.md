## 1. Архитектура «Локальный Ковчег»

Мы создаем изолированную среду на Mac Studio, которая содержит всё необходимое для разработки и эволюции.

### 1.1. Знания Гигантов (Giant Knowledge)

- **Scout-агенты (Rust-based):** Высокопроизводительные краулеры, которые индексируют:
  - `Rust Ecosystem`: Полная документация `std`, `tokio`, `axum`, `serde`, `sqlx`.
  - `AI/ML`: Спецификации MLX, Ollama API, архитектуры Transformer/DeepSeek.
  - `Infrastructure`: Docker, PostgreSQL, Redis, Nix (для воспроизводимых сборок).
- **Хранилище:** 200 ГБ выделенного пространства под GraphRAG узлы и локальные зеркала (Panamax для Rust, локальный PyPI).

### 1.2. Каскад Моделей (Brain + Hands)

- **Мозг (MLX):** `victoria-wisdom-30b` (стратегия, архитектура, сложный Rust).
- **Руки (Ollama):** `qwen3-coder:30b` или `phi4` (генерация кода, тесты).
- **Секретарь (Ollama):** `phi3.5:3.8b` (экстракция фактов, RAG-фильтрация).

## 2. Стратегия Миграции на Rust (Core Autonomy)

Я принимаю решение: миграция будет идти **параллельно** по двум направлениям для максимальной скорости.

### Фаза 1: Rust API Gateway (Надежность)

- **Что:** Замена Python-роутера на Rust (Axum + Tokio).
- **Зачем:** Исключить Python-overhead при пересылке тяжелых контекстов между Victoria и MLX/Ollama.
- **Результат:** Нулевые задержки, устойчивость к 100+ параллельным запросам экспертов.

### Фаза 2: Rust Knowledge Engine (Скорость)

- **Что:** Перенос логики GraphRAG и векторного поиска из Python в Rust.
- **Зачем:** Поиск по 50,000+ узлам знаний должен занимать < 10мс для мгновенной работы Victoria.
- **Инструменты:** `sqlx` для PostgreSQL, `ndarray` для векторов.

### Фаза 3: Автономный CLI (Замена Cursor)

- **Что:** Создание `atra-cli` на Rust.
- **Зачем:** Если Cursor перестанет работать, нам нужен свой инструмент, который умеет:
  - Применять `smart-patch` к файлам.
  - Вызывать Victoria напрямую через локальный сокет.
  - Запускать тесты в Docker-песочницах.

## 3. План реализации (Ближайшие шаги)

1.  **[Scout]** Запуск индексации всей документации по Rust в `knowledge_nodes`.
2.  **[Gateway]** Создание прототипа API Gateway на Rust (Axum) на порту `8081`.
3.  **[Mirror]** Настройка локального зеркала `crates.io` через Panamax.
