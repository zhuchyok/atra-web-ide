# Design Doc: Локальное формирование диалогов экспертов (Singularity 24.2)

## 1. Цель

Перенести процесс генерации обсуждений между экспертами (Игорь, Анна, Дмитрий и др.) из облачного контекста (Claude/GPT) в локальный инференс MLX на Mac Studio. Это позволит экономить до 80% облачных токенов на длинных ответах и повысить техническую точность за счет прямого доступа к локальным знаниям.

## 2. Архитектура

### 2.1. Компонент `TeamDiscussionEngine`

Новый логический слой в `ai_core.py`, отвечающий за симуляцию коллективного разума.

**Процесс:**

1.  **Selection:** Выбор 2-3 релевантных экспертов через `expert_hiring_manager`.
2.  **Context Injection:** Сбор данных из `memory_crystals`, последних логов и файлов проекта.
3.  **Scenario Prompting:** Формирование специального промпта для MLX, инструктирующего модель разыграть диалог.
4.  **Single-Pass Inference:** Генерация всего обсуждения за один вызов локальной модели `victoria-wisdom-v3.5`.

### 2.2. Интеграция с MLX (Pure Brain)

- **Endpoint:** `http://localhost:11435` (MLX API).
- **Optimization:** Использование `Speculative Decoding` (35B + 1B) для ускорения вывода.
- **Format:** Markdown-структура, совместимая с текущим отображением в Cursor.

## 3. Сценарный Промпт (Пример)

```text
### ROLE: Team Lead Victoria
### TASK: Разыграй техническое обсуждение задачи [TASK_TITLE].
### EXPERTS:
- Игорь (Backend): Технический перфекционист, ворчит про импорты.
- Анна (QA): Внимательная, ищет граничные случаи.
### CONTEXT: [LOCAL_CODE_SNIPPETS]
### INSTRUCTION: Выдай диалог в формате Markdown. Каждый эксперт должен высказать мнение по существу.
```

## 4. Плюсы и Риски

### Плюсы:

- **Нулевая стоимость:** Генерация текста обсуждения не тратит лимиты Claude.
- **Глубина:** Локальная модель видит реальные файлы и ошибки.
- **Скорость:** MLX на M4 Max выдает текст быстрее, чем идет запрос в облако.

### Риски:

- **Деградация интеллекта:** Если локальная модель не справится с ролью "режиссера".
  - _Защита:_ Автоматический fallback на облако при низком `confidence_score`.

## 5. Этапы внедрения

1. Создание `TeamDiscussionEngine` в `ai_core.py`.
2. Настройка маппинга личностей из `TEAM_PERSONALITIES.md` в промпт MLX.
3. Тестирование в Sandbox.
4. Обновление `MASTER_REFERENCE.md`.
