# Дизайн: ученичество Виктории «как Cursor»

**Дата:** 2026-08-15  
**Статус:** утверждён картбланшем  
**Цель:** Виктория работает методом этого агента; рой наследует тот же метод.

## Решение

Учить **метод**, мерить **одинаковой задачей**, автономию роя включать **последней**.

Не главный путь: утренний куратор по приветствиям.  
Не сейчас: новый оркестратор / снижение планки эволюции.

## Контур

```
задача → Cursor делает сам
      → близнец уходит Виктории (chat API или /run + poll)
      → два результата рядом
      → урок в knowledge_nodes (домен cursor_method)
      → следующий заход читает уроки через RAG + скилл cursor-method
```

## Первый кусок (этот план)

1. Канал Cursor→Victoria не возвращает пустое тело.
2. Always-on правило: на нетривиальной задаче обязателен близнец.
3. Скилл `cursor-method` + инъекция в `/run` и в воркеры.
4. Скрипт парного урока пишет узел в `cursor_method`.
5. Первый живой цикл с доказательством.

## Критерий «контур жив»

Три раза подряд: непустой ответ Виктории + записанный урок. Только после этого — журналы роя и более жёсткий quality gate.
