## 1. Цели

1. Повысить точность поиска (Hybrid Search + Re-ranking).
2. Расширить базу знаний внешними источниками (External Indexer).
3. Оптимизировать контекстное окно для разных типов данных.

## 2. Архитектура

### 2.1 Hybrid Search v2 (BM25 + Vector)

- **Текущее состояние:** Векторный поиск (nomic-embed-text) + ILIKE.
- **Улучшение:** Использовать PostgreSQL `tsvector` для полнотекстового поиска.
- **Формула ранжирования:** `Score = (Vector_Similarity * 0.7) + (BM25_Score * 0.3)`.

### 2.2 Cross-Encoder Re-ranking

- **Логика:** Топ-20 результатов из Hybrid Search передаются в легкую LLM (phi3.5) для финальной оценки релевантности.
- **Промпт для Re-ranking:** "Оцени релевантность документа запросу от 0 до 1. Запрос: {query}, Документ: {content}".

### 2.3 External Docs Indexer

- **Компонент:** `app/external_indexer.py`.
- **Функционал:** Принимает список URL, скачивает контент (через WebFetch), разбивает на чанки, генерирует эмбеддинги и сохраняет в домен `AI Research`.
