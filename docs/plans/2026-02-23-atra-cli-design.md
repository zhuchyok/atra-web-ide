# Дизайн: Atra CLI — Автономная замена Cursor (Singularity 14.6)

**Дата:** 2026-02-23  
**Статус:** Проектирование (Brainstorming)  
**Цель:** Создать высокопроизводительный CLI-инструмент на Rust, который позволит вести разработку в условиях отсутствия Cursor и интернета, используя локальный интеллект Victoria.

---

## 1. Концепция

Atra CLI (`atra`) — это мост между терминалом разработчика и локальным "мозгом" корпорации. Он заменяет функции AI-агента Cursor, работая полностью локально.

### Ключевые возможности:
*   **`atra chat`**: Интерактивный чат с Victoria (использует наш Rust API Gateway).
*   **`atra apply`**: Применение изменений к коду через XML-блоки `smart-patch` (как это делает Cursor/Aider).
*   **`atra plan`**: Генерация и выполнение пошаговых планов реализации фич.
*   **`atra context`**: Автоматический сбор контекста файлов (аналог `@file` в Cursor).

---

## 2. Архитектура

### 2.1. Технологический стек (Rust)
*   **`clap`**: Для парсинга командной строки.
*   **`tokio`**: Асинхронное ядро.
*   **`reqwest`**: Связь с Rust API Gateway (порт 8081).
*   **`dialoguer`**: Красивый интерактивный UI в терминале.
*   **`ignore`**: Быстрый обход файлов с учетом `.gitignore`.

### 2.2. Поток данных
1.  Пользователь вводит: `atra chat "Добавь логгер в main.rs"`.
2.  CLI собирает контекст: читает `main.rs`, находит связанные файлы.
3.  Запрос уходит в **Rust API Gateway** (8081) → **Victoria** (Docker).
4.  Victoria генерирует ответ с `smart-patch` блоками.
5.  CLI парсит ответ и предлагает: `Применить изменения? [Y/n]`.

---

## 3. План реализации (Bite-sized)

### Фаза 1: Основа (MVP)
1.  Создание проекта `rust_core/atra-cli`.
2.  Реализация команды `atra health` (проверка связи с Gateway и Victoria).
3.  Реализация базового чата `atra chat`.

### Фаза 2: Работа с кодом
1.  Интеграция движка `smart-patch` (поиск SEARCH/REPLACE блоков в ответе).
2.  Команда `atra apply` для автоматического редактирования файлов.
3.  Поддержка контекста: автоматическое прикрепление текущего файла к запросу.

### Фаза 3: Полная автономия
1.  Интеграция с локальным GraphRAG (через наш Rust Knowledge Engine).
2.  Режим "Offline Fortress": проверка доступности всех локальных зеркал.

---

## 4. Критерии успеха
*   Разработчик может создать новый эндпоинт, не открывая браузер и не используя Cursor AI.
*   Время от "запроса" до "правки файла" < 5 секунд.
*   Работает при выключенном интернете.
