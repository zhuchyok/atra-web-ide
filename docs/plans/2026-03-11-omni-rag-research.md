# Исследование и План внедрения Omni-RAG (Singularity 21.5)

## 🎯 Цель

Расширить возможности памяти Виктории (RAG), добавив поддержку мультимодальных данных. Виктория должна уметь "видеть" и понимать изображения, схемы и диаграммы, хранящиеся в проекте или базе знаний.

## 🏗️ Архитектура

### 1. Зрение (Vision Layer)

Использование существующего `VisionProcessor` для анализа визуальных данных.

- **Основная модель:** Moondream 3 (через Moondream Station на MLX).
- **Fallback:** Ollama (llava:7b, moondream).

### 2. Индексация (Indexing Layer)

Автоматическое обнаружение и описание изображений.

- **Discovery:** Поиск файлов `.png`, `.jpg`, `.jpeg`, `.svg` в директориях `docs/`, `frontend/public/`, `knowledge_os/data/`.
- **Description:** Генерация текстового описания для каждого изображения (что изображено, текст на картинке, логика схемы).
- **Storage:** Сохранение описания в таблицу `knowledge_nodes` с типом `image_description`.

### 3. Поиск (Retrieval Layer)

Интеграция в `enhanced_search.py`.

- **Hybrid Search:** Поиск по текстовым описаниям изображений наравне с обычными текстовыми узлами.
- **Context Injection:** При нахождении релевантной диаграммы, Виктория получает её описание и путь к файлу.
