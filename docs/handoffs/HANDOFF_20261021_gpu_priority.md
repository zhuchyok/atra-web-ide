# ХЭНДОФФ контуру саморазработки: приоритизация GPU-ресурса

**От:** SRE-сессия (волны v150.1–v150.19, библия §v150.19)
**Дата:** 2026-10-21
**Статус системы:** 41/41; слот-контракт: 11434=мозг / 11437=руки / 11436=coder; мозг 13–14 t/s в смешанном режиме (33 t/s соло).

## Суть запроса (владелец)
Разрулить **приоритет GPU**: баттлы/фоновые LLM-задачи не должны конкурировать с боевым трафиком Авито/Татьяны в дневные часы.

## Данные каузальной карты (наши замеры 20.10)
1. Мозг = 1 слот np=1 (архитектурный лимит qwen35), 16K-промпты, 3–4 мин/вызов соло.
2. GPU-соседи режут мозг **с 33 до 8–13 t/s (×2.5–4)**: coder-инстанс (3 резидентные модели: qwen2.5-coder+phi+tinyllama), veronica (до 3 раннеров, включая phi@32K), MLX-легаси при жизни.
3. Очередь мозга (100) забивается за ~2 мин при 90 req/мин → 503 → ntfy-шторм.
4. Уже закрыто нашими волнами: рекурсия (v150.17/18), Security-флуд (v150.16), парсинг → руки (v150.19), env-редиректы (v150.19).

## Что предлагаем разрулить вам (ваш контур, ваши механизмы)
1. **Расписание баттлов/consilium**: ночные окна (01:00–07:00 МСК), не дневные часы трафика Авито (~09:00–23:00). Механизм на ваш выбор — у вас уже есть `auto_night_peak_profile.py` (гистерезисный, untracked в вашем ворк-три) и `toggle_night_peak_profile.sh`.
2. **Прогрев/резидентность coder-инстанса**: 3 модели держатся всегда — оценить, нужны ли все днём (qwen2.5-coder:14b 9GB можно выгружать keep_alive=30м в дневные часы).
3. **Вероника-раннеры**: не держать phi@32K резидентным вне активных веб-исследований.
4. **max_steps extended_thinking 12→6** — второй по силе множитель мозга (до 13 вызовов/solve ×2 solve/задачу). Мы не трогали — это качество вашего конвейера.
