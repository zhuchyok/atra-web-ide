# Исправление проблемы с зависанием Victoria в чате

**Дата:** 26.01.2026  
**Проблема:** Victoria зависает в чате, показывая только "Обрабатываю..." без полного ответа

---

## 🔍 Проблема

Виктория зависала при обработке запросов:

- Первый запрос "привет" работал
- Последующие запросы ("как дела", "что кто ты") показывали только "Обрабатываю..." и зависали
- Нет таймаута для запросов к Victoria
- Нет обработки ошибок при зависании

---

## ✅ Исправления

### 1. **Добавлен таймаут для Victoria**

```python
# Вызываем Victoria с таймаутом
try:
    result = await asyncio.wait_for(
        victoria.run(
            prompt=message.content,
            expert_name=message.expert_name,
            project_context=project_context
        ),
        timeout=60.0  # 60 секунд таймаут
    )
except asyncio.TimeoutError:
    logger.error(f"Victoria timeout для запроса: {message.content[:50]}")
    error_event = {
        'type': 'error',
        'content': 'Превышено время ожидания ответа от Victoria. Попробуйте переформулировать вопрос или использовать более простой запрос.'
    }
    yield f"data: {json.dumps(error_event)}\n\n"
    yield f"data: {json.dumps({'type': 'end'})}\n\n"
    return
```

### 2. **Улучшена обработка ответов**

- Убрано дублирование сообщения "Обрабатываю..." в ответе
- Добавлена задержка для плавного стриминга
- Всегда отправляется событие `end` для завершения стрима

### 3. **Улучшена обработка ошибок**

- Все исключения теперь отправляют событие `end`
- Пользователь видит понятное сообщение об ошибке
- Логирование всех ошибок

---

## 📝 Изменения в коде

**Файл:** `backend/app/routers/chat.py`

1. Добавлен `import asyncio`
2. Добавлен таймаут 60 секунд для запросов к Victoria
3. Улучшена обработка ответов (убрано дублирование "Обрабатываю...")
4. Добавлена задержка `await asyncio.sleep(0.05)` для плавного стриминга
5. Всегда отправляется событие `end` в конце стрима

