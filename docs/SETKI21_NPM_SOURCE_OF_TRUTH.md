# Setki21: единый источник истины по NPM и стеку (VDS)

**Назначение:** При любых изменениях деплоя, NPM или контейнеров Setki21 — сверяться с этим документом. Это единственный источник истины для маршрутизации; он предотвращает возврат белых экранов из‑за рассинхронизации документации.

---

## Текущий продакшен-стек (единственно правильный)

На VDS в **`/home/atra/app/setki21_src`** работают:

| Сервис   | Контейнер           | Порт | Роль                                                           |
| -------- | ------------------- | ---- | -------------------------------------------------------------- |
| Frontend | **setki21-web-new** | 3000 | Nuxt.js, отдаёт HTML/JS/CSS                                    |
| API      | **setki21-api-new** | 8080 | Rust moskit-api: tenant config, цены, админка, uploads, health |

**NPM обязан направлять для всех доменов Setki21:**

- **/** (корень и всё, кроме перечисленного ниже) → **setki21-web-new:3000**
- **/api** → **setki21-api-new:8080**
- **/health** → **setki21-api-new:8080**
- **/uploads** → **setki21-api-new:8080**

Если в NPM указано **setki21-site:80** или **moskit-api** для корня / — на всех сайтах будет белый экран (нет Nuxt и/или не тот API).

## Домены, которые должны работать одинаково

Для каждого из этих доменов в NPM должен быть Proxy Host (или один хост с несколькими Domain Names) с настройками выше.

| Домен                                                         | Примечание                             |
| ------------------------------------------------------------- | -------------------------------------- |
| **www.setki21.ru**                                            | Главный сайт                           |
| **setki21.ru**                                                | Обычно редирект на www или тот же хост |
| **сеткимоскитки.рф** (Punycode: xn--e1agaahbbnszfhh.xn--p1ai) | Дилер                                  |
| **setkimoskitki.ru**                                          | Дилер                                  |

Во вкладке **Details** для каждого Proxy Host:

- **Forward Hostname / IP:** `setki21-web-new`
- **Forward Port:** `3000`

В **Custom Locations** (порядок важен, специфичные выше):

- `/api` → **setki21-api-new:8080**
- `/health` → **setki21-api-new:8080**
- `/uploads` → **setki21-api-new:8080**

## Перед любым изменением (чеклист)

1. Прочитайте этот файл и **docs/runbooks/SETKI21_WHITE_SCREEN.md**.
2. Не меняйте Forward на **setki21-site** или **moskit-api** для корня — это старый/альтернативный вариант, при нём белый экран.
3. После изменения NPM, деплоя или перезапуска контейнеров — запустите верификацию всех сайтов: **`./scripts/verify_setki21_all_sites.sh`** (см. ниже).

---

## После изменений: верификация

Скрипт **scripts/verify_setki21_all_sites.sh** проверяет с VDS, что для каждого хоста API возвращает JSON tenant config. Запуск (из корня репо, с доступом по SSH к VDS):

```bash
./scripts/verify_setki21_all_sites.sh
```

Если скрипт падает — исправьте NPM и/или контейнеры по **docs/runbooks/SETKI21_WHITE_SCREEN.md**, затем запустите проверку снова.
