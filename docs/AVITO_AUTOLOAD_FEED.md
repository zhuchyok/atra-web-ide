# Формат фида автозагрузки Авито — шпаргалка (ресёрч 26.10, субагент)

## Ключевые механики
- **Id (свой!) — ключ обновления**: тот же Id = то же объявление (обновление без снятия с публикации), новый Id = новое.
- **Удаление**: убрал строку из фида → при следующей загрузке авто-архивация.
- **Фото**: внешние ссылки (публичные, jpg/png, расширение в URL) в колонке ImageUrls через `|`, либо ZIP до 100 МБ рядом с Excel.
- **Валидатор перед каждой загрузкой**: https://autoload.avito.ru/format/xmlcheck
- **Шаблоны по категориям**: https://www.avito.ru/autoload/documentation/templates
- **Загрузка по ссылке**: до 3 URL, ~раз в час Авито сам синхронизирует; расписание обработки настраивается.
- **Цены**: только целое число. **Адрес**: как в справочнике («Чувашская Республика, Чебоксары»).
- Служебные колонки (AvitoId, AvitoStatus) — не заполнять.
- Заголовок ≤50 зн. живой (не «ключи через запятую» — модерация отклонит), описание ≤3000, HTML разрешён.

## Типовые ошибки (наши 42!)
1. Цена не в формате; 2. дубли Id; 3. дубли контента (= наша история!); 4. битые/непубличные фото-URL;
5. неверная категория / не заполнены категорийные свойства (GoodsType и пр.); 6. адрес не из справочника;
7. превышение квоты тарифа; 8. HTML-ошибки в описании; 9. заполненные служебные колонки; 10. спам-заголовки.

## План сборки нашего фида
1. Скачать шаблон категории с avito.ru/autoload/documentation/templates («Окна и балконы» / услуги).
2. Сгенерировать XLSX: Id=okno_01..43, наши уникальные заголовки, SEO-описания, цены целыми,
   Address «Чувашская Республика, <город>», ImageUrls — ссылки на фото (хостинг/Яндекс.Диск с публичными ссылками).
3. Валидатор xmlcheck → загрузка «Вручную» → разбор отчёта.
4. Затем XML-фид по ссылке (Яндекс.Диск/хостинг) + расписание — обновления цен/остатков автоматически.

## Официальный разбор ошибок (support.avito.ru/articles/4356) — выжимка

### ⚡ ВЕРОЯТНАЯ ПРИЧИНА НАШИХ 42 ОШИБОК
**Лимит: 2 редактирования объявления через автозагрузку в СУТКИ.**
Третье обновление не применяется. Восстановление: +1 через 12ч, ещё +1 через 12ч.
Наш фид грузится КАЖДУЮ НОЧЬ и трогает одни и те же карточки → лимит выжжен.
Цена — без лимита, НО если в одной загрузке цена + другое поле — вся загрузка идёт
в зачёт лимита. Правило: менять цену ОТДЕЛЬНОЙ загрузкой.

### Цвета ошибок в отчёте
Красный = критическая (не публикуется). Оранжевый = необязательный параметр.
Жёлтый = уведомление (не влияет, чинить не нужно).

### Критические ошибки и фиксы
- «Вариант платного размещения: Package» → нет/кончился пакет размещений.
- «Одинаковое описание у объявлений» → дубль внутри фида, удалить строку.
- «Ошибка параметра» → изменён неизменяемый параметр (категория/город) или значения
  нет в справочнике. Вернуть прежнее значение или ждать справочник.
- «Ошибка телефона» → номер из другого профиля; ставить подтверждённый номер профиля.
- «Объявление заблокировано/отклонено модератором» → смотреть причину в профиле
  (С ошибках/Архив); отклонённое правится в файле по рекомендации — публикуется
  в следующем цикле.
- «Объявление не принадлежит пользователю» → чужие AvitoId в файле.
- «Не удалось опубликовать / Удалено» → объявление с этим Id удаляли. Фикс:
  в отчёте отметить галочками и нажать **«Выгрузить как новые»** ← наш путь для
  реанимации удалённых карточек!

### Фото
- Серверы автозагрузки качают фото с IP **185.89.12.0/22 и 146.158.48.0/21** —
  хостинг фото должен пускать эти диапазоны.
- Яндекс.Диск/облака блокируются при **>3 выгрузок в день** (можно написать в
  поддержку и согласовать график выгрузок).
- Если в объявлении есть любая критическая ошибка — фото не обновятся тоже.
- ZIP: все фото в корне архива, без вложенных папок.

### Удобный фикс
**«Скачать файл с ошибками из отчёта»** (кнопка в Автозагрузке и в отчёте) →
Excel, где ошибочные поля выделены красным + колонка «Все ошибки».
Исправил → загрузил обратно → Авито сам обновит. Ничего создавать/удалять не надо.

## ⚡ КОРЕНЬ ВСЕХ ПРОБЛЕМ (support 4337 «Работа с объявлениями»)
**Объявлениями, размещёнными через автозагрузку, можно управлять ТОЛЬКО через файл.
Файл приоритетен: правки через профиль ОТМЕНЯЮТСЯ при очередной выгрузке.**
Наш фид (42 позиции старых дублей) каждую ночь в 2:26 перезаписывал наши 165
уникальных заголовков/текстов обратно к старым клонам. Поэтому «не работало».
ЕДИНСТВЕННЫЙ путь — править сам фид-файл и грузить его.

### Оплата размещений в фиде — элемент ListingFee
- Package — только из пакета (нет пакета → не публикуется);
- PackageSingle — из пакета, иначе разовое из кошелька;
- Single — разовое из кошелька;
- пусто = вести себя как Package.
← настройка решает проблему «Объявление скрылось, в пакете кончились размещения».

### Возможности официального API (support 4343)
Отчёты автозагрузки, баланс кошелька, статистика по объявлениям, статусы/услуги,
статистика и ЗАПИСИ звонков (коллтрекинг), подключение платных услуг, переписка,
публикация/редактирование вакансий, рейтинги и ответы на отзывы, голосовые сообщения,
обмен фото напрямую, подтверждение заказов.
Подключение: Авито Pro → «Профиль и настройки» → «Интеграции и API» → client_id/secret.
Два способа авторизации: персональная (свои ключи) и для приложений (сторонние юзеры).

### Настройка автозагрузки (4357)
- Параметр фида **MultiItem**: «Да»/пусто = авто-добавление в мультиобъявление
  (официальная альтернатива клонам для вариантов товара!), «Нет» = отключить.
- Загрузка «По расписанию» — для >200 объявлений или >500 МБ; до 3 ссылок на файлы (тест).
- PhotoNames (ZIP-архив) вместо ImageUrls — фото файлом, не ссылками.
- Валидатор: autoload.avito.ru/format/xmlcheck.

### Отчёты (4344)
Полный отчёт — только по ПОСЛЕДНЕЙ успешной выгрузке (история — сводкой).
Отчёт можно получать НА ПОЧТУ (настройки автозагрузки) и пересылать.
