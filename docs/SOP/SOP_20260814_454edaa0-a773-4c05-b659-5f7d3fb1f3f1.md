# Стоп Процесс: Куратор: Расхождение с эталоном «what_can_you_do»

## Название процесса
Проверка и исправление несоответствий между запросом о способностях и действительным ответом, основанным на эталоне «what_can_you_do».

## Когда применять этот процесс (Trigger)
Вызывается, когда запрос "что ты умеешь?" не совпадает с документом или системой отчетности в соответствии со стандартом «what_can_you_do».

## Пошаговые инструкции

1. Ознакомьтесь с ответами, представленными в документе `docs/curator_reports/standards/what_can_you_do.md`.

2. Проверка соответствия запроса с содержащимся в документе ответом:
   ```bash
   grep "что ты умеешь?" < docs/curator_reports/standards/what_can_you_do.md
   ```
