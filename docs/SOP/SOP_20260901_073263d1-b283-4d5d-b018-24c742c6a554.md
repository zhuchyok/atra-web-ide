# СТANDARD ОПЕРАТИВНЫЙ ПРОЦЕСС (SOP): КОНトロН КОНТロН КОНトロН

## Название процесса
Контроль очереди конторон

## Когда применять этот процесс
Применяйте этот процесс перед запуском любой очереди, чтобы обеспечить контроль времени выполнения и обнаружение любых проблем, которые могуntexause прокручивание или задержки в работе.

## Пошаговые инструкции

1. **Запрос времени выполнения**:
   - Используйте команду `fetchai timenow` для получения текущего времени выполнения. Это предоставит метку времени в секундах с точностью до миллисекунды.
   - Пример вывода: `fetchai timenow`  => `Время выполнения: 168789505234`
