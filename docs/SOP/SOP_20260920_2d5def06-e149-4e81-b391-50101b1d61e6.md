## Название процесса
Расхождение с эталона «what_can_you_do» для оценки соответствия задачи кураторскому прогону.

## Когда применять этот процесс
Запускайте этот процесс, когда ваша задача не совпадает с эталоном «what_can_you_do», как показано в отчёте.
