# Процесс 📋 МЕТОД CURSOR: Ревизия системы и отчетности

## Название процесса
**Ревизия системы и отчета для проверки состояния курсора в системе**

## Когда применять этот процесс
Применяется, когда необходимо провести регулярную оценку системы и гарантировать наличие корректной работы функций курсора. Обычно выполняется не менее одного раза в месяц или по требованию после каждого значительного обновления системы или при обнаружении сбоев.
