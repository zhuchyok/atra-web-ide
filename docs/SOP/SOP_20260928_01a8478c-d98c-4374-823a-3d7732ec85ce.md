# Процесс LOG_SCANNER: Исправление ошибок в контейнере knowledge_self_check

## Название процесса
Исправление ошибок в контейнере knowledge_self_check

## Когда применять этот процесс
Когда сообщение об ошибке "EXCEPTION" от LOG_SCАННЕР с содержащимся в нем типом ошибки knowledge_self_check.

1. Проверьте сообщение об ошибке для получения деталей:
   - Убедитесь, что ошибка касается "ERROR:self_check_system:🚨 [SELF-CHECK] КРИТИЧНО: 3 компонента нездоровы!"

2. Определите поврежденные компоненты:
   - Используйте инструменты мониторинга контейнера, такие как `docker logs knowledge_self_check` или `docker container inspect knowledge_self_check`, чтобы определить конкретные пробле
