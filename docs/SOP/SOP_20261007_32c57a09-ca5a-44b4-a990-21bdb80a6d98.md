# СТANDARD ОПЕРАТИВНАЯ ПРОЦЕССА: Куратор: расхождение с эталоном «code_audit»

## Название процесса

Проверка расхождения между фактическим файлом и эталоном «code_audit»

## Когда применять этот процесс (Trigger)

При обнаружении несоответствий между фактическим файлом `/app/knowledge_os/app/anti_hallucination.py` и эталоном «code_audit».

## Пошаговая инструкция (Step-by-step)

1. Ознакомитесь с эталоном «code_audit», представленным в документе `code_audit.md` в `docs/curator_reports/standards/`.
2. Проверьте фактический файл на наличие упоминания `pip install` в рамках рантайме, используя либо `subprocess` библиотеку, либо команду `os.system`.
3. Если упоминание отсутствует, сопоставьте фактический файл
