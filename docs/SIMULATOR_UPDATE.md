## 🎯 ИСПОЛЬЗОВАНИЕ

### Запуск симуляции:

1. Откройте `http://localhost:8501/#simulyator-biznes-idey`
2. Введите бизнес-идею
3. Нажмите "Запустить Симуляцию Совета Директоров"
4. Результат появится через 1-2 минуты

### Удаление симуляции:

1. Найдите нужную симуляцию в истории
2. Нажмите кнопку "🗑️ Удалить"
3. Симуляция будет удалена, список обновится автоматически
