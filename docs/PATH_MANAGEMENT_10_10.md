
### Определение окружения:

```python
from scripts.utils import is_docker, get_database_url, get_mlx_api_url

# Проверить Docker
if is_docker():
    print("Запущено в Docker")

# Получить DATABASE_URL
db_url = get_database_url(
    default_docker="postgresql://admin:secret@knowledge_postgres:5432/knowledge_os",
    default_local="postgresql://admin:secret@localhost:5432/knowledge_os"
```
