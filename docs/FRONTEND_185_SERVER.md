**Ручной запуск (одноразово):**

```bash
bash scripts/setup_frontend_tunnel.sh
```

**Автозапуск + постоянная проверка (рекомендуется):**

```bash
bash scripts/setup_tunnel_185_autostart.sh
```

- Туннель запускается при входе в систему (RunAtLoad).
- При падении туннеля launchd перезапускает его (KeepAlive).
- Watchdog каждые 2 минуты проверяет http://185.177.216.15:3002; если недоступен — перезапускает туннель.

**Вручную (без скрипта):**

```bash
ssh -fN -R 0.0.0.0:3002:localhost:3002 root@185.177.216.15
```

## ⚠️ Почему 185:3002 не открывается

### 1. SSH туннель не запущен

- Туннель живёт только пока активна SSH-сессия; после перезагрузки Mac или обрыва связи он пропадает.
- **Решение (разово):** `bash scripts/setup_frontend_tunnel.sh`
- **Решение (навсегда):** `bash scripts/setup_tunnel_185_autostart.sh` — автозапуск при входе + KeepAlive + watchdog каждые 2 мин.

### 2. Ошибка «Exceeded MaxStartups» на сервере 185

- Сервер отклоняет новые SSH-подключения: лимит одновременных стартующих сессий исчерпан.
- **Решение на сервере 185:** В `/etc/ssh/sshd_config` увеличить, например: `MaxStartups 100:30:200`, затем `systemctl restart sshd` (или перезапуск sshd по вашей схеме).
- **Временно:** Подождать 1–2 минуты и повторить подключение; часть старых сессий закроется.

### 3. GatewayPorts на сервере 185

- Для доступа к 185:3002 из интернета в `sshd_config` должно быть: `GatewayPorts yes`.
- Перезапуск sshd после изменения.

### 4. Firewall на сервере 185

- Порт 3002 должен быть открыт (входящий TCP), иначе браузер не откроет 185:3002 даже при работающем туннеле.
