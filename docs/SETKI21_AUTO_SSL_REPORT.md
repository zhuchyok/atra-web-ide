## 🔍 Диагноз

### Исходная проблема

Пользователь вводит `сеткимоскитки.рф` в браузер → попадает в поиск вместо сайта.

### Что обнаружено

1. **HTTP работает** для всех доменов ✅
2. **HTTPS не работает** для дилерских доменов (SSL handshake failed) ❌
3. **Proxy Host создан в NPM**, но **без SSL-сертификата** ⚠️
4. **Код автоматизации есть**, но **неполный** - создаёт хост, но не запрашивает SSL ❌

### Почему браузер отправляет в поиск

Современные браузеры (Chrome, Firefox, Safari):

1. При вводе домена без протокола пытаются открыть **HTTPS**
2. Если HTTPS не работает (SSL error) → интерпретируют строку как **поисковый запрос**
3. Пользователь попадает в Google/Yandex вместо на сайт

## ✅ Решение

### Что было исправлено в коде

**Файл:** `/Users/bikos/Documents/dev/setki-21/moskit-api/src/npm.rs`

#### Добавлено:

1. **`CertificateResponse` struct** - для парсинга ответа NPM API
2. **`request_ssl_certificate()` метод:**
   - POST запрос в `/nginx/certificates`
   - Параметры Let's Encrypt (email, согласие, домены)
   - Возвращает `certificate_id`

3. **`update_proxy_host_certificate()` метод:**
   - Получает текущую конфигурацию Proxy Host
   - Обновляет `certificate_id` и `ssl_forced: true`
   - PUT запрос для применения

4. **Обновлён `create_proxy_host()`:**
   - После создания хоста автоматически запрашивает SSL
   - Привязывает сертификат к хосту
   - Полное логирование всех этапов
   - Graceful fallback при ошибках (хост остаётся, HTTP работает)

#### Изменено:

- Timeout клиента: 30s → 60s (Let's Encrypt может занять время)
- Логирование: добавлены emoji для быстрой визуальной идентификации результата

## ⚠️ Важные замечания

### DNS для кириллического домена

Домен `сеткимоскитки.рф` показал "DNS: не резолвится" в проверке. Возможные причины:

1. DNS-резолвер на Mac не поддерживает кириллицу (нужен Punycode)
2. DNS ещё не обновился (TTL)
3. У регистратора не настроена A-запись

**Проверка через Punycode:**

```bash
dig +short xn--e1agaahbbnszfhh.xn--p1ai
# Должен вернуть: 45.10.43.248
```

Если IP другой или пустой → обновить A-запись у регистратора.

### Let's Encrypt лимиты

- **5 сертификатов** на домен в неделю
- **50 сертификатов** на аккаунт в неделю

При частом тестировании можно исчерпать лимит. В этом случае ждать неделю или использовать staging-сервер LE.
