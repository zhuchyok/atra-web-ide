## 🚀 Функциональность

### ✅ Единая база правил

- **Источник:** `~/.cursor/universal-rules.md` - один файл для всех проектов
- **Синхронизация:** Изменения применяются ко всем проектам одной командой
- **Автоматическое обновление:** Новые проекты получают актуальные правила

### ✅ Автоматическая инициализация

- **Новые проекты:** Правила создаются автоматически при открытии
- **Существующие проекты:** Правила добавляются при обнаружении
- **Массовая инициализация:** Все проекты обрабатываются одной командой

### ✅ Сохранение специфичных правил

- **Специфичные правила:** Сохраняются при синхронизации
- **Резервные копии:** Создаются перед обновлением
- **Безопасность:** Изменения не теряются

---

## 📋 Быстрые команды

### Для нового проекта

```bash
./scripts/init-cursor-rules.sh
```

### Для всех существующих проектов

```bash
./scripts/init-cursor-rules-all.sh ~
```

### Синхронизация после изменений

```bash
./scripts/sync-cursor-rules.sh ~
```

### Настройка автоматической инициализации

```bash
./scripts/setup-cursor-auto-init.sh
source ~/.zshrc  # или ~/.bashrc
```
