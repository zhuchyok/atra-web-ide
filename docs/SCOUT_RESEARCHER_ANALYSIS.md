**Что делает:**

1. ✅ **Веб-поиск через DuckDuckGo** (бесплатно, без API ключей)
   - Использует библиотеку `duckduckgo_search`
   - Выполняет 10 поисковых запросов
   - Получает результаты (title, href, body)

2. ✅ **Генерация эмбеддингов** (локально)
   - Использует **VectorCore** (порт 8001)
   - Локальный сервис, без облачных API
   - Модель: `all-MiniLM-L6-v2` (SentenceTransformer)

3. ✅ **Сохранение в БД**
   - Сохраняет результаты в `knowledge_nodes`
   - Metadata: `source = 'scout_research'`
   - Confidence: 0.90

**Использует ли LLM на этом этапе?**

- ❌ **НЕТ** - только сбор данных и сохранение

### Этап 2: Анализ данных (через задачу)

**Что происходит:**

1. ✅ **Создается задача** для эксперта "Глеб"
   - Title: `"🕵️ Анализ конкурентов: {business_name}"`
   - Description: `"Глеб, я собрала {total_insights} записей о рынке... Проведи анализ конкурентов и подготовь SWOT"`
   - Status: `pending`

2. ✅ **Задача обрабатывается через smart_worker_autonomous.py**
   - Worker берет задачу из БД
   - Вызывает `run_smart_agent_async(expert_name="Глеб")`
   - Использует **LocalAIRouter** для выбора модели

3. ✅ **Используются ЛОКАЛЬНЫЕ МОДЕЛИ**
   - Через `LocalAIRouter` → `MLX API Server` (порт 11435)
   - Модели: `qwen2.5-coder:32b`, `deepseek-r1-distill-llama:70b`, и т.д.
   - **0 токенов** - все локально!

## 📊 ИТОГОВАЯ СХЕМА

```
1. Пользователь запускает разведку
   └─> scout_researcher.py

2. Сбор данных (БЕЗ LLM)
   ├─> DuckDuckGo поиск (бесплатно)
   ├─> VectorCore эмбеддинги (локально)
   └─> Сохранение в БД

3. Создание задачи
   └─> Задача для Глеба: "Проанализировать данные"

4. Обработка задачи (С ЛОКАЛЬНЫМИ МОДЕЛЯМИ)
   ├─> smart_worker_autonomous.py
   ├─> run_smart_agent_async("Глеб")
   ├─> LocalAIRouter → MLX API Server
   └─> Анализ данных локальной моделью

5. Результат
   └─> Отчет сохраняется в knowledge_nodes
```

## ✅ ОТВЕТЫ НА ВОПРОСЫ

### 1. Работает ли разведка сама?

**✅ ДА, полностью автономно:**

- Сбор данных: DuckDuckGo (бесплатно, без API ключей)
- Эмбеддинги: VectorCore (локально)

- **Анализ данных:** Локальные модели через MLX API Server

  - 0 токенов, все локально!
