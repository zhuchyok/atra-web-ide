## 🔧 Backend API

### Реализованные эндпоинты:

1. **Files API** (`/api/files/`)
   - ✅ `GET /list` - список файлов
   - ✅ `GET /read` - чтение файла
   - ✅ `POST /write` - запись файла
   - ✅ `POST /create` - создание файла/папки
   - ✅ `DELETE /delete` - удаление файла

2. **Editor API** (`/api/editor/`)
   - ✅ `POST /autocomplete` - AI автодополнение
   - ✅ `POST /lint` - проверка кода

3. **Terminal API** (`/api/terminal/`)
   - ✅ `WebSocket /pty` - PTY терминал

4. **Chat API** (`/api/chat/`)
   - ✅ `POST /stream` - SSE стриминг
   - ✅ `GET /status` - статус Victoria

5. **Preview API** (`/api/preview/`)
   - ✅ `GET /file` - предпросмотр файла
