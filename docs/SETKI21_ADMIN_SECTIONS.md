# Разделы админки Сетки 21

## Что уже есть в админке и API

После деплоя moskit-api на VDS в админке доступны:

| Раздел           | Описание                                                                               | API                                                                                                           |
| ---------------- | -------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| **Цены**         | Полотно, профили, компоненты, наценки, услуги (монтаж, доставка)                       | `GET/POST /api/v1/admin/pricing`, `GET /api/v1/pricing`                                                       |
| **Дилеры**       | Список, создание, редактирование, отделы, статистика (в т.ч. алерты по балансу), аудит | `GET/POST /api/v1/admin/dealers`, `PUT /api/v1/admin/dealers/:id`, `.../stats` (поле `alerts`), отделы, audit |
| **Заказы**       | Список заказов, смена статуса (в т.ч. «В производстве»)                                | `GET /api/v1/admin/orders`, `PUT /api/v1/admin/orders/:id/status`                                             |
| **Производство** | Учёт через статусы заказа: `in_production`, подстатус производства, монтаж             | В БД: `orders.production_sub_status`, `installation_status`; API обновления статуса                           |

Роль в интерфейсе: «Администратор производства» (admin). Дашборд: счётчики (дилеры, заказы в работе, выручка), последние заказы.

## Что в плане (create_plan), но отдельным модулем пока нет

- **Остатки / склад** — отдельного раздела «остатки» или «склад» в API и админке нет. В плане упоминались учёт изготовления и монтажа (стадии и статусы) — это уже есть через заказы и статусы. Учёт остатков материалов/склада можно добавить отдельно (таблицы, эндпоинты, страницы админки).
- **CRM как модуль** — заложено в архитектуру (разделение ролей, дилеры, заказы), полноценная CRM — следующий этап.

## Итог

Производство и учёт этапов изготовления/монтажа — **уже в админке** (заказы + статусы). Остатки по складу/материалам — **можно добавить** как следующий шаг (отдельные миграции и раздел в админке).
