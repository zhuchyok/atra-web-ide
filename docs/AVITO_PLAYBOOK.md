# ПЛЕЙБУК АВИТОЛОГА — алгоритмы, правила, хитрости (ресёрч 05.10.2026)

## 1. Как работает алгоритм (что ранжирует)

- **Поиск**: сопоставление запроса покупателя с заголовком + текстом + характеристиками. Ключевые слова работают и из заголовка, и из описания.
- **Рекомендации**: алгоритм отбирает объявления «с адекватным контентом» по поведению людей: клики, время просмотра, чтение описания, избранное, сообщения/звонки.
- **Уровень сервиса**: скорость ответа в чатах (покупатели пишут 3–5 продавцам сразу — первый и полный ответ чаще закрывает сделку), рейтинг, отзывы. Влияет на видимость.
- **Первая страница выдачи** забирает до 80% внимания.

## 2. Дубли: как Авито ловит и как правильно (главное для нашего кабинета)

- Похожие объявления блокируются: проверяются **фото по хешу**, заголовки и текст.
- **Официальный легальный путь** для нескольких вариантов одного товара — функция **«Мультиобъявление»**: одно объявление + переключатель мульти, варианты как опции.
- Для УСЛУГ в разных городах дублирование допустимо; для ТОВАРОВ — нужна уникализация каждого: другой заголовок, другие фото (другой ракурс/фон/обработка), переписанное описание, заполненные характеристики.
- «Обойти» копипастом нельзя — ведёт к отклонениям (наш случай) и блокировкам.

**Вывод для кабинета:** 126 дублей с одинаковыми фото — главный тормоз. Путь: 1) уникальные заголовки и тексты (делаем), 2) **уникальные фото для каждой карточки** (сфотографировать реальные изделия со склада — у нас разные окна = разные фото естественно), 3) рассмотреть «Мультиобъявление» как официальную альтернативу клонам.

## 3. Заголовок (главный снайпер)

Формула Авито для строительства: **[Что именно] + [ключевая фишка/спецификация] + [гео/условие]**.

- Видят даже те, кто не доскроллил до фото.
- Хорошо: «Окна ПВХ от производителя — доставка по Чувашии», «Остекление беседки под ключ — замер бесплатно».
- Плохо: «Окна» (нет ключей), «Самые дешёвые окна!!!» (спам), дубли формулировок.

## 4. Описание

- Поиск работает по тексту: вплетай реальные запросы покупателей естественно.
- Структура: ключ в первой строке → конкретика (размеры, материалы, сроки) → преимущества → призыв.
- Поведенческая цель: удержать чтение — таблички, списки, ответы на типовые вопросы прямо в тексте.

## 5. Уровень сервиса (влияет на позиции)

- Отвечать в чатах быстро (первые 15 минут — золотое правило).
- Рейтинг и отзывы: просить отзыв после сделки, отвечать на каждый.
- Не допускать: долгих молчаний (понижает), отмен заказов.

## 6. Ключевые слова: как подбирать

- «Аналитика спроса» Авито Pro + подсказки в поисковой строке Авито.
- Яндекс Wordstat для объёмов.
- Мозговой штурм: кто покупает → что ищет → какими словами.
- Ядро для нашей ниши: пластиковые окна Чебоксары, купить окна ПВХ, окна от производителя, остекление балконов, остекление беседок под ключ, установка дверей ПВХ, панорамные окна цена, окна для дачи, остекление террасы, пластиковые двери купить.

## 7. Бесплатные усилители

- Заполненные «Условия сделки» (доставка + оплата) — влияет на показы.
- «Аналитика спроса» для заголовков под реальный спрос.
- Обновления объявлений (переиздание) — свежесть.
- Ответ на каждый отзыв.
- Видео в объявлении — удерживает дольше.

## 9. Платное продвижение: просмотры vs контакты (ресёрч 13.10.2026)

### Две модели оплаты
- **За просмотры (PPV)**: платим за уникальные просмотры, публикация 30 дней бесплатна.
  Товары: от ~0,1–0,4 ₽/просмотр. Услуги: от ~1,1 ₽. Цена растёт на аукционе.
- **За контакты (CPL)**: платим только за целевое действие (чат/звонок/«показать телефон»).
  В оконной нише реальная цена контакта от ~300 ₽, при слабой карточке доходило до 645 ₽.

### Формулы окупаемости (считать ДО подключения ставки)
```
Конверсия просмотр→контакт = контакты / просмотры
CPL_просмотры = ставка за просмотр / конверсия просмотр→контакт
ROMI = (маржа × конверсия контакта в сделку × средний чек) / CPL
```
Правило: `CPL_просмотры < CPL_контакты` → бери просмотры, иначе контакты.

### Когда что выбирать
| Ситуация | Модель |
|---|---|
| Карточка свежая, CTR не ясен | За просмотры, малый бюджет на тест |
| Конверсия просмотр→контакт > 3–5% | За просмотры дешевле |
| Конверсия низкая (<2%), карточка слабая | Сначала чинить карточку, не лить деньги |
| Услуги, редкий дорогой лид | За контакты |

### Ловушки
- PPV при плохой конверсии = слив бюджета на холодный трафик (кейс: 44 ₽/просмотр → 645 ₽/контакт).
- Без учёта звонков из Авито в CRM окупаемость не посчитать — смотреть в разрезе объявлений.
- Ставка за просмотры в рекомендациях: Авито поднимает карточки с высоким временем
  просмотра и досмотрами — поэтому фото/текст/видео окупаются дважды (и органика, и реклама).

## 10. CTR-диагностика 15.10.2026: главный убийца внимания — одинаковый баннер

Первым фото у большинства карточек стоит один и тот же рекламный баннер
(мужика с пальцем + логотип + «гарантируем лучшую цену»). В выдаче сетка
карточек выглядит одинаково → CTR 0–0,3%, отсюда «Плохо привлекают
внимание: 68».

Правила:
- Первое фото = ТОВАР крупно, светлый фон, без текста и лиц.
- Никогда не ставить одно фото на все карточки — сетка сливается.
- Уникальность фото для Авито: кроп/зеркалирование меняют хэш, качество сохраняют.
- Реальные складские снимки бьют рендеры: живая карточка дала CTR 1,32% (76 просм.)
  против 0–0,3% у баннерных.
- Скрипт починки: scripts/avito_fix_banner_photos.py (детект phash → замена
  на складское фото с уникальным кропом).

3. **Курс на сокращение похожих групп**: 103 активных при 12 группах товаров —

## 13. Ресёрч 25.10: правки, автоответы, API (самоаудит)

### ГЛАВНОЕ: массовые правки вредят ранжированию
Опыт продавцов: частые правки карточки (заголовок/фото/описание) обнуляют накопленную
статистику показов и кликов → временная потеря позиций. Правки после подключения
продвижения частично снимают эффект продвижения.
**Наша яма просмотров октября объясняется этим**: каждая карточка пережила 3–5 правок
подряд (заголовок + текст + фото + повторные фото).
ПРАВИЛО: правки только пакетами раз в месяц, точечно; заголовок не трогать без
необходимости; не редактировать карточку сразу после включения продвижения.

### Штатные автоответы Авито Pro — существуют
Сообщения → «⋯» → «Настроить автоответы»: мгновенное подтверждение получения +
**пересылка телефонов покупателей на email** (ловим лиды даже без ответа).
В нашем кабинете пункт не найден (вероятно A/B-раскатка) — проверить руками или
спросить поддержку. С Татьяной не конфликтует: автоответ — мгновенное подтверждение,
Татьяна — содержательный ответ через минуты.

### Управление по API — текущий статус
Токен аккаунта: messenger (чаты) ✅, core (профиль) ✅, items (объявления) ❌,
job ❌. Расширенный доступ к items-API — заявка через портал разработчика
(avito.ru/developers, для автозагрузки: supportautoload@avito.ru). Когда дадут —
заголовки/фото/публикации перейдут со скриптов-браузера на стабильные API-вызовы.

## 14. Антифрод Авито и «айпи» — как реально работает и что практикуется (25.10)

### Как Авито ловит (из блога самого Авито на Habr)
Поведенческий анализ + цифровые отпечатки устройства + чёрные списки IP + связи
между аккаунтами. Подозрительным объявлениям **понижают приоритет в выдаче,
убирают из рекомендаций, ставят задержку показа** — без явных баннеров.

### Что практикуется «на просторах»
Мультиаккаунщики и парсеры: антидетект-браузеры (Octo, AdsPower, Multilogin) +
резидентские/мобильные прокси (мобильный пул IP Авито почти не трогает), ротация,
симуляция живого поведения. Это серая зона: нарушает правила, риск вечного бана.

### Самоаудит нашего кабинета — риски
1. Браузерная автоматизация (CDP/Playwright) с домашнего IP: ежедневные прогоны,
   массовые правки, скролл-скрейпинг. Антифрод может это видеть → возможный вклад
   в яму просмотров октября (понижение приоритета, а не только переиндексация).
2. Инцидент с VPN (зарубежный IP) — 12.10 — мог добавить IP в наблюдение.
3. ПРАВИЛА ДЛЯ НАС:
   - Никаких прокси/антидетекта на основной аккаунт — бизнес-профиль с тарифом,
     один бан = потеря всего (отзывы, рейтинг, история с 2012).
   - Весь автоматический браузерный доступ — только с домашнего IP, никогда VPN.
   - Минимизировать Automation-след: дождаться items-API (заявка в поддержку),
     скрейпинг-марафоны не делать, прогоны разнести по времени и częстоте.
   - VPN на этой машине — никогда при открытой сессии Авито.

## 16. Топ и рекомендации 2026 — системный разбор (ресёрч 30.10)

### Как попадают в рекомендации (vc.ru, 2026)
Алгоритм даёт дополнительный трафик карточкам с лучшим **комплексным score**:

   конверсия в контакт выше средней по категории, добавления в избранное.
3. **Продавец**: рейтинг, уровень сервиса, оптимальное время публикации, платное
   продвижение как плюс в конкурентных нишах.

### Конкретные рычаги для нас (по приоритету)
1. **ВИДЕО — до +80% конверсии из просмотра в покупку** (блог Авито). У нас видео

2. **Инфографика на обложках** — плашки «Гарантия 5 лет / От завода / Замер
   бесплатно» на складских фото. Генерируется скриптом (PIL), легально и системно
   решает CTR.
3. **Отзывы и вопросы** — в API есть отзывы + ответы; мониторить вопросы под
   объявлениями (раздел «Вопросы») и отвечать ≤1 часа.
4. **Статистика запросов Авито** — частотники в заголовки при следующих правках.
5. **Мотивация в описаниях** — «напишите размеры — расчёт за 10 минут» уже есть;

## 17. Платное продвижение: реальные ставки аукциона (ресёрч 30.10)

### Как устроен аукцион позиций (на примере чемпиона 2701428520)
Страница «Настроить цену просмотра» (кнопка «Поднять просмотры» на карточке):
- **8 ₽/просмотр → топ-40 поиска**
- **35 ₽/просмотр → топ-30**
- **86 ₽/просмотр → топ-20**
- Режимы: «Автоматически» (алгоритм сам) / «Вручную» (своя ставка)
- + «Сколько тратить в день» (лимит) и «Где показывать»

### Экономика для нас (конверсия 4,1%, CPL базовый 224 ₽)
| Ставка | Позиция | CPL (если конверсия держится) |
|---|---|---|
| 8 ₽ | топ-40 | ~195 ₽ |
| 35 ₽ | топ-30 | ~850 ₽ |
| 86 ₽ | топ-20 | ~2100 ₽ |

Вывод: **топ-30 окупается только для карточек-чемпионов** (конверсия выше средней,
чек окна 25к+ — сделка отбивает даже 850₽/контакт при марже от 7 500). Топ-20 —
только для остекления коттеджей (чек от 100к).

### Услуги поверх (для Товаров с пакетами)
- x2/x5/x10 «Больше просмотров» — множители позиции (x2/x5 при низкой конкуренции,
  x5/x10 при высокой)
- XL-объявление + выделение цветом — размер карточки в выдаче + голубая цена
  (работают в паре, до 3000₽)
- «Продвижение с прогнозом» — фиксированные гарантированные просмотры

### Правила применения (из гайдов + наша практика)
1. Продвижение усиливает карточку, не заменяет её: сначала контент (фото/текст/видео),
   потом деньги (sostav.ru: «сначала качество, потом платное»).
2. Запускать утром/днём в пик спроса категории.
3. Тестировать на 1-2 карточках 3 дня, мерить CPL до/после; раскатывать только
   при CPL ≤ 450₽ (окна) / ≤900₽ (дома).
4. Не править карточку после включения продвижения (правки снимают эффект).
5. Метрики: Авито Перформанс / воронка показы→просмотр→контакт в кабинете.

## 18. АНАЛИЗ АУДИТОРИИ И СПРОСА (30.10, по 116 живым сообщениям клиентов)

### Как клиенты пишут (паттерн)
Приходят С РАЗМЕРАМИ и хотят цену сразу: «110х120 поворотно-откидное — какая цена?»,
«проём 700×2100, открывание наружное», «окно 2.80 шириной 2.40, 2 стекла».
Топ-слова спроса: размеры (18), ширина/высота (13), цена (7), стеклопакет (7),
в наличии (запрос «есть ли готовые изделия?»), витражные окна (запрос!).

### Выводы для карточек
1. **«В наличии» в заголовок** складских позиций — клиенты спрашивают готовое.
2. **Размеры в описании** — таблица популярных размеров с ценами «от» снимает
   80% вопросов ещё до чата (Татьяна не называет цены по правилам, а клиенты
   приходят именно за ценой по размеру — из-за этого часть лидов уходит молча).
3. **Витражные окна** — был прямой запрос, карточки нет. Кандидат на новую позицию.
4. **Дверь Veka Euroline 880×2080** — 13 клиентских сообщений, спрос горячий,
   а карточка не опубликована (ошибка Терморазрыв). Починить срочно.

расчётный отдел подготовит за 10 минут, либо приезжайте на склад: готовые
изделия в наличии.» (меньше ступеней до расчёта)
