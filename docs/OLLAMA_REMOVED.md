# Удаление Ollama из чата

**Дата:** 26.01.2026  
**Изменение:** Ollama полностью удален из логики чата, используется только Victoria + MLX

---

## ✅ Что изменилось

### Раньше:

1. Victoria (если доступна)
2. MLX API Server (fallback)
3. Ollama (fallback)

### Теперь:

1. **Victoria** (приоритет) ✅
2. **MLX API Server** (fallback если Victoria недоступна) ✅
3. Ollama **удален** ❌

---

## 🔧 Изменения в коде

### 1. `backend/app/routers/chat.py`

**Убрано:**

- Параметр `ollama: OllamaClient` из `sse_generator()`
- Параметр `ollama: OllamaClient` из `stream_message()`
- Вся логика fallback на Ollama
- Функция `_get_available_model()` больше не используется (оставлена для совместимости)

**Изменено:**

- Логика роутинга: только Victoria → MLX
- Эндпоинт `/status`: возвращает статус Victoria и MLX (вместо Ollama)
- Эндпоинт `/models`: возвращает список моделей MLX (вместо Ollama)

---

## 📊 Новая логика роутинга

### Если `use_victoria=True` (по умолчанию):

1. **Victoria Agent** (порт 8010)
   - Основной сервис для сложных задач
   - Используется по умолчанию

2. **MLX API Server** (fallback, порт 11435)
   - Используется только если Victoria недоступна
   - Предзагруженные модели готовы к использованию

### Если `use_victoria=False`:

1. **MLX API Server** (прямое использование)
   - Используется напрямую без Victoria
   - Если недоступен - показывается сообщение об ошибке

---

## 🎯 Преимущества

1. **Простота:**
   - Меньше зависимостей
   - Проще логика роутинга
   - Легче отладка

2. **Фокус на Victoria:**
   - Victoria - основной сервис
   - MLX только как резерв
   - Нет конфликтов между Ollama и Victoria

3. **Производительность:**
   - Меньше проверок доступности
   - Быстрее выбор сервиса
   - Меньше сетевых запросов

---

## 📝 Оставшиеся упоминания Ollama

Некоторые функции и импорты остались для совместимости:

- `_get_available_model()` - не используется, но оставлена
- Импорт `OllamaClient` - может использоваться в других эндпоинтах

Эти можно удалить позже, если не используются.
