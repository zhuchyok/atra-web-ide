# 📘 Инструкция: Интеграция диалогов экспертов ATRA во внешние приложения (OpenCode и др.)

Эта инструкция объясняет, как заставить любое приложение, поддерживающее OpenAI API (например, OpenCode, TypingMind, Chatbox), выводить «живые» обсуждения команды экспертов ATRA.

## 1. Принцип работы
Система использует **Victoria Proxy** — специальный слой, который перехватывает стандартные запросы и превращает их в многоагентные дискуссии.

*   **Вход:** Обычный вопрос пользователя.
*   **Обработка:** Прокси запускает `TeamDiscussionEngine`, который выбирает подходящих экспертов и имитирует их диалог.
*   **Выход:** Текст в формате Markdown, где реплики экспертов разделены жирными заголовками и эмодзи.

---

## 2. Настройка в OpenCode

Для подключения «Роя» к OpenCode выполните следующие шаги:

1.  **Откройте настройки провайдера (Provider Settings):**
    *   Выберите тип: `OpenAI` или `Custom`.
2.  **Укажите Base URL:**
    *   Вместо `https://api.openai.com/v1` введите:
        `http://<IP_ВАШЕГО_MAC_STUDIO>:8040/v1`
    *   *Примечание: Порт 8040 — это стандартный порт нашего прокси.*
3.  **API Key:**
    *   Введите любую строку (например, `sk-atra-swarm`). Прокси проигнорирует ключ, если не настроена жесткая авторизация.
4.  **Модель (Model ID):**
    *   Введите `victoria` или `discuss`. Эти ключевые слова триггерят режим диалога.

---

## 3. Как это выглядит в коде (для разработчиков)

Если вы пишете свою программу, вы можете получить диалог, отправив POST запрос:

```bash
curl http://localhost:8040/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "discuss",
    "messages": [{"role": "user", "content": "Как оптимизировать базу данных?"}]
  }'
```

### Внутренняя логика формирования:
За вывод диалогов отвечает класс `TeamDiscussionEngine` в `knowledge_os/app/ai_core.py`. Он использует шаблоны из `docs/TEAM_PERSONALITIES.md` для придания экспертам характера.

---

## 4. Поддержка стриминга (Streaming)
Для максимального эффекта «живого общения» убедитесь, что в вашем приложении включена опция **Stream**. 
Victoria Proxy поддерживает Server-Sent Events (SSE), поэтому реплики Игоря, Сергея и Анны будут появляться на экране постепенно, создавая ощущение реального чата.

---

## 5. Устранение неполадок
*   **Прокси не отвечает:** Проверьте, запущен ли контейнер `victoria-proxy` в Docker (`docker ps`).
*   **Обычный ответ вместо диалога:** Убедитесь, что в поле "Model" указано именно `discuss` или `victoria`.
*   **Текст некрасивый:** Проверьте, включена ли поддержка Markdown в настройках вашего чат-клиента.
