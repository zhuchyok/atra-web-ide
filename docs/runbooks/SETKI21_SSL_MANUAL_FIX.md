# Runbook: Быстрое исправление SSL для существующего домена

**Домен:** сеткимоскитки.рф (Punycode: xn--e1agaahbbnszfhh.xn--p1ai)  
**Проблема:** Домен создан в NPM, но без SSL-сертификата → браузер не открывает сайт  
**Время исправления:** 2-3 минуты

---

## Шаг 1: Открыть NPM

```
http://45.10.43.248:81
```

Логин: `zhuchyok@icloud.com`  
Пароль: `Bik6007OS`

## Шаг 2: Найти Proxy Host

1. Перейти в **Proxy Hosts**
2. Найти хост с доменом: `xn--e1agaahbbnszfhh.xn--p1ai` или `www.xn--e1agaahbbnszfhh.xn--p1ai`
3. Нажать на три точки → **Edit**

---

## Шаг 3: Настроить SSL

1. Перейти на вкладку **SSL**
2. В выпадающем списке **SSL Certificate** выбрать:
   - Если есть сертификат для этого домена → выбрать его
   - Если нет → выбрать **Request a new SSL Certificate**
3. Настройки SSL:
   - ✅ **Force SSL** (включить)
   - ✅ **HTTP/2 Support** (включить)
   - ✅ **HSTS Enabled** (включить)
   - ✅ **HSTS Subdomains** (включить)
4. Если выбрали "Request a new":
   - Email: `zhuchyok@icloud.com`
   - ✅ Согласиться с условиями Let's Encrypt
5. Нажать **Save**

---

## Шаг 4: Дождаться получения сертификата

NPM автоматически:

1. Проверит DNS (домен должен указывать на 45.10.43.248)
2. Создаст временный challenge-файл
3. Запросит сертификат у Let's Encrypt
4. Установит сертификат

**Время:** 10-30 секунд.

Если ошибка → проверить:

- DNS: `dig +short xn--e1agaahbbnszfhh.xn--p1ai` должен вернуть `45.10.43.248`
- Порты 80 и 443 открыты на VDS
- Домен не заблокирован у регистратора

## Если не работает

### Проблема: "DNS resolution error"

**Причина:** DNS ещё не обновился или домен указывает на другой IP.

**Решение:**

```bash
dig +short xn--e1agaahbbnszfhh.xn--p1ai
```

Должно быть: `45.10.43.248`. Если нет → обновить A-запись у регистратора.

### Проблема: "Too many certificates already issued"

**Причина:** Лимит Let's Encrypt (5 сертификатов на домен в неделю).

**Решение:** Подождать неделю или использовать существующий сертификат из списка NPM.

### Проблема: "Connection timed out"

**Причина:** Порт 80 или 443 закрыт фаерволом.

**Решение:**

```bash
ssh root@45.10.43.248 "ufw status"
```

Должны быть открыты:

- `80/tcp ALLOW`
- `443/tcp ALLOW`

Если закрыты:

```bash
ssh root@45.10.43.248 "ufw allow 80/tcp && ufw allow 443/tcp"
```
