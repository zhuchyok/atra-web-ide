Вариант **без одобрения API**: агент (Victoria/Veronica) заходит в кабинет Яндекс.Директа через браузер, один раз логинится — дальше сессия сохраняется в постоянном профиле.

## Где передать логин и пароль (Директ)

**Рекомендуется: не передавать пароль Виктории.** Сделай один раз вход сам в браузере агента:

1. Задай **BROWSER_USER_DATA_DIR** и **BROWSER_USE_HEADLESS=false** в среде, где запущена Victoria (Docker или хост).
2. Дай Виктории задачу «открой https://direct.yandex.ru» (через control_browser). Откроется окно браузера.
3. В этом окне **вручную** введи логин и пароль от Директа и войди. Сессия сохранится в профиле.
4. Дальше можно включать **BROWSER_USE_HEADLESS=true** — Виктория будет заходить в Директ уже авторизованной, пароль ей не нужен.

Так пароль не попадает в чат, логи и код.

**Если нужно передать креды программно (не рекомендуется):** положи логин и пароль в файл **вне репозитория**, например `~/.config/atra/direct_browser.env`:

```bash
DIRECT_LOGIN=твой_логин
DIRECT_PASSWORD=твой_пароль
```

Добавь этот путь в `.gitignore`. В задаче Виктории напиши: «при входе на direct.yandex.ru используй логин и пароль из файла ~/.config/atra/direct_browser.env». Тогда агент сможет прочитать файл и подставить данные в форму — но пароль будет храниться на диске в открытом виде; надёжнее один раз залогиниться вручную в браузере (абзац выше).

## 1. Постоянный профиль браузера (один раз)

Чтобы не логиниться при каждом запуске:

- В среде, где крутится Victoria/Veronica (Docker или хост), задай:
  - **BROWSER_USER_DATA_DIR** — каталог для профиля (куки, логин). Например: `./data/browser_profile` или `/app/data/browser_profile`.
  - **BROWSER_USE_HEADLESS=false** — для первого входа браузер должен быть видимым (логин в Директ).
- Один раз запусти задачу «зайти в direct.yandex.ru», **залогинься в кабинет в открывшемся окне** (см. раздел «Где передать логин и пароль» выше). После этого сессия сохранится в `BROWSER_USER_DATA_DIR`.
- Дальше можно ставить **BROWSER_USE_HEADLESS=true** и агент будет заходить в Директ уже авторизованным.

Код: `knowledge_os/app/browser_operator.py` (поддержка `BROWSER_USER_DATA_DIR` и создание папки при относительном пути).

## 2. Текст задачи для браузера

Конфиг заголовков и текстов: **configs/setki21_direct_ads.yaml**.

Собрать задачу (что именно делать в кабинете):

```bash
# из корня atra-web-ide
python3 scripts/build_setki21_direct_browser_goal.py
```

Записать в файл (например, для передачи агенту):

```bash
python3 scripts/build_setki21_direct_browser_goal.py -o docs/tasks/SETKI21_DIRECT_BROWSER_GOAL.txt
```

## 3. Запуск агентом

Victoria или Veronica выполняют задачу через **control_browser**: передаётся текст задачи и стартовый URL.

- **start_url:** `https://direct.yandex.ru`
- **task:** содержимое из `build_setki21_direct_browser_goal.py` (или из `docs/tasks/SETKI21_DIRECT_BROWSER_GOAL.txt`).

Пример вызова (из кода/оркестратора): вызвать `control_browser(task=<текст задачи>, start_url="https://direct.yandex.ru")`. В чате можно попросить: «Примени конфиг Setki21 в Директе через браузер» — агент должен подставить задачу из конфига и вызвать control_browser.
