### 2. Исправление ошибки с историей сигналов

**Проблема:** В `signal_live.py` неправильная обработка datetime объектов

**Решение:** Нужно исправить функцию `load_signal_history()`:

```python
# В signal_live.py, строка ~1523
def load_signal_history():
    try:
        if os.path.isfile(SIGNAL_HISTORY_FILE):
            with open(SIGNAL_HISTORY_FILE, "rb") as f:
                return pickle.load(f)
    except Exception as e:
        logging.error(f"Ошибка чтения файла истории сигналов: {e}", exc_info=True)
    return {}
```
