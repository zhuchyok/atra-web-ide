# Эталон: «Какой статус проекта?»

**Цель (goal):** «какой статус проекта», «статус проекта», «как дела с проектом», «в работе».

**Эталонный ответ:** любой из вариантов: статус из документации, ссылка на дашборд, упоминание разработки/активной работы. Victoria не обязана называть конкретный дашборд — главное, что ответ осмысленный и относится к статусу.

**Пример:** «Проект в разработке», «Статус: активная разработка», «Смотрите дашборд на порту 8501»

**Критерии:** ответ содержит слова о состоянии проекта (разработк / статус / активн / работ / готов / дашборд).

**Ключевые фразы (одна из них должна быть в ответе):**

- Singularity 31.2
- Кристаллизация
- разработк
- статус
- активн
- работ
- готов
