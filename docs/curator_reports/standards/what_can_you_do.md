# Эталон: «Что ты умеешь?» / «Кто ты?»

**Цель (goal):** запросы вида «что ты умеешь», «что умеешь», «кто ты», «твои возможности», «чем можешь помочь».

**Эталонный ответ:** должен содержать ключевые слова из области помощи, анализа, информации и задач. Точное словарное совпадение не требуется — модель отвечает свободно.

**Ключевые фразы (хотя бы 2 из списка):**

- предоставл / информац / отвеч
- анализ / обработк / вопрос
- задач / помог / помощ / умею
- выполн / создан / работ

**Критерии при проверке:**

- Ответ содержит 2+ ключевых фразы из списка.
- Нет бессмысленного мусора или обрыва.
- Нет лишнего уточняющего вопроса «уточни, что имеешь в виду».
