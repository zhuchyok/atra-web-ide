# Эталон: аудит файлов (pip install / hardcoded secrets)

**Цель (goal):** «проверь файл X — есть ли там pip install в рантайме», «проверь файл X — есть ли там hardcoded секреты или пароли».

**Эталонный ответ:** Victoria должна чётко ответить «ОК» или «ПРОБЛЕМА» + цитата. Допустимы любые формулировки содержащие «ОК» или «ПРОБЛЕМА».

**Пример OK:** «ОК — pip install не обнаружен»
**Пример ПРОБЛЕМА:** «ПРОБЛЕМА: строка 42: subprocess.run(["pip", "install", ...])»

**Критерии:** ответ содержит «ОК» или «ПРОБЛЕМА» (однозначный вердикт).

**Ключевые фразы (одна из них должна быть в ответе):**
- ОК
- ПРОБЛЕМА
- проблем
- не обнаружен
- не найден
