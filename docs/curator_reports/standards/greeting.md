# Эталон: приветствие

**Цель (goal):** «привет», «здравствуй», «добрый день» и т.п.

**Эталонный ответ:** короткое приветствие + предложение помочь. Victoria может использовать любой дружелюбный вариант.

**Пример:** «Привет! Как я могу помочь?» или «Добрый день! Чем могу помочь?»

**Критерии:** ответ содержит приветствие (Привет / Добрый день / Здравствуй) и предложение помощи (помочь / помогу / помощь).

**Ключевые фразы (одна из них должна быть в ответе):**

- Привет
- Добрый день
- помочь
- помогу
