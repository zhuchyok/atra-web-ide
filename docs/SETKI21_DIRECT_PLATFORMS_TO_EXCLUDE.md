## Как исключить в кабинете Директа

**Вариант А — отключить всю РСЯ (жёстко)**  
Кампания → настройки кампании → **Источники трафика** → снять галочку **«Рекламная сеть Яндекса»** (оставить только **«Поиск»**). Объявления не будут показываться ни на одной площадке РСЯ, в том числе на dsp.yandex.ru и dsp-opera-exchange (у них была по 1 конверсии). Плюс: весь бюджет только на поиск. Минус: теряются 2 конверсии с партнёрских площадок.

**Вариант Б — убрать только площадки без конверсий (мягко)**  
Исключить в настройках показов только те площадки, где **0 конверсий**: все игры (tiletrip, mahjong, mytalkingtom2, mytalkingangela2, wordpizza, fugo.wow), game.yandex.ru, dsp-mintagral, dsp-ironsource. **Не трогать:** Яндекс (поиск), dsp.yandex.ru, dsp-opera-exchange.yandex.ru — на них были конверсии. В разделе кампании/группы найти **«Исключения» / «Площадки»** и добавить в список исключений идентификаторы из таблицы «Что убрать» (только строки с 0 конверсий).

**Вариант В — исключить конкретные площадки вручную**  
Добавить в список исключений по одной только те площадки, которые решаешь отключить (например, только игры), оставив DSP на усмотрение.

Итого: если хочешь **«убрать все сайты, где не было конверсии»** — это **Вариант Б**. Если хочешь максимум целевого трафика и не жалко 2 конверсии с РСЯ — **Вариант А**.

## После изменений

Через 1–2 недели снова посмотреть отчёт по площадкам: показы должны быть в основном с Поиска. Конверсии при этом могут вырасти (меньше «пустых» кликов с игр).
