# Self-Dev Pipeline

Процесс разработки выстроен в замкнутый контур, где роль proposer инициирует изменения, а роль патчера реализует их в коде. После внесения правок запускаются автоматические проверки качества и тестирования, чтобы убедиться в отсутствии регрессий. Финальным этапом выступает ревью, которое гарантирует соответствие стандартам проекта перед слиянием изменений в основную ветку.
