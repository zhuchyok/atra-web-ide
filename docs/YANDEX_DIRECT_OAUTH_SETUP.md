# Настройка OAuth для API Яндекс.Директа

Аналогично [YANDEX_WEBMASTER_OAUTH_SETUP.md](YANDEX_WEBMASTER_OAUTH_SETUP.md), но для Директа. Можно использовать **отдельное приложение** в OAuth или добавить доступ Директа к существующему.

## 1. Приложение в OAuth

- [oauth.yandex.ru](https://oauth.yandex.ru/client/new) — создать приложение или открыть существующее.
- **Название** — например: `Atra Direct Export`.
- **Доступ к данным:** добавить доступ к **Яндекс.Директ** → «Использование API Яндекс.Директа» (в интерфейсе может называться «Яндекс.Директ» или «direct»).
- **Redirect URI:** оставь `https://oauth.yandex.ru/verification_code` для получения кода.
- ### Обязательно: заявка на доступ к API

Ошибка **58 «Незавершенная регистрация»** значит, что приложение ещё не допущено к API Директа. Нужно подать заявку:

1. Зайди в кабинет **Яндекс.Директа** (direct.yandex.ru) под тем логином, с которым будешь получать токен.
2. В интерфейсе Директа: **Настройки** (шестерёнка) → **Настройки API** → вкладка **«Мои заявки»**.
3. Нажми **«Новая заявка»**, выбери тип доступа (**Тестовый** или **Полный**).
4. Укажи **Client ID** твоего приложения из [oauth.yandex.ru](https://oauth.yandex.ru) (тот же, что вводишь в setup_yandex_direct_env.py).
5. Отправь заявку и дождись одобрения (обычно до 7 рабочих дней).

После одобрения скрипт `export_yandex_direct.py` начнёт работать. См. [документацию](https://yandex.ru/dev/direct/doc/ru/concepts/register).

## 2. Токен под логином Директа

При получении кода/токена **входить нужно под тем аккаунтом**, с которым заходишь в кабинет Яндекс.Директа (у тебя он «другой», чем для Вебмастера).

## 3. Скрипты в репозитории

| Скрипт                                          | Назначение                                                                                                      |
| ----------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| `python3 scripts/setup_yandex_direct_env.py`    | Ввести Client ID, Client secret, код или токен → запись в `.env.direct`                                         |
| `python3 scripts/export_yandex_direct.py`       | Выгрузка кампаний, групп, ключевых слов, объявлений в `docs/direct_export/`                                     |
| `python3 scripts/apply_yandex_direct_config.py` | Применить заголовки и тексты из `configs/setki21_direct_ads.yaml` к объявлениям (требует одобренную заявку API) |

Файл `.env.direct` в `.gitignore`, не коммитить. Для apply-скрипта нужен PyYAML: `pip install pyyaml`.

## 4. Что выгружается

- `campaigns.json` — список кампаний (Id, Name, State, Status, Type, StatusPayment).
- `adgroups.json` — группы объявлений по всем кампаниям.
- `keywords.json` — ключевые слова (до 500 групп).
- `ads.json` — объявления по тем же группам.

Статистику (клики, расход, показы) можно добавить через сервис [Reports](https://yandex.ru/dev/direct/doc/reports/reports.html) — запрос отчёта в формате JSON, ответ в TSV.
